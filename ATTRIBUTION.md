# Upstream Attribution and Project Independence

Charterforge originated as a fork and derivative of
[Hermes Agent](https://github.com/NousResearch/hermes-agent).
Hermes Agent, Nous Research, and the Hermes Agent contributors provided the
original software foundation.

Charterforge is independently developed. It is not an official Hermes Agent
distribution, and the upstream maintainers do not necessarily endorse it.
Charterforge-specific changes are not expected to be submitted to the upstream
Hermes Agent repository.

The rebrand does not remove or replace upstream licensing obligations. The
original MIT license, including its Nous Research copyright notice, remains in
[LICENSE](LICENSE). Existing copyright, attribution, and third-party notices
must be preserved when the software is redistributed.

The repository has not yet completed a dependency-by-dependency legal review.
Where a dependency or bundled asset imposes notices beyond the root MIT
license, its own license and notice files remain authoritative. This document
does not offer a legal conclusion about trademarks, corporate formation,
regulated activity, or the licenses of separately installed integrations.

Canonical upstream was determined from all of the following:

- Git remote `upstream`: `git@github.com:NousResearch/hermes-agent.git`
- the root MIT license copyright notice
- the pre-fork README and package metadata
- repository history before the independent Charterforge commits
