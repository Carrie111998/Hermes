## Observed defect

The Telegram adapter emitted `inbound accepted` with an opaque
`telegram_delivery_correlation_id`, but the ordinary streaming response path
constructed metadata from `SessionSource` only. `GatewayStreamConsumer` then
sent the visible response without the correlation id, so the Telegram
adapter's metadata-only outbound audit intentionally no-op'd. A real user
response was visible, but the runtime correlation record was missing.

## Correction

Changed `gateway/run.py`:

- Added `GatewayRunner._thread_metadata_for_event(event, reply_to_message_id)`.
- It starts with the existing runner-owned thread/topic metadata and copies
  only the opaque Telegram correlation id/list from `event.metadata`.
- Normal agent tool-progress metadata and stream status metadata now use the
  event-aware helper, preserving topic/reply routing while carrying audit
  correlation.
- No message content, credential, token, raw chat id, or user identity is
  added to metadata.

Changed `tests/gateway/test_telegram_delivery_audit.py`:

- Added a regression test proving GatewayRunner stream metadata preserves the
  single and batched opaque correlation ids while retaining thread metadata.

## Reviewable metadata-only diff excerpt

The following is the exact behavior-changing excerpt. It contains no Telegram
message body, credential, token, raw chat/user identifier, or runtime path:

```python
def _thread_metadata_for_event(
    self,
    event: MessageEvent,
    reply_to_message_id: Optional[str] = None,
) -> Optional[Dict[str, Any]]:
    metadata = self._thread_metadata_for_source(
        event.source,
        reply_to_message_id,
    )
    event_metadata = getattr(event, "metadata", None)
    correlation_id = (
        event_metadata.get("telegram_delivery_correlation_id")
        if isinstance(event_metadata, dict)
        else None
    )
    if correlation_id:
        metadata = dict(metadata) if metadata else {}
        metadata["telegram_delivery_correlation_id"] = str(correlation_id)
        correlation_ids = event_metadata.get("telegram_delivery_correlation_ids")
        if isinstance(correlation_ids, (list, tuple)):
            metadata["telegram_delivery_correlation_ids"] = [
                str(value) for value in correlation_ids if value
            ]
    return metadata
```

The ordinary agent path now calls this helper for both progress metadata and
stream status metadata; when progress resolves to a different thread, it
overrides only `thread_id` after the helper returns. The regression assertion
requires the original thread metadata plus both opaque correlation-id forms,
and verifies the existing source-metadata helper receives the original source
and reply anchor.
