# Ссылки на контекст

Введите `@`, а затем ссылку, чтобы добавить контент непосредственно в ваше сообщение. Hermes расширяет встроенную ссылку и добавляет содержимое в раздел `--- Attached Context ---`.

## Поддерживаемые ссылки

| Синтаксис | Описание |
|--------|-------------|
| `@file:path/to/file.py` | Внедрить содержимое файла |
| `@file:path/to/file.py:10-25` | Внедрить определенный диапазон строк (с индексом 1 включительно) |
| `@folder:path/to/dir` | Внедрить список дерева каталогов с метаданными файла |
| `@diff` | Внедрить `git diff` (непроиндексированные изменения рабочего дерева) |
| `@staged` | Внедрить `git diff --staged` (поэтапные изменения) |
| `@git:5` | Внедрить последние N коммитов с исправлениями (максимум 10) |
| `@url:https://example.com` | Извлечение и внедрение содержимого веб-страницы |

## Примеры использования

```text
Review @file:src/main.py and suggest improvements

What changed? @diff

Compare @file:old_config.yaml and @file:new_config.yaml

What's in @folder:src/components?

Summarize this article @url:https://arxiv.org/abs/2301.00001
```

В одном сообщении работают несколько ссылок:

```text
Check @file:main.py, and also @file:test.py.
```

Завершающие знаки препинания (`,`, `.`, `;`, `!`, `?`) автоматически удаляются из ссылочных значений.

## Завершение вкладки CLI

В интерактивном интерфейсе командной строки ввод `@` запускает автозаполнение:

- `@` показывает все типы ссылок (`@diff`, `@staged`, `@file:`, `@folder:`, `@git:`, `@url:`).
- `@file:` и `@folder:` запускают завершение пути к файловой системе с метаданными о размере файла.
- Пустой символ `@`, за которым следует частичный текст, показывает соответствующие файлы и папки из текущего каталога.

## Диапазоны строк

Ссылка `@file:` поддерживает диапазоны строк для точного внедрения контента:

```text
@file:src/main.py:42        # Single line 42
@file:src/main.py:10-25     # Lines 10 through 25 (inclusive)
```

Строки имеют 1-индекс. Недопустимые диапазоны игнорируются (возвращается полный файл).

## Ограничения размера

Ссылки на контекст ограничены, чтобы предотвратить перегрузку контекстного окна модели:

| Порог | Значение | Поведение |
|-----------|-------|----------|
| Мягкий лимит | 25% длины контекста | Предупреждение добавлено, расширение продолжается |
| Жесткий лимит | 50% длины контекста | В расширении отказано, исходное сообщение возвращается без изменений |
| Записи в папке | максимум 200 файлов | Лишние записи заменены на `- ...` |
| Git совершает | 10 макс | `@git:N` ограничен диапазоном [1, 10] |

## Безопасность

### Блокировка чувствительного пути

Эти пути всегда блокируются для ссылок `@file:`, чтобы предотвратить раскрытие учетных данных:

- Ключи и конфигурация SSH: `~/.ssh/id_rsa`, `~/.ssh/id_ed25519`, `~/.ssh/authorized_keys`, `~/.ssh/config`.
- Профили оболочки: `~/.bashrc`, `~/.zshrc`, `~/.profile`, `~/.bash_profile`, `~/.zprofile`.
- Файлы учетных данных: `~/.netrc`, `~/.pgpass`, `~/.npmrc`, `~/.pypirc`.
- Окружение Гермеса: `$HERMES_HOME/.env`

Эти каталоги полностью заблокированы (любой файл внутри):
- `~/.ssh/`, `~/.aws/`, `~/.gnupg/`, `~/.kube/`, `$HERMES_HOME/skills/.hub/`

### Защита от обхода пути

Все пути разрешаются относительно рабочего каталога. Ссылки, которые разрешаются за пределами разрешенного корня рабочей области, отклоняются.

### Обнаружение двоичных файлов

Двоичные файлы обнаруживаются с помощью типа MIME и сканирования нулевых байтов. Известные текстовые расширения (`.py`, `.md`, `.json`, `.yaml`, `.toml`, `.js`, `.ts` и т. д.) обходят обнаружение на основе MIME. Двоичные файлы отклоняются с предупреждением.

## Доступность платформы

Контекстные ссылки — это, прежде всего, **функция CLI**. Они работают в интерактивном интерфейсе командной строки, где `@` запускает заполнение табуляции, а ссылки расширяются перед отправкой сообщения агенту.

В **платформах обмена сообщениями** (Telegram, Discord и т. д.) синтаксис `@` не расширяется шлюзом — сообщения передаются как есть. Сам агент по-прежнему может ссылаться на файлы с помощью инструментов `read_file`, `search_files` и `web_extract`.

## Взаимодействие со сжатием контекста

Когда контекст разговора сжимается, расширенное справочное содержимое включается в сводку сжатия. Это означает:

- Содержимое большого файла, внедренное через `@file:`, способствует использованию контекста.
- Если разговор позже сжимается, содержимое файла суммируется (не сохраняется дословно)
– Для очень больших файлов рассмотрите возможность использования диапазонов строк (`@file:main.py:100-200`), чтобы вставлять только соответствующие разделы.

## Общие шаблоны

```text
# Code review workflow
Review @diff and check for security issues

# Debug with context
This test is failing. Here's the test @file:tests/test_auth.py
and the implementation @file:src/auth.py:50-80

# Project exploration
What does this project do? @folder:src @file:README.md

# Research
Compare the approaches in @url:https://arxiv.org/abs/2301.00001
and @url:https://arxiv.org/abs/2301.00002
```

## Обработка ошибок

Недопустимые ссылки вызывают встроенные предупреждения, а не сбои:

| Состояние | Поведение |
|-----------|----------|
| Файл не найден | Предупреждение: «файл не найден» |
| Бинарный файл | Внимание: «двоичные файлы не поддерживаются» |
| Папка не найдена | Предупреждение: «папка не найдена» |
| Команда Git не работает | Предупреждение с помощью git stderr |
| URL-адрес не возвращает содержимого | Предупреждение: «Содержимое не извлечено» |
| Чувствительный путь | Предупреждение: «путь является конфиденциальным файлом учетных данных» |
| Путь за пределами рабочей области | Предупреждение: «путь находится за пределами разрешенной рабочей области» |
