# Генерация изображения

Агент Hermes генерирует изображения из текстовых подсказок через FAL.ai. «Из коробки» поддерживаются одиннадцать моделей, каждая из которых имеет разное соотношение скорости, качества и стоимости. Активная модель настраивается пользователем через `hermes tools` и сохраняется в `config.yaml`.

|---|---|---|---|

## Настройка

:::tip Подписчики
Если у вас есть платная подписка на [Nous Portal](https://portal.nousresearch.com), вы можете использовать генерацию изображений через **[Tool Gateway](tool-gateway.md)** без ключа FAL API. Выбор модели сохраняется в обоих случаях. Новые установки могут запускать `hermes setup --portal` для входа в систему и одновременного включения всех инструментов шлюза; существующие установки могут выбрать **Nous Subscription** в качестве бэкэнда для создания изображений через `hermes tools`.

Если управляемый шлюз возвращает `HTTP 4xx` для конкретной модели, эта модель еще не проксирована на стороне портала — агент сообщит вам об этом с инструкциями по исправлению (переключитесь на FAL.ai в `hermes tools` со своим собственным `FAL_KEY` для прямого доступа или выберите другую модель).
:::

### Получите ключ API FAL

1. Зарегистрируйтесь на [fal.ai](https://fal.ai/)
2. Создайте ключ API на своей панели управления.

### Настройте и выберите модель

Запустите команду инструментов:

```bash
hermes tools
```

Перейдите к **🎨 Генерация изображений**, выберите серверную часть (Nous Subscription или FAL.ai), затем средство выбора отобразит все поддерживаемые модели в таблице с выравниванием по столбцам — клавиши со стрелками для навигации, Enter для выбора:

```
  Model                          Speed    Strengths                    Price
  fal-ai/flux-2/klein/9b         <1s      Fast, crisp text             $0.006/MP   ← currently in use
  fal-ai/flux-2-pro              ~6s      Studio photorealism          $0.03/MP
  fal-ai/z-image/turbo           ~2s      Bilingual EN/CN, 6B          $0.005/MP
  ...
```

Ваш выбор сохранен в `config.yaml`:

```yaml
image_gen:
  provider: fal                 # `nous` if you picked Nous Subscription
  model: fal-ai/flux-2/klein/9b
  max_parallel_requests: 4      # concurrent images in one tool-call batch
```

`image_gen.provider` — это единый ключ выбора: `nous` маршрутизируется через управляемый шлюз инструментов; имя поставщика (`fal`, `openai`, `xai`, `krea`, ...) напрямую связано с вашим собственным ключом. Среда выполнения всегда следует этому сохраненному выбору: `FAL_KEY` в `.env` игнорируется, а `provider: nous` и `provider: fal` без ошибок `FAL_KEY` с `image_gen is configured to use fal (set via hermes tools), but FAL_KEY is not set. Run 'hermes tools' to change it.` вместо автоматического перенаправления. Меняйте поставщиков через `hermes tools`, а не путем добавления/удаления ключей. (Старое логическое значение `use_gateway` является устаревшим — оно по-прежнему читается как `nous` при `true`, но больше никогда не записывается.)

`max_parallel_requests` по умолчанию — `4`. Гермес зажимает его хотя бы на один и
к глобальному пределу рабочего инструмента, поэтому поставщики изображений получают ограниченные параллельные
запросы, не позволяя пакету изображений обойти ограничение параллелизма агента.

### OpenRouter: полный каталог API изображений

При использовании `image_gen.provider: openrouter` средство выбора модели перечисляет OpenRouter.
весь каталог живых изображений — специальный
[API изображения](https://openrouter.ai/docs/guides/overview/multimodal/image-generation)
модели (Seedream, FLUX.2, Recraft, Qwen Image, MAI, Krea, Riverflow, Grok
Представьте себе, и еще — 40+ идентификаторов), объединенных с моделями изображений завершений чата.
Каталог загружается в реальном времени с `GET /images/models` и `GET /models`, поэтому
новые модели появляются в сборщике, как только OpenRouter их обслуживает; нет Гермеса
необходимо обновление. Генерация направляет каждую модель на поверхность, которая ее обслуживает.
(специально `POST /images/generations` вместо дополнений в чате) автоматически.
Nous Portal проксирует только протокол завершения чата, поэтому его средство выбора предлагает
модели, обслуживаемые в чате.

Дополнительные ручки для каждого запроса для моделей Image API находятся в конфигурации с ограниченной областью действия.
раздел (или переменные окружения `OPENROUTER_IMAGE_API_*`):

```yaml
image_gen:
  provider: openrouter
  model: bytedance-seed/seedream-4.5
  openrouter:
    resolution: 2K        # model-dependent: 1K / 2K / 4K
    quality: high         # gpt-image models
    output_format: png
```

### Качество изображения GPT

Качество запроса `fal-ai/gpt-image-1.5` и `fal-ai/gpt-image-2` привязано к `medium` (~0,034–0,06 доллара США за изображение при разрешении 1024×1024). Мы не предоставляем уровни `low` / `high` в качестве опции, ориентированной на пользователя, чтобы выставление счетов Nous Portal оставалось предсказуемым для всех пользователей — разброс затрат между уровнями составляет 3–22×. Если вам нужен более дешевый вариант, выберите Klein 9B или Z-Image Turbo; если вы хотите более высокое качество, используйте Nano Banana Pro или Recraft V4 Pro.

## Изображение в изображение/редактирование

Тот же инструмент `image_generate` также **редактирует существующие изображения**, когда активен
модель поддерживает это — передайте исходное изображение и бэкэнд-маршруты для его редактирования
конечная точка автоматически (отражает то, как `video_generate` обрабатывает преобразование изображения в видео).
Опустите исходное изображение, и оно будет преобразовано в обычный текст.

```
Take this photo and make it a rainy Tokyo street at night → <image>
```

```
Blend these two product shots into one hero image → <image1> <image2>
```

Два входа управляют редактированием:

- **`image_url`** — изображение основного источника для редактирования/преобразования (общедоступный URL-адрес или локальный путь).
- **`reference_image_urls`** — дополнительные ссылки на стиль/композицию (ограничено для каждой модели).

### Какие бэкэнды поддерживают редактирование

| Бэкэнд | Изображение к изображению | Справочная крышка | Как |
|---|---|---|---|
| **FAL.ai** (модели с возможностью редактирования ниже) | ✓ | до 9 | маршруты к конечной точке модели `/edit` |
| **OpenAI** (`gpt-image-2`) | ✓ | до 16 | `images.edit()` |
| **xAI** (Грок Вообразите) | ✓ | 1 | `/v1/images/edits` (`grok-imagine-image-quality`) |
| **Крея** (`Krea 2`) | ✓ | до 10 | генерация по ссылкам (`image_style_references`) |
| **OpenAI (авторизация Кодекса)** | ✓ | до 16 | Инструмент Codex Responses `image_generation` с частями содержимого `input_image` |
| **OpenRouter** (модели API изображений) | ✓ | до 14–16 лет (на модель) | `input_references` `POST /images/generations`; модели, обслуживаемые в чате, используют `image_url` частей контента (до 3) |

Модели FAL с конечной точкой редактирования: `flux-2/klein/9b`, `flux-2-pro`,
`nano-banana-pro`, `gpt-image-1.5`, `gpt-image-2`, `ideogram/v3` и
`qwen-image`. Модели FAL с чистым преобразованием текста в изображение (`z-image/turbo`, `recraft`,
`krea/*`) отклонить ввод изображения с явной ошибкой, указывающей на
модель с возможностью редактирования.

:::Примечание: OpenAI (аутентификация Кодекса) — лучший вариант

На поверхности Кодекса (`chatgpt.com/backend-api/codex`) находится `image_generation`.
как инструмент, который может вызвать модель чата, и Гермес не может вызвать вызов —
серверная часть отклоняет каждую форму `tool_choice` для размещенных инструментов, поэтому запрос
полагается на инструкции по управлению моделью. Когда основная модель отказывается
вызвать инструмент, вызов завершается с ошибкой `empty_response`. Является ли хостинг
Инструмент изображения вообще доступен, также сообщается, что он варьируется в зависимости от
счета. Если вам нужно, чтобы генерация изображений работала детерминированно, настройте
вместо этого используйте серверную часть **OpenAI** (ключ API), **FAL** или **xAI**.

:::

Возможность редактирования активной модели представлена в описании инструмента по адресу
во время выполнения, поэтому агент знает, будет ли `image_url` обработан до этого.
вызывает инструмент.

## Соотношения сторон

Каждая модель принимает одни и те же три соотношения сторон с точки зрения агента. Внутренняя спецификация размера каждой модели заполняется автоматически:

| Ввод агента | image_size (flux/z-image/qwen/recraft/ideogram) | аспектное соотношение (нано-банан-про) | размер_изображения (gpt-image-1.5) | размер_изображения (gpt-изображение-2) |
|---|---|---|---|---|
| `landscape` | `landscape_16_9` | `16:9` | `1536x1024` | `landscape_4_3` (1024×768) |
| `square` | `square_hd` | `1:1` | `1024x1024` | `square_hd` (1024×1024) |
| `portrait` | `portrait_16_9` | `9:16` | `1024x1536` | `portrait_4_3` (768×1024) |

Изображение GPT 2 сопоставляется с предустановками 4:3, а не 16:9, поскольку его минимальное количество пикселей составляет 655 360 — предустановка `landscape_16_9` (1024×576 = 589 824) будет отклонена.

Этот перевод происходит в `_build_fal_payload()` — коду агента никогда не нужно знать о различиях в схеме каждой модели.

## Апскейлинг

### Только по согласию

По умолчанию модель не масштабируется. Современные имиджевые модели излучают лучшее качество
изначально, а доступные средства масштабирования являются *творческими* усилителями (диффузия
проходы), которые могут тонко перерисовывать контент, ухудшая визуализируемый текст, лица и
мелкая деталь. Повышение масштаба выполняется только тогда, когда агент явно запрашивает это.

### Параметр `upscale` (согласие на каждый вызов)

- `upscale: true` — цепочка проходов высокого разрешения после генерации:

| Бэкэнд | Апскейлер |
|---|---|
| **FAL.ai** | Clarity Upscaler (2×, +$0,03/MP) |
| **Крея** | Krea Enhance (2×, потолок до 8K) |
| Другие серверные части | нет апскейлера; родное разрешение вернулось |

- `upscale: false` / опущено — родное разрешение (по умолчанию)

`video_generate` также принимает `upscale: true` на сервере FAL, создавая цепочку
Масштабирование видео **SeedVR2** компании ByteDance (2×, 0,001 долл. США/МП выходного видео) после
поколение.

Когда выполняется проход изображения FAL, он использует следующие настройки:

| Настройка | Значение |
|---|---|
| Высококлассный фактор | 2× |
| Творчество | 0,35 |
| Сходство | 0,6 |
| Шкала руководства | 4 |
| Шаги вывода | 18 |

Если масштабирование не удалось (проблема с сетью, ограничение скорости), исходное изображение возвращается автоматически. В ответе сообщается `upscaled: true/false`, чтобы агент знал, какое разрешение он получил.

## Как это работает внутри

1. **Разрешение модели** — `_resolve_fal_model()` считывает `image_gen.model` из `config.yaml`, возвращается к переменной env `FAL_IMAGE_MODEL`, а затем к `fal-ai/flux-2/klein/9b`.
2. **Построение полезных данных** — `_build_fal_payload()` преобразует ваш `aspect_ratio` в собственный формат модели (предустановленное перечисление, перечисление соотношения сторон или литерал GPT), объединяет параметры модели по умолчанию, применяет любые переопределения вызывающего объекта, а затем фильтрует его в белый список `supports` модели, чтобы неподдерживаемые ключи никогда не отправлялись.
3. **Отправка** — `_submit_fal_request()` направляется через прямые учетные данные FAL или управляемый шлюз Nous в соответствии с сохраненным выбором `image_gen.provider`.
4. **Апскейлинг** — запускается только тогда, когда агент прошел `upscale: true`; По умолчанию в каталоге каждой модели отключено.
5. **Доставка** — URL-адрес конечного изображения, возвращаемый агенту, который генерирует тег `MEDIA:<url>`, который адаптеры платформы преобразуют в собственный носитель.

## Ограничения

- **Требуются учетные данные** для активной серверной части (FAL `FAL_KEY` / Nous Subscription, `OPENAI_API_KEY`, xAI OAuth, `KREA_API_KEY`).
- **Редактирование зависит от модели** — преобразование изображения в изображение работает только на моделях с возможностью редактирования (см. таблицу выше); модели, преобразующие только текст в изображение, отклоняют входные изображения с явной ошибкой
- **Временные URL-адреса** – серверная часть возвращает размещенные URL-адреса, срок действия которых истекает через несколько часов/дней; Hermes материализует их в локальном кеше, поэтому доставка по-прежнему работает после истечения срока действия.
- **Ограничения для каждой модели** — некоторые модели не поддерживают `seed`, `num_inference_steps` и т. д. Фильтр `supports`/`edit_supports` автоматически удаляет неподдерживаемые параметры; это ожидаемое поведение
