# Домашние животные

Гермес может показать анимированного **питомца** — небольшой спрайт-талисман, который реагирует на то, что
агент делает (бездействует, запускает инструмент, думает, завершает, терпит неудачу) по всему
**CLI**, **TUI** и **приложение для ПК**. Домашние животные происходят из публики
Галерея [petdex](https://github.com/crafter-station/petdex).

Домашние животные чисто косметические. Они **не влияют на оперативное кэширование, токены или
поведение агента** — спрайт предназначен только для отображения. Эта функция
**по умолчанию отключено** и неактивно до тех пор, пока вы не установите и не выберете питомца.

## Как это работает

- Домашние животные устанавливаются в каталог `pets/` вашего профиля.
  (`<HERMES_HOME>/pets/<slug>/`), поэтому каждый [профиль](../profiles.md) сохраняет свой
  собственный набор.
- При выборе питомца записываются `display.pet.slug` и `display.pet.enabled` в
  `config.yaml` — ничего не сохраняется как секрет или переменная окружения.
- Каждая поверхность отслеживает активность, которую она уже отслеживает, и сопоставляет ее с одним из шести
  состояния анимации. Отображение хранится в одном месте, поэтому каждая поверхность ведет себя
  то же самое:

  | Агентская деятельность | Состояние питомца |
  | --- | --- |
  | Инструмент/токар только что вышел из строя | `failed` |
  | План выполнен (все дела выполнены) | `jump` (праздновать) |
  | Поворот закончился чисто | `wave` |
  | Инструмент выполняется | `run` |
  | Модель думает/читает | `review` |
  | Сдать в полет (не указано) | `run` |
  | Заблокировано у вас (открыто приглашение уточнить/одобрить) | `waiting` (возврат к `idle` на устаревших 8-строчных листах) |
  | Ничего не происходит | `idle` |

## Рендеринг

В терминале (CLI/TUI) Hermes отображает спрайт с полной точностью, когда вы
терминал поддерживает графический протокол (**kitty**, **Ghostty**, **WezTerm**,
**iTerm2** или **шестёрка**). В противном случае он автоматически возвращается к истинному цвету.
Юникод **полублочный** рендеринг. Внутри канала или перенаправления (без телетайпа), терминал
рендеринг отключен по умолчанию.

Настольное приложение рисует питомца в виде плавающего спрайта на холсте и переключает его.
в **Настройки → Внешний вид**.

## Быстрый старт (CLI)

```bash
# Browse the gallery (filter by substring)
hermes pets list
hermes pets list cat

# Install a pet and make it active in one step
hermes pets install boba --select

# Preview / animate it in your terminal (Ctrl+C to stop)
hermes pets show

# Check your setup
hermes pets doctor
```

## `hermes pets` команды

| Цель | Команда |
| --- | --- |
| Просмотреть галерею | `hermes pets list [query] [--limit N]` |
| Список установленных домашних животных | `hermes pets list --installed` |
| Установить домашнее животное | `hermes pets install <slug> [--select] [--force]` |
| Установить активного питомца | `hermes pets select [slug]` (опустите слизень для сборщика) |
| Измените размер питомца повсюду | `hermes pets scale <factor>` (например, `0.5`, фиксировано 0,1–3,0) |
| Предварительный просмотр/анимация | `hermes pets show [slug] [--state <s>] [--cycle] [--once] [--mode <m>] [--scale <f>]` |
| Отключить питомца | `hermes pets off` |
| Удалить установленного питомца | `hermes pets remove <slug>` |
| Диагностика установки | `hermes pets doctor` |

`hermes pets show` флаги:

- `--state` — играть в одном состоянии (`idle`, `wave`, `run`, `failed`, `review`,
  `jump`).
- `--cycle` — циклическое перебор каждого состояния.
- `--once` — воспроизвести один раз вместо зацикливания.
- `--mode` — переопределить протокол рендеринга (`kitty`, `iterm`, `sixel`,
  `unicode`, `auto`).
- `--scale` — переопределить масштаб на экране (`0` = использовать конфигурацию).

## `/pet` косая черта

Внутри CLI и TUI вы можете управлять питомцем, не выходя из сеанса:

- `/pet` — включение/выключение питомца (принимает первого установленного питомца, если его нет).
  активный).
- `/pet list` — просмотреть галерею.
- `/pet scale <factor>` — изменить размер питомца везде (например, `/pet scale 0.5`).
- `/pet <slug>` — завести конкретного питомца.
- `/pet off` — отключить питомца.

В TUI `/pet list` открывает интерактивное наложение средства выбора; в настольном приложении
он открывает палитру домашних животных Cmd+K.

## Создание питомца (`/hatch`)

Помимо установки готовых питомцев из галереи, Hermes может **создать совершенно нового питомца** на основе текстового описания — с помощью собственного конвейера генерации спрайтов ИИ.

- CLI/TUI: `/hatch <description>` (псевдоним `/generate-pet`) или `hermes pets` → поток генерации.
- Приложение для ПК: **генерирующий** пользовательский интерфейс в стиле Pokédex — анимированное яйцо, эффекты штриховки и средство выбора драфта.

Как работает генерация (двухэтапный, ограниченный по стоимости поток):

1. **Базовые черновики** — генерируются несколько дешевых вариантов «как должен выглядеть этот питомец», предназначенных только для подсказок. Вы выбираете один или делаете ремикс/повторяете попытку для нового раунда.
2. **Штриховка** — выбранная база используется в качестве эталонного изображения для создания одной строки обоснованной анимации для каждого состояния Гермеса (бездействие, мышление, использование инструментов и т. д.), которые детерминированно нарезаются на кадры и упаковываются в стандартный атлас petdex/codex (сетка 8×9, 192×208 ячеек). В результате вы сохраните действительную таблицу спрайтов — и можете `petdex submit`.

### Серверная часть изображения

Генерация использует активный [провайдер генерации изображений](/user-guide/features/image-generation), но требует **заземления эталонного изображения**, чтобы каждая строка анимации сохраняла тот же символ, что и базовый. Серверные модули с поддержкой ссылок: **Nous Portal**, **OpenRouter**, **OpenAI** (`gpt-image-2`) и **Krea**. OpenRouter/Nous по умолчанию запускает цепочку моделей, ориентированную на качество.

- Порядок разрешения предпочитает Nous Portal → OpenAI → OpenRouter.
- Если серверная часть с поддержкой ссылок не настроена, при генерации выдается ошибка, требующая действий, указывающая на `hermes tools` → Генерация изображения. (Для установки/адаптации существующих питомцев галереи не требуется серверная часть изображений.)
– Переопределите серверную часть с помощью переменной env `HERMES_PET_IMAGE_PROVIDER` (например, `HERMES_PET_IMAGE_PROVIDER=openrouter`).

## Настольное приложение

В настольном приложении вы можете управлять питомцем двумя способами:

- **Cmd+K → «Домашние животные…»** — просматривайте, ищите, усыновляйте и переключайте домашних животных, не выходя из дома.
  клавиатура (отражает выбор темы).
- **Настройки → Внешний вид** — та же галерея плюс **ползунок размера**, который
  изменяет размер плавающего талисмана в реальном времени при перетаскивании.

Оба принимают/переключают/изменяют размер плавающего талисмана на месте — применяются изменения размера.
мгновенно; принятие нового питомца мгновенно освещает его.

### Роуминг

Настройки → Внешний вид имеет переключатель **Бродить**: если он включен, питомец бродит по
окно само по себе, пока агент бездействует — ходьба по поверхностям, пауза и
прыгать между точками. Роуминг работает только тогда, когда домашнее животное находится в окне, активно,
и агент покоится; любое состояние, управляемое агентом (работа, праздник)
сразу берет на себя управление. По умолчанию этот переключатель отключен и сохраняется
перезапускается.

### Alt+изменение размера колеса

Удерживайте **Alt** и прокрутите колесо мыши над питомцем, чтобы изменить его размер —
как в окне приложения, так и во всплывающем окне. Наложение масштабируется
к положению курсора, и полученный масштаб сохраняется, поэтому он
выдерживает перезапуск и остается синхронизированным с домашним животным в приложении.

### Вибрационные реакции

Скажите агенту что-нибудь приятное — «хороший бот», «спасибо», «или», `<3` или
эмодзи сердца — и питомец реагирует плавающими сердечками (на рабочем столе) или сердечком
вспышка (CLI/TUI). Обнаружение — это тщательно подобранный словарь без токенов, который сопоставляется локально на
каждое сообщение пользователя (без вызова модели); он зажигается любовью и благодарностью, направленными на
агент, а не общее положительное настроение. Все поверхности — CLI pet, TUI, рабочий стол.
плавающий питомец и всплывающее наложение — реагируют на один и тот же сигнал.

### Всплывающее окно

**Удерживая клавишу Shift**, щелкните плавающего питомца, чтобы он стал прозрачным,
Окно рабочего стола всегда поверх экрана. Там он остается видимым, пока находится Гермес.
свернуто (в стиле Кодекса), поэтому с первого взгляда вы поймете, что делает агент.

Жесты, когда он выскочил:

| Жест | Действие |
| --- | --- |
| **Перетащите** | Переместите питомца в любое место экрана, даже за пределы приложения. Его место и состояние входа/выхода сохраняются при перезапусках. |
| **Один щелчок** | Откройте мини-композитор, чтобы отправить приглашение к последнему сеансу, не открывая приложение. |
| **Двойной щелчок** | Переключите окно приложения: сверните его, если оно находится спереди, восстановите, если оно скрыто. |
| **Удерживая клавишу Shift** | Поместите питомца обратно в окно. |
| **Значок почты** | Появляется только тогда, когда ход завершен, пока вас не было; нажмите, чтобы поднять приложение в самой последней теме (и отметить его как прочитанное). |

Только высунувшийся питомец показывает **речевой пузырь** (`working…`, `thinking…`,
`your turn`, …) — в окне само приложение является поверхностью, поэтому питомец остается
там тихо.

Оверлей — это чистая марионетка домашнего животного в приложении — у него нет отдельного шлюза.
соединение и никогда не появляется в доке или переключателе приложений.

## Конфигурация

Все настройки хранятся в `display.pet` в `config.yaml`:

```yaml
display:
  pet:
    enabled: false        # master on/off (true once you select a pet)
    slug: ""              # active pet; empty = first installed
    render_mode: auto      # auto | kitty | iterm | sixel | unicode | off
    scale: 0.33           # master size knob (relative to native 192x208 frames)
    unicode_cols: 0       # hard override for terminal width (0 = derive from scale)
```

- **`scale`** — это ручка единого основного размера. Одно число сжимает каждую поверхность:
  холст рабочего стола масштабирует свои пиксели, а CLI/TUI получает их
  ширина столбца терминала от него. Запасной вариант полублока обеспечивает разборчивость
  пол — он не может сжиматься до полнопиксельного рендеринга графического интерфейса без
  превращается в кашу, так что тот же `scale` выглядит хрустящим под котенком, но лежит на полу
  полублоки.
- **`render_mode: auto`** обнаруживает kitty/iTerm2/sixel и возвращается к юникоду.
  полублоки. Установите его явно, чтобы принудительно использовать протокол, или `off`, чтобы отключить его.
  рендеринг терминала, сохраняя питомца на рабочем столе.
- **`unicode_cols`** закрепляет ширину столбца терминала независимо от `scale`;
  оставьте значение `0`, чтобы получить ширину из `scale`.

## Устранение неполадок

Запускаем `hermes pets doctor` — он сообщает:

- каталог домашних животных и какие питомцы установлены,
- `display.pet.enabled`, `display.pet.slug` и разрешенный активный питомец,
- настроенный `render_mode`, обнаруженный графический протокол терминала и
  эффективный режим для телетайпа,
- можно ли импортировать Pillow (используется для декодирования спрайтов).

Он печатает `✓ ready`, как только питомец установлен, выбран, включен и подушка активирована.
доступен.

Распространенные ошибки:

- Питомец отображается только после того, как он **установлен И выбран** (`enabled: true`).
- Внутри канала/перенаправления (без TTY) рендеринг терминала отключен по умолчанию.
- Интерфейс командной строки petdex npm устанавливается на `~/.codex/pets`; Гермес использует свой собственный
  Вместо этого используйте `<HERMES_HOME>/pets/` в области профиля — установите через `hermes pets`.
