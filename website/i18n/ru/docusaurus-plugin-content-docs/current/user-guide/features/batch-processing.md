# Пакетная обработка

Пакетная обработка позволяет запускать агент Hermes параллельно с сотнями или тысячами запросов, генерируя структурированные данные о траектории. В основном это используется для **генерации обучающих данных** — создания траекторий в формате ShareGPT со статистикой использования инструментов, которую можно использовать для точной настройки или оценки.

## Обзор

Пакетный исполнитель (`batch_runner.py`) обрабатывает набор данных JSONL с подсказками, запуская каждое из них в течение полного сеанса агента с доступом к инструментам. Каждое приглашение получает свою изолированную среду. Выходные данные представляют собой структурированные данные о траектории с полной историей разговоров, статистикой вызовов инструментов и показателями охвата рассуждений.

## Быстрый старт

```bash
# Basic batch run
python batch_runner.py \
    --dataset_file=data/prompts.jsonl \
    --batch_size=10 \
    --run_name=my_first_run \
    --model=anthropic/claude-sonnet-4.6 \
    --num_workers=4

# Resume an interrupted run
python batch_runner.py \
    --dataset_file=data/prompts.jsonl \
    --batch_size=10 \
    --run_name=my_first_run \
    --resume

# List available toolset distributions
python batch_runner.py --list_distributions
```

:::tip Предсказуемая стоимость в зависимости от масштаба
Пакетные запуски запускают множество одновременных сеансов агентов, каждый из которых выполняет вызовы моделей и инструментов. Подписка на [Nous Portal](/user-guide/features/tool-gateway) объединяет доступ к модели, а также веб-поиск, создание изображений, TTS и облачные браузеры в одном счете — полезно, если вам нужна стабильная цена за траекторию без жонглирования ограничениями ставок для пяти учетных записей поставщиков. Настройте `hermes setup --portal`, затем наведите `--model` на модель Nous.
:::

## Формат набора данных

Входной набор данных представляет собой файл JSONL (по одному объекту JSON в строке). Каждая запись должна иметь поле `prompt`:

```jsonl
{"prompt": "Write a Python function that finds the longest palindromic substring"}
{"prompt": "Create a REST API endpoint for user authentication using Flask"}
{"prompt": "Debug this error: TypeError: cannot unpack non-iterable NoneType object"}
```

Записи могут дополнительно включать:
- `image` или `docker_image`: образ контейнера, который будет использоваться для песочницы этого приглашения (работает с бэкэндами Docker, Modal и Singularity).
- `cwd`: переопределение рабочего каталога для терминального сеанса задачи.

## Параметры конфигурации

| Параметр | По умолчанию | Описание |
|-----------|---------|-------------|
| `--dataset_file` | (обязательно) | Путь к набору данных JSONL |
| `--batch_size` | (обязательно) | Подсказки для каждой партии |
| `--run_name` | (обязательно) | Имя для этого запуска (используется для выходного каталога и контрольных точек) |
| `--distribution` | `"default"` | Распространение набора инструментов для выборки из |
| `--model` | `claude-sonnet-4.6` | Модель для использования |
| `--base_url` | `https://openrouter.ai/api/v1` | Базовый URL API |
| `--api_key` | (переменная окружения) | API-ключ для модели |
| `--max_turns` | `10` | Максимальное количество итераций вызова инструмента на одно приглашение |
| `--num_workers` | `4` | Параллельные рабочие процессы |
| `--resume` | `false` | Резюме с КПП |
| `--verbose` | `false` | Включить подробное ведение журнала |
| `--max_samples` | все | Обрабатывать только первые N выборок из набора данных |
| `--max_tokens` | модель по умолчанию | Максимальное количество токенов на ответ модели |

### Маршрутизация провайдера (OpenRouter)

| Параметр | Описание |
|-----------|-------------|
| `--providers_allowed` | Разрешенные поставщики, разделенные запятыми (например, `"anthropic,openai"`) |
| `--providers_ignored` | Поставщики, разделенные запятыми, которые следует игнорировать (например, `"together,deepinfra"`) |
| `--providers_order` | Порядок предпочтительного поставщика через запятую |
| `--provider_sort` | Сортировать по `"price"`, `"throughput"` или `"latency"` |

### Контроль рассуждений

| Параметр | Описание |
|-----------|-------------|
| `--reasoning_effort` | Усилие рассуждения: `none`, `minimal`, `low`, `medium`, `high`, `xhigh`, `max`, `ultra` |
| `--reasoning_disabled` | Полностью отключить жетоны рассуждения/мышления |

### Дополнительные параметры

| Параметр | Описание |
|-----------|-------------|
| `--ephemeral_system_prompt` | Системная подсказка используется во время выполнения, но НЕ сохраняется в траекториях |
| `--log_prefix_chars` | Символы для отображения в предварительном просмотре журнала (по умолчанию: 100) |
| `--prefill_messages_file` | Путь к файлу JSON с сообщениями предварительного заполнения для однократной заливки |

## Дистрибутивы наборов инструментов

Каждое приглашение получает случайно выбранный набор инструментов из **дистрибутива**. Это гарантирует, что данные обучения охватывают разнообразные комбинации инструментов. Используйте `--list_distributions`, чтобы просмотреть все доступные дистрибутивы.

В текущей реализации распределения присваивают вероятность **каждому отдельному набору инструментов**. Сэмплер переворачивает каждый набор инструментов независимо, а затем гарантирует, что хотя бы один набор инструментов включен. Это отличается от таблицы заранее созданных комбинаций, созданной вручную.

## Формат вывода

Весь вывод поступает в `data/<run_name>/`:

```text
data/my_run/
├── trajectories.jsonl    # Combined final output (all batches merged)
├── batch_0.jsonl         # Individual batch results
├── batch_1.jsonl
├── ...
├── checkpoint.json       # Resume checkpoint
└── statistics.json       # Aggregate tool usage stats
```

### Формат траектории

Каждая строка в `trajectories.jsonl` представляет собой объект JSON:

```json
{
  "prompt_index": 42,
  "conversations": [
    {"from": "human", "value": "Write a function..."},
    {"from": "gpt", "value": "I'll create that function...",
     "tool_calls": [...]},
    {"from": "tool", "value": "..."},
    {"from": "gpt", "value": "Here's the completed function..."}
  ],
  "metadata": {
    "batch_num": 2,
    "timestamp": "2026-01-15T10:30:00",
    "model": "anthropic/claude-sonnet-4.6"
  },
  "completed": true,
  "partial": false,
  "api_calls": 3,
  "toolsets_used": ["terminal", "file"],
  "tool_stats": {
    "terminal": {"count": 2, "success": 2, "failure": 0},
    "read_file": {"count": 1, "success": 1, "failure": 0}
  },
  "tool_error_counts": {
    "terminal": 0,
    "read_file": 0
  }
}
```

Поле `conversations` использует формат, подобный ShareGPT, с полями `from` и `value`. Статистика инструментов нормализована и включает все возможные инструменты с нулевыми значениями по умолчанию, что обеспечивает согласованность схемы между записями для совместимости наборов данных HuggingFace.

## Контрольная точка

Пакетный менеджер имеет надежную контрольную точку для обеспечения отказоустойчивости:

- **Файл контрольных точек:** сохраняется после завершения каждого пакета и позволяет отслеживать выполнение индексов подсказок.
- **Резюме на основе содержимого:** На `--resume` средство выполнения сканирует существующие пакетные файлы и сопоставляет заполненные запросы по фактическому текстовому содержимому (а не только по индексам), обеспечивая восстановление даже при изменении порядка набора данных.
- **Неудачные запросы:** Только успешно выполненные запросы помечаются как выполненные — невыполненные запросы будут повторяться при возобновлении.
- **Пакетное объединение:** по завершении все пакетные файлы (в том числе из предыдущих запусков) объединяются в один `trajectories.jsonl`.

### Как работает резюме

1. Сканируйте все файлы `batch_*.jsonl` на наличие заполненных запросов (по содержимому).
2. Отфильтруйте набор данных, чтобы исключить уже выполненные запросы.
3. Повторно пакетируйте оставшиеся запросы.
4. Обработайте только оставшиеся запросы.
5. Объедините все пакетные файлы (старые + новые) в окончательный результат.

## Фильтрация качества

Пакетный менеджер применяет автоматическую фильтрацию качества:

- **Фильтр без рассуждений:** Образцы, в которых нулевые ходы помощника содержат рассуждения (без `<REASONING_SCRATCHPAD>` или жетонов естественного мышления), отбрасываются.
- **Поврежден фильтр записей:** Записи с галлюцинаторными названиями инструментов (отсутствующие в допустимом списке инструментов) отфильтровываются во время окончательного слияния.
- **Статистика рассуждений:** отслеживает процент ходов с рассуждениями или без них на протяжении всего забега.

## Статистика

После завершения бегун выводит подробную статистику:

– **Использование инструмента:** количество вызовов, процент успешных/неудачных операций для каждого инструмента.
– **Охват рассуждений:** Процент ассистентов, которые аргументировали свою позицию.
- **Образцы отброшены:** Количество образцов, отфильтрованных из-за отсутствия обоснования.
- **Продолжительность:** Общее время обработки

Статистика также сохраняется в `statistics.json` для программного анализа.

## Варианты использования

### Генерация обучающих данных

Создавайте разнообразные траектории использования инструментов для точной настройки:

```bash
python batch_runner.py \
    --dataset_file=data/coding_prompts.jsonl \
    --batch_size=20 \
    --run_name=coding_v1 \
    --model=anthropic/claude-sonnet-4.6 \
    --num_workers=8 \
    --distribution=default \
    --max_turns=15
```

### Оценка модели

Оцените, насколько хорошо модель использует инструменты в стандартизированных подсказках:

```bash
python batch_runner.py \
    --dataset_file=data/eval_suite.jsonl \
    --batch_size=10 \
    --run_name=eval_gpt4 \
    --model=openai/gpt-4o \
    --num_workers=4 \
    --max_turns=10
```

### Изображения контейнера для каждого запроса

Для тестов, требующих определенных сред, в каждом приглашении можно указать собственный образ контейнера:

```jsonl
{"prompt": "Install numpy and compute eigenvalues of a 3x3 matrix", "image": "python:3.11-slim"}
{"prompt": "Compile this Rust program and run it", "image": "rust:1.75"}
{"prompt": "Set up a Node.js Express server", "image": "node:20-alpine", "cwd": "/app"}
```

Пакетный исполнитель проверяет доступность образов Docker перед запуском каждого запроса.
