# Извлечение документа

Инструмент `read_file` автоматически преобразует распространенные форматы документов в читаемый текст, поэтому агент может проверять PDF-файл или электронную таблицу так же, как он читает исходный код.

## Поддерживаемые форматы

| Формат | Расширения | Конвертер | Наличие |
|--------|-----------|-----------|--------------|
| Ноутбуки Jupyter | `.ipynb` | Встроенный (stdlib) | Всегда |
| Документы Word | `.docx` | Встроенный (stdlib) | Всегда |
| Книги Excel | `.xlsx` | Встроенный (stdlib) | Всегда |
| PDF | `.pdf` | Дополнительный преобразователь `anydoc` | Устанавливается автоматически при первом использовании* |
| Наследие Офис | `.doc`, `.ppt`, `.xls`, `.pptx` и варианты | Дополнительный преобразователь `anydoc` | Устанавливается автоматически при первом использовании* |
| Открытый документ | `.odt`, `.ods`, `.odp` | Дополнительный преобразователь `anydoc` | Устанавливается автоматически при первом использовании* |
| Форматированный текст / электронные книги | `.rtf`, `.epub` | Дополнительный преобразователь `anydoc` | Устанавливается автоматически при первом использовании* |

\* Дополнительным преобразователем является пакет `firecrawl-anydoc`, устанавливаемый лениво там, где установка разрешена (`security.allow_lazy_installs` в `config.yaml`). Без него три формата stdlib по-прежнему работают; другие форматы возвращаются к защите двоичных файлов.

Выходные данные преобразования — это Markdown, разбивка на страницы через обычное окно `offset`/`limit` `read_file`. Документы размером более 50 МБ не принимаются, чтобы ограничить обороты инструментов.

Извлечение работает с удаленными серверными модулями терминалов (Docker, Modal, SSH): байты файла передаются через внутреннюю границу и преобразуются на стороне хоста, поэтому документ внутри песочницы читается так же, как локальный.

## Отсканированные PDF-файлы: предупреждение о покрытии

При преобразовании PDF читается **только текстовый слой**. Страницы, представляющие собой отсканированные изображения (обычные в юридических документах, пакетах для перепродажи, подписанных контрактах, факсах), не содержат текстового слоя и автоматически преобразуются в ничто. Характерной чертой являются заголовки разделов с пустыми телами.

Если значительная часть страниц не содержит текста (более 20 % документа или более 10 страниц в целом), `read_file` добавляет к извлечению предупреждение. Каждый нечитаемый пробел помечен последним извлеченным перед ним текстом — обычно это разделитель разделов — поэтому агент может ориентироваться только на те пробелы, которые ему действительно нужны, вместо того, чтобы распознавать весь документ:

```
[EXTRACTION COVERAGE WARNING: 198 of 311 pages in this PDF yielded no
text. ... Unreadable gaps, each labeled with the last text extracted
before it:
  pages 42-77 (36 pages) — after "Antigua Maintenance Corp Bylaws" (p41)
  pages 92-213 (122 pages) — after "... Covenants, Codes and Regulations" (p91)
  page 224 (1 page) — after "... Insurance Declaration Pages" (p223)
Decide which gaps you actually need — do NOT OCR or render everything. ...]
```

В предупреждении перечислены точные диапазоны страниц и пути восстановления:

1. **Несколько страниц — рендеринг + визуализация.** Преобразуйте страницы в изображения и прочитайте их с помощью инструмента визуализации:
   ```bash
   pdftoppm -jpeg -r 150 -f 92 -l 94 document.pdf /tmp/page
   ```
   Затем проверьте каждое изображение с помощью `vision_analyze`. Ноль дополнительных зависимостей (для самого обнаружения необходим попплер).
2. **Много страниц — распознавание текста.** Навык `ocr-and-documents` охватывает массовое распознавание текста с помощью маркера-pdf (более 90 языков, обработка уравнений и таблиц; установка ~3–5 ГБ).

При обнаружении используется `pdftotext` Poppler для подсчета текста на странице. Если попплер не установлен, извлечение все равно работает — проверка покрытия молча пропускается.

:::совет
Агент самостоятельно обрабатывает предупреждение — предлагает отобразить или распознать недостающие страницы. Если вы читаете выдержки самостоятельно, воспринимайте «заголовок с пустым телом» как отсканированный раздел, а не как отсутствующий.
:::
