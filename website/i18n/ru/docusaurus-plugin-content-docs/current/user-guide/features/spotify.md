# Спотифай

Hermes может напрямую управлять Spotify — воспроизведением, очередью, поиском, списками воспроизведения, сохраненными треками/альбомами и историей прослушивания — используя официальный веб-API Spotify с PKCE OAuth. Токены хранятся в `~/.hermes/auth.json` и автоматически обновляются в коде 401; вы входите в систему только один раз на каждом компьютере (токены обновления истекают примерно через 6 месяцев; когда они истекают, повторно запустите `hermes auth spotify`).

В отличие от встроенной интеграции OAuth Hermes (Google, GitHub Copilot, Codex), Spotify требует, чтобы каждый пользователь зарегистрировал собственное легкое приложение для разработчиков. Spotify не позволяет третьим лицам распространять общедоступные приложения OAuth, которыми может пользоваться каждый. Это займет около двух минут, и `hermes auth spotify` проведет вас через него.

## Предварительные условия

- Аккаунт Spotify. **Бесплатно** работает для инструментов поиска, плейлистов, библиотеки и активности. **Премиум** требуется для управления воспроизведением (воспроизведение, пауза, пропуск, поиск, громкость, добавление в очередь, передача).
- Агент Гермес установлен и работает.
– Для инструментов воспроизведения: **активное устройство Spotify Connect** — приложение Spotify должно быть открыто хотя бы на одном устройстве (телефоне, настольном компьютере, веб-плеере, динамике), чтобы веб-API мог чем-то управлять. Если ничего не активно, вы получите `403 Forbidden` с сообщением «нет активного устройства»; откройте Spotify на любом устройстве и повторите попытку.

## Настройка

### Одноразовый: `hermes tools` или настройка при первом запуске.

Самый быстрый путь. Запустить:

```bash
hermes tools
```

Прокрутите до `🎵 Spotify`, нажмите пробел, чтобы включить его, затем `s`, чтобы сохранить. Тот же переключатель доступен и во время первого запуска потока `hermes setup`/`hermes setup tools`. Spotify остается включенным, поэтому при его включении запускается та же конфигурация с учетом поставщика, что и `hermes tools`.

Hermes отправляет вас прямо в поток OAuth — если у вас еще нет приложения Spotify, он поможет вам создать его в режиме онлайн. Как только вы закончите, набор инструментов будет включен и аутентифицирован за один проход.

Если вы предпочитаете выполнять эти шаги отдельно (или повторно авторизуетесь позже), используйте двухэтапную процедуру ниже.

### Двухэтапный поток

#### 1. Включите набор инструментов

```bash
hermes tools
```

Включите `🎵 Spotify`, сохраните и, когда откроется встроенный мастер, закройте его (Ctrl+C). Набор инструментов останется включенным; откладывается только шаг аутентификации.

#### 2. Запустите мастер входа в систему

```bash
hermes auth spotify
```

Семь инструментов Spotify появляются в наборе инструментов агента только после шага 1 — они отключены по умолчанию, поэтому пользователи, которым они не нужны, не отправляют дополнительные схемы инструментов при каждом вызове API.

Если `HERMES_SPOTIFY_CLIENT_ID` не установлен, Hermes проведет вас через онлайн-регистрацию приложения:

1. Открывает `https://developer.spotify.com/dashboard` в вашем браузере.
2. Распечатывает точные значения для вставки в форму «Создать приложение» Spotify.
3. Запрашивает идентификатор клиента, который вы получаете обратно.
4. Сохраняет его в `~/.hermes/.env`, чтобы при последующих запусках этот шаг можно было пропустить.
5. Переход непосредственно к потоку согласия OAuth.

После вашего одобрения токены записываются под `providers.spotify` в `~/.hermes/auth.json`. Активный поставщик вывода НЕ меняется — аутентификация Spotify не зависит от вашего поставщика LLM.

### Создание приложения Spotify (то, что просит мастер)

Когда откроется панель управления, нажмите **Создать приложение** и заполните:

| Поле | Значение |
|-------|-------|
| Название приложения | что-нибудь (например, `hermes-agent`) |
| Описание приложения | что-нибудь (например, `personal Hermes integration`) |
| Веб-сайт | оставить пустым |
| URI перенаправления | `http://127.0.0.1:43827/spotify/callback` |
| Какие API/SDK? | проверьте **Веб-API** |

Согласитесь с условиями и нажмите **Сохранить**. На следующей странице нажмите **Настройки** → скопируйте **Идентификатор клиента** и вставьте его в командную строку Hermes. Это единственное значение, которое нужно Hermes — PKCE не использует секрет клиента.

### Запуск через SSH/в безголовой среде

Если установлено `SSH_CLIENT` или `SSH_TTY`, Hermes пропускает автоматическое открытие браузера как во время работы мастера, так и на этапе OAuth. Скопируйте URL-адрес информационной панели и URL-адрес авторизации, которые печатает Hermes, откройте их в браузере на локальном компьютере и продолжайте работу в обычном режиме — локальный прослушиватель HTTP по-прежнему работает на удаленном хосте через порт `43827`. Браузер вашего ноутбука не сможет подключиться к удаленному шлейфу без локальной переадресации SSH:

```bash
ssh -N -L 43827:127.0.0.1:43827 user@remote-host
```

Информацию о настройках Jump-Box/бастиона и других ошибках (mosh, tmux, конфликты портов) см. в разделе [OAuth over SSH/Remote Hosts](../../guides/oauth-over-ssh.md).

## Проверить

```bash
hermes auth status spotify
```

Показывает, присутствуют ли токены и когда истекает срок действия токена доступа. Обновление происходит автоматически: когда любой вызов API Spotify возвращает 401, клиент обменивает токен обновления и повторяет попытку один раз. Токены обновления сохраняются при перезапуске Hermes, поэтому вы выполняете повторную аутентификацию только в том случае, если отзовете приложение в настройках своей учетной записи Spotify или запустите `hermes auth logout spotify`.

## Использование этого

После входа в систему агент получает доступ к 7 инструментам Spotify. Вы общаетесь с агентом естественно — он выбирает правильный инструмент и действие. Для лучшего поведения агент загружает сопутствующий навык, который обучает каноническим шаблонам использования (одиночный поиск, затем воспроизведение, когда не требуется предполетная подготовка `get_state` и т. д.).

```
> play some miles davis
> what am I listening to
> add this track to my Late Night Jazz playlist
> skip to the next song
> make a new playlist called "Focus 2026" and add the last three songs I played
> which of my saved albums are by Radiohead
> search for acoustic covers of Blackbird
> transfer playback to my kitchen speaker
```

### Справочник инструментов

Все действия по изменению воспроизведения принимают необязательный `device_id` для указания конкретного устройства. Если этот параметр опущен, Spotify использует текущее активное устройство.

#### `spotify_playback`
Управляйте и проверяйте воспроизведение, а также извлекайте историю недавно воспроизведенных игр.

| Действие | Цель | Премиум? |
|--------|---------|----------|
| `get_state` | Полное состояние воспроизведения (дорожка, устройство, прогресс, случайное/повторное воспроизведение) | Нет |
| `get_currently_playing` | Только текущая дорожка (возвращает пустое значение 204 — см. ниже) | Нет |
| `play` | Запуск/возобновление воспроизведения. Необязательно: `context_uri`, `uris`, `offset`, `position_ms` | Да |
| `pause` | Пауза воспроизведения | Да |
| `next` / `previous` | Пропустить трек | Да |
| `seek` | Перейти к `position_ms` | Да |
| `set_repeat` | `state` = `track` / `context` / `off` | Да |
| `set_shuffle` | `state` = `true` / `false` | Да |
| `set_volume` | `volume_percent` = 0-100 | Да |
| `recently_played` | Последние воспроизведенные треки. Необязательно `limit`, `before`, `after` (Unix MS) | Нет |

#### `spotify_devices`
| Действие | Цель |
|--------|---------|
| `list` | Каждое устройство Spotify Connect, видимое для вашей учетной записи |
| `transfer` | Переместить воспроизведение на `device_id`. Необязательно `play: true` запускает воспроизведение при передаче |

### Колонки, управляемые Home Assistant

Если Home Assistant управляет динамиками, которые уже поддерживают Spotify Connect (например, Sonos, Echo, Nest или другие динамики с поддержкой Connect), они автоматически появляются в `spotify_devices list` всякий раз, когда Spotify может их видеть. Для этого пути Hermes не требуется мост Home Assistant ↔ Spotify — Spotify самостоятельно обрабатывает маршрутизацию устройств.

Попросите Hermes передать воспроизведение по отображаемому имени говорящего (например, «перенести Spotify на кухонный динамик») или позвоните по номеру `spotify_devices list` и передайте точный номер `device_id` на `spotify_devices transfer` при написании сценария. Если динамик отсутствует, откройте приложение Spotify или интеграцию Spotify динамика один раз, чтобы Spotify зарегистрировал его как активную цель Connect.

#### `spotify_queue`
| Действие | Цель | Премиум? |
|--------|---------|----------|
| `get` | Треки в очереди | Нет |
| `add` | Добавить `uri` в очередь | Да |

#### `spotify_search`
Ищите в каталоге. Требуется `query`. Необязательно: `types` (массив `track` / `album` / `artist` / `playlist` / `show` / `episode`), `limit`, `offset`, `market`.

#### `spotify_playlists`
| Действие | Цель | Обязательные аргументы |
|--------|---------|---------------|
| `list` | Плейлисты пользователя | — |
| `get` | Один плейлист + треки | `playlist_id` |
| `create` | Новый плейлист | `name` (+ необязательные `description`, `public`, `collaborative`) |
| `add_items` | Добавить треки | `playlist_id`, `uris` (необязательно `position`) |
| `remove_items` | Удалить треки | `playlist_id`, `uris` (+ необязательный `snapshot_id`) |
| `update_details` | Переименовать/редактировать | `playlist_id` + любой из `name`, `description`, `public`, `collaborative` |

#### `spotify_albums`
| Действие | Цель | Обязательные аргументы |
|--------|---------|---------------|
| `get` | Метаданные альбома | `album_id` |
| `tracks` | Трек-лист альбома | `album_id` |

#### `spotify_library`
Единый доступ к сохраненным трекам и сохраненным альбомам. Выберите коллекцию с аргументом `kind`.

| Действие | Цель |
|--------|---------|
| `list` | Постраничный список библиотеки |
| `save` | Добавить `ids` / `uris` в библиотеку |
| `remove` | Удалить `ids` / `uris` из библиотеки |

Обязательно: `kind` = `tracks` или `albums` плюс `action`.

### Матрица функций: бесплатная или премиум-версия

Инструменты только для чтения работают на бесплатных учетных записях. Для всего, что изменяет воспроизведение или очередь, требуется Premium.

| Работает бесплатно | Требуется премиум |
|---------------|------------------|
| `spotify_search` (все) | `spotify_playback` — воспроизведение, пауза, следующий, предыдущий, поиск, set_repeat, set_shuffle, set_volume |
| `spotify_playback` — get_state, get_currently_playing, недавно_игралось | `spotify_queue` — добавить |
| `spotify_devices` — список | `spotify_devices` — перенос |
| `spotify_queue` — получить | |
| `spotify_playlists` (все) | |
| `spotify_albums` (все) | |
| `spotify_library` (все) | |

## Планирование: Spotify + cron

Поскольку инструменты Spotify являются обычными инструментами Hermes, задание cron, выполняемое в сеансе Hermes, может запускать воспроизведение по любому расписанию. Никакого нового кода не требуется.

### Плейлист для утреннего пробуждения

```bash
hermes cron add \
  --name "morning-commute" \
  "0 7 * * 1-5" \
  "Transfer playback to my kitchen speaker and start my 'Morning Commute' playlist. Volume to 40. Shuffle on."
```

Что происходит в 7 утра каждый будний день:
1. Крон запускает обезглавленный сеанс Гермеса.
2. Агент читает подсказку, звонит `spotify_devices list`, чтобы найти «кухонного динамика» по имени, затем `spotify_devices transfer` → `spotify_playback set_volume` → `spotify_playback set_shuffle` → `spotify_search` + `spotify_playback play`.
3. На целевом динамике заиграет музыка. Общая стоимость: один сеанс, несколько вызовов инструментов, без вмешательства человека.

### Ночное затишье

```bash
hermes cron add \
  --name "wind-down" \
  "30 22 * * *" \
  "Pause Spotify. Then set volume to 20 so it's quiet when I start it again tomorrow."
```

### Попался

- **При запуске cron должно существовать активное устройство.** Если клиент Spotify не запущен (телефон/компьютер/подключить динамик), действия по воспроизведению возвращают `403 no active device`. Для утренних плейлистов хитрость заключается в том, чтобы настроить таргетинг на устройство, которое всегда включено (Sonos, Echo, умная колонка), а не на телефон.
- **Премиум требуется для всего, что изменяет воспроизведение** — воспроизведение, пауза, пропуск, громкость, передача. Задания cron только для чтения (по расписанию «отправьте мне по электронной почте мои недавно прослушанные треки») отлично работают в Free.
- **Агент cron наследует ваши активные наборы инструментов.** Spotify должен быть включен в `hermes tools`, чтобы сеанс cron мог видеть инструменты Spotify.
- **Задания Cron выполняются с помощью `skip_memory=True`**, поэтому они не записываются в ваше хранилище памяти.

Полная ссылка на cron: [Cron Jobs](./cron).

## Выйти

```bash
hermes auth logout spotify
```

Удаляет токены из `~/.hermes/auth.json`. Чтобы также очистить конфигурацию приложения, удалите `HERMES_SPOTIFY_CLIENT_ID` (и `HERMES_SPOTIFY_REDIRECT_URI`, если вы его установили) из `~/.hermes/.env` или запустите мастер еще раз.

Чтобы отозвать приложение на стороне Spotify, посетите [Приложения, подключенные к вашей учетной записи](https://www.spotify.com/account/apps/) и нажмите **УДАЛИТЬ ДОСТУП**.

## Поиск неисправностей

**`403 Forbidden — Player command failed: No active device found`** — Spotify должен быть запущен хотя бы на одном устройстве. Откройте приложение Spotify на своем телефоне, компьютере или в веб-плеере, запустите любую дорожку на секунду, чтобы зарегистрировать ее, и повторите попытку. `spotify_devices list` показывает, что сейчас видно.

**`403 Forbidden — Premium required`** — Вы используете бесплатную учетную запись и пытаетесь использовать действие, изменяющее воспроизведение. См. матрицу функций выше.

**`204 No Content` на `get_currently_playing`** — в данный момент ни на одном устройстве ничего не воспроизводится. Это нормальный ответ Spotify, а не ошибка; Гермес представляет это как объяснительный пустой результат (`is_playing: false`).

**`INVALID_CLIENT: Invalid redirect URI`** — URI перенаправления в настройках вашего приложения Spotify не соответствует тому, что использует Hermes. По умолчанию — `http://127.0.0.1:43827/spotify/callback`. Либо добавьте это в разрешенные URI перенаправления вашего приложения, либо установите `HERMES_SPOTIFY_REDIRECT_URI` в `~/.hermes/.env` на то, что вы зарегистрировали.

**`429 Too Many Requests`** — ограничение скорости Spotify. Гермес возвращает дружественную ошибку; подождите минуту и ​​повторите попытку. Если проблема не исчезнет, ​​возможно, у вас в сценарии зациклен цикл — квота Spotify сбрасывается примерно каждые 30 секунд.

**`401 Unauthorized` продолжает возвращаться** — ваш токен обновления был отозван (обычно потому, что вы удалили приложение из своей учетной записи или приложение было удалено). Запустите `hermes auth spotify` еще раз.

**Мастер не открывает браузер** — если вы используете SSH или находитесь в контейнере без дисплея, Hermes обнаружит это и пропустит автоматическое открытие. Скопируйте URL-адрес информационной панели, которую он печатает, и откройте его вручную.

## Дополнительно: пользовательские области

По умолчанию компания Hermes запрашивает прицелы, необходимые для каждого поставляемого инструмента. Переопределите, если вы хотите ограничить доступ:

```bash
hermes auth spotify --scope "user-read-playback-state user-modify-playback-state playlist-read-private"
```

Ссылка на область действия: [Области действия Spotify Web API](https://developer.spotify.com/documentation/web-api/concepts/scopes). Если вы запрашиваете меньше областей, чем требуется инструменту, вызовы этого инструмента завершатся ошибкой 403.

## Дополнительно: собственный идентификатор клиента/URI перенаправления

```bash
hermes auth spotify --client-id <id> --redirect-uri http://localhost:3000/callback
```

Или установите их навсегда в `~/.hermes/.env`:

```
HERMES_SPOTIFY_CLIENT_ID=<your_id>
HERMES_SPOTIFY_REDIRECT_URI=http://localhost:3000/callback
```

URI перенаправления должен быть включен в список разрешенных в настройках вашего приложения Spotify. Значение по умолчанию работает практически у всех — меняйте его только в том случае, если порт 43827 занят.

## Где живут вещи

| Файл | Содержание |
|------|----------|
