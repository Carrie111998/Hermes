# Шлюз инструментов Nous

**Одна подписка. Каждый встроенный инструмент.**

Tool Gateway включен в каждую платную подписку на [Nous Portal](https://portal.nousresearch.com). Он маршрутизирует вызовы инструментов Hermes — веб-поиск, генерацию изображений, преобразование текста в речь и автоматизацию облачного браузера — через инфраструктуру, которую Nous уже использует, поэтому вам не нужно регистрироваться в Firecrawl, FAL, OpenAI, Browser Use или где-либо еще, чтобы сделать ваш агент полезным.

## Что включено

| | Инструмент | Что вы получаете |
|---|---|---|
| 🔍 | **Интернет-поиск и извлечение** | Веб-поиск агентского уровня и полностраничное извлечение с помощью Firecrawl. Никаких ограничений скорости, о которых стоит беспокоиться — шлюз обеспечивает масштабирование. |
| 🎨 | **Создание изображений** | Девять моделей под одной конечной точкой: **FLUX 2 Klein 9B**, **FLUX 2 Pro**, **Z-Image Turbo**, **Nano Banana Pro** (образ Gemini 3 Pro), **GPT Image 1.5**, **GPT Image 2**, **Ideogram V3**, **Recraft V4 Pro**, **Qwen Image**. Выберите каждое поколение с помощью флажка или позвольте Hermes по умолчанию использовать FLUX 2 Klein. |
| 🔊 | **Преобразование текста в речь** | Голоса OpenAI TTS, подключенные к инструменту `text_to_speech`. Добавляйте голосовые заметки в Telegram, генерируйте аудио для конвейеров, рассказывайте что угодно. |
| 🌐 | **Автоматизация облачного браузера** | Безголовые сеансы Chromium через использование браузера. `browser_navigate`, `browser_click`, `browser_type`, `browser_vision` — все примитивы управления агентом, учетная запись в базе браузера не требуется. |

Все четыре оплачиваются по мере использования в рамках вашей подписки Nous. Используйте любую комбинацию — запустите шлюз для Интернета и изображений, сохраняя при этом свой собственный ключ ElevenLabs для TTS, или направьте все через Nous.

## Почему это здесь

Создание агента, который действительно может *делать что-то*, означает объединение более 5 подписок API — каждая со своей собственной регистрацией, ограничениями скорости, выставлением счетов и особенностями. Шлюз объединяет это в одну учетную запись:

- **Один счет.** Оплатить Nous; мы позаботимся обо всем остальном.
- **Одна регистрация.** Никаких учетных записей Firecrawl, FAL, использования браузера или аудио OpenAI для управления.
- **Один ключ.** OAuth вашего Nous Portal охватывает все инструменты.
- **То же качество.** Те же серверные части, которые используются в маршруте с прямым ключом - только что мы их видим.

Приносите свои ключи в любое время — для каждого инструмента и в любое время. Шлюз — это не блокировка, это ярлык.

## Начать

Есть три способа — выберите тот, который подходит вам:

```bash
hermes setup --portal     # Fresh install: Nous OAuth + set Nous as provider + turn on the Tool Gateway in one go
```

```bash
hermes model              # Switch your inference provider to Nous Portal — Hermes then offers to turn on the gateway for all tools
```

```bash
hermes tools              # Enable the gateway per-tool — pick "Nous Subscription" for any tool you want
```

`hermes setup --portal` и `hermes model` — это универсальные пути: войдите в систему один раз, при необходимости переключите каждый инструмент на шлюз. `hermes tools` — это выбор по меню: включайте только те инструменты, которые вам нужны, по одному.

**Вам не нужно сначала входить в систему.** При использовании `hermes tools` серверные части, управляемые Nous (веб-поиск, изображения, видео, TTS, браузер), всегда отображаются в списке, даже если вы никогда не входили в Nous Portal. Выберите один из них, и Hermes сразу же запустит вход на портал, если вы еще не прошли аутентификацию — нет необходимости заранее запускать `hermes model`. Если ваш Nous OAuth уже активен, выбор серверной части активирует его немедленно, без дополнительного запроса. Этот путь позволяет вам войти в систему и включить только один выбранный вами инструмент — он **не** переключает вашего поставщика логических выводов и **не** предлагает вам включить шлюз для любого другого инструмента.

Проверьте, что активно в любое время:

```bash
hermes portal info        # Portal auth + Tool Gateway routing summary
hermes portal tools       # Gateway catalog with current routing per tool
hermes status             # Full system status (Tool Gateway is one section)
```

`hermes portal info` показывает такой раздел:

```
◆ Nous Tool Gateway
  Nous Portal     ✓ managed tools available
  Web tools       ✓ active via Nous subscription
  Image gen       ✓ active via Nous subscription
  TTS             ✓ active via Nous subscription
  Browser         ○ active via Browser Use key
```

Инструменты с пометкой «активно по подписке Nous» проходят через шлюз. Все остальное использует ваши собственные ключи.

## Право на участие

Tool Gateway – это функция **платной подписки**. Учетные записи Nous бесплатного уровня могут использовать Portal для вывода, но не включают управляемые инструменты — [обновите свой план] (https://portal.nousresearch.com/manage-subscription), чтобы разблокировать шлюз.

Некоторые учетные записи также имеют право на **бесплатный пул инструментов** — небольшое пособие на управляемые инструменты, которое покрывает вызовы инструментов шлюза без платной подписки. Когда доступен бесплатный пул, шлюз отображает его и отображает приглашение на установку при первом использовании, поэтому вы можете сразу же принять участие и начать использовать управляемые инструменты.

## Контрольный список включения

Выбор модели Nous (`hermes model`) предлагает контрольный список серверных частей шлюза для каждого инструмента. Его поведение соответствует вашей существующей настройке:

– Инструменты, которые вы явно указали на другой сервер (например, `web.backend: searxng`, `browser.cloud_provider: camofox`), **никогда не предлагаются** — ваш выбор нельзя случайно перезаписать.
– Инструменты, настроенные только с помощью переменных среды (например, `SEARXNG_URL`, `CAMOFOX_URL`), предлагаются **неотмеченными** и помечены для сохранения собственного бэкэнда.
- Предварительную проверку проходят только действительно ненастроенные инструменты.
- Отклонения сохраняются: если вы отправите контрольный список с неотмеченным инструментом, он не будет предварительно проверяться при будущих заменах моделей Nous (хранится в `tool_gateway_declined_tools` в `config.yaml`; последующая проверка отменяет отказ).

## Комбинируйте и сочетайте

Шлюз индивидуален для каждого инструмента. Включите его только для того, что вам нужно:

- **Все инструменты через Nous** — проще всего; одна подписка, готово.
- **Шлюз для Интернета + изображения, используйте свои собственные TTS** — сохраняйте свой голос ElevenLabs, пусть Nous позаботится обо всем остальном.
- **Шлюз только для вещей, для которых у вас нет ключей** — «Я уже плачу за Browserbase, но мне не нужна учетная запись Firecrawl» работает нормально.

Переключите любой инструмент в любое время с помощью:

```bash
hermes tools          # Interactive picker for each tool category
```

Выберите инструмент, выберите **Nous Subscription** в качестве поставщика (или любого прямого поставщика, который вы предпочитаете). Никакого редактирования конфигурации не требуется. Если вы еще не вошли в Nous Portal, выбор **Nous Subscription** запускает встроенный вход в портал — вам не нужно сначала проходить аутентификацию через `hermes model`.

## Справочник по конфигурации

Большинству пользователей это никогда не понадобится — `hermes model` и `hermes tools` охватывают каждый рабочий процесс в интерактивном режиме. Этот раздел предназначен для непосредственного написания config.yaml или настройки сценариев.

### Одна клавиша выбора для каждой категории инструментов

Каждая категория инструментов имеет один ключ выбора поставщика, написанный средством выбора `hermes tools` (или графическим пользовательским интерфейсом рабочего стола). При выборе строки **Nous Subscription** сохраняется значение `nous`, которое маршрутизирует эту категорию через управляемый шлюз инструментов. При выборе строки BYOK сохраняется имя поставщика (`fal`, `openai`, `firecrawl`, `browser-use`, ...), которое напрямую связано с вашими учетными данными:

```yaml
web:
  backend: nous          # web search/extract via the Tool Gateway

image_gen:
  provider: nous         # image generation via the Tool Gateway

tts:
  provider: nous         # TTS via the Tool Gateway

stt:
  provider: nous         # speech-to-text via the Tool Gateway

browser:
  cloud_provider: nous   # cloud browser via the Tool Gateway
```

Среда выполнения **всегда использует сохраненный выбор** — наличие учетных данных никогда не выбирает и не перенаправляет категорию. `FAL_KEY`, сидящий в `.env`, игнорируется, пока `image_gen.provider: nous`; и наоборот, `image_gen.provider: fal` без установленного `FAL_KEY` выдает явную ошибку вместо того, чтобы автоматически вернуться к шлюзу:

```
image_gen is configured to use fal (set via hermes tools), but FAL_KEY is not set. Run 'hermes tools' to change it.
```

Категории, которые вы **никогда не настраивали** (ключ выбора никогда не записывался), автоматически определяются на основе доступных учетных данных, как и раньше. Но как только выбор существует, добавление ключа к `.env` не меняет маршрут, а только `hermes tools` (или редактирование ключа выбора).

### Возврат к своим ключам

```bash
hermes tools    # pick the tool → choose a direct provider (e.g. Firecrawl)
```

Или установите клавишу выбора напрямую:

```yaml
web:
  backend: firecrawl   # Hermes now uses FIRECRAWL_API_KEY from .env
```

### Устаревший флаг `use_gateway` (устарел)

В более старых версиях Hermes для маршрутизации через шлюз использовалось логическое значение `use_gateway: true` для каждого инструмента. Этот флаг является **устаревшим**: он больше никогда не записывается, и средство выбора `hermes tools` удаляет его из конфигурации категории при переписывании выбора. Старые конфигурации, которые все еще содержат `use_gateway: true`, интерпретируются во время чтения как выбор `nous`, поэтому существующие настройки продолжают работать. Не устанавливайте `use_gateway` в новых конфигурациях — вместо этого выберите провайдера в `hermes tools`.

### Самостоятельный шлюз (расширенный)

У вас есть собственный шлюз, совместимый с Nous? Переопределить конечные точки в `~/.hermes/.env`:

```bash
TOOL_GATEWAY_DOMAIN=your-domain.example.com
TOOL_GATEWAY_SCHEME=https
TOOL_GATEWAY_USER_TOKEN=your-token        # normally auto-populated from Portal login
FIRECRAWL_GATEWAY_URL=https://...         # override one endpoint specifically
```

Эти ручки существуют для пользовательских настроек инфраструктуры (корпоративные развертывания, среды разработки). Постоянные абоненты их никогда не устанавливают.

## Часто задаваемые вопросы

### Работает ли он с Telegram/Discord/другими шлюзами обмена сообщениями?

Да. Tool Gateway работает на уровне выполнения инструмента, а не на уровне CLI. Каждый интерфейс, который может вызывать инструмент — CLI, Telegram, Discord, Slack, IRC, Teams, сервер API и т. д. — извлекает из этого прозрачную выгоду.

### Что произойдет, если срок действия моей подписки истечет?

Инструменты, проходящие через шлюз, перестают работать до тех пор, пока вы не обновите или не замените прямые ключи API через `hermes tools`. Гермес показывает явную ошибку, указывая на портал.

### Могу ли я увидеть использование или стоимость каждого инструмента?

Да. [Панель управления Nous Portal](https://portal.nousresearch.com) разбивает использование по инструментам, чтобы вы могли видеть, на что влияет ваш счет.

### Включен ли модальный (бессерверный терминал)?

Modal доступен как **дополнительное дополнение** через подписку Nous, а не как часть стандартного пакета Tool Gateway. Настройте его через `hermes setup terminal` или непосредственно в `config.yaml`, если вам нужна удаленная изолированная программная среда для выполнения оболочки.

### Нужно ли удалять существующие ключи API при включении шлюза?

Нет — оставьте их в `.env`. Если для инструмента выбрано **Nous Subscription**, клавиши прямого доступа для этого инструмента просто игнорируются. Снова выберите прямого поставщика в `hermes tools`, и ваши ключи снова станут источником. Шлюз не является замком.
