# QQ-бот

Подключите Hermes к QQ через **Официальный API-интерфейс QQ Bot (v2)** — с поддержкой частных (C2C), групповых @-упоминаний, гильдий и прямых сообщений с голосовой транскрипцией.

## Обзор

Адаптер QQ Bot использует [Официальный API QQ Bot](https://bot.q.qq.com/wiki/develop/api-v2/) для:

- Получайте сообщения через постоянное соединение **WebSocket** со шлюзом QQ.
- Отправляйте текстовые ответы и ответы с уценкой через **REST API**.
- Загрузка и обработка изображений, голосовых сообщений и вложенных файлов.
- Транскрибируйте голосовые сообщения с помощью встроенного ASR Tencent или настраиваемого поставщика STT.

## Предварительные условия

1. **Приложение QQ Bot** — зарегистрируйтесь на [q.qq.com](https://q.qq.com):
   – Создайте новое приложение и запишите свой **Идентификатор приложения** и **Секрет приложения**.
   - Включить необходимые намерения: сообщения C2C, групповые @-сообщения, сообщения гильдии.
   - Настройте своего бота в режиме песочницы для тестирования или опубликуйте для производства.

2. **Зависимости**. Для адаптера требуются `aiohttp` и `httpx`:
   ```bash
   pip install aiohttp httpx
   ```

## Конфигурация

### Интерактивная настройка

```bash
hermes gateway setup
```

Выберите **QQ Bot** из списка платформ и следуйте инструкциям.

### Ручная настройка

Установите необходимые переменные среды в `~/.hermes/.env`:

```bash
QQ_APP_ID=your-app-id
QQ_CLIENT_SECRET=your-app-secret
```

## Переменные среды

| Переменная | Описание | По умолчанию |
|---|---|---|
| `QQ_APP_ID` | Идентификатор приложения QQ Bot (обязательно) | — |
| `QQ_CLIENT_SECRET` | Секрет приложения QQ Bot (обязательно) | — |
| `QQBOT_HOME_CHANNEL` | OpenID для cron/доставки уведомлений | — |
| `QQBOT_HOME_CHANNEL_NAME` | Отображаемое имя домашнего канала | `Home` |
| `QQ_ALLOWED_USERS` | Открытые идентификаторы пользователей, разделенные запятыми, для доступа к DM | открыть (все пользователи) |
| `QQ_GROUP_ALLOWED_USERS` | Групповые OpenID, разделенные запятыми, для группового доступа | — |
| `QQ_ALLOW_ALL_USERS` | Установите значение `true`, чтобы разрешить все DM | `false` |
| `QQ_PORTAL_HOST` | Переопределить хост портала QQ (установить значение `sandbox.q.qq.com` для маршрутизации в песочнице) | `q.qq.com` |
| `QQ_STT_API_KEY` | API-ключ для провайдера голосовой связи | — |
| `QQ_STT_BASE_URL` | (Не читать напрямую — вместо этого установите `platforms.qqbot.extra.stt.baseUrl` в `config.yaml`) | н/д |
| `QQ_STT_MODEL` | Название модели STT | `glm-asr` |

## Расширенная конфигурация

Для более детального управления добавьте настройки платформы в `~/.hermes/config.yaml`:

```yaml
platforms:
  qqbot:
    enabled: true
    extra:
      app_id: "your-app-id"
      client_secret: "your-secret"
      markdown_support: true       # enable QQ markdown (msg_type 2). Config-only; no env-var equivalent.
      dm_policy: "open"          # open | allowlist | disabled
      allow_from:
        - "user_openid_1"
      group_policy: "open"       # open | allowlist | disabled
      group_allow_from:
        - "group_openid_1"
      stt:
        provider: "zai"          # zai (GLM-ASR), openai (Whisper), etc.
        baseUrl: "https://open.bigmodel.cn/api/coding/paas/v4"
        apiKey: "your-stt-key"
        model: "glm-asr"
```

## Голосовые сообщения (СТТ)

Транскрипция голоса работает в два этапа:

1. **Встроенный ASR QQ** (бесплатно, всегда пробуйте в первую очередь) — QQ предоставляет `asr_refer_text` во вложениях голосовых сообщений, который использует собственную систему распознавания речи Tencent.
2. **Настроенный поставщик STT** (резервный вариант). Если ASR QQ не возвращает текст, адаптер вызывает OpenAI-совместимый STT API:

   - **Zhipu/GLM (zai)**: поставщик по умолчанию, использует модель `glm-asr`.
   - **OpenAI Whisper**: установите `QQ_STT_BASE_URL` и `QQ_STT_MODEL`.
   - Любая конечная точка STT, совместимая с OpenAI.

## Устранение неполадок

###Бот сразу отключается (быстрое отключение)

Обычно это означает:
- **Неверный идентификатор приложения/секрет** — дважды проверьте свои учетные данные на q.qq.com.
- **Отсутствуют разрешения** – убедитесь, что у бота включены необходимые намерения.
- **Бот только для песочницы** — если бот находится в режиме песочницы, он может получать сообщения только из тестового канала песочницы QQ.

### Голосовые сообщения не расшифрованы

1. Проверьте, присутствует ли встроенный `asr_refer_text` QQ в данных вложения.
2. Если вы используете собственный поставщик STT, убедитесь, что `QQ_STT_API_KEY` установлен правильно.
3. Проверьте журналы шлюза на наличие сообщений об ошибках STT.

### Сообщения не доставлены

– Убедитесь, что **намерения** бота включены на сайте q.qq.com.
– Проверьте `QQ_ALLOWED_USERS`, ограничен ли доступ к DM.
– Для групповых сообщений убедитесь, что бот **@упоминается** (групповая политика может требовать внесения в белый список)
- Проверьте `QQBOT_HOME_CHANNEL` на предмет доставки cron/уведомлений.

### Ошибки подключения

– Убедитесь, что `aiohttp` и `httpx` установлены: `pip install aiohttp httpx`.
– Проверьте сетевое подключение к `api.sgroup.qq.com` и шлюзу WebSocket.
- Просмотр журналов шлюза для получения подробных сообщений об ошибках и поведения повторного подключения.
