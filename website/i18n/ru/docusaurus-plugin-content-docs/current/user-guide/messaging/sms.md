# Настройка SMS (Twilio)

Hermes подключается к SMS через API [Twilio](https://www.twilio.com/). Люди отправляют текстовые сообщения на ваш номер телефона Twilio и получают ответы от искусственного интеллекта — то же самое, что и в Telegram или Discord, но вместо стандартных текстовых сообщений.

:::info Общие учетные данные
Шлюз SMS использует учетные данные совместно с необязательным [навыком телефонии](/reference/skills-catalog). Если вы уже настроили Twilio для голосовых вызовов или одноразовых SMS, шлюз работает с теми же `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN` и `TWILIO_PHONE_NUMBER`.
:::

---

## Предварительные условия

- **Учетная запись Twilio** — [Зарегистрируйтесь на twilio.com](https://www.twilio.com/try-twilio) (доступна бесплатная пробная версия)
- **Номер телефона Twilio** с возможностью отправки SMS.
- **Общедоступный сервер** — Twilio отправляет веб-перехватчики на ваш сервер при поступлении SMS.
- **aiohttp** — `cd ~/.hermes/hermes-agent && uv pip install -e ".[sms]"`

---

## Шаг 1. Получите учетные данные Twilio

1. Перейдите в [Консоль Twilio](https://console.twilio.com/).
2. Скопируйте **SID аккаунта** и **токен аутентификации** с панели управления.
3. Перейдите в раздел **Телефонные номера → Управление → Активные номера** — запишите свой номер телефона в формате E.164 (например, `+15551234567`).

---

## Шаг 2: Настройте Гермес

### Интерактивная настройка (рекомендуется)

```bash
hermes gateway setup
```

Выберите **SMS (Twilio)** из списка платформ. Мастер запросит ваши учетные данные.

### Ручная настройка

Добавьте в `~/.hermes/.env`:

```bash
TWILIO_ACCOUNT_SID=ACxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
TWILIO_AUTH_TOKEN=your_auth_token_here
TWILIO_PHONE_NUMBER=+15551234567

# Security: restrict to specific phone numbers (recommended)
SMS_ALLOWED_USERS=+15559876543,+15551112222

# Optional: set a home channel for cron job delivery
SMS_HOME_CHANNEL=+15559876543
```

---

## Шаг 3. Настройте Twilio Webhook

Twilio необходимо знать, куда отправлять входящие сообщения. В [консоли Twilio](https://console.twilio.com/):

1. Откройте раздел **Номера телефонов → Управление → Активные номера**.
2. Нажмите на свой номер телефона.
3. В разделе **Сообщения → ПРИХОДИТ СООБЩЕНИЕ** установите:
   - **Вебхук**: `https://your-server:8080/webhooks/twilio`
   - **Метод HTTP**: `POST`

:::tip Раскрытие вашего вебхука
Если вы используете Hermes локально, используйте туннель, чтобы открыть веб-перехватчик:

```bash
# Using cloudflared
cloudflared tunnel --url http://localhost:8080

# Using ngrok
ngrok http 8080
```

Установите полученный общедоступный URL-адрес в качестве веб-перехватчика Twilio.
:::

**Установите для `SMS_WEBHOOK_URL` тот же URL-адрес, который вы настроили в Twilio.** Это необходимо для проверки подписи Twilio — без него адаптер откажется запускаться:

```bash
# Must match the webhook URL in your Twilio Console
SMS_WEBHOOK_URL=https://your-server:8080/webhooks/twilio
```

Порт веб-перехватчика по умолчанию — `8080`. Переопределить с помощью:

```bash
SMS_WEBHOOK_PORT=3000
```

---

## Шаг 4: Запустите шлюз

```bash
hermes gateway
```

Вы должны увидеть:

```
[sms] Twilio webhook server listening on 127.0.0.1:8080, from: +1555***4567
```

Если вы видите `Refusing to start: SMS_WEBHOOK_URL is required`, задайте `SMS_WEBHOOK_URL` общедоступный URL-адрес, настроенный в вашей консоли Twilio (см. шаг 3).

Отправьте сообщение на свой номер Twilio — Hermes ответит по SMS.

## Переменные среды

| Переменная | Требуется | Описание |
|----------|----------|-------------|
| `TWILIO_ACCOUNT_SID` | Да | SID учетной записи Twilio (начинается с `AC`) |
| `TWILIO_AUTH_TOKEN` | Да | Токен аутентификации Twilio (также используется для проверки подписи веб-перехватчика) |
| `TWILIO_PHONE_NUMBER` | Да | Ваш номер телефона Twilio (формат E.164) |
| `SMS_WEBHOOK_URL` | Да | Публичный URL-адрес для проверки подписи Twilio — должен совпадать с URL-адресом веб-перехватчика в вашей консоли Twilio |
| `SMS_WEBHOOK_PORT` | Нет | Порт прослушивателя веб-перехватчика (по умолчанию: `8080`) |
| `SMS_WEBHOOK_HOST` | Нет | Адрес привязки вебхука (по умолчанию: `127.0.0.1`) |
| `SMS_INSECURE_NO_SIGNATURE` | Нет | Установите значение `true`, чтобы отключить проверку подписи (только для локальных разработчиков — **не для рабочей**) |
| `SMS_ALLOWED_USERS` | Нет | Телефонные номера E.164, разделенные запятыми, разрешены для общения в чате |
| `SMS_ALLOW_ALL_USERS` | Нет | Установите значение `true`, чтобы разрешить всем (не рекомендуется) |
| `SMS_HOME_CHANNEL` | Нет | Номер телефона для заданий cron/доставки уведомлений |
| `SMS_HOME_CHANNEL_NAME` | Нет | Отображаемое имя домашнего канала (по умолчанию: `Home`) |

## Поведение, специфичное для SMS

- **Только обычный текст** — Markdown автоматически удаляется, поскольку SMS отображает его как буквальные символы.
- **Ограничение в 1600 символов** — более длинные ответы разбиваются на несколько сообщений по естественным границам (новые строки, затем пробелы).
- **Предотвращение эха** — сообщения с вашего собственного номера Twilio игнорируются во избежание образования петель.
- **Редактирование номера телефона** — номера телефонов в журналах редактируются в целях конфиденциальности.

## Безопасность

### Проверка подписи вебхука

Hermes подтверждает, что входящие веб-перехватчики действительно исходят из Twilio, проверяя заголовок `X-Twilio-Signature` (HMAC-SHA1). Это не позволяет злоумышленникам внедрить поддельные сообщения.

**`SMS_WEBHOOK_URL` обязателен.** Установите общедоступный URL-адрес, настроенный в консоли Twilio. Без него адаптер откажется запускаться.

Для локальной разработки без общедоступного URL-адреса вы можете отключить проверку:

```bash
# Local dev only — NOT for production
SMS_INSECURE_NO_SIGNATURE=true
```

### Белые списки пользователей

**Шлюз по умолчанию запрещает доступ всем пользователям.** Настройте белый список:

```bash
# Recommended: restrict to specific phone numbers
SMS_ALLOWED_USERS=+15559876543,+15551112222

# Or allow all (NOT recommended for bots with terminal access)
SMS_ALLOW_ALL_USERS=true
```

:::предупреждение
SMS не имеет встроенного шифрования. Не используйте SMS для конфиденциальных операций, если не понимаете последствия для безопасности. Для деликатных случаев использования отдайте предпочтение Signal или Telegram.
:::

## Устранение неполадок

### Сообщения не приходят

1. Убедитесь, что URL-адрес веб-перехватчика Twilio верен и общедоступен.
2. Убедитесь, что `TWILIO_ACCOUNT_SID` и `TWILIO_AUTH_TOKEN` верны.
3. Проверьте консоль Twilio → **Монитор → Журналы → Сообщения** на наличие ошибок доставки.
4. Убедитесь, что ваш номер телефона находится в формате `SMS_ALLOWED_USERS` (или `SMS_ALLOW_ALL_USERS=true`).

### Ответы не отправляются

1. Убедитесь, что `TWILIO_PHONE_NUMBER` установлен правильно (формат E.164 с `+`).
2. Убедитесь, что в вашей учетной записи Twilio есть номера с поддержкой SMS.
3. Проверьте журналы шлюза Hermes на наличие ошибок Twilio API.

### Конфликты портов Webhook

Если порт 8080 уже используется, измените его:

```bash
SMS_WEBHOOK_PORT=3001
```

Обновите URL-адрес веб-перехватчика в консоли Twilio, чтобы он соответствовал.
