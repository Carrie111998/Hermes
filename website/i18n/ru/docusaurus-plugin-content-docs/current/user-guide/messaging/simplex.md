# Чат SimpleX

[SimpleX Chat](https://simplex.chat/) — это частная децентрализованная платформа обмена сообщениями, где пользователи владеют своими контактами и группами. В отличие от других платформ, SimpleX не присваивает постоянных идентификаторов пользователей — каждый контакт идентифицируется непрозрачным внутренним идентификатором, генерируемым во время соединения, что делает его одним из самых закрытых доступных мессенджеров.

> Запустите `hermes gateway setup` и выберите **SimpleX** для пошагового руководства.

## Предварительные условия

- Интерфейс командной строки **simplex-chat** установлен и работает как демон.
- Пакет Python **websockets** (`pip install websockets`)

## Установить симплекс-чат

Загрузите последнюю версию со страницы [выпуски simplex-chat GitHub](https://github.com/simplex-chat/simplex-chat/releases):

```bash
# Linux / macOS binary
curl -L https://github.com/simplex-chat/simplex-chat/releases/latest/download/simplex-chat-ubuntu-22_04-x86_64 -o simplex-chat
chmod +x simplex-chat
```

Проект SimpleX Chat не публикует предварительно созданный образ Docker для клиента чата; чтобы запустить его в Docker, создайте его из исходного кода из [репозитория simplex-chat](https://github.com/simplex-chat/simplex-chat).

## Запуск демона

```bash
simplex-chat -p 5225
```

По умолчанию демон прослушивает WebSocket по адресу `ws://127.0.0.1:5225`.

## Настройка Гермеса

### Через мастер настройки

```bash
hermes gateway setup
```

Выберите **Чат SimpleX** и следуйте инструкциям.

### Через переменные среды

Добавьте это в `~/.hermes/.env`:

```
SIMPLEX_WS_URL=ws://127.0.0.1:5225
SIMPLEX_ALLOWED_USERS=<contact-id-1>,<contact-id-2>
SIMPLEX_HOME_CHANNEL=<contact-id>
```

| Переменная | Требуется | Описание |
|---|---|---|
| `SIMPLEX_WS_URL` | Да | URL-адрес WebSocket демона simplex-chat |
| `SIMPLEX_ALLOWED_USERS` | Рекомендуется | Белый список, разделенный запятыми. Каждая запись может быть числовым `contactId` **или** отображаемым именем — обе формы работают. |
| `SIMPLEX_ALLOW_ALL_USERS` | Необязательно | Установите `true`, чтобы разрешить каждый контакт (используйте осторожно) |
| `SIMPLEX_AUTO_ACCEPT` | Необязательно | Автоматически принимать входящие запросы на контакт (по умолчанию: `true`) |
| `SIMPLEX_GROUP_ALLOWED` | Необязательно | Идентификаторы групп, в которых участвует бот, разделенные запятыми, или `*` для любой группы. Полностью игнорировать групповые сообщения |
| `SIMPLEX_HOME_CHANNEL` | Необязательно | Идентификатор контакта/группы по умолчанию для доставки заданий cron |
| `SIMPLEX_HOME_CHANNEL_NAME` | Необязательно | Человеческий ярлык для домашнего канала |
| `HERMES_SIMPLEX_TEXT_BATCH_DELAY` | Необязательно | Секунды периода молчания (по умолчанию: `0.8`), используемые для объединения быстрых входящих текстовых сообщений в одно событие |

## Найдите свой идентификатор контакта или отображаемое имя

После запуска демона откройте разговор с контактом вашего агента. Число `contactId` отображается в журналах сеансов. Если вы предпочитаете использовать отображаемое имя, отображаемое в пользовательском интерфейсе SimpleX, это тоже работает — `SIMPLEX_ALLOWED_USERS` принимает любую форму.

## Авторизация

По умолчанию **все контакты запрещены**. Вы должны либо:

1. Задайте для `SIMPLEX_ALLOWED_USERS` разделенный запятыми список `contactId` и/или отображаемых имен (например, `SIMPLEX_ALLOWED_USERS=4,alice` соответствует либо contactId 4, либо контакту, отображаемое имя которого — «Алиса»), или
2. Используйте **Сопряжение с DM** — отправьте боту любое сообщение, и он ответит кодом сопряжения. Введите этот код через `hermes pairing approve simplex <CODE>`.

## Групповые чаты

По умолчанию адаптер игнорирует групповые сообщения — в противном случае бот в группе.
обрабатывает трафик каждого участника. Явно согласитесь:

```
SIMPLEX_GROUP_ALLOWED=12,34          # specific group IDs
# or
SIMPLEX_GROUP_ALLOWED=*              # any group the bot is in
```

Адресуйте группы, добавляя к идентификатору чата префикс `group:`, например:
`simplex:group:12` в качестве цели cron `deliver=` или в вызове `hermes send`.

## Отправка с помощью `hermes send`

SimpleX работает как отдельная цель отправки — демон должен быть запущен,
но для обычного текста живой шлюз не требуется:

```bash
hermes send --to simplex:alice "hello"          # DM by contact display name
hermes send --to simplex:group:12 "hello"       # group by numeric ID
hermes send --to simplex "hello"                # SIMPLEX_HOME_CHANNEL
```

Пока шлюз работает, адаптер перечисляет ваши контакты и
разрешенные группы в каталог каналов (обновляется каждые 5 минут), поэтому
`hermes send --list` показывает их по имени. Прежде чем первый шлюз запустит
платформа по-прежнему отображается в `--list` с надписью «Каналы еще не обнаружены».
подсказка — прямые цели, подобные приведенным выше, работают в любом случае.

## Вложения

Адаптер поддерживает вложения SimpleX в обоих направлениях:

- **Входящие** — входящие изображения, голосовые заметки и файлы принимаются через
  поток XFTP демона (`rcvFileDescrReady` → `/freceive` → дождаться
  `rcvFileComplete`) и появился как `MessageEvent.media_urls` с
  соответствующий `MessageType` (`PHOTO`, `VOICE`, `TEXT` + документ).
- **Исходящие** — `send_image_file`, `send_voice`, `send_document` и
  Все `send_video` используют структурированную форму `/_send` с `filePath`, поэтому
  принимающий клиент SimpleX визуализирует изображения и воспроизводит голос.
  заметки встроены, а не предлагаются для загрузки.

Ответы агента также могут включать теги `MEDIA:/path/to/file` в виде обычного текста —
адаптер удаляет тег из тела и отправляет файл либо как
голосовая заметка (аудиорасширения) или документ.

## Использование SimpleX с заданиями cron

```python
cronjob(
    action="create",
    schedule="every 1h",
    deliver="simplex",          # uses SIMPLEX_HOME_CHANNEL
    prompt="Check for alerts and summarise."
)
```

Или выберите конкретный контакт через поле `deliver:` задания cron или из сценария оболочки с помощью [`hermes send` CLI](/guides/pipe-script-output):

```bash
hermes send simplex:<contact-id> "Done!"
```

## Примечания о конфиденциальности

- SimpleX никогда не раскрывает номера телефонов или адреса электронной почты — контакты используют непрозрачные идентификаторы.
- Соединение между Hermes и демоном осуществляется через локальный WebSocket (`ws://127.0.0.1:5225`) — никакие данные не покидают вашу машину.
- Сообщения шифруются по протоколу SimpleX перед тем, как достичь демона.

## Устранение неполадок

**"Невозможно связаться с демоном"** — убедитесь, что `simplex-chat -p 5225` запущен и порт соответствует `SIMPLEX_WS_URL`.

**"веб-сокеты не установлены"** — запустите `pip install websockets`.

**Сообщения не получены** — убедитесь, что идентификатор контакта находится в `SIMPLEX_ALLOWED_USERS`, или подтвердите его через соединение DM.
