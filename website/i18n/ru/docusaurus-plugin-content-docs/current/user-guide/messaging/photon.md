# Фотон iMessage

Подключите Hermes к **iMessage** через [Photon][photon], управляемый
служба, которая управляет распределением линий Apple и предотвращает злоупотребления
слой, чтобы вам не приходилось запускать собственный ретранслятор Mac.

На бесплатном уровне используется общий пул линий iMessage Photon — другой
получатели могут видеть разные номера отправки, но каждый разговор
остается стабильным. Платный уровень Business предоставляет каждому пользователю одинаковые
выделенный номер; плагин поддерживает оба варианта, а уровень бесплатного пользования — это
рекомендуемая отправная точка.

:::info Бесплатное начало
Общий бассейн Photon предоставляется бесплатно. Для отправки не требуется подписка
ваше первое iMessage от Hermes — просто номер телефона, к которому мы можем привязать
ваш аккаунт.
:::

## Архитектура

Photon — это канал с **постоянным соединением**, такой как Discord или Slack.
**нет веб-перехватчика, нет общедоступного URL-адреса, нет секрета подписи, которым нужно управлять.**

`spectrum-ts` SDK хранит долговременный **поток gRPC** для Photon.
оба направления. Поскольку SDK предназначен только для TypeScript, Hermes запускает его в
small контролирует **Node Sidecar** и обращается к нему через шлейф:

- **Входящий** — коляска использует `app.messages` gRPC SDK.
  поток и пересылает каждое сообщение адаптеру Python через петлю
  `GET /inbound` (NDJSON). Адаптер выполняет дедупликацию и отправляет ее в
  агент, автоматически переподключающийся, если поток прерывается.
- **Исходящие** — ответы представляют собой POST-запросы обратной связи для боковой машины, которая вызывает
  `space.send(...)` в SDK.

Плагин Python запускает, контролирует и выключает коляску.
автоматически.

## Предварительные условия

- Аккаунт Photon — зарегистрируйтесь по адресу [app.photon.codes][app]
- **Node.js 18.17 или новее** в PATH (`node --version`)
- Номер телефона, на который можно получать iMessage (используется для привязки вашей учетной записи)

Вот и все — нет общедоступного URL-адреса или туннеля для настройки.

## Первоначальная настройка

Либо запустите мастер единого шлюза и выберите **Photon iMessage**:

```bash
hermes gateway setup
```

…или запустите настройку Photon напрямую (мастер вызывает тот же процесс):

```bash
# Device-code login + project + user + sidecar deps, all in one
hermes photon setup --phone +15551234567
```

Настройка по порядку:

1. **Вход на устройство** (`client_id=photon-cli`) — открывается.
   `https://app.photon.codes/` для утверждения и сохраняет токен на предъявителя.
2. **Находит или создает** проект `Hermes Agent` в вашем аккаунте.
3. **Включает Spectrum**, считывает идентификатор Spectrum проекта и вращает
   секрет проекта.
4. **Регистрирует ваш номер телефона** в качестве пользователя Spectrum — пропускается, если
   пользователь с таким номером уже существует, поэтому повторный запуск безопасен.
5. **Печатает назначенную вам строку iMessage** — номер, на который вы отправляете текстовое сообщение.
   ваш агент.
6. **Запускает `npm install`** внутри дополнительного каталога плагина. Вкл.
   деревья установки только для чтения/неизменяемые (размещенные образы Docker, Podman,
   Никс) коляска автоматически возвращается к записываемому зеркалу под
   `~/.hermes/photon/sidecar`; установите `PHOTON_SIDECAR_DIR`, чтобы закрепить
   явное местоположение.

Учетные данные времени выполнения записываются в `~/.hermes/.env`.
(`PHOTON_PROJECT_ID` = идентификатор проекта Spectrum, `PHOTON_PROJECT_SECRET`),
там же, где любой другой канал хранит свой токен. Метаданные управления
(токен устройства, идентификатор проекта информационной панели) находится в `~/.hermes/auth.json` под
`credential_pool.photon` / `credential_pool.photon_project`.

## Авторизация пользователей

Photon использует ту же модель авторизации, что и любой другой Hermes.
канал. Выберите один подход:

**Сопряжение с DM (по умолчанию).** Когда неизвестный номер отправляет сообщение на ваш Photon
линии, Гермес отвечает кодом сопряжения. Утвердите это с помощью:

```bash
hermes pairing approve photon <CODE>
```

Используйте `hermes pairing list`, чтобы просмотреть ожидающие коды и одобренных пользователей.

**Предварительная авторизация определенных номеров** (в `~/.hermes/.env`):

```bash
PHOTON_ALLOWED_USERS=+15551234567,+15559876543
```

**Открытый доступ** (только для разработчиков, в `~/.hermes/.env`):

```bash
PHOTON_ALLOW_ALL_USERS=true
```

Если установлен `PHOTON_ALLOWED_USERS`, неизвестные отправители молча
игнорируется, а не предлагает код сопряжения (белый список сигнализирует о том, что вы
намеренно ограничили доступ).

### Требовать упоминания в групповых чатах

По умолчанию Hermes отвечает на каждое авторизованное личное сообщение и групповое сообщение.
Чтобы включить групповые чаты, включите ограничение упоминаний (DM по-прежнему всегда
работа):

```yaml
gateway:
  platforms:
    photon:
      enabled: true
      require_mention: true
```

При использовании `require_mention: true` сообщения группового чата игнорируются, если только
они соответствуют образцу пробуждающего слова. Значения по умолчанию соответствуют `Hermes` и
`@Hermes agent` вариантов. Для имени пользовательского агента установите шаблоны регулярных выражений:

```yaml
gateway:
  platforms:
    photon:
      require_mention: true
      mention_patterns:
        - '(?<![\w@])@?amos\b[,:\-]?'
```

Оба ключа также принимают переменные окружения (`PHOTON_REQUIRE_MENTION`,
`PHOTON_MENTION_PATTERNS`). Это та же самая модель пропуска упоминаний, что и
Использование канала BlueBubbles iMessage.

## Запускаем шлюз

```bash
hermes gateway start
```

Вы увидите что-то вроде:

```
[photon] connected — sidecar on 127.0.0.1:8789, streaming inbound over gRPC
```

Отправьте iMessage на назначенный вам номер, и Hermes ответит.

## Статус и устранение неполадок

```bash
hermes photon status
```

Распечатывает сохраненные учетные данные, информацию о состоянии коляски, ваш зарегистрированный номер и
назначенная строка iMessage, которую использует Hermes. Когда проект токена Photon и информационной панели
доступны, `status` обновляет недостающие числовые строки на информационной панели
без предоставления новых строк.

```
Photon iMessage status
──────────────────────
  device token        : ✓ stored
  dashboard project   : 3c90c3cc-0d44-4b50-...
  spectrum project id : sp-...
  project secret      : ✓ stored
  my number           : +15551234567
  assigned number     : +16282679185
  node binary         : /usr/bin/node
  sidecar deps        : ✓ installed
```

Общие проблемы:

- **`sidecar deps : ✗ run hermes photon install-sidecar`** — Узел
  установлен, но `spectrum-ts` нет. Запустите предложенную команду.
- **`device token : ✗ missing`** — запустите `hermes photon setup` для входа.
- **`No iMessage line assigned yet`** — Спектр включен, но линии нет.
  было предоставлено; перезапустите `hermes photon setup` или проверьте
  [панель управления][приложение].
- **Коляска не заводится** — убедитесь, что `node --version` имеет версию 18,17+ и это
  `hermes photon install-sidecar` выполнено без ошибок.

## Ограничения сегодня

- **Входящие вложения содержат только метаданные.** Входящие события несут
  имя файла + тип MIME; агент видит маркер, но еще не может прочитать
  байты. SDK предоставляет байты вложения через `content.read()`, поэтому это
  это продолжение коляски.
- **Поддерживаются исходящие вложения.** Hermes отправляет изображения и голос.
  заметки, видео и документы через Spectrum-ts' `attachment()` /
  `voice()` конструкторы контента с помощью боковой панели `/send-attachment`
  конечная точка. Подписи появляются в виде отдельного пузырька iMessage после
  СМИ.
- **Поддерживаются собственные опросы.** Hermes отправляет контент опросов через
  построитель `poll()` Spectrum-ts через конечную точку `/send-poll` коляски.
- **Поддерживаются эффекты сообщений.** Hermes отправляет текст с помощью собственного iMessage.
  эффекты пузырьков/экрана с помощью конструктора iMessage `effect()` Spectrum-ts
  через конечную точку `/send-effect` коляски.
- **Бесплатные квоты Photon:** 5000 сообщений на сервер в день,
  50 новых разговоров на общую линию в день. Увеличивает
  доступен — электронная почта `help@photon.codes`.
- **Cron и автономные отправки требуют работающего шлюза.** Вне процесса.
  отправители (задания cron, `hermes send`, панель управления) повторно используют коляску
  шлюз породил — они прочитали его порт/токен из
  `<hermes-home>/runtime/photon-sidecar.json`, написано когда-то в коляске
  проходит проверку работоспособности и удаляется при остановке. Если отдельная отправка
  сообщает, что шлюз не работает, запустите (или перезапустите) шлюз
  сначала.
- **Общие/бесплатные линии не могут инициировать разговоры с новыми
  цели.** Политика на стороне Photon: общая линия может передавать только номер
  после того, как этот номер первым отправил текстовое сообщение. Cron/автономная отправка на
  новый получатель будет отклонен Фотоном, даже если установлен Гермес
  вверх правильно — либо попросите получателя отправить сообщение на линию один раз, либо переместите
  на выделенную линию.

## Переменные окружения

| Переменная | По умолчанию | Заметки |
|---------------------------|--------------------|--------------------------------------------|
| `PHOTON_PROJECT_ID` | от `.env` | Идентификатор проекта Spectrum (SDK `projectId`); устанавливается настройкой |
| `PHOTON_PROJECT_SECRET` | от `.env` | Секрет проекта; устанавливается настройкой |
| `PHOTON_SIDECAR_PORT` | `8789` | Шлейфовый порт для управления коляской + входящий канал |
| `PHOTON_SIDECAR_AUTOSTART`| `true` | Создает ли адаптер коляску |
| `PHOTON_NODE_BIN` | `which node` | Переопределить двоичный путь узла |
| `PHOTON_HOME_CHANNEL` | (не установлено) | Идентификатор пространства по умолчанию для cron/уведомлений |
| `PHOTON_HOME_CHANNEL_NAME`| (не установлено) | Человеческий ярлык для домашнего канала |
| `PHOTON_ALLOWED_USERS` | (не установлено) | Белый список E.164, разделенный запятыми |
| `PHOTON_ALLOW_ALL_USERS` | `false` | Только для разработчиков — принимать любого отправителя |
| `PHOTON_REQUIRE_MENTION` | `false` | Требовать слово для пробуждения, прежде чем отвечать в группах |
| `PHOTON_MENTION_PATTERNS` | Слова пробуждения Гермеса | Шаблоны регулярных выражений списка JSON/запятых/новой строки для упоминаний группы |
| `PHOTON_DASHBOARD_HOST` | `app.photon.codes` | Переопределить хост панели мониторинга/входа в устройство |
| `PHOTON_SPECTRUM_HOST` | `spectrum.photon.codes` | Переопределить хост Spectrum API |
