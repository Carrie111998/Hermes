# IRC

Адаптер IRC подключает Hermes к любому IRC-серверу и передает сообщения между каналом IRC (или прямыми сообщениями) и агентом. Он использует протокол IRC через стандартную библиотеку Python `asyncio` — **без внешних зависимостей, без SDK, без демона**. Он работает с общедоступными сетями, такими как [Libera.Chat](https://libera.chat/) и любыми локальными ircd.

IRC представляет собой обычный текст: нет поддержки голоса, изображения, файла, потока, реакции, ввода или потоковой передачи — ответы отправляются в виде `PRIVMSG` строк, а длинные сообщения разделяются в соответствии с ограничением количества строк IRC.

> Запустите `hermes gateway setup` и выберите **IRC** для пошагового руководства.

## Предварительные условия

– IRC-сервер для подключения (например, `irc.libera.chat`).
- Канал для присоединения (например, `#hermes`) — через запятую для присоединения к нескольким
- Ник для бота (по умолчанию: `hermes-bot`)
- Необязательно: зарегистрированный ник + пароль NickServ, если ваша сеть требует идентификации.

## Настройка Гермеса

Вы можете настроить IRC двумя способами — переменными среды (для быстрой настройки только для env) или блоком `gateway` в `~/.hermes/gateway-config.yaml`.

### Вариант А — шлюз-config.yaml

```yaml
gateway:
  platforms:
    irc:
      enabled: true
      extra:
        server: irc.libera.chat
        port: 6697
        nickname: hermes-bot
        channel: "#hermes"
        use_tls: true
        server_password: ""       # optional server password
        nickserv_password: ""     # optional NickServ identification
        allowed_users: []         # empty = allow all, or list of nicks
        max_message_length: 450   # IRC line limit (safe default)
```

### Вариант Б — переменные среды

| Переменная | Требуется | Описание |
|----------|:--------:|-------------|
| `IRC_SERVER` | ✅ | Имя хоста IRC-сервера (например, `irc.libera.chat`) |
| `IRC_CHANNEL` | ✅ | Канал(ы), к которым нужно присоединиться — несколько через запятую |
| `IRC_NICKNAME` | ✅ | Ник бота (по умолчанию: `hermes-bot`) |
| `IRC_PORT` | — | Порт сервера (по умолчанию: `6697` с TLS, `6667` без) |
| `IRC_USE_TLS` | — | Использовать TLS (`true`/`false`; по умолчанию `true` на порту 6697) |
| `IRC_SERVER_PASSWORD` | — | Пароль сервера для команды `PASS` |
| `IRC_NICKSERV_PASSWORD` | — | Пароль NickServ для автоматической идентификации при подключении |
| `IRC_ALLOWED_USERS` | — | Ники, разделенные запятыми, разрешены для общения с ботом |
| `IRC_ALLOW_ALL_USERS` | — | Разрешить любому пользователю канала общаться с ботом (только для разработчиков) |
| `IRC_HOME_CHANNEL` | — | Канал для cron/доставки уведомлений (по умолчанию `IRC_CHANNEL`) |

## Контроль доступа

По умолчанию с ботом могут общаться только ники, перечисленные в `allowed_users` (или `IRC_ALLOWED_USERS`). Оставьте список пустым **и** установите `IRC_ALLOW_ALL_USERS=true`, чтобы любой участник канала мог общаться с Гермесом — полезно для тестирования, но не рекомендуется в общедоступных сетях, поскольку никнеймы IRC не аутентифицируются, если сеть не применяет NickServ.

Если ваша сеть регистрирует псевдонимы, установите `IRC_NICKSERV_PASSWORD` (или `nickserv_password`), чтобы бот идентифицировался с NickServ при подключении и сохранял свой зарегистрированный псевдоним.

## Каналы против DM

– Сообщения в присоединенном канале рассматриваются как **групповой** разговор.
- Личные сообщения боту считаются **прямыми сообщениями**.

Задания и уведомления Cron доставляются на **домашний канал** — `IRC_HOME_CHANNEL`, если установлено, в противном случае — первый `IRC_CHANNEL`.

## Запускаем шлюз

```bash
hermes gateway start
```

Проверьте статус с помощью `hermes gateway status` — там сообщается о состоянии IRC-соединения, в том числе для настроек только для env.

## Примечания

- Длинные ответы агента автоматически разбиваются на несколько строк `PRIVMSG`, чтобы не выходить за пределы лимита строк IRC (`max_message_length`, по умолчанию 450 байт после служебных данных протокола).
- Адаптер получает ограниченную блокировку учетных данных для каждого сервера + псевдонима, поэтому два профиля Hermes не будут конфликтовать из-за одного и того же идентификатора IRC.
