# Навык карт

Анализ местоположения с использованием бесплатных открытых источников данных. 8 команд, 44 POI
категории, нулевые зависимости (только Python stdlib), ключ API не требуется.

Источники данных: OpenStreetMap/Nominatim, Overpass API, OSRM, TimeAPI.io.

Этот навык заменяет старый навык `find-nearby` — все функции find-nearby.
функциональность обеспечивается приведенной ниже командой `nearby` с той же
`--near "<place>"` ярлыки и поддержка нескольких категорий.

## Когда использовать

- Пользователь отправляет в Telegram метку местоположения (широта/долгота в сообщении) → `nearby`
- Пользователь хочет получить координаты названия места → `search`
- Пользователь имеет координаты и хочет получить адрес → `reverse`
- Пользователь спрашивает ближайшие рестораны, больницы, аптеки, отели и т. д. → `nearby`
- Пользователь хочет проехать на автомобиле/пешеходе/велосипеде расстояние или время в пути → `distance`
– Пользователь хочет получить пошаговые инструкции между двумя местами → `directions`
– Пользователю нужна информация о часовом поясе для определенного местоположения → `timezone`.
- Пользователь хочет найти POI в пределах географической области → `area` + `bbox`

## Предварительные условия

Python 3.8+ (только stdlib — установка pip не требуется).

Путь сценария: `~/.hermes/skills/maps/scripts/maps_client.py`

## Команды

```bash
MAPS=~/.hermes/skills/maps/scripts/maps_client.py
```

### поиск — геокодирование названия места

```bash
python3 $MAPS search "Eiffel Tower"
python3 $MAPS search "1600 Pennsylvania Ave, Washington DC"
```

Возвращает: широта, долгота, отображаемое имя, тип, ограничивающая рамка, показатель важности.

### реверс — Координаты для адреса

```bash
python3 $MAPS reverse 48.8584 2.2945
```

Возвращает: полная разбивка по адресу (улица, город, штат, страна, почтовый индекс).

### рядом — Найдите места по категориям

```bash
# By coordinates (from a Telegram location pin, for example)
python3 $MAPS nearby 48.8584 2.2945 restaurant --limit 10
python3 $MAPS nearby 40.7128 -74.0060 hospital --radius 2000

# By address / city / zip / landmark — --near auto-geocodes
python3 $MAPS nearby --near "Times Square, New York" --category cafe
python3 $MAPS nearby --near "90210" --category pharmacy

# Multiple categories merged into one query
python3 $MAPS nearby --near "downtown austin" --category restaurant --category bar --limit 10
```

46 категорий: ресторан, кафе, бар, больница, аптека, гостиница, гостевой дом,
место для лагеря, супермаркет, банкомат, заправочная станция, парковка, музей, парк, школа,
университет, банк, полиция, пожарная_станция, библиотека, аэропорт, железнодорожная станция,
автобусная остановка, церковь, мечеть, синагога, дантист, врач, кино, театр, тренажерный зал,
плавательный_бассейн, почта, круглосуточный_магазин, пекарня, книжный магазин, прачечная,
автомойка, прокат машин, прокат велосипедов, такси, ветеринария, зоопарк, детская площадка,
стадион, ночной клуб.

Каждый результат включает в себя: `name`, `address`, `lat`/`lon`, `distance_m`,
`maps_url` (кликабельная ссылка на Карты Google), `directions_url` (Карты Google
направления от точки поиска), а также продвигаемые теги, если они доступны —
`cuisine`, `hours` (часы_работы), `phone`, `website`.

### distance — Расстояние и время путешествия.

```bash
python3 $MAPS distance "Paris" --to "Lyon"
python3 $MAPS distance "New York" --to "Boston" --mode driving
python3 $MAPS distance "Big Ben" --to "Tower Bridge" --mode walking
```

Режимы: вождение (по умолчанию), ходьба, езда на велосипеде. Возвращает расстояние, продолжительность,
и расстояние по прямой для сравнения.

### направления — пошаговая навигация

```bash
python3 $MAPS directions "Eiffel Tower" --to "Louvre Museum" --mode walking
python3 $MAPS directions "JFK Airport" --to "Times Square" --mode driving
```

Возвращает пронумерованные шаги с инструкциями, расстоянием, продолжительностью, названием дороги и
тип маневра (поворот, отход, прибытие и т. д.).

### timezone — Часовой пояс для координат

```bash
python3 $MAPS timezone 48.8584 2.2945
python3 $MAPS timezone 35.6762 139.6503
```

Возвращает имя часового пояса, смещение UTC и текущее местное время.

### area — ограничивающая рамка и площадь места.

```bash
python3 $MAPS area "Manhattan, New York"
python3 $MAPS area "London"
```

Возвращает координаты ограничивающего прямоугольника, ширину/высоту в км и приблизительную площадь.
Полезно в качестве входных данных для команды bbox.

### bbox — Поиск внутри ограничительной рамки.

```bash
python3 $MAPS bbox 40.75 -74.00 40.77 -73.98 restaurant --limit 20
```

Находит POI в географическом прямоугольнике. Сначала используйте `area`, чтобы получить
координаты ограничивающего прямоугольника для именованного места.

## Работа с пинами местоположения Telegram

Когда пользователь отправляет PIN-код местоположения, сообщение содержит `latitude:` и
`longitude:` полей. Извлеките их и передайте прямо `nearby`:

```bash
# User sent a pin at 36.17, -115.14 and asked "find cafes nearby"
python3 $MAPS nearby 36.17 -115.14 cafe --radius 1500
```

Представляйте результаты в виде нумерованного списка с именами, расстояниями и
`maps_url`, чтобы пользователь мог открыть ссылку в чате. Для «открытого
сейчас?» вопросы, проверьте поле `hours`; если отсутствует или неясно, проверьте
с `web_search`, поскольку часы OSM поддерживаются сообществом и не всегда
ток.

## Примеры рабочих процессов

**"Найдите итальянские рестораны рядом с Колизеем":**
1. `nearby --near "Colosseum Rome" --category restaurant --radius 500`
   — одна команда, автогеокодирование

**"Что находится рядом с этой меткой, которую они прислали?":**
1. Извлеките широту/долготу из сообщения Telegram.
2. `nearby LAT LON cafe --radius 1500`

**"Как мне пройти от отеля до конференц-центра?":**
1. `directions "Hotel Name" --to "Conference Center" --mode walking`

**"Какие рестораны есть в центре Сиэтла?":**
1. `area "Downtown Seattle"` → получить ограничивающую рамку
2. `bbox S W N E restaurant --limit 30`

## Подводные камни

- Nominatim ToS: максимум 1 запрос/с (автоматически обрабатывается сценарием)
- `nearby` требует широты/долготы ИЛИ `--near "<address>"` — требуется одно из двух
- Покрытие маршрутизации OSRM лучше всего подходит для Европы и Северной Америки.
— Overpass API может работать медленно в часы пик; сценарий автоматически
  возвращается между зеркалами (overpass-api.de → overpass.kumi.systems)
- `distance` и `directions` используют флаг `--to` для пункта назначения (не позиционный)
– Если один только почтовый индекс дает неоднозначные результаты во всем мире, укажите страну/штат.
