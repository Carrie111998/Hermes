#песню

Создавайте спектрограммы и многопанельные визуализации аудиофункций из аудиофайлов.

## Предварительные условия

Требуется [Go](https://go.dev/doc/install):
```bash
go install github.com/steipete/songsee/cmd/songsee@latest
```

Необязательно: `ffmpeg` для форматов, отличных от WAV/MP3.

## Быстрый старт

```bash
# Basic spectrogram
songsee track.mp3

# Save to specific file
songsee track.mp3 -o spectrogram.png

# Multi-panel visualization grid
songsee track.mp3 --viz spectrogram,mel,chroma,hpss,selfsim,loudness,tempogram,mfcc,flux

# Time slice (start at 12.5s, 8s duration)
songsee track.mp3 --start 12.5 --duration 8 -o slice.jpg

# From stdin
cat track.mp3 | songsee - --format png -o out.png
```

## Типы визуализации

Используйте `--viz` со значениями, разделенными запятыми:

| Тип | Описание |
|------|-------------|
| `spectrogram` | Спектрограмма стандартной частоты |
| `mel` | Мел-масштабированная спектрограмма |
| `chroma` | Распределение классов смолы |
| `hpss` | Гармоническое/ударное разделение |
| `selfsim` | Матрица самоподобия |
| `loudness` | Громкость с течением времени |
| `tempogram` | Оценка темпа |
| `mfcc` | Мел-частотные кепстральные коэффициенты |
| `flux` | Спектральный поток (обнаружение начала) |

Несколько типов `--viz` отображаются в виде сетки в одном изображении.

## Общие флаги

| Флаг | Описание |
|------|-------------|
| `--viz` | Типы визуализации (через запятую) |
| `--style` | Цветовая палитра: `classic`, `magma`, `inferno`, `viridis`, `gray` |
| `--width` / `--height` | Размеры выходного изображения |
| `--window` / `--hop` | Окно БПФ и размер скачка |
| `--min-freq` / `--max-freq` | Фильтр частотного диапазона |
| `--start` / `--duration` | Временной интервал аудио |
| `--format` | Формат вывода: `jpg` или `png` |
| `-o` | Путь к выходному файлу |

## Примечания

- WAV и MP3 декодируются изначально; для других форматов требуется `ffmpeg`
- Выходные изображения можно проверить с помощью `vision_analyze` для автоматического анализа звука.
- Полезно для сравнения аудиовыходов, отладки синтеза или документирования конвейеров обработки звука.
