# Xlsx навык

Работа с книгами Excel .xlsx с использованием Python и openpyxl: создание стиля
многолистовые книги с формулами и диаграммами, проверка или удаление существующих
файлы, редактировать ячейки и структуру, а также конвертировать в/из CSV. Все помощники
сценарии представляют собой CLI argparse, которые печатают JSON и используют явный ввод-вывод UTF-8.

## Когда использовать

- Создание отчетов .xlsx: несколько листов, числовые форматы, стили,
  объединенные ячейки, закрепить панели, автофильтр, условное форматирование,
  диаграммы, раскрывающиеся списки для проверки данных.
- Чтение книги: инвентаризация листов, выгрузка данных в формате JSON или CSV,
  формулы списка и кэшированные значения.
- Редактирование существующих файлов: установка ячеек, добавление строк, вставка/удаление.
  строки/столбцы, копирование/переименовывание листов.
- Взаимодействие CSV с выводом типа и кодировками, отличными от UTF-8.
- Не для устаревшего двоичного формата .xls (используйте LibreOffice для преобразования
  сначала: `soffice --headless --convert-to xlsx old.xls`).

## Предварительные условия

- Python 3.10+ с `openpyxl` (`pip install openpyxl`). Никакой другой
  нужны сторонние пакеты; все остальное — стандартная библиотека.
- Необязательно: LibreOffice (`soffice`) для безголового пересчета или
  преобразование формата.

## Как бежать

Запустите вспомогательные сценарии с помощью инструмента `terminal` из этого навыка.
Каталог `scripts/` (каждый скрипт поддерживает `--help`):

```bash
python scripts/xlsx_create.py spec.json report.xlsx   # build from JSON spec
python scripts/xlsx_read.py report.xlsx --sheets      # inventory
python scripts/xlsx_read.py report.xlsx --json --sheet Data
python scripts/xlsx_read.py report.xlsx --formulas
python scripts/xlsx_edit.py report.xlsx --sheet Data --set B2=42 --recalc
python scripts/csv_to_xlsx.py data.csv out.xlsx --encoding utf-8
python scripts/xlsx_to_csv.py report.xlsx out.csv --sheet Data
```

Создайте спецификацию JSON с помощью `write_file`, проверьте выходные данные JSON сценария с помощью
`read_file` или непосредственно из стандартного вывода.

## Краткий справочник

| Задача | Команда |
|---|---|
| Создать книгу из спецификации | `xlsx_create.py spec.json out.xlsx` |
| Названия листов + размеры | `xlsx_read.py f.xlsx --sheets` |
| Дамп-лист в формате JSON | `xlsx_read.py f.xlsx --json --sheet S` |
| Дамп листа в формате CSV | `xlsx_read.py f.xlsx --csv --out d.csv` |
| Получение списка формул + кэшированные значения | `xlsx_read.py f.xlsx --formulas` |
| Установить ячейку/формулу | `xlsx_edit.py f.xlsx --set "A1==SUM(B:B)"` |
| Добавить строку | `xlsx_edit.py f.xlsx --append '[1,"x",true]'` |
| Вставить 2 строки перед строкой 3 | `xlsx_edit.py f.xlsx --insert-rows 3:2` |
| Копировать/переименовать лист | `--copy-sheet Src:New --rename-sheet Old:New` |
| Принудительный пересчет при открытии | `xlsx_edit.py f.xlsx --recalc` |
| CSV -> стиль xlsx | `csv_to_xlsx.py in.csv out.xlsx` |
| xlsx -> CSV | `xlsx_to_csv.py f.xlsx out.csv --encoding utf-8` |

## Процедура

1. **Создать**: напишите спецификацию JSON (схема описана в
   `xlsx_create.py --help` и его строка документации). Каждый лист поддерживает
   `rows` (скаляры или стилизованные объекты ячеек), разреженные переопределения `cells`,
   `column_widths`, `row_heights`, `merges`, `freeze_panes`,
   `autofilter`, `conditional_formats` (правила и цвет ячейки_is
   масштабы), `charts` (столбик/линия/круговая диаграмма из диапазонов ячеек) и
   `validations` (раскрывающийся список). Типизированные значения: числа JSON/логические значения.
   пройти; даты используют `{"value": "2026-01-31", "type": "date"}`.
   Числовые форматы — это строки формата Excel: валюта `"$#,##0.00"`,
   процент `"0.0%"`, дата `"yyyy-mm-dd"`.
2. **Формулы**: задаются с помощью `"formula": "SUM(B2:B9)"` в спецификации или
   `--set "C1==SUM(A:A)"` в редакторе. При написании формул добавляйте
   `"full_calc_on_load": true` (спецификация) или `--recalc` (редактор); это устанавливает
   флаг `fullCalcOnLoad` книги, чтобы Excel/LibreOffice пересчитал
   все на открытом месте. Сам openpyxl НИКОГДА не оценивает формулы.
3. **Читать**: `--sheets` для инвентаря (имена, размеры, объединенные
   диапазоны, количество диаграмм), `--json`/`--csv` для данных, `--formulas` до
   соедините каждую строку формулы с ее кэшированным результатом. Кэшированные результаты
   существовать только в том случае, если файл последний раз сохранялся в реальном приложении для работы с электронными таблицами;
   файлы, свежие из openpyxl, возвращают туда `null`. Чтобы материализовать
   результаты бездумно: `soffice --headless --convert-to xlsx file.xlsx`
   затем перезагрузите с помощью `--data-only`.
4. **Изменить**: `xlsx_edit.py` сначала применяет переименование/копирование, затем
   структурная строка/столбец изменяется, затем `--set`/`--append`. Он редактируется в
   место, если не указан `--out` — сначала скопируйте файл, если вам нужен
   оригинал.
5. **Взаимодействие с CSV**: `csv_to_xlsx.py` выводит дату int/float/bool/ISO.
   на ячейку и стилизует строку заголовка; `xlsx_to_csv.py` записывает ISO
   даты и пустые строки для пустых ячеек. Оба по умолчанию используют UTF-8 и
   принять `--encoding` (например, `utf-8-sig` для спецификации, оптимизированной для Excel,
   `cp1252` для экспорта устаревших версий Windows).

## Подводные камни

- **openpyxl не выполняет вычисления.** Доступны только результаты формул
  через `load_workbook(path, data_only=True)` и только тогда, когда файл был
  ранее сохраненный в Excel/LibreOffice. В противном случае вы получите `None`.
- **Вставка/удаление не приводит к смещению ссылок.** `insert_rows`,
  `delete_cols` и т. д. перемещают значения ячеек, но НЕ обновляют объединенную ячейку.
  диапазоны, ссылки на формулы, привязки диаграммы или условное форматирование.
  диапазоны. После структурных изменений на листах со слияниями или формулами
  перепроверьте их с помощью `--sheets` и `--formulas` и исправьте вручную.
- **`data_only=True` then save** автоматически отменяет все формулы.
  (кэшированные значения заменяют их). Никогда не сохраняйте книгу, загруженную таким образом.
  если только это не цель.
- **Загрузка полосок диаграмм/изображений**: openpyxl не выполняет двусторонний обмен данными.
  диаграммы, поэтому при редактировании книги с диаграммами и сохранении диаграммы удаляются.
  Добавляйте диаграммы повторно после редактирования или избегайте повторного сохранения файлов диаграмм.
- **Ловушки локали CSV**: всегда передаются явные кодировки (скрипты
  уже есть) и помните, что европейские CSV часто используют разделители `;` и
  десятичные запятые — используйте `--delimiter ';'` и ожидайте строки типа
  `"12,5"`, чтобы оставаться строкой.
- **Даты — это дата-время**: Excel хранит даты в виде серийных номеров;
  openpyxl возвращает `datetime`/`date` объектов. Свалки здесь излучают ISO
  струны.
– Имена листов ограничены 31 символом и отклоняют `[ ] : * ? / \`.

## Проверка

- После создания: `xlsx_read.py out.xlsx --sheets` и листа подтверждения.
  имена, измерения, объединенные диапазоны и количество диаграмм соответствуют замыслу.
– Сбросьте данные с помощью `--json` и сравните их с исходными значениями.
- После правок: пересохранить затронутый диапазон; если бы формулы были написаны,
  подтвердите, что `--formulas` перечисляет их и что `--recalc` был применен.
- Для полной визуальной проверки откройте в LibreOffice:
  `soffice --headless --convert-to pdf out.xlsx` и проверьте PDF-файл.
