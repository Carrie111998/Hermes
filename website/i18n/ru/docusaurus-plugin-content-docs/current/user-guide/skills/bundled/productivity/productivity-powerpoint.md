# Навык Powerpoint

Создавайте, проверяйте и редактируйте презентации PowerPoint (.pptx) с помощью
библиотека python-pptx. Четыре вспомогательных сценария охватывают создание колоды из JSON.
спецификации, структурированное чтение, редактирование на месте и бренд на основе шаблонов.
колоды — все в автономном режиме, установка PowerPoint не требуется.

## Когда использовать

- Пользователь просит создать слайд-презентацию, презентацию отчета или презентацию.
- Вам необходимо извлечь текст, заметки, таблицы, данные диаграммы или изображения из файла.
  .pptx кто-то поделился.
- Вам необходимо обновить существующую колоду: заменить текст, обновить данные диаграммы,
  поменять логотип, удалить или изменить порядок слайдов.
- Вы должны создать фирменную презентацию на основе шаблона компании в формате .pptx.
- НЕ используйте это для файлов .ppt (устаревшие двоичные файлы) — сначала преобразуйте их с помощью
  `soffice --convert-to pptx old.ppt`, если доступен LibreOffice.

## Предварительные условия

- Python 3.10+ с установленным `python-pptx`
  (`pip install python-pptx`). Подушка не является обязательной (только если вам необходимо).
  проверьте размеры изображения самостоятельно).
- Необязательно: LibreOffice (`soffice`) для рендеринга слайдов в изображения для
  визуальная проверка. Деградируйте корректно, если его нет — все создавать/читать/редактировать
  операции работают и без него.
– Проверьте наличие через `terminal`:
  `python3 -c "import pptx; print(pptx.__version__)"` и `which soffice`.

## Как бежать

Все скрипты находятся в `scripts/`, берут `--help`, выводят JSON на стандартный вывод и
выход ненулевой в случае неудачи. Запустите их с помощью `terminal`:

```bash
python3 scripts/pptx_create.py deck.json out.pptx
python3 scripts/pptx_read.py deck.pptx --outline      # full JSON outline
python3 scripts/pptx_read.py deck.pptx --notes        # speaker notes
python3 scripts/pptx_read.py deck.pptx --images ./img # export pictures
python3 scripts/pptx_edit.py deck.pptx --replace-text "Old Corp" "New Corp"
python3 scripts/pptx_edit.py deck.pptx --chart-data update.json
python3 scripts/pptx_edit.py deck.pptx --remove-slide 3 --move-slide 2 0
python3 scripts/pptx_from_template.py brand.pptx out.pptx --values vals.json
```

Создание спецификаций JSON с помощью `write_file`; проверить вывод скрипта и сгенерировать
JSON с `read_file`.

## Краткий справочник

| Задача | Команда |
|---|---|
| Новая колода из спецификации | `pptx_create.py spec.json out.pptx` |
| 16:9 против 4:3 | `"slide_size": "16:9"` или `"4:3"` в спецификации |
| Схема в формате JSON | `pptx_read.py deck.pptx --outline` |
| Экспорт изображений | `pptx_read.py deck.pptx --images DIR` |
| Заменить текст | `pptx_edit.py deck.pptx --replace-text OLD NEW` |
| Обновить график | `pptx_edit.py deck.pptx --chart-data spec.json` |
| Обменять картинку | `pptx_edit.py deck.pptx --swap-image N NAME new.png` |
| Удалить слайд | `pptx_edit.py deck.pptx --remove-slide N` |
| Изменение порядка слайдов | `pptx_edit.py deck.pptx --move-slide FROM TO` |
| Заполнить шаблон | `pptx_from_template.py tpl.pptx out.pptx --values v.json` |

## Процедура

### 1. Создайте колоду

Напишите спецификацию JSON (полный формат см. в `pptx_create.py --help`), затем
запустите `pptx_create.py`. Для каждого слайда вы можете установить: `layout` (заголовок,
title_content, раздел, two_content, title_only, пусто), `title`,
`subtitle`, `bullets` (строки или словари с `level` 0–4, `size` pt,
`bold`, `italic`, `font`, `color` шестнадцатеричный), `images` (путь + влево/вверх/ширину/
высота в дюймах), `tables` (`rows` в виде списка списков), `shapes`
(прямоугольник, округлый_прямоугольник, овал, ромб, стрелка вправо, шеврон, с
`fill` шестнадцатеричный + необязательный `text`), `charts` (бар, bar_h, линия, круговая диаграмма с
`categories` + `series`) и `notes` (заметки докладчика).

### 2. Прочтите колоду

`pptx_read.py deck.pptx --outline` возвращает размер слайда, инвентарь макета,
и для каждого слайда: название макета, все тексты фигур, ячейки таблицы, инвентарь изображений.
(имя файла/расширение/байты), категории/серии/значения диаграммы и заметки докладчика.
Используйте `--images DIR` для сохранения встроенных изображений в файлы, а затем
`vision_analyze` на любом экспортированном изображении, если вам нужно просмотреть его содержимое.

### 3. Редактировать колоду

`pptx_edit.py` объединяет операции за один проход; используйте `--output`, чтобы сохранить
оригинал. Замена текста сканирует фигуры слайдов, ячейки таблиц и примечания.
Обновление диаграммы использует `chart.replace_data()` со спецификацией JSON, именующей
Указатель слайдов/диаграмм и новые категории/серии. Замена изображений перенацеливает
идентификатор отношения изображения, поэтому положение и размер сохраняются. Слайд
при удалении удаляются отношения и запись `<p:sldId>`; изменить порядок ходов
элемент `<p:sldId>` внутри `<p:sldIdLst>` (python-pptx не имеет общедоступного
API для любого из них — скрипт выполняет работу на уровне XML).

### 4. Сборка по шаблону

`pptx_from_template.py` открывает бренд .pptx, заменяет каждый
`{{token}}` из значений JSON в слайдах, таблицах и заметках и может добавлять
новые слайды, использующие собственные макеты шаблона (по имени макета или индексу)
поэтому они наследуют шрифты и цвета мастера. Совет: начать с
шаблон без слайдов, затем удалите существующие с помощью
`pptx_edit.py --remove-slide`.

### 5. Визуальная проверка (опционально)

Если `soffice` существует, отобразите слайды в PNG и проверьте их с помощью
`vision_analyze`:

```bash
soffice --headless --convert-to png --outdir ./render deck.pptx  # slide 1
soffice --headless --convert-to pdf --outdir ./render deck.pptx  # all slides
```

Экспорт PNG отображает только первый слайд; конвертировать в PDF все слайды
(затем `pdftoppm -png render/deck.pdf render/slide`, если Попплер
имеется). Если `soffice` отсутствует, используйте структуру JSON из
`pptx_read.py` — проверяет содержание и структуру, а не визуальные эффекты.

## Подводные камни

- **Выполнить разделение**: PowerPoint фрагментирует текст абзаца на несколько
  работает на границах проверки орфографии и форматирования. `--replace-text`
  сохраняет форматирование точно тогда, когда совпадение находится в пределах одного прогона; когда
  совпадение охватывает прогоны, абзац перезаписывается только с использованием первого прогона
  форматирование. Проверьте важные слайды после замены.
- **Переупорядочение осуществляется на уровне XML**: python-pptx не поддерживает API изменения порядка.
  `--move-slide` напрямую манипулирует `<p:sldIdLst>`; это безопасно для
  обычные колоды, но потом перечитайте колоду для подтверждения.
- **Копирование слайдов между деками не поддерживается** — макеты, изображения и
  отношениям потребуется глубокое клонирование. Восстановить слайд в целевом объекте
  вместо этого колода.
- Редактирование диаграммы заменяет весь набор данных; вы не можете исправить одну ячейку.
  Добавление/удаление серий работает, а изменение *типа* диаграммы — нет.
— Шаблон python-pptx по умолчанию — 4:3; скрипт создания устанавливает 16:9
  если в спецификации не указано иное. Пользовательские шаблоны сохраняют свой размер.
- Индексы макета различаются в зависимости от шаблона. Для шаблонов брендов укажите названия макетов списка.
  первый: `pptx_read.py template.pptx --outline` (`layouts_available`).
- `slide.shapes.title` имеет значение «Нет» на пустых макетах — сценарий создания.
  обрабатывает это, но помните об этом при написании специального кода Python-pptx.
- Всегда передайте `encoding="utf-8"` при написании файлов спецификаций; жетоны, такие как
  `{{city}}` может быть заполнен значениями, отличными от ASCII.

## Проверка

1. После любого создания/редактирования запустите `pptx_read.py OUT.pptx --outline` и проверьте
   количество слайдов, тексты, таблицы, примечания и значения диаграмм соответствуют замыслу.
2. `--images DIR`, затем проверка размера файла подтверждает вставленные изображения.
3. Для колод с высокими ставками выполните рендеринг через `soffice` (см. шаг процедуры 5) и
   просмотрите каждое изображение слайда с помощью `vision_analyze`.
4. Включенный набор тестов представляет собой полный контракт:
   `python3 -m pytest tests/ -q` (требуется python-pptx + pytest).
