# Проверка живого DOM рабочего стола Hermes

## Обзор

Когда вы разрабатываете `apps/desktop` и пользователь запускает это же приложение
(`hgui` / `npm run dev`), вы можете прочитать **отрисованный в реальном времени DOM** окна.
они смотрят — вычисленные стили, геометрия, какое правило CSS действительно выиграло,
вывод консоли — вместо того, чтобы сделать вывод из `.tsx` и оказаться неверным.

Сервер разработки открывает порт протокола Chrome DevTools на `127.0.0.1:9222`.
автоматически. Средство рендеринга представляет собой страницу Chromium, поэтому все, что DevTools может прочитать,
сценарий может читать.

**Это не заменяет просмотр.** CDP отвечает на *фактические* вопросы («что
это вычисленное заполнение", "отрисовывался ли этот элемент", "какой селектор соответствует").
Он не может сказать вам, выглядит ли результат хорошо. Цветовой баланс, ощущение пространства,
и «это уродливо» все равно нужны глаза пользователя или скриншот. Отвечайте на факты с помощью
CDP; эстетика рук для пользователя.

## Когда использовать

- Проверка того, что изменение пользовательского интерфейса действительно вступило в силу в работающем приложении.
- «Почему этот элемент все еще X?» — найдите выигрышное правило, прежде чем что-либо редактировать
- Поиск стабильного селектора для компонента, который вы собираетесь изменить.
- Проверка вычисленного значения токена дизайна на реальном узле.
- Чтение ошибок консоли рендеринга, которые пользователь упоминает, но не может скопировать.

**Не используйте для:** профилирования производительности или работы с кучей (`node-inspect-debugger`,
`debugging-hermes-desktop`) или что-нибудь еще, где настоящий вопрос звучит так: «Это
посмотрите правильно».

## Порт

Открыто `127.0.0.1:9222` для запуска любого сервера разработки. Закрыто ровно в двух случаях
(`apps/desktop/electron/dev-cdp.ts`):

- **пакетные сборки** — всегда, и никакие значения среды не переопределяют их;
- **нет `HERMES_DESKTOP_DEV_SERVER`** — неупакованный `electron .` против
  `dist/` — это то, как упакованное приложение проходит дымовое тестирование, поэтому оно ведет себя как таковое.

`HERMES_DESKTOP_CDP_PORT` перемещает порт (`=9333`) или отключает его (`=off`).

Прежде чем делать что-либо еще, проверьте:

```bash
curl -s --max-time 3 http://127.0.0.1:${HERMES_DESKTOP_CDP_PORT:-9222}/json/version
```

Пусто → нет порта. Не угадывайте молча другой порт.

**Никогда не перезапускайте приложение пользователя, чтобы получить порт.** Это разрушает его сеанс и
их состояние. Вместо этого запустите свой собственный изолированный экземпляр (ниже).

## Чтение DOM

`apps/desktop/scripts/eval.mjs` — это однострочный текст:

```bash
cd apps/desktop
node scripts/eval.mjs "document.querySelectorAll('[data-slot]').length"
```

Для многошаговой работы используйте общий клиент — у него есть обнаружение целей и
оценка с учетом обещаний:

```js
import { CDP, SELECTORS } from './scripts/perf/lib/cdp.mjs'

const cdp = await CDP.connect({ port: 9222, match: '5174' })
const out = await cdp.eval(`JSON.stringify({
  radius: getComputedStyle(document.documentElement).getPropertyValue('--radius-scalar').trim(),
  composer: !!document.querySelector('[data-slot="composer-rich-input"]')
})`)
cdp.close()
```

`SELECTORS` в `scripts/perf/lib/cdp.mjs` содержит стабильные крючки `data-slot`.
(композитор, окно просмотра резьбы, сообщение помощника, пара витков, профильная направляющая). Предпочитаю
им пришлось изобретать `querySelector` — они обновляются как единое целое, когда
компоненты перемещаются.

## Вопрос, который он лучше всего решает: какое правило выиграло?

Редактировать каждое место вызова из-за того, что стиль «не подходит», — это классическая растрата.
Сначала прочитайте реальный узел:

```js
const el = document.querySelector('[data-slot="aui_assistant-message-root"] a')
JSON.stringify({
  ownClasses: el.className,
  weight: getComputedStyle(el).fontWeight,
  parents: (() => {
    const out = []
    let n = el
    while ((n = n.parentElement) && out.length < 6) out.push(n.className)
    return out
  })()
})
```

Если узел не содержит собственного класса, значение **унаследовано** — очистка
сайты вызовов не исправят это, и вам нужно правило предка. Таблица стилей плагина
(например, `prose a { font-weight: 500 }` из `@tailwindcss/typography`) обычно превосходит
класс полезности; переопределить общий класс, а не при каждом использовании.

## Ваш собственный изолированный экземпляр

Когда порта нет или нельзя беспокоить окно пользователя:

```bash
cd apps/desktop
HERMES_HOME=/tmp/cdp-probe-home \
HERMES_DESKTOP_DEV_SERVER=http://127.0.0.1:5174 \
HERMES_DESKTOP_CDP_PORT=9333 \
  npx electron . --user-data-dir=/tmp/cdp-probe-userdata
```

Отдельный `--user-data-dir` обходит одноэкземплярную блокировку Electron, поэтому
не может столкнуться с работающим `hgui`; отдельный `HERMES_HOME` удерживает его подальше
из реальных сессий. По той же причине выберите порт, отличный от 9222. Запустите это
фон и убейте его, когда закончите.

`npm run perf:serve` делает то же самое со встроенной температурой `HERMES_HOME`, если вы
также хочу перфорированную подвеску.

## Подводные камни

- **Никогда не отключайте сервер разработки или приложение пользователя, чтобы «освободить» что-либо.**
  убить пул сокетов Chromium ядерным оружием и в результате получить `ERR_NETWORK_CHANGED`
  его обвиняют во всем, что вы только что изменили.
- **У одноразового `HERMES_HOME` нет серверной части.** Приложение регистрирует `ECONNREFUSED` для
  `hermes:api` и может выйти самостоятельно. Рендерер все еще монтируется, а DOM
  читаемый — читайте быстро и не принимайте самовозбуждающийся зонд за сломанный
  порт. Chromium регистрирует `DevTools listening on ws://127.0.0.1:<port>/…`, когда
  связывает; эта строка является доказательством открытия порта.
- **Опрос, не проверяйте один раз.** Только что запущенному приложению требуется секунда или две, прежде чем
  порт отвечает.
- **Никогда не сбрасывайте весь DOM.** Рабочий стол отображает сотни узлов и
  `outerHTML` похоронит ваш контекст. Спроектируйте небольшой объект JSON внутри
  оцененное выражение.
- **Передайте `match` на `CDP.connect`.** Без него вы можете привязаться к питомцу.
  наложение, окно быстрого входа или цель devtools вместо главного окна.
- **`cdp.eval` возвращает значение; raw `Runtime.evaluate` выполняет двойное вложение**
  (`.result.result.value`). Используйте обертку.
- **`import.meta.env.DEV` — это `true` под `vite dev`** в этом репозитории. Примечание в
  `apps/desktop/scripts/profile-typing-lag.md` Утверждения об обратном устарели.
