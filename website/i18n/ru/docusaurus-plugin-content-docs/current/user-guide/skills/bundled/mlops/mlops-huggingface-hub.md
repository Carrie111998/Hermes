# Справочное руководство по интерфейсу командной строки Hugging Face (`hf`)

Команда `hf` — это современный интерфейс командной строки для взаимодействия с Hugging Face Hub, предоставляющий инструменты для управления репозиториями, моделями, наборами данных и пространствами.

> **ВАЖНО:** Команда `hf` заменяет устаревшую команду `huggingface-cli`.

## Быстрый старт
* **Установка:** `curl -LsSf https://hf.co/cli/install.sh | bash -s`
* **Справка.** Используйте `hf --help` для просмотра всех доступных функций и реальных примеров.
* **Аутентификация:** рекомендуется использовать переменную среды `HF_TOKEN` или флаг `--token`.

---

## Основные команды

### Общие операции
* `hf download REPO_ID`: Загрузка файлов из Hub.
* `hf upload REPO_ID`: Загрузка файлов и папок (рекомендуется для одиночной фиксации; также поддерживается возобновляемая загрузка больших каталогов).
* `hf upload-large-folder REPO_ID LOCAL_PATH`: **[Устарело]** — вместо этого используйте `hf upload`.
* `hf sync`: синхронизировать файлы между локальным каталогом и корзиной.
* `hf env` / `hf version`: просмотр сведений о среде и версии.

### Аутентификация (`hf auth`)
* `login` / `logout`: управляйте сеансами с помощью токенов из [huggingface.co/settings/tokens](https://huggingface.co/settings/tokens).
* `list` / `switch`: управление несколькими сохраненными токенами доступа и переключение между ними.
* `whoami`: Определите учетную запись, с которой вы вошли в систему.

### Управление репозиторием (`hf repos`)
* `create` / `delete`: создание или окончательное удаление репозиториев.
* `duplicate`: клонируйте модель, набор данных или пространство с новым идентификатором.
* `move`: Перенос репозитория между пространствами имен.
* `branch` / `tag`: Управление ссылками в стиле Git.
* `delete-files`: удаление определенных файлов с помощью шаблонов.

## Взаимодействия со специализированным хабом

### Наборы данных и модели
* **Наборы данных:** `hf datasets list`, `info` и `parquet` (список URL-адресов паркета).
* **SQL-запросы:** `hf datasets sql SQL` — выполнение необработанного SQL через DuckDB для URL-адресов паркета набора данных.
* **Модели:** `hf models list` и `info`.
* **Гуматы:** `hf papers ls` — Просмотр ежедневных газет.

### Обсуждения и запросы на включение (`hf discussions`)
* Управляйте жизненным циклом вкладов Hub: `list`, `create`, `info`, `comment`, `close`, `reopen` и `rename`.
* `diff`: просмотр изменений в PR.
* `merge`: Завершить запросы на включение.

### Инфраструктура и вычисления
* **Конечные точки.** Развертывание и управление конечными точками вывода (`deploy`, `pause`, `resume`, `scale-to-zero`, `catalog`).
* **Работы:** Выполняйте вычислительные задачи в высокочастотной инфраструктуре. Включает `hf jobs uv` для запуска сценариев Python со встроенными зависимостями и `stats` для мониторинга ресурсов.
* **Пространства:** Управление интерактивными приложениями. Включает `dev-mode` и `hot-reload` для файлов Python без полного перезапуска.

### Хранение и автоматизация
* **Сегменты:** Полное управление сегментами в стиле S3 (`create`, `cp`, `mv`, `rm`, `sync`).
* **Кэш:** Управляйте локальным хранилищем с помощью `list`, `prune` (удаление отдельных ревизий) и `verify` (проверка контрольной суммы).
* **Веб-перехватчики.** Автоматизируйте рабочие процессы, управляя веб-перехватчиками Hub (`create`, `watch`, `enable`/`disable`).
* **Коллекции.** Организуйте элементы Hub в коллекции (`add-item`, `update`, `list`).

## Расширенное использование и советы

### Глобальные флаги
* `--format json`: Обеспечивает машиночитаемый вывод для автоматизации.
* `-q` / `--quiet`: ограничивает вывод только идентификаторами.

### Расширения и навыки
* **Расширения:** Расширьте функциональность CLI через репозитории GitHub с помощью `hf extensions install REPO_ID`.
* **Навыки.** Управляйте навыками помощника ИИ с помощью `hf skills add`.
