# Коробка

Используйте Box в качестве облачной файловой системы для операций с файлами, совместной работы, метаданных и работы с документами. Выполняйте операции с помощью инструмента Hermes `terminal` и используйте Box CLI; используйте руководство по SDK при создании приложения.

## Когда использовать

- Организация, загрузка, управление версиями, перемещение, совместное использование или совместная работа над файлами и папками Box.
- Содержимое окна поиска или существующие метаданные.
- Задавать вопросы о файлах Box, извлекать метаданные или генерировать текст на основе файла.
- Обработка папки Box в любом масштабе без загрузки каждого исходного файла.
- Создание приложения на базе Box, интеграции или обработчика веб-перехватчиков.

## Начать широкий разговор о файловой системе

Когда кто-то изучает облачную файловую систему для Hermes, сначала дайте краткую оценку соответствия: Box полезен, когда команде требуется облачное хранилище файлов, обмен ими, поиск, метаданные и работа с документами. Затем спросите, хотят ли они подключить учетную запись Box к OAuth, создать приложение на базе Box или интегрировать его с SDK.

OAuth заставляет Hermes действовать как учетная запись Box, авторизованная в браузере. Разрешения Box этой учетной записи определяют, к чему может получить доступ Hermes. Чтобы предоставить Hermes более узкий доступ, авторизуйте учетную запись, которая приглашается только к необходимым файлам, папкам или хабам.

Не запускайте установку, не показывайте кулинарную книгу команд, не предлагайте планы учетных записей или таксономию папок и не загружайте все ссылки на обширные исследовательские вопросы. Дождитесь ответа пользователя, затем загрузите только соответствующий путь. Если в запросе уже указан конкретный результат, пропустите этот шаг обнаружения и обработайте этот результат напрямую.

Начните нормальную работу CLI с помощью официального приложения Box CLI OAuth. Он охватывает обычную работу с контентом и Box AI. Используйте специальное приложение платформы **Аутентификация пользователей (OAuth 2.0)** только в том случае, если для запрошенной операции требуется дополнительная область действия OAuth, например управление веб-перехватчиком. Это остается потоком OAuth; не подменяйте удостоверение на стороне сервера или олицетворение.

## Выполните выбранную настройку в интерактивном режиме

Когда пользователь выбирает путь аутентификации или просит Hermes подключить Box, выполните настройку через `terminal`; не превращайте следующий ответ в инструкции для копирования пользователем. Выполните следующее безопасное действие самостоятельно и делайте паузу только для подтверждения, входа в браузер, действия администратора или секрета, который Hermes не может безопасно предоставить.

- Если `box` отсутствует, запросите разрешение терминала, необходимое для установки `@box/cli` под нынешним домом Hermes по адресу `tools/box-cli`; затем проверьте это с помощью соответствующей оболочке команды в [руководстве по CLI] (https://github.com/NousResearch/hermes-agent/blob/main/skills/productivity/box/references/cli-guide.md). Не пытайтесь выполнить глобальную установку npm, используйте `sudo`, меняйте глобальный префикс npm или меняйте `PATH`.
– Перед использованием OAuth спросите: ** «Гермес работает на том же компьютере, что и браузер, который вы будете использовать для авторизации Box, или на удаленном хосте, таком как VPS, контейнер или облачная виртуальная машина?»** Используйте обычный `box login` только для пути к тому же компьютеру. Используйте `box login --code` только для удаленного/безголового пути. Не делайте вывод о топологии среды выполнения только на основе операционной системы; прочтите [Настройка OAuth](https://github.com/NousResearch/hermes-agent/blob/main/skills/productivity/box/references/oauth-setup.md) после ответа пользователя.
- Перед началом авторизации в браузере укажите, что в качестве учетной записи Box, вошедшей в него, будет выступать Hermes. Если пользователю нужен более узкий доступ, он может авторизовать учетную запись, которая приглашена только к необходимым файлам, папкам или хабам. Не делайте эту учетную запись администратором, чтобы разблокировать исключительную операцию.
- Если необходимо специальное приложение платформы OAuth, используйте поток интерактивного приложения платформы CLI. Попросите пользователя вводить секрет своего клиента только в локальной строке CLI; никогда не запрашивайте его в чате, не записывайте в конфигурацию Hermes и не фиксируйте.
- Если установка, авторизация браузера, переключение среды или изменение разрешений требуют одобрения, запросите это одобрение и возобновите установку после его получения. Не заменяйте действие списком команд.

## Запуск каждой задачи

1. Подтвердите CLI и текущего актера. Проверьте с помощью `command -v box` в оболочках POSIX или `Get-Command box -ErrorAction SilentlyContinue` в PowerShell. Если `box` находится на `PATH`, используйте его. Если Hermes установил CLI в своем текущем доме, используйте соответствующий оболочке проверенный исполнитель в [руководстве по CLI](https://github.com/NousResearch/hermes-agent/blob/main/skills/productivity/box/references/cli-guide.md) вместо каждого ведущего `box`. Затем запустите `box users:get me --json --fields id,name,login` с этим бегуном.
   Если это удалось, запишите актера и продолжайте. Не спрашивайте об аутентификации снова. Рассматривайте `folders:items 0` только как список корня актера; это не является доказательством того, что общий файл, папка или хаб недоступны. Для известного файла или папки проверьте его идентификатор напрямую; для концентратора используйте путь обнаружения концентраторов в [Box Hubs](https://github.com/NousResearch/hermes-agent/blob/main/skills/productivity/box/references/hubs.md).
2. Если аутентификация отсутствует, попросите подключить учетную запись Box с OAuth, затем спросите, работают ли Hermes и браузер авторизации на одном компьютере или на разных хостах. Прочтите [Настройка OAuth](https://github.com/NousResearch/hermes-agent/blob/main/skills/productivity/box/references/oauth-setup.md).
3. Перед началом работы прочтите соответствующую справку. Сначала используйте документированные команды; запускайте подкоманду help только в том случае, если для запроса требуется опция, не указанная в ссылке, или если установленный интерфейс командной строки отклоняет документированную форму.

В примерах, помеченных `bash`, используется синтаксис продолжения POSIX. В PowerShell запустите команду Box в одной строке или замените каждый конечный `\` продолжением обратного кавычка PowerShell. Не вставляйте назначения переменных POSIX в PowerShell.

## Расширяем CLI без паузы

Если в интерфейсе командной строки Box отсутствует выделенная подкоманда, используйте `box request` для соответствующей конечной точки REST и продолжайте обычную операцию. Не просите пользователя сделать выбор только потому, что реализация использует REST; это та же задача Box, которая сохраняет настроенную идентичность CLI. Прочтите [резервный вариант REST API](https://github.com/NousResearch/hermes-agent/blob/main/skills/productivity/box/references/rest-api.md), когда конечной точке требуется тело запроса или настраиваемый заголовок.

Спрашивайте перед удалением, изменением совместной работы/общей ссылки или разрешений, изменением удостоверения, широкой или дорогостоящей пакетной мутацией, а также когда цель или область действия неоднозначны. В противном случае выполните запрошенную операцию и проверьте ее.

## Политика обработки контента

Для семантического анализа контента, размещенного на Box, отдайте предпочтение Box AI: он сохраняет разрешения Box, обрабатывает исходные файлы посредством управляемой AI-интеграции Box, сохраняет тела исходных файлов вне контекста модели кодирования Hermes и масштабирует работу с документами без загрузки каждого файла. Не критикуйте и не блокируйте другой рабочий процесс; используйте его, когда пользователь явно выбирает его.

Используйте существующие метаданные Box или запросы метаданных для детерминированного поиска. В противном случае используйте Box AI:

– `ai:ask` для вопросов и ответов, резюме и сравнений.
- `ai:extract-structured` для известных полей или шаблонов метаданных.
- `ai:extract` для гибкого извлечения значений ключа.
- `ai:text-gen` для записи в одном файле Box

Если вы хотите задать вопросы и ответы по более чем 25 файлам или курируемой базе знаний многократного использования, отдайте предпочтение Box AI for Hubs. Сначала откройте существующий доступный хаб; создавайте или заполняйте его только после того, как пользователь одобрит изменение общего ресурса. Если хаб недоступен и пользователь не хочет его создавать, сузьте одноразовый запрос поиском или метаданными. Не используйте Hub для извлечения метаданных или генерации текста. Прочтите [Box Hubs](https://github.com/NousResearch/hermes-agent/blob/main/skills/productivity/box/references/hubs.md).

Когда пользователь просит извлечь метаданные из файла Box, рассматривайте это как запрос на сохранение результата, если он не попросит предварительный просмотр. Используйте структурированное извлечение со встроенными полями, если известна желаемая схема, и извлечение произвольной формы, когда поля являются исследовательскими. Повторно используйте совместимый существующий корпоративный шаблон, если он представляет каждое запрошенное поле. В противном случае сохраните результаты плоских скаляров во встроенном экземпляре метаданных `global.properties` или загрузите дополнительный JSON рядом с исходным файлом, если результат содержит вложенные объекты, таблицы или значения, которые должны сохранять свои типы. Прочтите каждую обратную запись и сравните ее с предполагаемым результатом. Никогда не заменяйте молча описание файла, не прикрепляйте частичный или несвязанный шаблон, не усекайте и не удаляйте поля.

Не создавайте и не изменяйте шаблоны метаданных. Box не позволяет создавать глобальные шаблоны, а администрирование корпоративных шаблонов выходит за рамки обычного рабочего процесса с контентом OAuth в Hermes. Если пользователю нужны повторно используемые типизированные корпоративные метаданные, а совместимого шаблона не существует, объясните, что администратор Box или уполномоченный соадминистратор должен создать их отдельно, оставить существующие структурированные метаданные без изменений и вместо этого сообщить о сохраненном экземпляре `global.properties` или дополнительном компоненте JSON. Прочтите [Поиск и искусственный интеллект](https://github.com/NousResearch/hermes-agent/blob/main/skills/productivity/box/references/search-and-ai.md) для полного рабочего процесса извлечения и обратной записи.

Перед первым запросом Box AI укажите, что Box AI должен быть включен, потребляет единицы AI и остается ограниченным разрешениями текущего актера; не ждите подтверждения. Ответ ИИ, возвращенный в «Гермес», все еще может содержать конфиденциальную информацию. Подтверждайте только в том случае, если объем файла партии материала или ожидаемое использование единиц AI неоднозначны или если пользователь явно не запросил этот масштаб. См. [Поиск и искусственный интеллект](https://github.com/NousResearch/hermes-agent/blob/main/skills/productivity/box/references/search-and-ai.md).

## Работайте безопасно

- Предпочитайте идентификаторы путям и проверяйте текущего актера перед диагностикой отсутствующего файла.
– Используйте `--json` и `--fields`, чтобы результат был небольшим. В случае мутаций сначала проведите инвентаризацию, подтвердите неоднозначность или большой объем, а затем прочитайте результат.
- Запускайте упорядоченные мутации CLI последовательно, чтобы прогресс и восстановление были однозначными. Используйте документированную поддержку массового ввода или ограниченный параллелизм SDK для масштабируемой работы.
– Не создавайте общую ссылку просто для обеспечения навигации. Общие ссылки меняют доступ и требуют явного подтверждения.
- Не размещайте секреты в чате, выводе команд, системе контроля версий или журналах.

## Сообщить о результатах

Для каждого отдельного элемента Box укажите его идентификатор и интерактивную ссылку навигации:

- Файл: `https://app.box.com/file/<FILE_ID>`
- Папка: `https://app.box.com/folder/<FOLDER_ID>`
- Хаб: `https://app.box.com/hubs/<HUB_ID>`

Для больших пакетов свяжите исходную и целевую папки, а также исключения, вместо того, чтобы перечислять сотни элементов. Человек может не иметь возможности открыть контент, который виден только подключенной учетной записи Box; заявите это ясно. Включите субъекта и выполняемую проверку в каждую сводку записи.

## Проверить

После любой записи извлеките файл или папку с тем же актером или перечислите его родителя и подтвердите возвращенный идентификатор и имя. Для записи метаданных извлеките экземпляр метаданных и сравните каждое возвращаемое поле с предполагаемым значением; успех HTTP сам по себе не является проверкой. Сообщайте об отсутствующих, нормализованных или отклоненных значениях. Для одноразовой проверки настройки создайте папку дыма, проверьте ее, а затем удалите ее, только если пользователь разрешил очистку.
