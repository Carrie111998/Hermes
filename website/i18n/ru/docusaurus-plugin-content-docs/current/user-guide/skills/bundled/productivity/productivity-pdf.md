# PDF-навык

Создавайте PDF-файлы на основе структурированных спецификаций, извлекайте текст/таблицы/метаданные, объединяйте/разделяйте/поворачивайте страницы/страницы с водяными знаками, заполняйте поля форм AcroForm и шифруйте/дешифруйте — с помощью pypdf, reportlab и pdfplumber. Отсканированные PDF-файлы (только изображения) не содержат текстового слоя: распознавание текста здесь явно выходит за рамки — если страница содержит только изображения, остановитесь и используйте навык `ocr-and-documents` вместо того, чтобы притворяться, что извлекаете текст.

## Когда использовать

- Создайте отчет, счет или многостраничный документ в формате PDF.
- Извлекайте текст, таблицы (JSON/CSV), метаданные или значения полей формы из PDF-файла.
- Объединяйте, разделяйте, вращайте, извлекайте подмножества страниц, ставьте водяные знаки, закладки или сжимайте PDF-файлы.
- Заполнять или выравнивать формы AcroForm; шифровать или расшифровывать с помощью паролей.
- НЕ для отсканированных PDF-файлов или PDF-файлов, содержащих только изображения (используйте `ocr-and-documents`) и НЕ для точного рендеринга HTML в PDF (используйте автономный браузер).

## Предварительные условия

- Python 3.10+ с `pypdf`, `reportlab`, `pdfplumber`:
  `python3 -m pip install pypdf reportlab pdfplumber`
- Каждый вспомогательный скрипт лениво проверяет импорт и печатает подсказку по установке, если зависимость отсутствует.

## Как бежать

Все помощники живут в `scripts/` и представляют собой CLI argparse — запускайте их с помощью инструмента `terminal`; все поддерживают `--help`. Они читают/записывают JSON строго как UTF-8, выводят результаты JSON на стандартный вывод и в случае сбоя завершают работу с ненулевым значением.

```bash
python3 scripts/pdf_create.py spec.json -o out.pdf         # build PDF from JSON spec
python3 scripts/pdf_read.py doc.pdf --text                 # per-page text (JSON)
python3 scripts/pdf_read.py doc.pdf --tables --csv-dir t/  # tables to JSON + CSV files
python3 scripts/pdf_read.py doc.pdf --meta                 # metadata, page sizes, encrypted/scanned flags
python3 scripts/pdf_read.py form.pdf --fields              # form fields: name, type, value
python3 scripts/pdf_merge.py a.pdf b.pdf -o merged.pdf [--bookmarks]
python3 scripts/pdf_split.py doc.pdf --pages 1-3,7 -o part.pdf [--rotate 90]
python3 scripts/pdf_fill_form.py form.pdf --fields-json values.json -o filled.pdf [--flatten]
python3 scripts/pdf_secure.py doc.pdf --encrypt -o enc.pdf --user-password your-password
python3 scripts/pdf_secure.py enc.pdf --decrypt -o dec.pdf --password your-password
python3 scripts/pdf_watermark.py doc.pdf --stamp mark.pdf -o stamped.pdf [--under]
```

## Краткий справочник

| Задача | Инструмент | Команда/API |
|---|---|---|
| Создать документ (заголовки, таблицы, изображения) | репортажная лаборатория утконос | `pdf_create.py spec.json -o out.pdf` |
| Постраничный текст | PDFсантехник | `pdf_read.py f.pdf --text` |
| Таблицы → JSON/CSV | PDFсантехник | `pdf_read.py f.pdf --tables` |
| Метаданные/размеры/зашифрованные/сканированные | pypdf + pdfсантехник | `pdf_read.py f.pdf --meta` |
| Объединить (+ контур) | pypdf | `pdf_merge.py a.pdf b.pdf -o m.pdf` |
| Разделить/извлечь/повернуть | pypdf | `pdf_split.py f.pdf --pages 2-5 --rotate 90` |
| Список/заполнение/сведение формы | pypdf | `pdf_read.py --fields`, `pdf_fill_form.py` |
| Шифровать/дешифровать (AES-256) | pypdf | `pdf_secure.py --encrypt/--decrypt` |
| Водяной знак/штамп | pypdf | `pdf_watermark.py f.pdf --stamp w.pdf` |
| Сжатие потоков контента | pypdf | `pdf_split.py f.pdf --pages 1-N --compress` |

## Процедура

1. **Сначала проверьте.** Запустите `pdf_read.py file.pdf --meta`. Проверьте `encrypted` (если это правда, сначала расшифруйте с помощью `pdf_secure.py --decrypt`) и `likely_scanned_pages`. Если страницы содержат только изображения, передайте их навыку `ocr-and-documents` — не сообщайте о пустом тексте как об «нете контента».
2. **Создайте.** Напишите спецификацию JSON с помощью `write_file` (элементы: `heading`, `paragraph`, `table`, `image`, `pagebreak`; необязательные метаданные `title`/`author`; номера страниц добавляются автоматически), затем запустите `pdf_create.py`. Проверьте визуально с помощью `vision_analyze` на отрисованном изображении страницы, имеет ли макет значение.
3. **Извлечение.** `--text` предоставляет список строк на каждой странице в формате JSON; `--tables` предоставляет массивы строк на странице, а также может создавать файлы CSV. Прочитайте результаты с помощью `read_file`; никогда не смотрите непосредственно на двоичный PDF-файл.
4. **Манипулировать.** `pdf_merge.py` объединяет и может добавлять одну закладку для каждого исходного файла; `pdf_split.py` обрабатывает диапазоны страниц (отсчет от 1, например `1-3,5,9-`), поворот с шагом 90° и `--compress`. Водяной знак путем подготовки одностраничного PDF-файла со штампом (например, с помощью `pdf_create.py`) и наложения на него `pdf_watermark.py`.
5. **Формы.** Перечислите поля (`--fields`), чтобы узнать точные имена и типы, напишите JSON UTF-8 `{"FieldName": "value"}` с `write_file` (флажки допускают `true`/`false`; значения радио/выбора должны соответствовать параметрам экспорта поля), затем `pdf_fill_form.py`. Перечитайте с помощью `--fields`, чтобы подтвердить полученные значения.
6. **Безопасность.** Шифрование с использованием отдельных паролей пользователя/владельца и AES-256. Чтобы удалить известный вам пароль, `--decrypt` записывает незашифрованную копию.
7. **Проверьте** (см. ниже), прежде чем сообщать об успехе.

## Подводные камни

– **Отсканированные PDF-файлы**: пустой `extract_text()` плюс изображения страниц означают отсутствие текстового слоя. Маршрут к `ocr-and-documents`; не выдумывайте текст.
- **Ограничения сглаживания**: `pdf_fill_form.py --flatten` использует поддержку сглаживания pypdf, которая преобразует внешний вид виджета в содержимое страницы. Он надежен для полей и флажков с обычным текстом, но может удалять или неправильно отображать экзотические виджеты (форматированный текст, потоки пользовательского внешнего вида, некоторые радиогруппы). Проверьте сведенный вывод визуально с помощью `vision_analyze`; для надежного выравнивания используйте внешний рендерер (например, Ghostscript или `pdftoppm`+reassembly) в качестве запасного варианта.
- **NeedAppearances**: после заполнения средства просмотра отображают значения только в том случае, если существуют потоки внешнего вида. Сценарий заполнения устанавливает флаг AcroForm `NeedAppearances`, поэтому соответствующие средства просмотра повторно создают их; некоторые минимальные зрители игнорируют это — сглаживайте, если точность отображения имеет значение.
- **Значения в нелатинской форме**: значения сохраняются правильно (UTF-16), но в шрифте поля по умолчанию могут отсутствовать глифы, поэтому средство просмотра может отображать пробелы даже при обратном обмене данными. Проверьте с помощью `--fields`, а не только визуально.
- **Ожидания сжатия**: `--compress` только выкачивает потоки контента. Типичная экономия составляет 0–20%; он ничего не делает для PDF-файлов, в которых преобладают изображения или уже сжатые потоки. Это не замена субдискретизации изображения (территория Ghostscript).
- **Флаги разрешений не применяются**: биты разрешения пароля владельца (не печатать, не копировать) представляют собой вежливые запросы, которые зрители могут выполнить; любая библиотека (включая pypdf) может прочитать и удалить их. Только пароль пользователя фактически защищает контент посредством шифрования. Никогда не представляйте флаги разрешений в качестве защиты.
- **Извлечение таблиц является эвристическим**: pdfplumber обнаруживает таблицы по направляющим линиям/выравниванию слов; Таблицам без полей или с объединенными ячейками может потребоваться настройка `table_settings` или очистка вручную.
- **Индексация страниц**: вспомогательные интерфейсы командной строки берут страницы с индексом 1; API pypdf основаны на 0. Скрипты преобразуют, а не выполняют двойное преобразование.
- Ротация должна быть кратна 90; зашифрованные входные данные должны быть расшифрованы перед любой другой операцией.

## Проверка

– После создания/объединения/разделения: `pdf_read.py out.pdf --meta` — подтвердите `page_count` и постранично `rotation` при повороте.
- После извлечения: убедитесь, что JSON не пуст, и выборочно проверьте известную строку или ячейку.
- После заполнения формы: `pdf_read.py filled.pdf --fields` и сравнения значений (точное совпадение, включая не-ASCII).
- После шифрования: `--meta` показывает `"encrypted": true`, и открытие без пароля не выполняется; после расшифровки извлечение текста соответствует оригиналу.
– Для всего визуального (водяные знаки, сплющенные формы) визуализируйте и проверяйте с помощью `vision_analyze`.
