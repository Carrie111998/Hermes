# Напоминания Apple

Используйте `remindctl` для управления напоминаниями Apple напрямую с терминала. Задачи синхронизируются на всех устройствах Apple через iCloud.

## Предварительные условия

- **macOS** с Reminders.app
- Установить: `brew install steipete/tap/remindctl`
- Предоставить разрешение на напоминания при появлении соответствующего запроса.
- Проверка: `remindctl status` / Запрос: `remindctl authorize`

## Когда использовать

- Пользователь упоминает «напоминание» или «приложение напоминаний».
- Создание личных задач со сроками выполнения, которые синхронизируются с iOS.
- Управление списками напоминаний Apple.
- Пользователь хочет, чтобы задачи появлялись на его iPhone/iPad.

## Когда НЕ использовать

- Планирование оповещений агента → вместо этого используйте инструмент cronjob.
- События календаря → используйте Календарь Apple или Календарь Google.
- Управление задачами проекта → используйте GitHub Issues, Notion и т. д.
- Если пользователь говорит «напомнить мне», но имеет в виду предупреждение агента → сначала уточните

## Краткий справочник

### Просмотр напоминаний

```bash
remindctl                    # Today's reminders
remindctl today              # Today
remindctl tomorrow           # Tomorrow
remindctl week               # This week
remindctl overdue            # Past due
remindctl all                # Everything
remindctl 2026-01-04         # Specific date
```

### Управление списками

```bash
remindctl list               # List all lists
remindctl list Work          # Show specific list
remindctl list Projects --create    # Create list
remindctl list Work --delete        # Delete list
```

### Создание напоминаний

```bash
remindctl add "Buy milk"
remindctl add --title "Call mom" --list Personal --due tomorrow
remindctl add --title "Meeting prep" --due "2026-02-15 09:00"
```

### Срок выполнения против сигнала тревоги/раннего подталкивания

`--due` и `--alarm` — это разные поля:

– `--due` устанавливает дату и время напоминания.
- `--alarm` устанавливает триггер тревоги/уведомления EventKit. Напоминания о сроке выполнения по умолчанию могут подавать сигнал в назначенное время, но явно передают `--alarm`, когда пользователь запрашивает более раннее напоминание.

Для напоминания в 14:00 с уведомлением на 30 минут раньше:

```bash
remindctl add --title "Hairdresser" --due "2026-05-15 14:00" --alarm "2026-05-15 13:30"
```

Чтобы отредактировать существующее напоминание:

```bash
remindctl edit 87354 --due "2026-05-15 14:00" --alarm "2026-05-15 13:30"
```

Пользовательский интерфейс напоминаний может отображать или группировать элементы по времени будильника, поскольку именно в это время срабатывает уведомление. Проверьте с помощью JSON вместо того, чтобы предполагать, что срок сдвинулся:

```bash
remindctl today --json
```

Ожидаемая форма:

- `dueDate`: фактический срок выполнения
- `alarmDate`: уведомление/время раннего напоминания

В общедоступных документах Apple `EKReminder` перечислены только свойства, относящиеся к напоминаниям. Поддержка сигналов тревоги обеспечивается унаследованным поведением `EKCalendarItem`, предоставляемым флагом `--alarm` напоминаний.

### Завершить/Удалить

```bash
remindctl complete 1 2 3          # Complete by ID
remindctl delete 4A83 --force     # Delete by ID
```

### Выходные форматы

```bash
remindctl today --json       # JSON for scripting
remindctl today --plain      # TSV format
remindctl today --quiet      # Counts only
```

## Форматы даты

Принято `--due` и фильтрами по дате:
- `today`, `tomorrow`, `yesterday`
- `YYYY-MM-DD`
- `YYYY-MM-DD HH:mm`
- ISO 8601 (`2026-01-04T12:34:56Z`)

## Правила

1. Когда пользователь говорит «Напомнить мне», уточните: Apple Reminders (синхронизируется с телефоном) или оповещение агента cronjob.
2. Всегда проверяйте содержание напоминания и дату его выполнения перед созданием.
3. Используйте `--json` для программного анализа.
