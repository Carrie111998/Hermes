# Навык построения архитектурных диаграмм

Создавайте профессиональные диаграммы технической архитектуры в темной тематике в виде отдельных файлов HTML со встроенной графикой SVG. Никаких внешних инструментов, ключей API и библиотек рендеринга — просто напишите HTML-файл и откройте его в браузере.

## Область применения

**Наилучшим образом подходит для:**
- Архитектура программной системы (интерфейсный/бэкенд/уровни базы данных)
- Облачная инфраструктура (VPC, регионы, подсети, управляемые сервисы)
- Микросервисная/сервисная топология.
- Карта базы данных + API, схемы развертывания
- Все, что связано с технологической тематикой и соответствует темной, сетчатой эстетике.

**Сначала поищите в другом месте:**
- Физика, химия, математика, биология или другие научные предметы.
- Физические объекты (транспортные средства, оборудование, анатомия, поперечные сечения)
- Планы этажей, повествовательные путешествия, образовательные/учебные визуальные эффекты.
– Нарисованные от руки эскизы на доске (рассмотрите `excalidraw`).
- Анимированные объяснители (учтите навык анимации)

Если для данного предмета доступен более специализированный навык, отдайте предпочтение этому. Если ни один из них не подходит, этот навык также может служить запасным вариантом для общей SVG-диаграммы — выходные данные будут просто нести эстетику темных технологий, описанную ниже.

На основе [генератора диаграмм архитектуры Cocoon AI] (https://github.com/Cocoon-AI/architecture-diagram-generator) (MIT).

## Рабочий процесс

1. Пользователь описывает архитектуру своей системы (компоненты, соединения, технологии).
2. Создайте HTML-файл, следуя приведенной ниже системе дизайна.
3. Сохраните с помощью `write_file` в файл `.html` (например, `~/architecture-diagram.html`).
4. Пользователь открывается в любом браузере — работает оффлайн, никаких зависимостей

## Система дизайна и визуальный язык

### Цветовая палитра (семантическое картографирование)

Используйте специальные заливки `rgba` и шестигранные штрихи для классификации компонентов:

| Тип компонента | Заполнить (rgba) | Инсульт (шестнадцатеричный) |
| :--- | :--- | :--- |
| **Фронтэнд** | `rgba(8, 51, 68, 0.4)` | `#22d3ee` (голубой-400) |
| **Бэкенд** | `rgba(6, 78, 59, 0.4)` | `#34d399` (изумруд-400) |
| **База данных** | `rgba(76, 29, 149, 0.4)` | `#a78bfa` (фиолетовый-400) |
| **AWS/Облако** | `rgba(120, 53, 15, 0.3)` | `#fbbf24` (янтарный-400) |
| **Безопасность** | `rgba(136, 19, 55, 0.4)` | `#fb7185` (роза-400) |
| **Шина сообщений** | `rgba(251, 146, 60, 0.3)` | `#fb923c` (оранжевый-400) |
| **Внешний** | `rgba(30, 41, 59, 0.5)` | `#94a3b8` (шифер-400) |

### Типографика и фон
- **Шрифт:** JetBrains Mono (Monospace), загруженный из Google Fonts.
– **Размеры:** 12 пикселей (имена), 9 пикселей (дополнительные метки), 8 пикселей (аннотации), 7 пикселей (маленькие ярлыки).
– **Фон:** Slate-950 (`#020617`) с тонкой сеткой размером 40 пикселей.

## Детали технической реализации

### Рендеринг компонентов
Компоненты представляют собой прямоугольники с закругленными углами (`rx="6"`) с обводкой 1,5 пикселя. Чтобы стрелки не отображались сквозь полупрозрачные заливки, используйте **технику маскировки двойным прямоугольником**:
1. Нарисуйте непрозрачный фоновый прямоугольник (`#0f172a`).
2. Нарисуйте полупрозрачный прямоугольник сверху.

### Правила подключения
- **Z-порядок:** рисуйте стрелки *раньше* в SVG (после сетки), чтобы они отображались за рамками компонентов.
– **Наконечники**: определяются с помощью SVG-маркеров.
– **Потоки безопасности:** используйте пунктирные линии розового цвета (`#fb7185`).
- **Границы:**
  - *Группы безопасности:* Пунктир (`4,4`), розовый цвет.
  - *Регионы:* Большой пунктир (`8,4`), янтарный цвет, `rx="12"`.

### Логика интервалов и макета
- **Стандартная высота:** 60 пикселей (Сервисы); 80–120 пикселей (крупные компоненты)
– **Вертикальный зазор:** минимум 40 пикселей между компонентами.
- **Шины сообщений:** должны располагаться *в промежутке* между службами, не перекрывая их.
- **Размещение легенды:** **КРИТИЧНО.** Должно быть размещено за пределами всех граничных рамок. Вычислите самую низкую координату Y из всех границ и поместите легенду как минимум на 20 пикселей ниже нее.

## Структура документа

Сгенерированный HTML-файл состоит из четырех частей:
1. **Заголовок**: заголовок с мигающей точкой и подзаголовком.
2. **Основной SVG:** диаграмма, заключенная в закругленную рамку.
3. **Сводные карточки.** Сетка из трех карточек под диаграммой содержит подробную информацию.
4. **Нижний колонтитул:** Минимальные метаданные.

### Шаблон информационной карты
```html
<div class="card">
  <div class="card-header">
    <div class="card-dot cyan"></div>
    <h3>Title</h3>
  </div>
  <ul>
    <li>• Item one</li>
    <li>• Item two</li>
  </ul>
</div>
```

## Требования к выходу
– **Один файл:** Один автономный файл `.html`.
– **Нет внешних зависимостей.** Все CSS и SVG должны быть встроенными (кроме шрифтов Google).
- **Нет JavaScript:** используйте чистый CSS для любой анимации (например, пульсирующих точек).
- **Совместимость:** Должно корректно отображаться в любом современном веб-браузере.
