# Инструмент содержания YouTube

## Когда использовать

Используйте, когда пользователь делится URL-адресом YouTube или ссылкой на видео, просит суммировать видео, запрашивает расшифровку или хочет извлечь и переформатировать контент из любого видео YouTube. Преобразует стенограммы в структурированный контент (главы, резюме, темы, сообщения в блогах).

Извлекайте расшифровки видео YouTube и конвертируйте их в полезные форматы.

## Настройка

Используйте `uv`, чтобы зависимость была установлена в той же среде, управляемой Hermes.
который запускает вспомогательный скрипт:

```bash
uv pip install youtube-transcript-api
```

## Вспомогательный скрипт

`SKILL_DIR` — это каталог, содержащий этот файл SKILL.md. Скрипт принимает любой стандартный формат URL-адресов YouTube, короткие ссылки (youtu.be), шорты, вставки, живые ссылки или необработанный 11-значный идентификатор видео.

```bash
# JSON output with metadata
uv run python3 SKILL_DIR/scripts/fetch_transcript.py "https://youtube.com/watch?v=VIDEO_ID"

# Plain text (good for piping into further processing)
uv run python3 SKILL_DIR/scripts/fetch_transcript.py "URL" --text-only

# With timestamps
uv run python3 SKILL_DIR/scripts/fetch_transcript.py "URL" --timestamps

# Specific language with fallback chain
uv run python3 SKILL_DIR/scripts/fetch_transcript.py "URL" --language tr,en
```

## Выходные форматы

После получения стенограммы отформатируйте ее в соответствии с запросами пользователя:

- **Главы**: группировка по сменам тем, вывод списка глав с отметкой времени.
– **Краткое содержание**: краткий обзор всего видео (5–10 предложений).
- **Краткое содержание глав**: главы с кратким описанием абзацев для каждой.
- **Тема**: формат темы Twitter/X — пронумерованные сообщения, каждое из которых не превышает 280 символов.
– **Запись в блоге**: полная статья с заголовком, разделами и основными выводами.
- **Цитаты**: известные цитаты с временными метками.

### Пример — вывод глав

```
00:00 Introduction — host opens with the problem statement
03:45 Background — prior work and why existing solutions fall short
12:20 Core method — walkthrough of the proposed approach
24:10 Results — benchmark comparisons and key takeaways
31:55 Q&A — audience questions on scalability and next steps
```

## Рабочий процесс

1. **Получите** расшифровку с помощью вспомогательного сценария с `--text-only --timestamps` через `uv run python3`.
2. **Проверить**: убедитесь, что вывод непустой и отображается на ожидаемом языке. Если пусто, повторите попытку без `--language`, чтобы получить доступную расшифровку. Если все еще пусто, сообщите пользователю, что, вероятно, в видео отключена расшифровка.
3. **При необходимости фрагментируйте**: если расшифровка превышает ~50 тысяч символов, разделите ее на перекрывающиеся фрагменты (~40 тысяч с перекрытием в 2 КБ) и суммируйте каждый фрагмент перед объединением.
4. **Преобразовать** в запрошенный выходной формат. Если пользователь не указал формат, по умолчанию используется сводка.
5. **Проверка**: перед представлением перечитайте преобразованный результат, чтобы проверить его согласованность, правильность временных меток и полноту.

## Обработка ошибок

- **Расшифровка отключена**: сообщите об этом пользователю; предложите им проверить, доступны ли субтитры на странице видео.
– **Частное/недоступное видео**: сообщите об ошибке и попросите пользователя подтвердить URL-адрес.
- **Нет подходящего языка**: повторите попытку без `--language`, чтобы получить любую доступную расшифровку, а затем сообщите пользователю фактический язык.
- **Зависимость отсутствует**: запустите `uv pip install youtube-transcript-api` и повторите попытку.
