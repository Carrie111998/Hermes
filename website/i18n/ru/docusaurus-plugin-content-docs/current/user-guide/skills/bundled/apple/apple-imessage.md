# iMessage

Используйте `imsg` для чтения и отправки iMessage/SMS через приложение macOS Messages.app.

## Предварительные условия

- **macOS** с входом в приложение Messages.app.
- Установить: `brew install steipete/tap/imsg`
- Предоставить полный доступ к диску для терминала (Настройки системы → Конфиденциальность → Полный доступ к диску)
- Предоставьте разрешение автоматизации для Messages.app при появлении соответствующего запроса.

## Когда использовать

- Пользователь просит отправить iMessage или текстовое сообщение.
- Чтение истории разговоров iMessage
- Проверка последних чатов Messages.app.
- Отправка на номера телефонов или Apple ID

## Когда НЕ использовать

- Сообщения Telegram/Discord/Slack/WhatsApp → используйте соответствующий канал шлюза.
- Управление групповым чатом (добавление/удаление участников) → не поддерживается.
- Массовая рассылка → всегда сначала уточняйте у пользователя.

## Краткий справочник

### Список чатов

```bash
imsg chats --limit 10 --json
```

### Просмотреть историю

```bash
# By chat ID
imsg history --chat-id 1 --limit 20 --json

# With attachments info
imsg history --chat-id 1 --limit 20 --attachments --json
```

### Отправлять сообщения

```bash
# Text only
imsg send --to "+14155551212" --text "Hello!"

# With attachment
imsg send --to "+14155551212" --text "Check this out" --file /path/to/image.jpg

# Force iMessage or SMS
imsg send --to "+14155551212" --text "Hi" --service imessage
imsg send --to "+14155551212" --text "Hi" --service sms
```

### Следите за новыми сообщениями

```bash
imsg watch --chat-id 1 --attachments
```

## Варианты обслуживания

- `--service imessage` — принудительно использовать iMessage (требуется, чтобы у получателя было iMessage)
- `--service sms` — Принудительное SMS (зеленый пузырь)
- `--service auto` — пусть Messages.app решает (по умолчанию).

## Правила

1. **Всегда подтверждайте получателя и содержание сообщения** перед отправкой.
2. **Никогда не отправляйте сообщения на неизвестные номера** без явного разрешения пользователя.
3. **Перед прикреплением убедитесь, что пути к файлам** существуют.
4. **Не спамьте** — ограничьте свою скорость

## Пример рабочего процесса

Пользователь: «Напиши маме, что я опоздаю»

```bash
# 1. Find mom's chat
imsg chats --limit 20 --json | jq '.[] | select(.displayName | contains("Mom"))'

# 2. Confirm with user: "Found Mom at +1555123456. Send 'I'll be late' via iMessage?"

# 3. Send after confirmation
imsg send --to "+1555123456" --text "I'll be late"
```
