## Как использовать

1. Выберите дизайн из каталога ниже.
2. Загрузите его: `skill_view(name="popular-web-designs", file_path="templates/<site>.md")`
3. Используйте токены дизайна и спецификации компонентов при создании HTML.
4. Соединитесь с навыком `generative-widgets`, чтобы достичь результата через облачный туннель.

Каждый шаблон включает в себя блок **Примечания по внедрению Hermes** вверху со следующей информацией:
— Замена шрифта CDN и тег Google Fonts `<link>` (готов к вставке)
- Стеки семейств шрифтов CSS для основного и моноширинного пространства.
– Напоминания об использовании `write_file` для создания HTML и `browser_vision` для проверки.

## Шаблон генерации HTML

```html
<!DOCTYPE html>
<html lang="en">
<head>
  <meta charset="UTF-8">
  <meta name="viewport" content="width=device-width, initial-scale=1.0">
  <title>Page Title</title>
  <!-- Paste the Google Fonts <link> from the template's Hermes notes -->
  <link href="https://fonts.googleapis.com/css2?family=..." rel="stylesheet">
  <style>
    /* Apply the template's color palette as CSS custom properties */
    :root {
      --color-bg: #ffffff;
      --color-text: #171717;
      --color-accent: #533afd;
      /* ... more from template Section 2 */
    }
    /* Apply typography from template Section 3 */
    body {
      font-family: 'Inter', system-ui, sans-serif;
      color: var(--color-text);
      background: var(--color-bg);
    }
    /* Apply component styles from template Section 4 */
    /* Apply layout from template Section 5 */
    /* Apply shadows from template Section 6 */
  </style>
</head>
<body>
  <!-- Build using component specs from the template -->
</body>
</html>
```

Запишите файл с помощью `write_file`, используйте рабочий процесс `generative-widgets` (облачный туннель),
и проверьте результат с помощью `browser_vision`, чтобы убедиться в визуальной точности.

## Справочник по замене шрифтов

Большинство сайтов используют собственные шрифты, недоступные через CDN. Каждый шаблон сопоставляется с Google Fonts.
заменитель, сохраняющий характер дизайна. Общие сопоставления:

| Собственный шрифт | Замена CDN | Персонаж |
|---|---|---|
| Гейст / Гейст Санс | Гейст (в Google Fonts) | Геометрическое, сжатое отслеживание |
| Гейст Моно | Geist Mono (в Google Fonts) | Чистый моноширин, лигатуры |
| сохне-вар (Полоса) | Исходник Санс 3 | Легкая элегантность |
| Беркли Моно | ДжетБрэйнс Моно | Технический моноширин |
| Airbnb Зерновые VF | ДМ Санс | Округлые, дружелюбные геометрические |
| Проспект (Spotify) | ДМ Санс | Геометрический, теплый |
| фигмаСанс | Интер | Чистый гуманист |
| Пин Санс (Pinterest) | ДМ Санс | Дружелюбный, округлый |
| NVIDIA-EMEA | Интер (или система Arial) | Промышленный, чистый |
| CoinbaseDisplay/Санс | ДМ Санс | Геометрический, заслуживающий доверия |
| UberMove | ДМ Санс | Смелый, плотный |

Если шрифт CDN шаблона соответствует оригиналу (Inter, IBM Plex, Rubik, Geist), нет
происходит потеря замещения. При использовании замены (DM Sans вместо Circular, Source Sans 3
для sohne-var), внимательно следите за значениями веса, размера и межбуквенного интервала шаблона —
они несут больше визуальной идентичности, чем конкретный шрифт.
