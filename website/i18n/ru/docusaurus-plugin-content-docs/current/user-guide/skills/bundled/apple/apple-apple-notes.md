# Заметки Apple

Используйте `memo` для управления Apple Notes непосредственно с терминала. Заметки синхронизируются на всех устройствах Apple через iCloud.

## Предварительные условия

- **macOS** с Notes.app
- Установить: `brew tap antoniorodr/memo && brew install antoniorodr/memo/memo`
- Предоставьте автоматизации доступ к Notes.app при появлении запроса (Настройки системы → Конфиденциальность → Автоматизация).

## Когда использовать

- Пользователь просит создать, просмотреть или выполнить поиск в Apple Notes.
- Сохранение информации в Notes.app для доступа к нескольким устройствам.
- Организация заметок по папкам.
- Экспорт заметок в Markdown/HTML.

## Когда НЕ использовать

- Управление обсидиановым хранилищем → используйте навык `obsidian`.
- Bear Notes → отдельное приложение (здесь не поддерживается)
– Быстрые заметки только для агента → вместо этого используйте инструмент `memory`.

## Краткий справочник

### Просмотр заметок

```bash
memo notes                        # List all notes
memo notes -f "Folder Name"       # Filter by folder
memo notes -s "query"             # Search notes (fuzzy)
```

### Создание заметок

```bash
memo notes -a                     # Add a note (opens your $EDITOR)
memo notes -a -f "Folder Name"    # Add a note into a specific folder
```

`-a`/`--add` — это пустой флажок — он открывает ваш `$EDITOR` для создания заметки; это так
не принимать аргумент заголовка. Используйте `-f/--folder` для выбора папки. Установить `$EDITOR`
сначала (например, `export EDITOR=vim`).

### Редактировать заметки

```bash
memo notes -e                     # Interactive selection to edit
```

### Удалить заметки

```bash
memo notes -d                     # Interactive selection to delete
```

### Переместить заметки

```bash
memo notes -m                     # Move note to folder (interactive)
```

### Экспортировать примечания

```bash
memo notes -ex                    # Export to HTML/Markdown
```

## Ограничения

- Невозможно редактировать заметки, содержащие изображения или вложения.
- Интерактивные подсказки требуют доступа к терминалу (при необходимости используйте pty=true)
- только для macOS — требуется Apple Notes.app

## Правила

1. Предпочитайте Apple Notes, если пользователю нужна синхронизация между устройствами (iPhone/iPad/Mac).
2. Используйте инструмент `memory` для внутренних заметок агента, которые не нужно синхронизировать.
3. Используйте навык `obsidian` для управления знаниями с помощью Markdown.
