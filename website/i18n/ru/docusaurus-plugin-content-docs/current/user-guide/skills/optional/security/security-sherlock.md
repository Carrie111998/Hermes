# Шерлок OSINT Поиск по имени пользователя

Выслеживайте учетные записи в более чем 400 социальных сетях по имени пользователя с помощью [Sherlock Project](https://github.com/sherlock-project/sherlock).

## Когда использовать

- Пользователь просит найти учетные записи, связанные с именем пользователя.
- Пользователь хочет проверить доступность имени пользователя на разных платформах.
- Пользователь проводит OSINT или рекогносцировочные исследования.
- Пользователь спрашивает: «Где зарегистрировано это имя пользователя?» или подобное

## Требования

- Установлен интерфейс командной строки Sherlock: `pipx install sherlock-project` или `pip install sherlock-project`.
- Альтернативно: доступен Docker (`docker run -it --rm sherlock/sherlock`).
- Доступ к сети для запроса социальных платформ.

## Процедура

### 1. Проверьте, установлен ли Шерлок

**Прежде чем делать что-либо еще**, убедитесь, что Шерлок доступен:

```bash
sherlock --version
```

Если команда не выполнена:
- Предложение установить: `pipx install sherlock-project` (рекомендуется) или `pip install sherlock-project`.
- **НЕ** пробуйте несколько способов установки — выберите один и продолжайте.
- Если установка не удалась, сообщите об этом пользователю и остановите установку.

### 2. Извлечь имя пользователя

**Извлеките имя пользователя непосредственно из сообщения пользователя, если оно четко указано.**

Примеры, в которых **НЕ** следует использовать уточнение:
- «Найти аккаунты для НАСА» → имя пользователя `nasa`.
- «Найти johndoe123» → имя пользователя `johndoe123`.
- «Проверьте, существует ли Алиса в социальных сетях» → имя пользователя `alice`
- «Найти пользователя bob в социальных сетях» → имя пользователя `bob`

**Используйте уточнение, только если:**
- Упоминается несколько потенциальных имен пользователей («поиск Алисы или Боба»)
- Неоднозначная формулировка («поиск моего имени пользователя» без указания)
- Имя пользователя вообще не упоминается («выполните OSINT-поиск»)

При извлечении используйте **точное** имя пользователя, как указано — сохраняйте регистр, цифры, символы подчеркивания и т. д.

### 3. Команда сборки

**Команда по умолчанию** (используйте ее, если пользователь не требует иного):
```bash
sherlock --print-found --no-color "<username>" --timeout 90
```

**Необязательные флаги** (добавляются только по явному запросу пользователя):
- `--nsfw` — Включить сайты NSFW (только по запросу пользователя)
- `--tor` — Маршрут через Tor (только если пользователь запрашивает анонимность)

**НЕ спрашивайте о вариантах через «Уточнение»** — просто запустите поиск по умолчанию. При необходимости пользователи могут запросить определенные параметры.

### 4. Выполнить поиск

Запустите с помощью инструмента `terminal`. Команда обычно занимает 30–120 секунд в зависимости от условий сети и количества сайтов.

**Пример терминального вызова:**
```json
{
  "command": "sherlock --print-found --no-color \"target_username\"",
  "timeout": 180
}
```

### 5. Анализ и представление результатов

Шерлок выводит найденные аккаунты в простом формате. Проанализируйте вывод и представьте:

1. **Сводная строка:** «Найдено X учетных записей для имени пользователя «Y»».
2. **Ссылки по категориям.** Сгруппируйте по типу платформы, если это полезно (социальные, профессиональные, форумы и т. д.).
3. **Расположение выходного файла:** Шерлок по умолчанию сохраняет результаты в `<username>.txt`.

**Пример синтаксического анализа вывода:**
```
[+] Instagram: https://instagram.com/username
[+] Twitter: https://twitter.com/username
[+] GitHub: https://github.com/username
```

По возможности представляйте результаты в виде кликабельных ссылок.

## Подводные камни

### Результатов не найдено
Если «Шерлок» не находит учетных записей, зачастую это правильно — имя пользователя может не быть зарегистрировано на проверенных платформах. Предложить:
- Проверка правописания/вариантности
– Пробуем использовать похожие имена пользователей с подстановочным знаком `?`: `sherlock "user?name"`.
- У пользователя могут быть настройки конфиденциальности или удаленные аккаунты.

### Проблемы с тайм-аутом
Некоторые сайты работают медленно или блокируют автоматические запросы. Используйте `--timeout 120`, чтобы увеличить время ожидания, или `--site`, чтобы ограничить область действия.

### Конфигурация Tor
`--tor` требует запуска демона Tor. Если пользователю нужна анонимность, но Tor недоступен, предложите:
- Установка сервиса Tor
- Использование `--proxy` с альтернативным прокси.

### Ложные срабатывания
Некоторые сайты всегда возвращают «найдено» из-за своей структуры ответа. Сопоставьте неожиданные результаты с ручными проверками.

### Ограничение скорости
Агрессивный поиск может привести к ограничению скорости. Для массового поиска по имени пользователя добавьте задержки между вызовами или используйте `--local` с кешированными данными.

```bash
pipx install sherlock-project
```



### пакеты Linux
Доступно в Debian 13+, Ubuntu 22.10+, Homebrew, Kali, BlackArch.

## Этическое использование

Этот инструмент предназначен только для законных OSINT и исследовательских целей. Напомните пользователям:
- Ищите только имена пользователей, которыми они владеют или имеют разрешение на расследование.
- Соблюдайте условия обслуживания платформы.
- Не используйте для преследования, преследования или незаконной деятельности.
- Учитывайте последствия для конфиденциальности, прежде чем делиться результатами.

## Проверка

После запуска Шерлока проверьте:
1. Вывод списков найденных сайтов с URL-адресами.
2. Создан файл `<username>.txt` (вывод по умолчанию), если используется вывод файла.
3. Если используется `--print-found`, выходные данные должны содержать только `[+]` строк для совпадений.

1. Проверьте `sherlock --version` (убедитесь, что он установлен).

3. Бегите: `sherlock --print-found --no-color "johndoe123" --timeout 90`
4. Анализ вывода и представление ссылок
