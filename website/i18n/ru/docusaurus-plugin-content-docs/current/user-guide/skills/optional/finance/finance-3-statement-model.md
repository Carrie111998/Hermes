# Завершение шаблона финансовой модели с 3 отчетами

Заполните и заполните шаблоны интегрированных финансовых моделей с надлежащими связями между отчетом о прибылях и убытках, балансовым отчетом и отчетом о движении денежных средств.

## ⚠️ КРИТИЧЕСКИЕ ПРИНЦИПЫ — прочтите перед заполнением любого шаблона

**Формулы для жестких кодов (не подлежат обсуждению):**
- Каждая ячейка прогноза, прокрутка вперед, связь и промежуточный итог ДОЛЖНЫ быть формулой Excel, а не заранее вычисленным значением.
– При использовании Python/openpyxl: записывайте строки формул (`ws["D15"] = "=D14*(1+Assumptions!$B$5)"`), а НЕ вычисляемые результаты (`ws["D15"] = 12500`).
- ЕДИНСТВЕННЫЕ ячейки, которые должны содержать жестко запрограммированные числа: (1) фактические данные за прошлые периоды, (2) драйверы предположений на вкладке «Предположения».
- Если вы обнаружите, что вычисляете значение в Python и записываете результат в ячейку — СТОП. Вместо этого напишите формулу.
- Почему: модель должна изменяться при изменении сценариев или предположений. Жесткие коды молча нарушают все последующие проверки целостности.

**Пошаговое согласование с пользователем:**
1. **После сопоставления шаблона** → покажите пользователю, какие вкладки/разделы вы определили, и подтвердите, прежде чем касаться каких-либо ячеек.
2. **После заполнения исторических данных** → покажите пользователю исторический блок и подтвердите, что значения/периоды соответствуют исходным данным.
3. **После построения прогнозов ИБ** → запустить промежуточные проверки, показать пользователю прогнозируемую ИБ, подтвердить перед переходом к БС
4. **После построения BS** → показать пользователю проверку баланса (Активы = L+E) для каждого периода, подтвердить перед переходом в CF.
5. **После построения CF** → покажите пользователю распределение денежных средств (окончание денежных средств CF = денежные средства BS), подтвердите перед завершением
6. **НЕ заполняйте всю модель целиком и не представляйте ее полностью** — делайте перерывы на каждом операторе, показывайте работу, выявляйте ошибки заранее

## Форматирование — профессиональная синяя/серая палитра (по умолчанию, если шаблон/пользователь не указали иное)

**Сохраняйте минимальное количество цветов.** Для заливки ячеек используйте только синие и серые оттенки. НЕ используйте зеленые, желтые, оранжевые цвета или несколько акцентных цветов — в чистой модели используется сдержанность.

| Элемент | Заполнить | Шрифт |
|---|---|---|
| Заголовки разделов (заголовки IS/BS/CF) | Темно-синий `#1F4E79` | Белый жирный |
| Заголовки столбцов (2024A финансового года, 2025E финансового года и т. д.) | Голубой `#D9E1F2` | Черный жирный |
| Входные ячейки (исторические данные, драйверы предположений) | Светло-серый `#F2F2F2` или белый | Синий `#0000FF` |
| Ячейки формулы | Белый | Черный |
| Перекрестные ссылки | Белый | Зеленый `#008000` |
| Проверьте строки/ключевые итоги | Средний синий `#BDD7EE` | Черный жирный |

**Это 3 синих + 1 серый + белый.** Если шаблон имеет собственную цветовую схему, используйте шаблон.

Цвет шрифта сигнализирует *что* представляет собой ячейка (ввод/формула/ссылка). Цветовые сигналы заливки *где* вы находитесь (заголовок/данные/проверка).

## Структура модели

### Определение организации вкладок шаблона

Шаблоны различаются по правилам именования вкладок и организации. Прежде чем заполнять, просмотрите все вкладки, чтобы понять структуру шаблона. Ниже приведены распространенные названия вкладок и их типичное содержимое:

| Общие имена вкладок | Содержание для поиска |
|------------------|----------------------|
| IS, P&L, отчет о прибылях и убытках | Отчет о прибылях и убытках |
| BS, Баланс | Балансовый отчет |
| CF, CFS, денежный поток | Отчет о движении денежных средств |
| туалет, оборотный капитал | График оборотного капитала |
| DA, D&A, Амортизация, Основные средства | График износа и амортизации |
| Долг, График долга | График долга |
| НОЛ, Налоги, DTA | График чистых операционных убытков |
| Предположения, входные данные, драйверы | Предположения и входные данные драйвера |
| Проверки, Аудит, Валидация | Панель проверки ошибок |

**Контрольный список проверки шаблона**
- Определите, какие вкладки существуют в шаблоне (не все шаблоны включают все расписания).
– Обратите внимание на все вкладки, относящиеся к шаблону, не перечисленные выше.
- Понять зависимости вкладок (например, какие расписания входят в основные операторы)
- Найдите ячейки ввода и ячейки формулы на каждой вкладке.

### Понимание структуры шаблона

Прежде чем заполнять шаблон, ознакомьтесь с его существующим макетом, чтобы убедиться, что данные вводятся в правильных местах и формулы остаются нетронутыми.

**Определение структуры строк**
- Найдите название модели вверху каждой вкладки.
- Определить заголовки разделов и их визуальное разделение.
- Найдите строку единиц, в которой указаны миллионы долларов, %, x и т. д.
- Обратите внимание на заголовки столбцов, отличающие фактические и расчетные периоды.
– Подтвердите метки периодов (например, 2024A финансового года, 2025E финансового года).
- Определите ячейки ввода и ячейки формулы (обычно различаются по цвету шрифта).

**Определение структуры столбца**
– Подтвердите ярлыки позиций в крайнем левом столбце.
- Убедитесь, что исторические годы предшествуют прогнозным годам.
- Обратите внимание на визуальную границу, отделяющую исторический период от прогнозируемого.
- Проверьте единообразный порядок столбцов на всех вкладках.

**Работа с именованными диапазонами**
В шаблонах часто используются именованные диапазоны для ключевых входных и выходных данных. Прежде чем вводить данные:
- Просмотрите существующие именованные диапазоны в шаблоне (Формулы → Диспетчер имен в Excel).
- Общие именованные диапазоны включают в себя: темпы роста доходов, проценты затрат, ключевые результаты (чистая прибыль, EBITDA, общий долг, денежные средства), ячейка выбора сценария.
- Убедитесь, что входные данные вводятся в ячейки, которые попадают в эти именованные диапазоны.

### Период прогноза
– Шаблоны обычно прогнозируют на 5 лет вперед по сравнению с прошлым историческим годом.
- Убедитесь, что исторические (A) и прогнозируемые (E) столбцы четко разделены.
– Убедитесь, что в столбцах используется обозначение финансового года (например, 2024A финансового года, 2025E финансового года).

## Анализ маржи

Рассчитайте и отобразите рентабельность на вкладке «Отчет о прибылях и убытках» (IS), чтобы отслеживать операционную эффективность и проводить сравнение с аналогами.

### Основные поля для включения

| Маржа | Формула | Что он измеряет |
|--------|---------|------------------|
| Валовая прибыль | Валовая прибыль/выручка | Ценообразование, эффективность производства |
| Маржа EBITDA | EBITDA / Выручка | Основная операционная рентабельность |
| Маржа EBIT | EBIT / Выручка | Операционная рентабельность после D&A |
| Маржа чистой прибыли | Чистая прибыль/выручка | Итоговая рентабельность |

## Кредитные показатели

**Примечание. Следующий кредитный анализ следует выполнять только по запросу пользователя или если этого явно требует шаблон. Если подсказка не отображается, пропустите этот раздел.**

Рассчитайте и отобразите показатели кредитного плеча/кредитного плеча на вкладке «Балансовый отчет» (BS), чтобы оценить финансовое состояние, долговую способность и соответствие ковенантам.

### Основные показатели кредитоспособности, которые следует включить

| Метрическая | Формула | Что он измеряет |
|--------|---------|------------------|
| Общий долг / EBITDA | Общий долг / LTM EBITDA | Используйте несколько |
| Чистый долг / EBITDA | (Общий долг – денежные средства) / LTM EBITDA | Кредитное плечо за вычетом денежных средств |
| Покрытие процентов | EBITDA / Процентные расходы | Возможность обслуживания долга |
| Долг/Общая капитализация | Общий долг / (Общий долг + Собственный капитал) | Капитальная структура |
| Долг/Капитал | Общий долг / Общий капитал | Финансовый рычаг |
| Текущий коэффициент | Текущие активы/Текущие обязательства | Краткосрочная ликвидность |
| Коэффициент быстрой ликвидности | (Оборотные активы - Запасы) / Текущие обязательства | Немедленная ликвидность |

### Проверки иерархии кредитных показателей

Убедитесь, что Upside показывает самый сильный кредитный профиль:
- Кредитное плечо: Потенциал роста &lt; База &lt; Недостаток (чем ниже, тем лучше)
- Покрытие: Верхний > Базовый > Нижний (чем выше, тем лучше)
- Ликвидность: Потенциал роста > База > Нижняя сторона (чем выше, тем лучше).

### Отслеживание соблюдения соглашений

Если известны ковенанты, добавьте явные проверки соответствия, сравнивающие фактические показатели с пороговыми значениями ковенантов.

## Анализ сценариев (базовый / положительный / отрицательный)

Используйте переключатель сценария (раскрывающийся список) на вкладке «Предположения» с формулами «ВЫБРАТЬ» или «ИНДЕКС/ПОИСКПОЗ».

| Сценарий | Описание |
|----------|-------------|
| Базовый вариант | Рекомендации руководства или консенсусные оценки |
| Верхний случай | Рост выше прогноза, расширение маржи |
| Обратная сторона дела | Рост ниже тренда, сжатие маржи |

**Ключевые факторы, требующие внимания**: рост выручки, валовая прибыль, % SG&A, DSO/DIO/DPO, % капитальных затрат, процентная ставка, ставка налога.

**Аудитские проверки сценариев**: тумблеры переключают все отчеты, балансы BS во всех сценариях, денежные привязки, иерархия сохраняется (верхняя сторона > база > нижняя сторона для NI, EBITDA, свободного денежного потока, маржи).

## Завершение шаблонов моделей

В этом разделе представлены общие рекомендации по заполнению любого шаблона финансовой модели, состоящей из трех утверждений, с сохранением существующих формул и обеспечением целостности данных.

### Шаг 1. Анализ структуры шаблона

Прежде чем вводить какие-либо данные, внимательно просмотрите шаблон, чтобы понять его архитектуру:

**Определение входных данных и ячеек формулы**
- Ищите визуальные подсказки (цвет шрифта, заливка ячеек), которые отличают входные ячейки от ячеек формулы.
- Общие условные обозначения: синий шрифт = входные данные, черный шрифт = формулы, зеленый шрифт = ссылки на другие листы.
- Используйте прецеденты/зависимые трассировки Excel (Формулы → Прецеденты трассировки), чтобы понять взаимосвязи ячеек.
- Проверьте именованные диапазоны, которые могут контролировать ввод клавиш (Формулы → Диспетчер имен).

**Составьте схему работы шаблона**
- Определите, какие вкладки связаны с другими (например, «Предположения» → «IS» → «BS» → «CF»).
- Обратите внимание на все вспомогательные таблицы и их связи с основными положениями.
- Документируйте конкретные позиции и структуру шаблона перед заполнением.

### Шаг 2. Заполнение данных без нарушения формул

**Золотые правила ввода данных**

| Правило | Описание |
|------|-------------|
| Редактировать только ячейки ввода | Никогда не перезаписывайте ячейки, содержащие формулы, за исключением случаев намеренной замены формулы |
| Сохранять ссылки на ячейки | При копировании данных используйте «Вставить значения» (Ctrl+Shift+V), чтобы избежать перезаписи формул исходным форматированием |
| Сопоставьте единицы измерения шаблона | Перед вводом данных убедитесь, что шаблон использует тысячи, миллионы или фактические значения |
| Уважайте соглашения о знаках | Следуйте существующему соглашению о знаках шаблона (например, расходы должны быть положительными или отрицательными) |
| Проверьте наличие циклических ссылок | Если в шаблоне используются итеративные вычисления, убедитесь, что включен параметр «Включить итеративные вычисления» |

**Безопасный процесс ввода данных**
1. Определите точные ячейки, предназначенные для ввода (обычно выделенные или помеченные).
2. Сначала введите исторические данные, а затем проверьте правильность расчета формул для этих периодов.
3. Введите драйверы предположений, которые будут использоваться в прогнозных расчетах.
4. Просмотрите рассчитанные результаты, чтобы убедиться, что формулы работают должным образом.
5. Если ячейку формулы необходимо изменить, задокументируйте исходную формулу перед внесением изменений.

**Обработка готовых формул**
- Если формулы ссылаются на ячейки, которые вы еще не заполнили, ожидайте временных ошибок (#ССЫЛКА!, #ДЕЛ/0!), пока все входные данные не будут завершены.
- Когда формулы дают неожиданные результаты, отслеживайте прецеденты, чтобы выявить пропущенные или неправильные входные данные.
- Никогда не удаляйте строки/столбцы без проверки зависимостей формул на всех вкладках.

### Шаг 3. Проверка формул

**Проверка целостности формул**

Прежде чем полагаться на выходные данные шаблона, убедитесь, что формулы работают правильно:

| Тип проверки | Метод |
|------------|--------|
| Отследить прецеденты | Выберите ячейку формулы → Формулы → Отследить прецеденты, чтобы убедиться, что она ссылается на правильные входные данные |
| Отследить иждивенцев | Проверка потока ключевых входных данных в ожидаемые выходные ячейки |
| Оценить формулу | Используйте «Формулы» → «Вычислить формулу» для выполнения сложных вычислений |
| Проверьте жесткие коды | Формулы прогнозирования должны ссылаться на предположения, а не содержать жестко закодированные значения |
| Тест с известными значениями | Введите простые тестовые значения, чтобы убедиться, что формулы дают ожидаемые результаты |
| Согласованность перекрестных таблиц | Убедитесь, что одна и та же логика формулы применяется ко всем периодам прогнозирования |

**Распространенные проблемы с формулами, на которые следует обратить внимание**
- Смешанные абсолютные/относительные ссылки, приводящие к неверным результатам при копировании между периодами.
- Неработающие ссылки на внешние файлы или удаленные диапазоны (ошибки #REF!).
- Деление на ноль в ранние периоды до роста доходов (ошибки #DIV/0!).
- Циркулярные справочные предупреждения (могут быть предназначены для расчета процентов)
- Несогласованные формулы в столбцах прогноза (используйте Ctrl+\, чтобы найти различия)

**Проверка межтабличных связей**
– Убедитесь, что значения, отображаемые на нескольких вкладках, связаны (не дублируются).
- Проверка связи итоговых показателей графика с соответствующими позициями в основных отчетах.
– Убедитесь, что метки периодов совпадают на всех вкладках.

### Шаг 4: Проверка качества по листам

Выполните следующие проверки на каждом листе после заполнения шаблона:

**Проверка качества отчета о прибылях и убытках (IS)**
- Показатели выручки соответствуют исходным данным за исторические периоды.
- Все статьи расходов суммируются с отчетными итогами.
- Промежуточные итоги (валовая прибыль, EBIT, EBT, чистая прибыль) рассчитываются правильно.
- Логика расчета налога правильная (правильно обрабатывает убытки)
- Вкладка «Допущения для ссылок на драйверы прогнозирования» (без жестких кодов)
- Изменения от периода к периоду являются направленно обоснованными.

**Проверка качества баланса (BS)**
- Активы = Обязательства + Собственный капитал за каждый период (первичная проверка)
- Остаток денежных средств соответствует отчету о движении денежных средств на конец денежных средств.
- Счета оборотного капитала привязаны к вспомогательным графикам (если применимо)
- Нераспределенная прибыль корректно переносится вперед: Предыдущий RE + Чистая прибыль - Дивиденды +/- Корректировки = Конечный RE.
- Остатки задолженности привязаны к графику задолженности (если применимо)
- Все статьи баланса имеют соответствующие знаки (активы положительные, большинство пассивов положительные)

**Проверка качества отчета о движении денежных средств (CF)**
- Чистая прибыль выше показателей финансового директора соответствует чистой прибыли отчета о прибылях и убытках.
- Неденежные надбавки (D&A, SBC и т. д.) привязаны к их исходным графикам/ведомостям.
- Изменения оборотного капитала имеют правильные знаки (увеличение активов = использование денежных средств = отрицательное значение)
- Капитальные затраты привязаны к графику основных средств или переносу основных средств
- Финансовая деятельность связана с изменениями в счетах долга и капитала на BS.
- Конечные денежные средства соответствуют балансовым денежным средствам
- Начальные денежные средства равны конечным денежным средствам предыдущего периода.

**Поддержка плановых проверок качества**
- Начальные остатки равны конечным остаткам предыдущего периода.
- Логика прокрутки вперед завершена (Начало + Дополнения - Вычеты = Окончание)
- Итоговые суммы графика привязаны к основным позициям отчета.
- Допущения, использованные в расчетах, соответствуют вкладке «Допущения».

### Шаг 5. Проверка целостности перекрестных операторов

После проверки отдельных листов убедитесь, что три утверждения правильно интегрированы:

| Проверить | Формула | Ожидаемый результат |
|-------|---------|-----------------|
| Баланс Баланс | Активы - Обязательства - Капитал | = 0 |
| Денежная привязка | Окончание денежных средств CF - BS Cash | = 0 |
| Ссылка на чистый доход | Чистая прибыль IS - Начальная чистая прибыль CF | = 0 |
| Нераспределенная прибыль | Предыдущие RE + NI - Дивиденды - BS Окончание RE | = 0 (при необходимости откорректируйте SBC/другие элементы) |

### Шаг 6: Окончательная проверка

Прежде чем считать модель завершенной:
- Переключайтесь между всеми сценариями (если применимо), чтобы проверить прохождение проверок в каждом случае.
- Просмотрите все #REF!, #DIV/0!, #VALUE! и #NAME? ошибки и устранить или задокументировать
– Убедитесь, что все входные ячейки заполнены (найдите значения-заполнители).
- Убедитесь, что единицы измерения одинаковы на всех вкладках.
- Сохраните чистую версию перед внесением каких-либо дополнительных изменений.

### Циклическая обработка ссылок

Процентные расходы создают цикличность: Процент → Чистая прибыль → Денежные средства → Остаток долга → Проценты.

Включите итеративный расчет в Excel: Файл → Параметры → Формулы → Включить итеративный расчет. Установите максимальное количество итераций на 100, максимальное изменение на 0,001. Добавьте переключатель автоматического выключателя на вкладке «Допущения».

### Проверить категории

**Раздел 1. Согласованность валют**
- Валюта указана и документирована в «Допущениях».
- На всех вкладках используется единый символ валюты и масштаб.
– Строка единиц измерения соответствует валюте модели.

**Раздел 2: Целостность баланса**
- Активы = Обязательства + Капитал (за каждый период)
- Формула: Активы - Обязательства - Собственный капитал (должен = 0)

**Раздел 3: Целостность денежных потоков**
- Денежные привязки к BS (CF Ending Cash = BS Cash)
- Денежные средства ежемесячно или ежегодно: итоговые денежные средства (ежемесячно) = итоговые денежные средства (годовые)
- Связь NI с IS (Чистый доход CF = Чистый доход IS)
- Привязка D&A к графику
- Связи SBC с ИГ
- ΔAR, ΔInventory, ΔAP привязаны к расписанию WC
- CapEx привязан к графику DA

**Раздел 4: Нераспределенная прибыль**
- Проверка повтора транзакций RE: предшествующий RE + NI + SBC - Дивиденды = окончательный RE
- Показать разбивку компонентов для отладки.

**Раздел 5: Оборотный капитал**
- AR, инвентарь, AP привязаны к BS
- Проверки обоснованности DSO, DIO, DPO (отметьте, если они выходят за пределы нормального диапазона)

**Раздел 6: График задолженности**
- Общий долг привязан к BS (текущий + долгосрочный долг)
- Расчет процентов привязан к IS

**Раздел 6b: Долевое финансирование**
- Выручка от выпуска акций привязана к увеличению обыкновенных акций BS/APIC.
- Увеличение денежных средств за счет собственного капитала = увеличение собственного счета (необходимо сбалансировать)
- Привязка к увеличению капитала: ΔОбыкновенные акции/APIC (BS) = Выпуск акций (CFF) (должен = 0)
- Привязка капитала в 0-м году: привлеченный акционерный капитал (0-й год) = начальный акционерный капитал (1-й год)

**Раздел 6c: График NOL**
- Начало NOL (1 год / Формирование) = 0 (новый бизнес начинается с нулевого NOL)
- NOL увеличивается только тогда, когда EBT &lt; 0 (для генерации NOL необходимо осознать потери)
- Привязка DTA к BS (График NOL DTA = Отложенный налоговый актив BS)
- Использование NOL ≤ 80% от EBT (федеральное ограничение после 2017 г.)
- Баланс NOL неотрицательный (нельзя использовать больше, чем доступно)
- NOL генерируется только тогда, когда EBT &lt; 0
- Налоговые расходы = 0, когда налогооблагаемый доход ≤ 0

**Раздел 7: Иерархия сценариев**
- Абсолютные показатели: Потенциал роста > База > Потенциал снижения (NI, EBITDA, свободный денежный поток)
- Маржа: Потенциал роста > База > Потенциал снижения (GM%, EBITDA%, NI%)
- Кредитные показатели: Потенциал роста &lt; База &lt; Недостаток кредитного плеча (перевернутый)

**Раздел 8: Целостность формулы**
- COGS, S&M, G&A, R&D, SBC, определяемые % от дохода (без жестких кодов)
- Согласованные формулы на протяжении прогнозируемых лет
- Нет #REF!, #DIV/0!, #VALUE! ошибки

**Раздел 9: Пороговые значения кредитных показателей**
- Помечать показатели как зеленые/желтые/красные в зависимости от пороговых значений соглашения.
- Сводка всех тревожных флажков
