# Пиксель Арт

Преобразуйте любое изображение в пиксель-арт в стиле ретро, а затем, при необходимости, анимируйте его в короткий видеоролик.
MP4 или GIF с эффектами, соответствующими эпохе (дождь, светлячки, снег, угли).

Два скрипта поставляются с этим умением:

- `scripts/pixel_art.py` — фото → пиксель-арт PNG (дизеринг Флойда-Стейнберга)
- `scripts/pixel_art_video.py` — пиксельный PNG → анимированный MP4 (+ необязательный GIF)

Каждый из них можно импортировать или запускать напрямую. Пресеты привязаны к аппаратным палитрам
если вам нужны цвета с точностью до эпохи (NES, Game Boy, PICO-8 и т. д.) или используйте
адаптивное квантование N-цвета для аркадного стиля/стиля SNES.

## Когда использовать

- Пользователь хочет ретро-пиксельную графику из исходного изображения.
- Пользователь запрашивает стиль NES/Game Boy/PICO-8/C64/arcade/SNES
- Пользователь хочет короткую зацикленную анимацию (сцена дождя, ночное небо, снег и т. д.).
- Плакаты, обложки альбомов, посты в социальных сетях, спрайты, персонажи, аватары.

## Рабочий процесс

Перед генерацией согласуйте стиль с пользователем. Различные пресеты производят
очень разные выходы, и регенерация обходится дорого.

### Шаг 1 — Предложите стиль

Позвоните по номеру `clarify` с четырьмя репрезентативными пресетами. Выбирайте набор исходя из того, что
пользователь просил — не выбрасывайте просто все 14.

Меню по умолчанию, когда намерения пользователя неясны:

```python
clarify(
    question="Which pixel-art style do you want?",
    choices=[
        "arcade — bold, chunky 80s cabinet feel (16 colors, 8px)",
        "nes — Nintendo 8-bit hardware palette (54 colors, 8px)",
        "gameboy — 4-shade green Game Boy DMG",
        "snes — cleaner 16-bit look (32 colors, 4px)",
    ],
)
```

Если пользователь уже назвал эпоху (например, «Аркада 80-х», «Gameboy»), пропустите
`clarify` и напрямую используйте соответствующий набор настроек.

### Шаг 2. Предложите анимацию (необязательно)

Если пользователь запросил видео/GIF или результат может быть улучшен за счет движения,
спроси, какая сцена:

```python
clarify(
    question="Want to animate it? Pick a scene or skip.",
    choices=[
        "night — stars + fireflies + leaves",
        "urban — rain + neon pulse",
        "snow — falling snowflakes",
        "skip — just the image",
    ],
)
```

НЕ вызывайте `clarify` более двух раз подряд. Один для стиля, другой для сцены, если
анимация на столе. Если пользователь явно запросил определенный стиль
и сцену в своем сообщении, полностью пропустите `clarify`.

### Шаг 3 — Генерация

Сначала запустите `pixel_art()`; если была запрошена анимация, выполните цепочку
`pixel_art_video()` о результате.


## Обоснование конвейера

**Преобразование пикселей:**
1. Увеличьте контрастность/цвет/резкость (сильнее для меньших палитр)
2. Постеризация для упрощения тональных областей перед квантованием.
3. Уменьшите масштаб на `block` с помощью `Image.NEAREST` (жесткие пиксели, без интерполяции).
4. Квантование с использованием дизеринга Флойда-Стейнберга — против адаптивного
   N-цветовая палитра ИЛИ именованная аппаратная палитра
5. Вернитесь к более высокому уровню с `Image.NEAREST`

Квантование ПОСЛЕ уменьшения масштаба сохраняет сглаживание в соответствии с окончательной пиксельной сеткой.
Предыдущее квантование привело бы к расточительству ошибок на исчезающих деталях.

**Наложение видео:**
- Копирует базовый кадр при каждом тике (статический фон)
- Наложение отрисовок частиц без сохранения состояния для каждого кадра (одна функция на эффект)
- Кодирует через ffmpeg `libx264 -pix_fmt yuv420p -crf 18`
- Дополнительный GIF-файл через `palettegen` + `paletteuse`.

## Зависимости

- Питон 3.9+
- Подушка (`pip install Pillow`)
- ffmpeg в PATH (нужен только для видео — этот пакет устанавливает Hermes)

## Подводные камни

- Ключи поддонов чувствительны к регистру (`"NES"`, `"PICO_8"`, `"GAMEBOY_ORIGINAL"`).
- Очень маленькие источники (шириной менее 100 пикселей) сворачиваются под блоки размером 8–10 пикселей. Повысьте масштаб
  источник сначала, если он крошечный.
- Дробные числа `block` или `palette` нарушат квантование — оставьте их положительными целыми числами.
- Количество частиц анимации настроено для холстов размером ~640x480. На очень большом
  изображений, вам может потребоваться второй проход с другим начальным значением плотности.
- `mono_green` / `mono_amber` усилие `color=0.0` (обесцвечивание). Если вы переопределите
  и сохраняя цветность, двухцветная палитра может создавать полосы на гладких участках.
- Цикл `clarify`: вызовите его не более двух раз за ход (стиль, затем сцена). Не надо
  подарите пользователю больше вариантов выбора.

## Проверка

- PNG создается на пути вывода.
- Четкие квадратные пиксельные блоки, видимые при размере блока пресета.
- Количество цветов соответствует заданному (насмотритесь на изображение или запустите `Image.open(p).getcolors()`).
- Видео имеет действительный формат MP4 (`ffprobe` может его открыть) с ненулевым размером.
