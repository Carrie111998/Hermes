# Навык акций

Рыночные данные только для чтения через Yahoo Finance. Пять команд: `quote`, `search`,
`history`, `compare`, `crypto`. Только stdlib Python — без ключа API, без pip
устанавливает. Конечная точка Yahoo является неофициальной и может ограничивать или изменять скорость.

## Когда использовать

- Пользователь запрашивает текущую цену акций (AAPL, TSLA, MSFT, ...)
- Пользователь хочет найти тикер по названию компании.
- Пользователь хочет историю или производительность OHLCV за определенный диапазон дат.
- Пользователь хочет сравнить несколько тикеров рядом
- Пользователь запрашивает цену криптовалюты (BTC, ETH, SOL,...)

## Предварительные условия

Только стандартная библиотека Python 3.8+. Необязательно: установите `ALPHA_VANTAGE_KEY` для обогащения
`market_cap`, `pe_ratio` и 52-недельные уровни, когда Yahoo защищена от крошек
поля возвращаются к нулю. Бесплатный ключ: https://www.alphavantage.co/support/#api-key.

## Как бежать

Вызовите с помощью инструмента `terminal`. После установки:

```
SCRIPT=~/.hermes/skills/finance/stocks/scripts/stocks_client.py
python3 $SCRIPT quote AAPL
```

Весь вывод — это JSON на стандартный вывод — перенаправьте его через `jq`, если вы хотите его разрезать.

## Краткий справочник

```
python3 $SCRIPT quote AAPL
python3 $SCRIPT quote AAPL MSFT GOOGL TSLA
python3 $SCRIPT search "Tesla"
python3 $SCRIPT history NVDA --range 6mo
python3 $SCRIPT compare AAPL MSFT GOOGL
python3 $SCRIPT crypto BTC ETH SOL
```

## Команды

### `quote SYMBOL [SYMBOL2 ...]`

Текущая цена, изменение, процент изменения, объем, 52-недельный максимум/минимум.

### `search QUERY`

Найдите тикеры по названию компании. Возвращает топ-5: символ, имя, обмен, тип.

### `history SYMBOL [--range RANGE]`

Ежедневная OHLCV плюс статистика (мин, максимум, среднее, общая доходность %). Диапазоны: `1mo`,
`3mo`, `6mo`, `1y`, `5y`. По умолчанию: `1mo`.

### `compare SYMBOL1 SYMBOL2 [...]`

Рядом: цена, процент изменения, производительность за 52 недели.

### `crypto SYMBOL [SYMBOL2 ...]`

Цены на криптовалюту. Передайте `BTC` (скрипт автоматически добавляет `-USD`).

## Подводные камни

- API Yahoo Finance является неофициальным. Конечные точки могут измениться или ограничить скорость
  без предварительного уведомления — если запросы начнут терпеть неудачу, вот почему.
- `market_cap` и `pe_ratio` могут возвращать значение null на `quote`, когда Yahoo
  сессия крошки не установлена. Установите `ALPHA_VANTAGE_KEY` для обратной засыпки.
- Добавьте небольшую задержку между массовыми запросами, чтобы избежать ограничения скорости.
- Доступно только для чтения — размещение заказа и интеграция учетной записи невозможны.
