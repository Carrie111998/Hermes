# AgentMail — почтовые ящики, принадлежащие агенту.

## Требования

- **Ключ API AgentMail** (обязательно) — зарегистрируйтесь на https://console.agentmail.to (уровень бесплатного пользования: 3 почтовых ящика, 3000 электронных писем в месяц; платные планы от 20 долларов США в месяц).
- Node.js 18+ (для сервера MCP)

## Когда использовать
Используйте этот навык, когда вам нужно:
- Дайте агенту собственный адрес электронной почты.
- Отправлять электронные письма автономно от имени агента
- Получать и читать входящие электронные письма
- Управление потоками электронной почты и разговорами
- Зарегистрируйтесь для получения услуг или выполните аутентификацию по электронной почте.
- Общайтесь с другими агентами или людьми по электронной почте.

Это НЕ для чтения личной электронной почты пользователя (используйте для этого Himalaya или Gmail).
AgentMail предоставляет агенту собственную личность и почтовый ящик.

## Настройка

### 1. Получите ключ API
- Перейдите на https://console.agentmail.to.
– Создайте учетную запись и сгенерируйте ключ API (начинается с `am_`).

### 2. Настройте MCP-сервер
Добавьте в `~/.hermes/config.yaml` (вставьте свой фактический ключ — переменные среды MCP не расширяются из .env):
```yaml
mcp_servers:
  agentmail:
    command: "npx"
    args: ["-y", "agentmail-mcp"]
    env:
      AGENTMAIL_API_KEY: "am_your_key_here"
```

### 3. Перезапустите Гермес
```bash
hermes
```
Все 11 инструментов AgentMail теперь доступны автоматически.

## Доступные инструменты (через MCP)

| Инструмент | Описание |
|------|-------------|
| `list_inboxes` | Список всех входящих сообщений агентов |
| `get_inbox` | Получить подробную информацию о конкретном почтовом ящике |
| `create_inbox` | Создать новый почтовый ящик (получает реальный адрес электронной почты) |
| `delete_inbox` | Удалить входящие |
| `list_threads` | Список веток электронной почты во входящих |
| `get_thread` | Получить конкретную цепочку писем |
| `send_message` | Отправить новое письмо |
| `reply_to_message` | Ответить на существующее письмо |
| `forward_message` | Переслать письмо |
| `update_message` | Обновить метки/статус сообщений |
| `get_attachment` | Загрузить вложение к электронной почте |

## Процедура

### Создайте почтовый ящик и отправьте электронное письмо
1. Создайте отдельный почтовый ящик:
   – Используйте `create_inbox` с именем пользователя (например, `hermes-agent`).
   - Агент получает адрес: `hermes-agent@agentmail.to`.
2. Отправьте электронное письмо:
   – Используйте `send_message` с `inbox_id`, `to`, `subject`, `text`.
3. Проверьте ответы:
   – Используйте `list_threads`, чтобы увидеть входящие разговоры.
   – Используйте `get_thread`, чтобы прочитать конкретную тему.

### Проверьте входящую электронную почту
1. Используйте `list_inboxes`, чтобы найти идентификатор своего почтового ящика.
2. Используйте `list_threads` с идентификатором папки «Входящие», чтобы просматривать беседы.
3. Используйте `get_thread` для чтения обсуждения и его сообщений.

### Ответ на электронное письмо
1. Получите тред с `get_thread`.
2. Используйте `reply_to_message` с идентификатором сообщения и текстом ответа.

## Примеры рабочих процессов

**Запишитесь на услугу:**
```
1. create_inbox (username: "signup-bot")
2. Use the inbox address to register on the service
3. list_threads to check for verification email
4. get_thread to read the verification code
```

**Обращение агента к человеку:**
```
1. create_inbox (username: "hermes-outreach")
2. send_message (to: user@example.com, subject: "Hello", text: "...")
3. list_threads to check for replies
```

## Подводные камни
- Уровень бесплатного пользования ограничен 3 почтовыми ящиками и 3000 электронными письмами в месяц.
– Электронная почта поступает из домена `@agentmail.to` на бесплатном уровне (пользовательские домены на платных планах).
- Для сервера MCP (`npx -y agentmail-mcp`) требуется Node.js (18+).
- Должен быть установлен пакет Python `mcp`: `pip install mcp`.
- Для входящей электронной почты в режиме реального времени (веб-перехватчики) требуется общедоступный сервер — вместо этого используйте опрос `list_threads` через cronjob для личного использования.

## Проверка
После установки протестируйте с помощью:
```
hermes --toolsets mcp -q "Create an AgentMail inbox called test-agent and tell me its email address"
```
Вы должны увидеть возвращенный новый адрес почтового ящика.
