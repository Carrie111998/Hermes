# Игрок в покемонов

Играйте в игры про покемонов с помощью безголовой эмуляции, используя пакет `pokemon-agent`.

## Когда использовать
- Пользователь говорит «играть в покемонов», «начать покемонов», «играть в покемонов».
- Пользователь спрашивает о Pokemon Red, Blue, Yellow, FireRed и т. д.
- Пользователь хочет посмотреть, как ИИ играет в покемонов.
- Пользователь ссылается на файл ПЗУ (.gb, .gbc, .gba)

## Процедура запуска

### 1. Первоначальная настройка (клонирование, venv, установка)
Репозиторий — NousResearch/pokemon-agent на GitHub. Клонируйте его, затем
настройте виртуальную среду Python 3.10+. Используйте УФ (предпочтительно для скорости)
чтобы создать venv и установить пакет в редактируемом режиме с помощью
пибой экстра. Если uv недоступен, вернитесь к python3 -m venv + pip.

Если касса уже существует (например, ~/pokemon-agent с готовым венвом),
просто перейдите туда и укажите источник .venv/bin/activate вместо повторного клонирования.

Вам также понадобится файл ROM. Попросите пользователя указать его (предыдущая настройка может
уже есть один в roms/pokemon_red.gb внутри кассы).
НИКОГДА не загружайте и не предоставляйте файлы ПЗУ — всегда спрашивайте пользователя.

### 2. Запускаем игровой сервер
Из каталога pokemon-agent с активированным venv запустите
pokemon-agent служит с --rom, указывающим на ПЗУ, и --port 9876.
Запустите его в фоновом режиме с помощью &.
Чтобы возобновить игру из сохраненной игры, добавьте --load-state к имени сохранения.
Подождите 4 секунды перед запуском, затем проверьте с помощью GET /health.

### 3. Настройте панель мониторинга в реальном времени для просмотра пользователем.
Используйте обратный туннель SSH через localhost.run, чтобы пользователь мог просматривать
панель управления в своем браузере. Подключиться по ssh, перенаправить локально
порт 9876 на удаленный порт 80 на конечной точке localhost.run без ключа
(ssh -R 80:localhost:9876 ssh://nokey@localhost.run). Перенаправить вывод
в файл журнала, подождите 10 секунд, затем найдите журнал для .lhr.life
URL-адрес. Дайте пользователю URL-адрес с добавлением /dashboard/.
URL-адрес туннеля меняется каждый раз — при перезапуске дайте пользователю новый.

## Сохранить и загрузить

### Когда сохранять
- Каждые 15-20 ходов игрового процесса
- ВСЕГДА перед битвами в спортзале, встречами с соперниками или рискованными боями.
- Перед входом в новый город или подземелье
- Перед любым действием, в котором вы не уверены

### Как сохранить
POST/save с описательным именем. Хорошие примеры:
before_brock, Route1_start, mt_moon_entrance, got_cut

### Как загрузить
POST /load с именем сохранения.

### Список доступных сохранений
GET /saves возвращает все сохраненные состояния.

### Загрузка при запуске сервера
Используйте флаг --load-state при запуске сервера для автоматической загрузки сохранения.
Это быстрее, чем загрузка через API после запуска.

## Цикл игрового процесса

### Шаг 1. НАБЛЮДАЙТЕ — проверьте состояние И сделайте снимок экрана
GET /state для позиции, HP, битвы, диалога.
ПОЛУЧИТЕ /screenshot и сохраните его в /tmp/pokemon.png, затем используйте Vision_analyze.
Всегда делайте ОБА — состояние RAM дает цифры, зрение дает пространственную осведомленность.

### Шаг 2: ОРИЕНТАЦИЯ
- Диалог/текст на экране → продвинуть его вперед
- В бою → сражайся или беги
- Вечеринка пострадала → отправляйтесь в Центр Покемонов.
- Рядом с целью → ориентируйтесь осторожно.

### Шаг 3: РЕШИТЕ
Приоритет: диалог > битва > лечение > сюжетная цель > обучение > исследование.

### Шаг 4: ДЕЙСТВУЙТЕ — сделайте максимум 2–4 шага, затем повторите проверку.
POST/action с КОРОТКИМ списком действий (2-4 действия, а не 10-15).

### Шаг 5: ПРОВЕРКА — снимок экрана после каждой последовательности ходов
Сделайте снимок экрана и используйте Vision_analyze, чтобы подтвердить, что вы переместились туда, куда
предназначено. Это САМЫЙ ВАЖНЫЙ шаг. Без видения вы заблудитесь.

## Справочник действий
- press_a — подтвердить, поговорить, выбрать
- press_b — отменить, закрыть меню
- press_start — открыть меню игры
- walk_up/down/left/right — переместить одну плитку
-hold_b_N — удерживать B в течение N кадров (используйте для ускорения просмотра текста)
- wait_60 — подождать около 1 секунды (60 кадров)
- a_until_dialog_end — нажимайте A несколько раз, пока диалог не очистится.

## Важные советы из опыта

### ПОСТОЯННО ИСПОЛЬЗУЙТЕ ЗРЕНИЕ
- Делайте скриншот каждые 2-4 шага движения
- Состояние ОЗУ говорит вам о положении и HP, но НЕ о том, что вокруг вас.
- Выступы, заборы, знаки, двери зданий, NPC — видны только на скриншоте.
- Задайте модели видения конкретные вопросы: «Что находится в одной клетке к северу от меня?»
- При застревании всегда делайте снимок экрана, прежде чем пробовать случайные направления.

### Деформационные переходы требуют дополнительного времени ожидания
При проходе через дверь или лестницу экран становится черным во время
переход карты. Вы ДОЛЖНЫ дождаться его завершения. Добавьте 2-3 ожидания_60
действия после любой деформации двери/лестницы. Не дожидаясь, позиция гласит:
как устаревшие, и вы подумаете, что все еще находитесь на старой карте.

### Ловушка для выхода из здания
Когда вы выходите из здания, вы оказываетесь прямо ПЕРЕД дверью.
Если вы пойдете на север, вы вернетесь обратно внутрь. ВСЕГДА отступайте первым
пройдя 2 плитки влево или вправо, затем продолжайте движение в намеченном направлении.

### Обработка диалогов
Текст Gen 1 прокручивается медленно, буква за буквой. Чтобы ускорить диалог,
удерживайте B в течение 120 кадров, затем нажмите A. Повторите при необходимости. Холдинг B делает
отображение текста на максимальной скорости. Затем нажмите A, чтобы перейти к следующей строке.
Действие a_until_dialog_end проверяет флаг диалога RAM, но этот флаг
не улавливает ВСЕ текстовые состояния. Если диалог кажется зависшим, воспользуйтесь руководством
Вместо этого используйте шаблон Hold_b + press_a и проверьте скриншот.

### Уступы односторонние
Уступы (небольшие края скалы) можно перепрыгнуть только ВНИЗ (на юг), но никогда не подниматься.
ВВЕРХ (север). Если вас заблокировал уступ, идущий на север, вы должны пойти налево или направо.
чтобы найти пробел вокруг него. Используйте зрение, чтобы определить, в каком направлении
разрыв есть. Задайте явный вопрос модели видения.

### Стратегия навигации
- Двигайтесь по 2–4 шага за раз, затем сделайте снимок экрана, чтобы проверить положение.
- При входе в новую область сразу же делайте снимок экрана, чтобы сориентироваться.
- Спросите модель видения: «В каком направлении к [пункту назначения]?»
- Если зависло на 3+ попытки, сделайте снимок экрана и полностью переоцените результат.
- Не спамьте 10-15 движениями — промахнетесь или застрянете.

### Бегство от диких сражений
В меню боя кнопка «БЕГ» находится в правом нижнем углу. Чтобы добраться до него по умолчанию
положение курсора (БОРЬБА, вверху слева): нажмите вниз, затем вправо, чтобы переместить курсор.
для запуска, затем нажмите A. Перенесите с помощью Hold_b для ускорения просмотра текста/анимации.

### Битва (БОРЬБА)
В боевом меню БОЙ находится вверху слева (положение курсора по умолчанию).
Нажмите A, чтобы войти в выбор хода, еще раз A, чтобы использовать первый ход.
Затем удерживайте B, чтобы ускорить анимацию атак и текст.

## Боевая стратегия

### Дерево решений
1. Хотите поймать? → Ослабьте, а затем бросьте покебол
2. Дикий тебе не нужен? → БЕГАТЬ
3. Тип преимущества? → Используйте суперэффективный прием
4. Нет преимуществ? → Используйте самый сильный удар STAB.
5. Низкое здоровье? → Переключиться или использовать Зелье

### Таблица типов Gen 1 (ключевые совпадения)
- Вода побеждает Огонь, Землю, Камень
- Огонь побеждает Траву, Насекомое, Лед
- Трава побеждает воду, землю, камень
- Электрический бьет Воду, Полет
- Земля превосходит огонь, электричество, камень, яд
- Психика превосходит Файтинг, Яд (доминирует в Гене 1!)

### Причуды первого поколения
- Специальная характеристика = как нападение, так и защита для специальных приемов.
- Психический тип подавлен (призрачные движения ошибочны)
- Критические удары основаны на характеристике скорости.
- Wrap/Bind не позволяет противнику действовать.
- Ошибка фокусировки энергии: СНИЖАЕТ уровень критического удара, а не повышает его.

## Этапы прогресса
- Выберите стартер
- Доставить посылку из Viridian Mart и получить Pokedex
- Значок валуна — Брок (Камень) → используйте воду/траву.
- Каскадный значок — Туман (Вода) → используйте Траву/Электрик.
- Значок Грома — Лейтенант Сурдж (Электрический) → использовать Землю
- Радужный значок — Эрика (Трава) → использовать Огонь/Лед/Полет.
- Значок души — Кога (Яд) → использовать Землю/Психическую силу.
- Знак болота — Сабрина (Экстрасенс) → самый сложный тренажерный зал
- Значок вулкана — Блейн (Огонь) → используйте воду/землю
- Значок Земли — Джованни (Земля) → используйте Воду/Траву/Лед
- Элитная Четверка → Чемпион!

## Остановка игры
1. Сохраните игру с описательным именем через POST /save.
2. Обновите память с помощью PKM:PROGRESS.
3. Сообщите пользователю: «Игра сохранена как [имя]! Скажите «играть в покемонов», чтобы продолжить».
4. Уничтожьте фоновые процессы сервера и туннеля.

## Подводные камни
- НИКОГДА не загружайте и не предоставляйте файлы ROM.
- НЕ отправляйте более 4-5 действий без проверки зрения
- Всегда обходите стороной после выхода из здания, прежде чем идти на север.
- Всегда добавляйте wait_60 x2-3 после деформации двери/лестницы.
- Обнаружение диалогов через ОЗУ ненадежно — проверьте скриншотами.
- Сохраняйтесь ПЕРЕД опасными встречами.
- URL-адрес туннеля меняется каждый раз при его перезапуске.
