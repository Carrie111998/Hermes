# Интеграция NeuroSkill BCI

Подключите Hermes к работающему экземпляру [NeuroSkill](https://neuroskill.com/), чтобы прочитать
Показатели мозга и тела в реальном времени с носимого устройства BCI. Используйте это, чтобы дать
когнитивно-ориентированные реакции, предлагать меры вмешательства и отслеживать умственную работоспособность
со временем.

> **⚠️ Только для исследовательского использования** — NeuroSkill — это исследовательский инструмент с открытым исходным кодом. Это

## Предварительные условия

- **Node.js 20+** установлен (`node --version`)
- **Настольное приложение NeuroSkill**, работающее с подключенным устройством BCI.
- **Аппаратное обеспечение BCI**: Muse 2, Muse S или OpenBCI (4-канальная ЭЭГ + PPG + IMU через BLE)
- `npx neuroskill status` возвращает данные без ошибок

### Проверка настройки
```bash
node --version                    # Must be 20+
npx neuroskill status             # Full system snapshot
npx neuroskill status --json      # Machine-parseable JSON
```

Если `npx neuroskill status` возвращает ошибку, сообщите пользователю:
- Убедитесь, что настольное приложение NeuroSkill открыто.
- Убедитесь, что устройство BCI включено и подключено через Bluetooth.
- Проверьте качество сигнала — зеленые индикаторы в NeuroSkill (≥0,7 на электрод)
- Если `command not found`, установите Node.js 20+.

## Ссылка CLI: `npx neuroskill <command>`

Все команды поддерживают `--json` (необработанный JSON, безопасный для канала) и `--full` (человеческое резюме + JSON).

| Команда | Описание |
|---------|-------------|
| `status` | Полный снимок системы: устройство, баллы, полосы, коэффициенты, сон, история |
| `session [N]` | Разбивка по одной сессии с тенденциями первого и второго полугодия (0 = самые последние) |
| `sessions` | Список всех записанных сессий за все дни |
| `search` | ИНС-поиск сходства для нейроподобных исторических моментов |
| `compare` | Сравнение сеансов A/B с дельтами показателей и анализом тенденций |
| `sleep [N]` | Классификация стадий сна (Пробуждение/N1/N2/N3/REM) с анализом |
| `label "text"` | Создать аннотацию с отметкой времени в текущий момент |
| `search-labels "query"` | Семантический векторный поиск по прошлым меткам |
| `interactive "query"` | Кросс-модальный поиск по 4-слойному графу (текст → EXG → метки) |
| `listen` | Потоковая передача событий в реальном времени (по умолчанию 5 с, установите `--seconds N`) |
| `umap` | 3D-проекция UMAP вложений сеансов |
| `calibrate` | Открыть окно калибровки и запустить профиль |
| `timer` | Запустить таймер фокусировки (предустановки Pomodoro/Deep Work/Short Focus) |
| `notify "title" "body"` | Отправьте уведомление ОС через приложение NeuroSkill |
| `raw '{json}'` | Передача необработанного JSON на сервер |

### Глобальные флаги
| Флаг | Описание |
|------|-------------|
| `--json` | Необработанный вывод JSON (без ANSI, конвейерная безопасность) |
| `--full` | Человеческое резюме + раскрашенный JSON |
| `--port <N>` | Переопределить порт сервера (по умолчанию: автоматическое обнаружение, обычно 8375) |
| `--ws` | Принудительный транспорт WebSocket |
| `--http` | Принудительно использовать HTTP-транспорт |
| `--k <N>` | Подсчет ближайших соседей (поиск, поисковые метки) |
| `--seconds <N>` | Продолжительность прослушивания (по умолчанию: 5) |
| `--trends` | Показать тенденции показателей за сеанс (сеансы) |
| `--dot` | Вывод Graphviz DOT (интерактивный) |

## 1. Проверка текущего состояния

### Получайте текущие показатели
```bash
npx neuroskill status --json
```

**Всегда используйте `--json`** для надежного анализа. Вывод по умолчанию раскрашен
человекочитаемый текст.

### Ключевые поля в ответе

Объект `scores` содержит все текущие метрики (шкала 0–1, если не указано иное):

```jsonc
{
  "scores": {
    "focus": 0.70,           // β / (α + θ) — sustained attention
    "relaxation": 0.40,      // α / (β + θ) — calm wakefulness
    "engagement": 0.60,      // active mental investment
    "meditation": 0.52,      // alpha + stillness + HRV coherence
    "mood": 0.55,            // composite from FAA, TAR, BAR
    "cognitive_load": 0.33,  // frontal θ / temporal α · f(FAA, TBR)
    "drowsiness": 0.10,      // TAR + TBR + falling spectral centroid
    "hr": 68.2,              // heart rate in bpm (from PPG)
    "snr": 14.3,             // signal-to-noise ratio in dB
    "stillness": 0.88,       // 0–1; 1 = perfectly still
    "faa": 0.042,            // Frontal Alpha Asymmetry (+ = approach)
    "tar": 0.56,             // Theta/Alpha Ratio
    "bar": 0.53,             // Beta/Alpha Ratio
    "tbr": 1.06,             // Theta/Beta Ratio (ADHD proxy)
    "apf": 10.1,             // Alpha Peak Frequency in Hz
    "coherence": 0.614,      // inter-hemispheric coherence
    "bands": {
      "rel_delta": 0.28, "rel_theta": 0.18,
      "rel_alpha": 0.32, "rel_beta": 0.17, "rel_gamma": 0.05
    }
  }
}
```

Также включает: `device` (состояние, батарея, прошивка), `signal_quality` (для каждого электрода 0–1),
`session` (длительность, эпохи), `embeddings`, `labels`, `sleep` сводка и `history`.

### Интерпретация вывода

Разберите JSON и переведите метрики на естественный язык. Никогда не сообщайте необработанные данные
одни лишь цифры — всегда придавайте им значение:

**ДЕЛАТЬ:**
> «Ваш фокус сейчас твердый на 0,70 — это территория состояния потока. Сердце
> Частота стабильна и составляет 68 ударов в минуту, а ваш ФАА положительный, что говорит о хорошем
>подход к мотивации. Прекрасное время, чтобы заняться чем-то сложным».

**НЕЛЬЗЯ:**
> «Фокус: 0,70, Релаксация: 0,40, ЧСС: 68»

Ключевые пороговые значения интерпретации (полное руководство см. в `references/metrics.md`):
- **Фокус > 0,70** → перемещайте территорию государства, защищайте ее
- **Фокус &lt; 0,40** → предложите перерыв или протокол
- **Сонливость > 0,60** → предупреждение об усталости, риск микросна
- **Расслабление &lt; 0,30** → необходимо вмешательство при стрессе
- **Когнитивная нагрузка > 0,70 продолжительная** → сброс сознания или перерыв
- **TBR > 1,5** → тета-доминантность, снижение исполнительного контроля
- **ФАУ &lt; 0** → отказ/негативный эффект — рассмотреть вопрос о ребалансировке FAA
- **SNR &lt; 3 дБ** → ненадежный сигнал, предложите переместить электрод.

## 2. Анализ сессии

### Разбивка по одному сеансу
```bash
npx neuroskill session --json         # most recent session
npx neuroskill session 1 --json       # previous session
npx neuroskill session 0 --json | jq '{focus: .metrics.focus, trend: .trends.focus}'
```

Возвращает полные показатели с **тенденциями первого и второго полугодия** (`"up"`, `"down"`, `"flat"`).
Используйте это, чтобы описать, как развивалась сессия:

> «Ваш фокус начался с 0,64 и к концу поднялся до 0,76 — явный восходящий тренд.
> Когнитивная нагрузка снизилась с 0,38 до 0,28, что позволяет предположить, что задача стала более автоматической.
> как ты поселился."

### Список всех сеансов
```bash
npx neuroskill sessions --json
npx neuroskill sessions --trends      # show per-session metric trends
```

## 3. Исторический поиск

### Поиск сходства нейронов
```bash
npx neuroskill search --json                    # auto: last session, k=5
npx neuroskill search --k 10 --json             # 10 nearest neighbors
npx neuroskill search --start <UTC> --end <UTC> --json
```

Находит моменты в истории, которые нейронно похожи, используя приближение HNSW.
поиск ближайшего соседа по 128-D вложениям ZUNA. Возвращает статистику расстояния,
временное распределение (часы суток) и наиболее подходящие дни.

Используйте это, когда пользователь спрашивает:
- «Когда я последний раз был в таком состоянии?»
- «Найди мои лучшие фокус-сессии»
- «Когда я обычно терплю крах днем?»

### Поиск по семантической метке
```bash
npx neuroskill search-labels "deep focus" --k 10 --json
npx neuroskill search-labels "stress" --json | jq '[.results[].EXG_metrics.tbr]'
```

Ищет текст метки с использованием векторных вложений (Xenova/bge-small-en-v1.5). Возврат
сопоставление меток со связанными с ними показателями EXG во время маркировки.

### Межмодальный поиск по графу
```bash
npx neuroskill interactive "deep focus" --json
npx neuroskill interactive "deep focus" --dot | dot -Tsvg > graph.svg
```

Четырехслойный график: запрос → текстовые метки → точки EXG → близлежащие метки. Используйте `--k-text`,
`--k-EXG`, `--reach <minutes>` для настройки.

## 4. Сравнение сессий
```bash
npx neuroskill compare --json                   # auto: last 2 sessions
npx neuroskill compare --a-start <UTC> --a-end <UTC> --b-start <UTC> --b-end <UTC> --json
```

Возвращает дельты показателей с абсолютным изменением, процентным изменением и направлением
~50 показателей. Также включает массивы `insights.improved[]` и `insights.declined[]`,
подготовка сна для обоих сеансов и идентификатор задания UMAP.

Интерпретируйте сравнения с учетом контекста — упоминайте тенденции, а не только дельты:
> «Вчера у вас было два сильных блока фокусировки (10 утра и 14 часов). Сегодня у вас был один
> примерно с 11 утра это продолжается. Ваша общая вовлеченность сегодня выше
> но всплесков стресса было больше — ваш индекс стресса подскочил на 15% и
> ФАУ чаще оказывалось отрицательным».

```bash
# Sort metrics by improvement percentage
npx neuroskill compare --json | jq '.insights.deltas | to_entries | sort_by(.value.pct) | reverse'
```

## 5. Данные о сне
```bash
npx neuroskill sleep --json                     # last 24 hours
npx neuroskill sleep 0 --json                   # most recent sleep session
npx neuroskill sleep --start <UTC> --end <UTC> --json
```

Возвращает поэтапную стадию сна (5-секундные окна) с анализом:
- **Коды стадий**: 0=Пробуждение, 1=N1, 2=N2, 3=N3 (глубокий), 4=REM
- **Анализ**: эффективность_pct, onset_latency_min, rem_latency_min, количество боев.
- **Здоровые мишени**: N3 15–25 %, REM 20–25 %, эффективность >85 %, начало &lt;20 мин.

```bash
npx neuroskill sleep --json | jq '.summary | {n3: .n3_epochs, rem: .rem_epochs}'
npx neuroskill sleep --json | jq '.analysis.efficiency_pct'
```

Используйте это, когда пользователь упоминает сон, усталость или восстановление.

Метки хранятся в базе данных и индексируются для последующего извлечения через `search-labels`.
и команды `interactive`.

## 7. Потоковая передача в реальном времени
```bash
npx neuroskill listen --seconds 30 --json
npx neuroskill listen --seconds 5 --json | jq '[.[] | select(.event == "scores")]'
```

Потоковая передача событий WebSocket в реальном времени (EXG, PPG, IMU, оценки, метки) для указанных
продолжительность. Требуется подключение WebSocket (недоступно для `--http`).

Используйте это для сценариев непрерывного мониторинга или для наблюдения за изменениями показателей в режиме реального времени.
во время протокола.

## 8. Визуализация UMAP
```bash
npx neuroskill umap --json                      # auto: last 2 sessions
npx neuroskill umap --a-start <UTC> --a-end <UTC> --b-start <UTC> --b-end <UTC> --json
```

3D-проекция UMAP с графическим ускорением встроенных элементов ZUNA. `separation_score`
показывает, насколько нейронно различны два сеанса:
- **> 1,5** → Сеансы нейронно различны (разные состояния мозга)
- **&lt; 0,5** → Похожие состояния мозга на обоих сеансах

## 9. Проактивное информирование государства

### Проверка начала сеанса
В начале сеанса при необходимости запустите проверку статуса, если пользователь упоминает
он носит свое устройство или спрашивает об его состоянии:
```bash
npx neuroskill status --json
```

Введите краткое описание состояния:
> «Быстрая проверка: концентрация внимания повышается на 0,62, расслабление хорошее на 0,55, а ваш
> ФАУ позитивно — задействована мотивация подхода. Похоже, начало хорошее».

### Когда следует активно упоминать состояние

Упоминайте когнитивное состояние **только**, когда:
- Пользователь прямо спрашивает («Как у меня дела?», «Проверьте мою концентрацию»)
- Пользователь сообщает о трудностях с концентрацией внимания, стрессе или усталости.
- Критический порог пересечен (сонливость > 0,70, концентрация внимания < 0,30 устойчива)
- Пользователь собирается сделать что-то требующее когнитивных функций и запрашивает готовность.

**НЕ** прерывайте состояние потока для отчета о показателях. Если фокус > 0,75, защитите
сессия — молчание — правильный ответ.

## 10. Предложение протоколов

Если метрики указывают на необходимость, предложите протокол от `references/protocols.md`.
Всегда спрашивайте перед началом — никогда не прерывайте состояние потока:

> «Последние 15 минут ваше внимание снижается, а TBR преодолевает
> 1,5 — признаки тета-доминирования и умственной усталости. Хочешь, чтобы я провел тебя через
> Тета-бета-якорь нейробиоуправления? Это 90-секундное упражнение, в котором используются ритмичные упражнения.
> счет и дыхание для подавления теты и подъема бета».

Ключевые триггеры:
- **Фокус &lt; 0,40, TBR > 1,5** → Тета-бета-якорь нейробиоуправления или коробочное дыхание
- **Расслабление &lt; 0,30, высокий индекс стресса** → Сердечная когерентность или Дыхание 4-7-8.
- **Когнитивная нагрузка > 0,70 продолжительная** → Разгрузка когнитивной нагрузки (свалка разума)
- **Сонливость > 0,60** → Сброс ультрадиана или сброс бодрствования
- **ФАУ &lt; 0 (отрицательный)** → Ребалансировка ФАУ
- **Состояние потока (фокус > 0,75, вовлеченность > 0,70)** → НЕ прерывайте
- **Высокая неподвижность + head_index** → Последовательность расслабления шеи
- **Низкое RMSSD (&lt;25 мс)** → Тонирование вагуса

## 11. Дополнительные инструменты

### Таймер фокусировки
```bash
npx neuroskill timer --json
```
Запускает окно Таймера фокусировки с помощью Pomodoro (25/5), Deep Work (50/10) или
Предустановки короткого фокуса (15/5).

### Калибровка
```bash
npx neuroskill calibrate
npx neuroskill calibrate --profile "Eyes Open"
```
Открывает окно калибровки. Полезно, когда качество сигнала плохое или пользователь
хочет установить персонализированный базовый уровень.

### Уведомления ОС
```bash
npx neuroskill notify "Break Time" "Your focus has been declining for 20 minutes"
```

### Передача необработанного JSON
```bash
npx neuroskill raw '{"command":"status"}' --json
```
Для любой команды сервера, которая еще не сопоставлена с подкомандой CLI.

## Обработка ошибок

| Ошибка | Вероятная причина | Исправить |
|-------|-------------|-----|
| `npx neuroskill status` зависает | Приложение NeuroSkill не работает | Открыть настольное приложение NeuroSkill |
| `device.state: "disconnected"` | Устройство BCI не подключено | Проверьте Bluetooth, батарею устройства |
| Все результаты возвращаются 0 | Плохой контакт электродов | Переставьте повязку, смочите электроды |
| `signal_quality` значений &lt; 0,7 | Свободные электроды | Отрегулируйте посадку, очистите контакты электродов |
| ОСШ &lt; 3 дБ | Шумный сигнал | Минимизируйте движения головой, проверьте окружающую среду |
| `command not found: npx` | Node.js не установлен | Установите Node.js 20+ |

## Примеры взаимодействий

**"Как у меня сейчас дела?"**
```bash
npx neuroskill status --json
```
→ Интерпретируйте результаты естественно, упоминая концентрацию, расслабление, настроение и любые заметные
  коэффициенты (ФАУ, TBR). Предлагайте действие только в том случае, если метрики указывают на необходимость.

**"Я не могу сконцентрироваться"**
```bash
npx neuroskill status --json
```
→ Проверьте, подтверждают ли это показатели (высокая тета, низкая бета, повышение TBR, высокая сонливость).
→ В случае подтверждения предложите соответствующий протокол от `references/protocols.md`.
→ Если показатели в порядке, проблема может быть мотивационной, а не неврологической.

**"Сравните мое внимание сегодня и вчера"**
```bash
npx neuroskill compare --json
```
→ Интерпретируйте тенденции, а не только цифры. Укажите, что улучшилось, что ухудшилось и
  возможные причины.

**"Когда я последний раз был в состоянии потока?"**
```bash
npx neuroskill search-labels "flow" --json
npx neuroskill search --json
```
→ Сообщайте о временных метках, связанных показателях и о том, что делал пользователь (из ярлыков).

**"Как я спал?"**
```bash
npx neuroskill sleep --json
```
→ Сообщите об архитектуре сна (N3%, REM%, эффективность), сравните со здоровыми целями,
  и обратите внимание на любые проблемы (высокие периоды бодрствования, низкий уровень REM).

**"Запомните этот момент — у меня только что случился прорыв"**
```bash
npx neuroskill label "breakthrough"
```
→ Подтвердите сохранение метки. При желании запишите текущие показатели, чтобы запомнить состояние.
