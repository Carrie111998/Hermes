# Генерация мемов

Создавайте реальные изображения мемов по теме. Выбирает шаблон, пишет подписи и визуализирует настоящий файл .png с наложением текста.

## Когда использовать

- Пользователь просит вас создать мем.
- Пользователь хочет мем о конкретной теме, ситуации или разочаровании.
- Пользователь говорит «Мем это» или что-то подобное.

## Доступные шаблоны

Скрипт поддерживает **любой из примерно 100 популярных шаблонов imgflip** по имени или идентификатору, а также 10 тщательно подобранных шаблонов с настроенным вручную позиционированием текста.

### Кураторские шаблоны (настраиваемое размещение текста)

| удостоверение личности | Имя | Поля | Лучшее для |
|----|------|--------|----------|
| `this-is-fine` | Это нормально | верх, низ | хаос, отрицание |
| `drake` | Яркая горячая линия Drake | отклонить, одобрить | отвергая/предпочитая |
| `distracted-boyfriend` | Отвлеченный парень | отвлечение, ток, человек | искушение, смена приоритетов |
| `two-buttons` | Две кнопки | левый, правый, человек | невозможный выбор |
| `expanding-brain` | Расширение мозга | 4 уровня | нарастающая ирония |
| `change-my-mind` | Измени мое мнение | заявление | горячие дубли |
| `woman-yelling-at-cat` | Женщина кричит на кошку | женщина, кошка | аргументы |
| `one-does-not-simply` | Делать не просто | верх, низ | обманчиво трудные вещи |
| `grus-plan` | План Грю | шаг 1-3, реализация | планы, которые имеют неприятные последствия |
| `batman-slapping-robin` | Бэтмен бьет Робина | Робин, Бэтмен | отказ от плохих идей |

### Динамические шаблоны (из API imgflip)

Любой шаблон, которого нет в курируемом списке, можно использовать по имени или идентификатору imgflip. Они имеют интеллектуальное позиционирование текста по умолчанию (сверху/снизу для 2 полей, равномерное расположение для 3+). Искать с помощью:
```bash
python "$SKILL_DIR/scripts/generate_meme.py" --search "disaster"
```

## Процедура

### Режим 1: Классический шаблон (по умолчанию)

1. Прочитайте тему пользователя и определите основную динамику (хаос, дилемма, предпочтения, ирония и т. д.).
2. Выберите шаблон, который лучше всего подходит. Используйте столбец «Наиболее подходящее для» или выполните поиск по запросу `--search`.
3. Напишите короткие подписи для каждого поля (максимум 8–12 слов на поле, чем короче, тем лучше).
4. Найдите каталог скриптов навыка:
   ```
   SKILL_DIR=$(dirname "$(find ~/.hermes/skills -path '*/meme-generation/SKILL.md' 2>/dev/null | head -1)")
   ```
5. Запускаем генератор:
   ```bash
   python "$SKILL_DIR/scripts/generate_meme.py" <template_id> /tmp/meme.png "caption 1" "caption 2" ...
   ```
6. Верните изображение с помощью `MEDIA:/tmp/meme.png`.

### Режим 2: Пользовательское изображение AI (когда доступно image_generate)

Используйте это, когда классический шаблон не подходит или когда пользователь хочет чего-то оригинального.

1. Сначала напишите подписи.
2. Используйте `image_generate`, чтобы создать сцену, соответствующую концепции мема. НЕ включайте какой-либо текст в приглашение к изображению — текст будет добавлен сценарием. Опишите только визуальную сцену.
3. Найдите путь к сгенерированному изображению по URL-адресу результата image_generate. При необходимости загрузите его по локальному пути.
4. Запустите скрипт с `--image` для наложения текста, выбрав режим:
   - **Наложение** (текст прямо на изображении, белый с черным контуром):
     ```bash
     python "$SKILL_DIR/scripts/generate_meme.py" --image /path/to/scene.png /tmp/meme.png "top text" "bottom text"
     ```
   - **Полоски** (черные полосы вверху/внизу с белым текстом — более четкие, всегда читаемые):
     ```bash
     python "$SKILL_DIR/scripts/generate_meme.py" --image /path/to/scene.png --bars /tmp/meme.png "top text" "bottom text"
     ```
   Используйте `--bars`, если изображение насыщенное/детализированное и текст поверх него трудно прочитать.
5. **Проверьте визуально** (если `vision_analyze` доступен). Убедитесь, что результат хороший:
   ```
   vision_analyze(image_url="/tmp/meme.png", question="Is the text legible and well-positioned? Does the meme work visually?")
   ```
   Если с флагами модели визуального представления возникают проблемы (трудночитаемый текст, неправильное размещение и т. д.), попробуйте другой режим (переключение между наложением и полосами) или заново сгенерируйте сцену.
6. Верните изображение с помощью `MEDIA:/tmp/meme.png`.

## Примеры

**"отладка производства в 2 часа ночи":**
```bash
python generate_meme.py this-is-fine /tmp/meme.png "SERVERS ARE ON FIRE" "This is fine"
```

**"выбор между сном и еще одним эпизодом":**
```bash
python generate_meme.py drake /tmp/meme.png "Getting 8 hours of sleep" "One more episode at 3 AM"
```

**"этапы утра понедельника":**
```bash
python generate_meme.py expanding-brain /tmp/meme.png "Setting an alarm" "Setting 5 alarms" "Sleeping through all alarms" "Working from bed"
```

## Шаблоны листингов

Чтобы просмотреть все доступные шаблоны:
```bash
python generate_meme.py --list
```

## Подводные камни

- Делайте подписи КОРОТКИМИ. Мемы с длинным текстом выглядят ужасно.
- Сопоставьте количество текстовых аргументов с количеством полей шаблона.
- Выберите шаблон, который соответствует структуре шутки, а не только теме.
– Не создавайте разжигающий ненависть, оскорбительный или лично ориентированный контент.
- Скрипт кэширует изображения шаблонов в `scripts/.cache/` после первой загрузки.

## Проверка

Вывод правильный, если:
- По выходному пути был создан файл .png.
- Текст в шаблоне разборчивый (белый с черным контуром).
- Шутка удаётся — заголовок соответствует задуманной структуре шаблона.
- Файл можно доставить через MEDIA: путь
