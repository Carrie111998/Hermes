## Краткий справочник

### Общие шаблоны

**Схема 1:** Чтобы убедиться в том, что для вашего задания по обучению существует приемлемая скорость передачи данных, запуск тестов NCCL может помочь выявить узкие места, например:

```
./build/all_reduce_perf -b 8 -e 128M -f 2 -g 3
```

**Шаблон 2.** Настройте свою модель для использования FSDP в YAML-файле Axolotl. Например:

```
fsdp_version: 2
fsdp_config:
  offload_params: true
  state_dict_type: FULL_STATE_DICT
  auto_wrap_policy: TRANSFORMER_BASED_WRAP
  transformer_layer_cls_to_wrap: LlamaDecoderLayer
  reshard_after_forward: true
```

**Шаблон 3:** context_parallel_size должен быть делителем общего количества графических процессоров. Например:

```
context_parallel_size
```

**Схема 4:** Например: - С 8 графическими процессорами и без параллелизма последовательностей: 8 различных пакетов обрабатываются за шаг - С 8 графическими процессорами и context_parallel_size=4: за шаг обрабатываются только 2 разных пакета (каждый разделен на 4 графических процессора) - Если ваш micro_batch_size для каждого графического процессора равен 2, глобальный размер пакета уменьшается с 16 до 4

```
context_parallel_size=4
```

**Шаблон 5:** Установка save_compressed: true в вашей конфигурации позволяет сохранять модели в сжатом формате, что: - Уменьшает использование дискового пространства примерно на 40 % - Поддерживает совместимость с vLLM для ускорения вывода - Поддерживает совместимость с llmcompressor для дальнейшей оптимизации (пример: квантование)

```
save_compressed: true
```

**Шаблон 6:** Примечание. Необязательно помещать интеграцию в папку интеграций. Он может находиться в любом месте, если он установлен в пакете в вашей среде Python. Пример см. в этом репозитории: https://github.com/axolotl-ai-cloud/diff-transformer.

```
integrations
```

**Схема 7:** Обработка как отдельных примеров, так и пакетных данных. - отдельный пример: образец['input_ids'] представляет собой список[int] - пакетные данные: образец['input_ids'] представляет собой список[список[int]]

```
utils.trainer.drop_long_seq(sample, sequence_len=2048, min_sequence_len=2)
```
