# Интерфейс командной строки Антигравитации (`agy`)

Руководство оператора для интерфейса командной строки Antigravity, вызываемого как `agy`. Запустить все `agy`
команды через инструмент Hermes `terminal`; проверьте его конфигурацию и журналы с помощью
`read_file`. Этот навык является справочным + процедурным — он не накручивает сеть
API, поэтому у самого Гермеса аутентифицироваться нечем.

## Когда использовать

- Установка, обновление или дымовое тестирование двоичного файла `agy`.
- Вождение неинтерактивных `agy --print` / `agy -p` одиночных снимков.
- Отладка аутентификации, песочницы, разрешений или состояния плагина Antigradity.
- Чтение настроек Антигравитации, сочетаний клавиш, разговоров или журналов.

## Ментальная модель

Антигравитация имеет два слоя — держите их отдельно, иначе руководство будет неправильным:

1. **Команды оболочки** — `agy help`, `agy install`, `agy plugin`,
   `agy update`, `agy changelog`. Запустите их с помощью инструмента `terminal`.
2. **Интерактивные слэш-команды в сеансе** — `/config`, `/permissions`,
   `/skills`, `/agents` и т. д. Они существуют только внутри работающего `agy` TUI.
   сеанс, а не в оболочке оболочки.

`agy help` показывает поверхность оболочки оболочки, а НЕ команды слэша в сеансе.

## Предварительные условия

— Бинарный файл `agy` в PATH. Проверьте с помощью инструмента `terminal`:
  `command -v agy && agy --version`.
- Для этого навыка не требуются переменные окружения или ключи API — Антигравитация управляет самостоятельно.
  авторизация через связку ключей ОС / вход в браузер (см. Аутентификация ниже).

## Как бежать

Вызовите каждую команду `agy` с помощью инструмента `terminal`. Примеры:

```
terminal(command="agy --version")
terminal(command="agy help")
terminal(command="agy plugin list")
terminal(command="agy --print 'Summarize the repo in 3 bullets'", workdir="/path/to/project")
```

Для интерактивного многоходового сеанса TUI запустите `agy` с помощью `pty=true` (и
tmux для захвата/мониторинга), тот же шаблон, что и `codex`/`claude-code`.
использование навыков. Для одноразовых дымовых тестов и скриптовых подсказок предпочитайте
`agy --print` (неинтерактивный).

Чтобы проверить собственные файлы Антигравитации, используйте `read_file` в путях в разделе Core.
пути ниже — не `cat` их через терминал.

## Шаблоны делегирования

`agy` — это серверная часть агента кодирования из того же семейства, что и `codex` / `claude-code`,
поэтому применяются те же формы делегирования. Используйте их при передаче реальной работы (функции,
исправления, обзоры, второе мнение) в Antigravity, а не просто дымовое тестирование.

### One-shot (предпочтительно для сценарных подсказок и второго мнения)

```
terminal(command="agy -p 'Review this diff for bugs and security issues' --model 'Gemini 3.1 Pro (High)'", workdir="/path/to/repo", timeout=300)
```

`-p` неинтерактивен: он запускает приглашение и завершает работу. Выберите двигатель с
`--model` (запустите `agy models` для получения точных отображаемых строк, например
`'Gemini 3.1 Pro (High)'`, `'Claude Opus 4.6 (Thinking)'`). Добавьте дополнительный контекст
корни с повторяющимся `--add-dir`.

### Длинные/ограниченные прогоны (тесты, сборки, многофайловые изменения)

Сделайте это фоном и получите уведомление о завершении, как и в случае с навыком `codex`:

```
terminal(command="agy -p 'Implement the change described in TASK.md and run the tests' --dangerously-skip-permissions", workdir="/path/to/repo", background=true, notify_on_complete=true)
# then: process(action="poll"/"log"/"wait", session_id=<id>)
```

###Интерактивный многооборотный (PTY + tmux)

Для разговорного сеанса запустите `agy -i` (или пустой `agy`) под `pty=true`.
с tmux для `capture-pane`/`send-keys`, именно такой шаблон описан в
навыки `codex` / `claude-code`. Возобновите работу позже с помощью `--continue` / `-c` или
конкретный `--conversation <id>`.

### Параллельные экземпляры (пакетная подзадача/разветвление рабочего дерева)

Создайте по одному рабочему дереву git для каждой задачи и запустите независимый `agy -p` в каждом.
(фон), затем соберите результаты — то же самое рабочее дерево с разветвлением навыка `codex`
используется для пакетного исправления проблем. Привязанный параллелизм к тому, что машина и ваш
обзорная емкость может поглотить.

### Вывод + ограничивающее предупреждение (отличается от Claude Code)

- `agy -p` возвращает **обычный текст** — `--output-format json`** нет и
  Конверт без результата с `session_id` / стоимостью / количеством ходов. Разобрать стандартный вывод
  напрямую; не ожидайте объекта JSON.
- **нет `--max-turns`**. Тираж ограничен **`--print-timeout`**
  (по умолчанию `5m`). Поднимите его для длительных задач: `--print-timeout 20m`. Сопряжение с
  `terminal` `timeout=`, чтобы внешний вызов не прерывал прохождение.

### Граница оркестрации

Антигравитация — это **серверная часть исполнения рабочих или сторонний рецензент**.
деталь выполнения принадлежит агенту/профилю, выполняющему задачу, а НЕ первоклассному
оркестровка примитивная. Не размещайте `agy` на канбан-доске как отдельную карточку или
относиться к нему как к координационному уровню; маршрутизировать работу через обычный граф задач и
пусть назначенный работник выберет `agy` (вместо инструментов codex/claude-code/direct) в качестве своего
метод. Обращайтесь к нему явно только тогда, когда пользователь спрашивает, когда работник
настроен для его упаковки или когда вы хотите провести перекрестную проверку семейства Gemini по
план другого агента или разница.

## Основные пути

- Двоичный файл/точка входа: `agy`
– Каталог данных приложения: `~/.gemini/antigravity-cli/`.
- Файл настроек: `~/.gemini/antigravity-cli/settings.json`
- Файл привязок клавиш: `~/.gemini/antigravity-cli/keybindings.json`.
- Журналы: `~/.gemini/antigravity-cli/log/cli-*.log`
- Разговоры: `~/.gemini/antigravity-cli/conversations/`
- Мозговые артефакты: `~/.gemini/antigravity-cli/brain/`
- История: `~/.gemini/antigravity-cli/history.jsonl`
- Установка плагина: `~/.gemini/antigravity-cli/plugins/<plugin_name>/`

## Краткий справочник

### Команды оболочки
- `agy changelog`
- `agy help`
- `agy install`
- `agy plugin` / `agy plugins`
- `agy update`

### Полезные флаги
- `--add-dir`
- `--continue` / `-c`
- `--conversation`
- `--dangerously-skip-permissions`
- `--print` / `-p`
- `--print-timeout`
- `--prompt`
- `--prompt-interactive` / `-i`
- `--sandbox`
- `--log-file`
- `--version`

### Подкоманды плагина (`agy plugin --help`)
- `list`, `import [source]`, `install <target>`, `uninstall <name>`,
  `enable <name>`, `disable <name>`, `validate [path]`, `link <mp> <target>`,
  `help`

### Флаги установки (`agy install --help`)
- `--dir`, `--skip-aliases`, `--skip-path`

### Команды с косой чертой в сеансе
- **Управление беседой:** `/resume` (`/switch`), `/rewind` (`/undo`),
  `/rename <name>`, `/clear`, `/fork`, `/reset`, `/new`
- **Настройки и инструменты:** `/config`, `/settings`, `/permissions`, `/model`,
  `/keybindings`, `/statusline`, `/tasks`, `/skills`, `/mcp`, `/open <path>`,
  `/usage`, `/logout`, `/agents`
- **Помощники по подсказкам**: `@` автозаполнение пути, `esc esc` очищает подсказку (когда
  без потоковой передачи), `!` запускает команду терминала напрямую, `?` открывает справку

## Настройки и разрешения

### Клавиши общих настроек (`settings.json`)
- `allowNonWorkspaceAccess`
- `colorScheme`
- `permissions.allow`
- `trustedWorkspaces`

### Режимы разрешений
`request-review`, `always-proceed`, `strict`, `proceed-in-sandbox`.

### Поведение в песочнице
- `enableTerminalSandbox` — логическое значение в `settings.json`; по умолчанию `false`.
- Переопределения времени запуска (`--sandbox`, `--dangerously-skip-permissions`) могут
  заменить постоянные настройки для текущего сеанса.

## Поведение аутентификации

- CLI сначала пытается использовать безопасный набор ключей ОС.
- При отсутствии сохраненного сеанса происходит возврат к входу в Google через браузер.
- Локально открывается браузер по умолчанию; через SSH он печатает URL-адрес авторизации
  и ожидает, что код авторизации будет вставлен обратно.
- `/logout` удаляет сохраненные учетные данные.

## Плагины

- Этап плагинов под `~/.gemini/antigravity-cli/plugins/<plugin_name>/`.
- Они могут объединять навыки, агентов, правила, серверы MCP и перехватчики.
- `agy plugin list`, возвращающий отсутствие импортированных плагинов, является допустимым пустым состоянием.

## Подводные камни

- `agy help` показывает команды-оболочки, а не интерактивные команды с косой чертой.
- `agy --version` — безопасная неинтерактивная проверка версии; `agy version` — это
  интерактивный и может выйти из строя без реального телетайпа.
- Первое место для поиска сбоев: `~/.gemini/antigravity-cli/log/cli-*.log`.
  (прочитайте с помощью `read_file`).
– Не путайте постоянные настройки JSON с переопределениями времени запуска.
- `~/.gemini/antigravity-cli/bin/agentapi` — это тонкая оболочка для `agy agentapi`.
- В WSL хранилище токенов основано на файлах, поэтому проблемы аутентификации обычно возникают в локальных файлах/файлах.
  проблемы состояния сеанса, а не проблемы только браузера.
- Идентификация рабочей области может зависеть от каталога запуска и `.antigravitycli`.
  маркер проекта.
- `agy -p` печатает только обычный текст — нет `--output-format json`, нет результата
  конверт. Не пытайтесь проанализировать из него объект JSON (в отличие от `claude-code`).
– Связанные тиражи с `--print-timeout` (по умолчанию `5m`), а не `--max-turns`.
  (которого нет на `agy`).
