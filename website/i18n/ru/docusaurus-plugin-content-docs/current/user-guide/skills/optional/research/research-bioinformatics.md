# Портал навыков биоинформатики

Используйте, когда вас спрашивают о биоинформатике, геномике, секвенировании, вызове вариантов, экспрессии генов, анализе отдельных клеток, структуре белка, фармакогеномике, метагеномике, филогенетике или любой другой задаче вычислительной биологии.

Этот навык открывает доступ к двум библиотекам навыков в области биоинформатики с открытым исходным кодом. Вместо того, чтобы объединять сотни навыков, специфичных для конкретной предметной области, он индексирует их и выбирает то, что вам нужно, по запросу.

## Как получить и использовать навык

1. Определите домен и имя навыка из указателя ниже.
2. Клонируйте соответствующий репозиторий (поверхностное клонирование для экономии времени):
   ```bash
   # bioSkills (reference material)
   git clone --depth 1 https://github.com/GPTomics/bioSkills.git /tmp/bioSkills

   # ClawBio (runnable pipelines)
   git clone --depth 1 https://github.com/ClawBio/ClawBio.git /tmp/ClawBio
   ```
3. Прочитайте конкретный навык:
   ```bash
   # bioSkills — each skill is at: <category>/<skill-name>/SKILL.md
   cat /tmp/bioSkills/variant-calling/gatk-variant-calling/SKILL.md

   # ClawBio — each skill is at: skills/<skill-name>/
   cat /tmp/ClawBio/skills/pharmgx-reporter/README.md
   ```
4. Используйте полученный навык в качестве справочного материала. Это НЕ навыки в формате Hermes — относитесь к ним как к экспертным гидам в предметной области. Они содержат правильные параметры, правильные флаги инструментов и проверенные конвейеры.

## Настройка среды

Эти навыки предполагают использование биоинформатической рабочей станции. Общие зависимости:

```bash
# Python
pip install biopython pysam cyvcf2 pybedtools pyBigWig scikit-allel anndata scanpy mygene

# R/Bioconductor
Rscript -e 'BiocManager::install(c("DESeq2","edgeR","Seurat","clusterProfiler","methylKit"))'

# CLI tools (Ubuntu/Debian)
sudo apt install samtools bcftools ncbi-blast+ minimap2 bedtools

# CLI tools (macOS)
brew install samtools bcftools blast minimap2 bedtools

# Or via Conda (recommended for reproducibility)
conda install -c bioconda samtools bcftools blast minimap2 bedtools fastp kraken2
```

## Подводные камни

- Полученные навыки НЕ в формате Hermes SKILL.md. Они используют свою собственную структуру (bioSkills: кулинарные книги шаблонов кода; ClawBio: README + скрипты Python). Прочтите их как экспертный справочный материал.
— BioSkills — это справочные руководства — они показывают правильные параметры и шаблоны кода, но не являются исполняемыми конвейерами.
- Навыки ClawBio являются исполняемыми — многие из них имеют флаги `--demo` и могут запускаться напрямую.
- Оба репозитория предполагают, что установлены инструменты биоинформатики. Проверьте предварительные условия перед запуском конвейеров.
- Для ClawBio сначала запустите `pip install -r requirements.txt` в клонированном репозитории.
- Файлы геномных данных могут быть очень большими. Помните о дисковом пространстве при загрузке эталонных геномов, наборов данных SRA или построении индексов.
