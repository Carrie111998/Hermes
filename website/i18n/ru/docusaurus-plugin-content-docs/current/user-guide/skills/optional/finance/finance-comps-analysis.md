## ⚠️ ВАЖНО: приоритет источника данных (ПРОЧИТАЙТЕ ПЕРВУЮ)

**ВСЕГДА следуйте следующей иерархии источников данных:**

1. **ПЕРВОЕ: проверьте источники данных MCP**. Если доступны S&P Kensho MCP, FactSet MCP или Daloopa MCP, используйте их исключительно для финансовой и торговой информации.
2. **НЕ используйте веб-поиск**, если доступны указанные выше источники данных MCP.
3. **ТОЛЬКО если MCP недоступны:** Используйте терминал Bloomberg, документы SEC EDGAR или другие институциональные источники.
4. **НИКОГДА не используйте веб-поиск в качестве основного источника данных** — ему не хватает точности, контрольных журналов и надежности, необходимых для анализа институционального уровня.

**Почему это важно.** Источники MCP предоставляют проверенные данные институционального уровня с соответствующими цитатами. Результаты веб-поиска могут быть устаревшими, неточными или ненадежными для финансового анализа.

## Обзор
Этот навык учит агента проводить сопоставимый анализ компаний институционального уровня, который сочетает в себе операционные показатели, коэффициенты оценки и статистический сравнительный анализ. Результатом является структурированная электронная таблица Excel, которая позволяет принимать обоснованные инвестиционные решения посредством сравнения с аналогами.

**Справочный материал и контекстуализация:**

Пример сравнительного анализа компании представлен в `examples/comps_example.xlsx`. При использовании этого или других файлов примеров в этом каталоге навыков используйте их разумно:

**ОБЯЗАТЕЛЬНО используйте примеры для:**
- Понимание структурной иерархии (как расположены разделы)
- Понимание ожидаемого уровня строгости (статистическая глубина, стандарты документации)
- Принципы обучения (понятные заголовки, прозрачные формулы, контрольные журналы)

**НЕ используйте примеры для:**
- Точное воспроизведение формата или метрики
- Копирование макета без учета контекста.
- Применение одного и того же визуального стиля независимо от аудитории.

**ВСЕГДА сначала спросите себя:**
1. **"У вас есть предпочтительный формат или мне следует адаптировать стиль шаблона?"**
2. **«Кто аудитория?»** (Инвестиционный комитет, презентация совету директоров, краткий справочник, подробная памятка)
3. **"Какой ключевой вопрос?"** (Оценка, анализ роста, конкурентное позиционирование, эффективность)
4. **"Каков контекст?"** (оценка слияний и поглощений, инвестиционное решение, отраслевой сравнительный анализ, обзор эффективности)

**Адаптируйте с учетом особенностей:**
- **Отраслевой контекст**: крупным технологическим мегакомпаниям нужны другие показатели, чем новым SaaS-стартапам.
- **Специфические отраслевые потребности**: заранее добавьте соответствующие показатели (например, ARR в облаке, корпоративные клиенты, экосистема разработчиков для технологий).
- **Знакомство с компанией**: известным компаниям может потребоваться меньше опыта, больше внимания уделять дельта-анализу.
- **Тип решения**: слияния и поглощения требуют иного внимания, чем постоянный мониторинг портфеля.

**Основной принцип.** Используйте принципы шаблонов (четкая структура, статистическая строгость, прозрачные формулы), но меняйте исполнение в зависимости от контекста. Целью является анализ институционального качества, а не шаблоны, выглядящие как институциональные.

Предоставленные пользователем примеры и явные предпочтения всегда имеют приоритет над значениями по умолчанию.

## Основная философия
**"Сначала создайте правильную структуру, а затем позвольте данным рассказать историю".**

Начните с заголовков, которые заставляют стратегически думать о том, что важно, вводят точные данные, создают прозрачные формулы и позволяют автоматически получать статистику. Хороший сборник должен быть сразу же прочитан тем, кто его не создавал.

## ⚠️ ВАЖНО: формулы вместо жестких кодов + пошаговая проверка

**Формулы, а не жесткие коды:**
- Каждое производное значение (маржа, кратное, статистика) ДОЛЖНО представлять собой формулу Excel, ссылающуюся на ячейки ввода. Никогда не вставляйте заранее вычисленное число.
– При использовании Python/openpyxl для построения листа: напишите `cell.value = "=E7/C7"` (строка формулы), а НЕ `cell.value = 0.687` (вычисленный результат).

- Почему: модель должна обновляться автоматически при изменении входных данных. Жестко запрограммированное поле — это тихая ошибка, ожидающая своего часа.

**Пошаговое согласование с пользователем:**
- После настройки структуры → покажите пользователю макет заголовка перед заполнением данных.
- После ввода необработанных данных → покажите пользователю блок ввода и подтвердите источники/периоды перед построением формул.
- После построения формул операционных показателей → покажите рассчитанную прибыль и проверьте здравомыслие пользователя, прежде чем переходить к оценке.
- После построения мультипликаторов → покажите мультипликаторы и убедитесь, что они выглядят разумными, прежде чем добавлять статистику.
– НЕ создавайте весь лист целиком, а затем представляйте его — выявляйте ошибки заранее, проверяя каждый раздел.

## Раздел 1: Структура и настройка документа

### Блок заголовка (строки 1–3)
```
Row 1: [ANALYSIS TITLE] - COMPARABLE COMPANY ANALYSIS
Row 2: [List of Companies with Tickers] • [Company 1 (TICK1)] • [Company 2 (TICK2)] • [Company 3 (TICK3)]
Row 3: As of [Period] | All figures in [USD Millions/Billions] except per-share amounts and ratios
```

**Почему это важно:** Мгновенно устанавливает контекст. Любой, кто открывает этот файл, знает, на что он смотрит, когда он был создан и как интерпретировать цифры.

### Стандарты Visual Convention (НЕОБЯЗАТЕЛЬНО: пользовательские настройки и загруженные шаблоны всегда имеют приоритет)

**ВАЖНО: Это только рекомендуемые значения по умолчанию. Всегда расставляйте приоритеты:**
1. Явные предпочтения пользователя в отношении форматирования.
2. Форматирование из любых загруженных файлов шаблонов.
3. Руководства по стилю компании/команды
4. Эти значения по умолчанию (только если не предоставлено других указаний)

**Рекомендуемый шрифт и типографика:**
- **Семейство шрифтов**: Times New Roman (профессиональный, читаемый, отраслевой стандарт).
- **Размер шрифта**: 11 пт для ячеек данных, 12 пт для заголовков.
– **Жирный текст**: заголовки разделов, названия компаний, статистические метки.

**Цвет и затенение по умолчанию — профессиональная сине-серая палитра (лучше минимальная):**
- **Сохраняйте сдержанность** — только синий и серый цвета. НЕ добавляйте зеленый, оранжевый, красный или несколько акцентных цветов. В чистом листе композиций всего используется 3-4 цвета.
– **Заголовки разделов** (например, «ОПЕРАЦИОННАЯ СТАТИСТИКА И ФИНАНСОВЫЕ ПОКАЗАТЕЛИ»):
  - Темно-синий фон (`#1F4E79` или `#17365D` темно-синий)
  - Белый жирный текст
  - Полное затенение строк во всех столбцах.
– **Заголовки столбцов** (например, «Компания», «Выручка», «Маржа»):
  - Голубой фон (`#D9E1F2` или аналогичный бледно-голубой)
  - Черный жирный текст
  - Центрированное выравнивание
- **Строки данных**:
  - Белый фон для данных компании
  - Черный текст для формул; синий текст для жестко закодированных входов
– **Строки статистики** (максимум, 75-й процентиль и т. д.):
  - Светло-серый фон (`#F2F2F2`)
  - Черный текст, метки с выравниванием по левому краю.
- **Вот вся палитра**: темно-синий + голубой + светло-серый + белый. Ничего больше, если в шаблоне пользователя не указано иное.

**Рекомендуемые соглашения о форматировании:**
- **Десятичная точность**:
  - Проценты: 1 десятичный (12,3%)
  - Кратность: 1 десятичная (13,5x)
  - Суммы в долларах: без десятичных знаков, разделитель тысяч (69 632).
  - Маржа указана в процентах: 1 десятичный знак (68,7%).
- **Границы**: без границ (чистый, минималистичный внешний вид).
- **Выравнивание**: все показатели выравниваются по центру для обеспечения четкого и однородного вида.
– **Размеры ячеек**: ширина всех столбцов должна быть одинаковой/равной, высота всех строк должна быть одинаковой (создается четкая, профессиональная сетка).

**Примечание.** Если пользователь предоставляет файл шаблона или указывает другое форматирование, используйте его.

## Раздел 2: Операционная статистика и финансовые показатели

### Основные столбцы (начните с них)
1. **Компания** – имена с единообразным форматированием.
2. **Доход** – показатель размера (может быть долгосрочным, ежеквартальным или годовым в зависимости от контекста).
3. **Рост выручки** – процентное изменение по сравнению с прошлым годом.
4. **Валовая прибыль** – выручка за вычетом себестоимости проданных товаров.
5. **Валовая прибыль** – GP/выручка (фундаментальная рентабельность).
6. **EBITDA** – прибыль до вычета процентов, налогов, износа и амортизации.
7. **Маржа EBITDA** – EBITDA/выручка (операционная эффективность).

### Дополнительные дополнения (выбирайте в зависимости от отрасли/цели)
– **Ежеквартально или долгосрочно** – Включите оба варианта, если сезонность имеет значение.
- **Свободный денежный поток** - Для капиталоемких предприятий или предприятий SaaS.
- **Маржа свободного денежного потока** - свободный денежный поток/выручка (эффективность генерации денежных средств)
- **Чистая прибыль** - Для зрелых и прибыльных компаний.
- **Операционная прибыль** - Для предприятий с различными показателями D&A.
- **Показатели капитальных затрат** - Для отраслей с большим объемом активов
- **Правило 40** - Специально для SaaS (Рост % + Маржа %)
- **Конверсия свободного денежного потока** - Для анализа качества доходов (расширенный уровень)

### Примеры формул (на примере строки 7)
```excel
// Core ratios - these are always calculated
Gross Margin (F7): =E7/C7
EBITDA Margin (H7): =G7/C7

// Optional ratios - include if relevant
FCF Margin: =[FCF]/[Revenue]
Net Margin: =[Net Income]/[Revenue]
Rule of 40: =[Growth %]+[FCF Margin %]
```

**Золотое правило:** каждое соотношение должно быть следующим: [Что-то] / [Доход] или [Что-то] / [Что-то из этого листа]. Будьте проще.

### Блок статистики (после данных компании)

**ВАЖНО: добавьте статистические формулы для всех сопоставимых показателей (коэффициенты, маржа, темпы роста, мультипликаторы).**

```
[Leave one blank row for visual separation]
- Maximum: =MAX(B7:B9)
- 75th Percentile: =QUARTILE(B7:B9,3)
- Median: =MEDIAN(B7:B9)
- 25th Percentile: =QUARTILE(B7:B9,1)
- Minimum: =MIN(B7:B9)
```

**Столбцы, для которых НЕОБХОДИМА статистика (сопоставимые показатели):**
- Рост выручки %, валовая прибыль %, рентабельность EBITDA %, прибыль на акцию
- EV/Выручка, EV/EBITDA, P/E, % дивидендной доходности, бета

**Столбцы, которым НЕ нужна статистика (показатели размера):**
- Выручка, EBITDA, чистая прибыль (абсолютный размер зависит от масштаба компании)
- Рыночная капитализация, стоимость предприятия (не сопоставимы между компаниями разного размера)

**Примечание.** Добавьте одну пустую строку между строками данных компании и статистикой для визуального разделения. НЕ добавляйте строку заголовка «СТАТИСТИКА СЕКТОРА» или «СТАТИСТИКА ОЦЕНКИ».

**Почему квартили важны.** Они показывают распределение, а не только среднее значение. Мультипликатор 75-го процентиля говорит вам, по какой цене торгуют «премиальные» компании.

## Раздел 3: Мультипликаторы оценки и инвестиционные показатели

### Основные столбцы оценки (начните с них)
1. **Компания** – тот же порядок, что и в рабочем разделе.
2. **Рыночная капитализация** – текущая рыночная оценка.
3. **Стоимость предприятия** – рыночная капитализация ± чистый долг/денежные средства.
4. **EV/Выручка** – сколько рынок платит за доллар продаж.
5. **EV/EBITDA** – сколько рынок платит за доллар прибыли.
6. **Коэффициент P/E** – цена относительно чистой прибыли.

### Дополнительные показатели оценки (выбирайте в зависимости от контекста)
- **Доходность свободного денежного потока** – свободный денежный поток/рыночная капитализация (для анализа, ориентированного на денежные средства)
- **Коэффициент PEG** - P/E/коэффициент роста (для растущих компаний)
- **Цена/Бухгалтерская** – рыночная стоимость по сравнению с балансовой стоимостью (для предприятий с большим объемом активов)
- **ROE/ROA** – показатели рентабельности (для сравнения рентабельности).
- **Средний темп роста выручки/EBITDA** - Исторические темпы роста (для анализа тенденций)
- **Оборачиваемость активов** - Выручка/активы (для операционной эффективности)
- **Долг/Капитал** - Кредитное плечо (для анализа структуры капитала)

**Ключевой принцип:** Включите 3–5 основных мультипликаторов, которые важны для вашей отрасли. Не включайте все возможные показатели только потому, что можете.

### Примеры формул
```excel
// Core multiples - always include these
EV/Revenue: =[Enterprise Value]/[LTM Revenue]
EV/EBITDA: =[Enterprise Value]/[LTM EBITDA]
P/E Ratio: =[Market Cap]/[Net Income]

// Optional multiples - include if data available
FCF Yield: =[LTM FCF]/[Market Cap]
PEG Ratio: =[P/E]/[Growth Rate %]
```

### Правило перекрестных ссылок
**КРИТИЧЕСКОЕ:** Коэффициенты оценки ДОЛЖНЫ ссылаться на раздел операционных показателей. Никогда не вводите одни и те же необработанные данные дважды. Если выручка указана в C7, то формула EV/Выручка должна ссылаться на C7.

### Блок статистики
Та же структура, что и в рабочем разделе: Макс, 75-й, Медиана, 25-й, Мин для каждой метрики. Добавьте одну пустую строку для визуального разделения данных компании и статистики. НЕ добавляйте строку заголовка «СТАТИСТИКА ОЦЕНКИ».

## Раздел 4: Примечания и методическая документация

### Необходимые компоненты

**Источники данных и качество:**
- Откуда данные? (S&P Kensho MCP, FactSet MCP, Daloopa MCP, Bloomberg, документы SEC)
- Какой период это охватывает? (4 квартал 2024 г., аудированные данные)
- Как это проверялось? (Перекрестная проверка с 10-K/10-Q)
- Примечание. Отдайте приоритет источникам данных MCP (S&P Kensho, FactSet, Daloopa), если они доступны, для большей точности и отслеживаемости.

**Основные определения:**
- Метод расчета EBITDA (валовая прибыль + D&A или операционная прибыль + D&A)
- Формула свободного денежного потока (операционный CF - CapEx)
- Объяснение специальных показателей (Правило 40, конвертация свободного денежного потока)
- Определения периодов времени (периоды расчета LTM, CAGR)

**Методология оценки:**
- Как рассчитывалась стоимость предприятия? (Рыночная капитализация + Чистый долг)
- Какие темпы роста использовались? (Исторический среднегодовой темп роста, прогнозные оценки)
- Какие-то корректировки внесены? (исключены единоразовые статьи, нормализованная прибыль)

**Схема анализа:**
- Каков инвестиционный тезис? (Эффективность облака/SaaS)
- Какие показатели наиболее важны? (генерация денежных средств, эффективность капитала)
- Как читателям интерпретировать статистику? (Квартили предоставляют контекст)

## Раздел 5: Выбор правильных показателей (структура принятия решений)

### Начните с «На какой вопрос я отвечаю?»

**"Какая компания недооценена?"**
→ Фокус на: EV/выручка, EV/EBITDA, P/E, рыночная капитализация.
→ Пропустить: операционные детали, показатели роста

**"Какая компания наиболее эффективна?"**
→ Фокус на: валовой прибыли, рентабельности EBITDA, рентабельности свободного денежного потока, оборачиваемости активов.
→ Пропустить: показатели размера, абсолютные суммы в долларах.

**"Какая компания растет быстрее всего?"**
→ Фокус на: % роста выручки, среднегодовой темп роста EBITDA, рост числа пользователей/клиентов.
→ Пропустить: показатели маржи, коэффициенты кредитного плеча.

**"Какой генератор денег лучший?"**
→ Фокус на: свободный денежный поток, маржа свободного денежного потока, конверсия свободного денежного потока, интенсивность капитальных затрат.
→ Пропустить: EBITDA, коэффициенты P/E.

### Выбор отраслевых показателей

**Программное обеспечение/SaaS:**
Должно быть: рост выручки, валовая прибыль, правило 40.
Дополнительно: ARR, чистое удержание долларов, окупаемость CAC.
Пропустить: оборачиваемость активов, показатели запасов.

**Производство/Промышленность:**
Должно быть: рентабельность по EBITDA, оборачиваемость активов, капитальные затраты/выручка.
Необязательно: рентабельность инвестиций, обороты запасов, отставание
Пропустить: Правило 40, метрики SaaS.

**Финансовые услуги:**
Должны быть: ROE, ROA, коэффициент эффективности, P/E.
Дополнительно: чистая процентная маржа, резервы на возможные потери по кредитам.
Пропустить: Валовая прибыль, EBITDA (не имеет значения для банков)

**Розничная торговля/электронная коммерция:**
Должно быть: рост выручки, валовая прибыль, оборачиваемость запасов.
Необязательно: продажи в одном магазине, стоимость привлечения клиентов.
Пропустите: показатели тяжелых исследований и разработок или капитальных вложений.

### «Правило 5-10»

**5 операционных показателей** – доход, рост, 2–3 показателя рентабельности/эффективности.
**5 показателей оценки** – рыночная капитализация, EV, 3 кратных.
**= всего 10 столбцов** – достаточно, чтобы рассказать историю, не так много, чтобы не потерять нить

Если у вас более 15 метрик, вы, вероятно, включаете шум. Редактируйте безжалостно.

## Раздел 6: Лучшие практики и проверки качества

### Прежде чем начать
1. **Определите группу аналогов**. Компании должны быть действительно сопоставимы (схожая бизнес-модель, масштаб, географическое положение).
2. **Выберите правильный период** — LTM сглаживает сезонность; ежеквартально показывает тенденции
3. **Стандартизируйте единицы заранее** — решение «миллионы против миллиардов» влияет на все
4. **Источники данных карты**. Знайте, откуда взялось каждое число.

### Пока вы строите
1. **Сначала введите все необработанные данные**. Прежде чем писать формулы, заполните синий текст.
2. **Добавьте комментарии к ячейке ко ВСЕМ жестко закодированным входным данным**. Щелкните ячейку правой кнопкой мыши → Вставить комментарий → Источник документа ИЛИ предположение.

   **Для исходных данных укажите, откуда они взяты:**
   – Пример: «Терминал Bloomberg – MSFT Equity DES, доступ осуществлен 2 октября 2024 г.».
   – Пример: «Отчет 10-K за 4 квартал 2024 г., стр. 42, позиция «Общий доход»».
   – Пример: «Консенсусная оценка FactSet по состоянию на 2 октября 2024 г.».
   - **По возможности включайте гиперссылки**: щелкните ячейку правой кнопкой мыши → Ссылка → вставьте URL-адрес в файл SEC, источник данных или отчет.

   **Для предположений поясните причину:**
   - Пример: «Предполагаемая рентабельность по EBITDA составляет 15 % на основе медианного значения аналогов, компания не раскрывает информацию».
   - Пример: «Оценочная стоимость предприятия как рыночная капитализация + чистый долг в размере 50 миллионов долларов США (из балансового отчета за третий квартал, данные за четвертый квартал еще недоступны)».
   - Пример: «Форвардный P/E на основе консенсус-прогноза EPS в размере $3,45 (среднее из оценок 12 аналитиков)».

   **Почему это важно**: обеспечивает контрольные журналы, проверку данных, прозрачность предположений и будущие обновления.
3. **Создавайте формулы построчно**. Прежде чем двигаться дальше, проверяйте каждое вычисление.
4. **Использовать абсолютные ссылки для заголовков** — $C$6 блокирует строку заголовка.
5. **Последовательное форматирование** — Проценты указаны в процентах, а не в десятичных дробях.
6. **Добавить условное форматирование** – автоматически выделять выбросы.

### Проверка работоспособности
- **Тест маржи**: валовая прибыль > рентабельность EBITDA > чистая рентабельность (всегда верно по определению).
- **Множественная разумность**: 
  - EV/выручка: обычно 0,5–20x (в зависимости от отрасли).
  - EV/EBITDA: обычно 8-25x (достаточно одинаково в разных отраслях).
  - P/E: обычно 10-50x (зависит от темпов роста)
- **Корреляция мультипликатора роста**: более высокий рост обычно означает более высокие мультипликаторы.
- **Компромисс размера и эффективности**: более крупные компании часто имеют более высокую прибыль (выгоды от масштаба).

### Распространенные ошибки, которых следует избегать
❌ Смешение рыночной капитализации и стоимости предприятия в формулах.
❌ Использование разных периодов времени для числителя и знаменателя (долгосрочный или ежеквартальный)
❌ Жесткое кодирование чисел в формулы вместо ссылок на ячейки.
❌ **Жестко запрограммированные входные данные без комментариев к ячейкам со ссылкой на источник ИЛИ объяснением предположения**
❌ Отсутствуют гиперссылки на документы SEC или источники данных, если они доступны.
❌ Включение слишком большого количества показателей без четкой цели
❌ Включая несравнимые компании (разные бизнес-модели)
❌ Использование устаревших данных без раскрытия
❌ Неправильный расчет средних процентов (должна быть медиана)

## Раздел 10: Красные флажки и предупреждающие знаки

### Проблемы с качеством данных
🚩 Непоследовательные периоды времени (смешение квартальных и годовых)  
🚩 Отсутствуют данные без объяснения причин  
🚩 Значительные различия между источниками данных (расхождение> 10 %)

### Красные флаги оценки
🚩 Компании с отрицательной EBITDA оцениваются по коэффициентам EBITDA (вместо этого используйте коэффициенты выручки)  
🚩 Коэффициент P/E >100x без истории гиперроста  
🚩 Маржа, которая не имеет смысла для отрасли

### Проблемы сопоставимости
🚩 Разное окончание финансового года (вызывает проблемы со сроками)  
🚩фиксация чистой игры и конгломератов  
🚩 Существенно разные бизнес-модели, помеченные как «компенсации».

**Если есть сомнения, исключите компанию.** Лучше иметь 3 идеальных компании, чем 6 сомнительных.

```excel
// Financial Calculations
=B7/C7                   // Simple ratio (Margin)
=SUM(B7:B9)/3            // Average of multiple companies
=IF(B7>0, C7/B7, "N/A")  // Conditional calculation
=IFERROR(C7/D7, 0)       // Handle divide by zero

// Cross-Sheet References
='Sheet1'!B7             // Reference another sheet
=VLOOKUP(A7, Table1, 2)  // Lookup from data table
=INDEX(MATCH())          // Advanced lookup

// Formatting
=TEXT(B7, "0.0%")        // Format as percentage
=TEXT(C7, "#,##0")       // Thousands separator
```

### Общие формулы соотношений
```excel
Gross Margin = Gross Profit / Revenue
EBITDA Margin = EBITDA / Revenue
FCF Margin = Free Cash Flow / Revenue
FCF Conversion = FCF / Operating Cash Flow
ROE = Net Income / Shareholders' Equity
ROA = Net Income / Total Assets
Asset Turnover = Revenue / Total Assets
Debt/Equity = Total Debt / Shareholders' Equity
```

## Краткое изложение ключевых принципов

1. **Структура способствует пониманию**. Правильные заголовки способствуют правильному мышлению.
2. **Меньше значит больше**: 5–10 важных показателей превосходят 20 незначимых.
3. **Выберите показатели для вашего вопроса** — Анализ оценки ≠ анализ эффективности.
4. **Статистика показывает закономерности**. Медиана/квартиль показывает показатели выше среднего.
5. **Прозрачность побеждает сложность**. Простые формулы, понятные каждому.
6. **Сравнительность превыше всего**. Лучше исключить, чем навязывать плохую компанию.
7. **Задокументируйте свой выбор**. В разделе примечаний объясните, какие показатели и почему.

1. Открыла ли статистика неожиданные открытия?

## Источники данных — сначала MCP, резервный веб-интерфейс

Во многих отрывках ниже говорится: «Используйте S&P Kensho MCP / Daloopa MCP / FactSet MCP». Это коммерческие MCP финансовых данных из исходного контекста плагина Cowork. В Гермесе:

- **Если у вас настроен какой-либо MCP для структурированных финансовых данных** (Hermes поддерживает MCP — см. навык `native-mcp`), предпочтите его для расчетов на определенный момент времени, прецедентных транзакций и отчетности.
