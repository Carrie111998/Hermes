# Polymarket — прогнозирование рыночных данных

Запрашивайте рыночные данные прогнозирования у Polymarket, используя их общедоступные API-интерфейсы REST.
Все конечные точки доступны только для чтения и не требуют аутентификации.

См. `references/api-endpoints.md` для получения полной справки по конечной точке с примерами завитков.

## Когда использовать

- Пользователь спрашивает о рынках прогнозов, коэффициентах ставок или вероятности событий.
- Пользователь хочет знать, «какова вероятность того, что X произойдет?»
- Пользователь спрашивает конкретно о Полимаркете
- Пользователю нужны рыночные цены, данные книги заказов или история цен.
- Пользователь просит отслеживать или прогнозировать движения рынка.

## Ключевые понятия

- **События** содержат один или несколько **Рынок** (отношения 1:много).
- **Рынки** – это бинарные исходы с ценами Да/Нет от 0,00 до 1,00.
- Цены ЯВЛЯЮТСЯ вероятностями: цена 0,65 означает, что рынок считает вероятность 65%.
– Поле `outcomePrices`: массив в формате JSON, например `["0.80", "0.20"]`.
- Поле `clobTokenIds`: массив из двух идентификаторов токенов в формате JSON [Да, Нет] для запросов цены/книги.
- Поле `conditionId`: шестнадцатеричная строка, используемая для запросов истории цен.
- Объем указан в USDC (долларах США).

## Три общедоступных API

1. **Gamma API** на `gamma-api.polymarket.com` — обнаружение, поиск, просмотр.
2. **CLOB API** на `clob.polymarket.com` — цены в реальном времени, книги заказов, история.
3. **API данных** на `data-api.polymarket.com` — Сделки, открытый интерес

## Типичный рабочий процесс

Когда пользователь спрашивает о прогнозируемых рыночных шансах:

1. **Поиск** с использованием конечной точки общедоступного поиска Gamma API по их запросу.
2. **Проанализируйте** ответ — извлеките события и вложенные в них рынки.
3. **Существующий** рыночный вопрос, текущие цены в процентах и объем.
4. **Подробнее**, если вас спросят: используйте clobTokenIds для книги заказов, ConditionId для истории.

## Представление результатов

Отформатируйте цены в процентах для удобства чтения:
- resultPrices `["0.652", "0.348"]` становится «Да: 65,2%, Нет: 34,8%»
- Всегда показывать рыночный вопрос и вероятность
- Включить громкость, если она доступна

Пример: `"Will X happen?" — 65.2% Yes ($1.2M volume)`

## Анализ полей с двойным кодированием

Gamma API возвращает `outcomePrices`, `outcomes` и `clobTokenIds` в виде строк JSON.
внутри ответов JSON (с двойным кодированием). При обработке с помощью Python анализируйте их с помощью
`json.loads(market['outcomePrices'])`, чтобы получить фактический массив.

## Ограничения скорости

Щедрый — вряд ли подойдет при обычном использовании:
- Гамма: 4000 запросов за 10 секунд (общее)
- CLOB: 9000 запросов за 10 секунд (общее)
- Данные: 1000 запросов за 10 секунд (общие)

## Ограничения

- Этот навык доступен только для чтения — он не поддерживает размещение сделок.
- Для торговли требуется крипто-аутентификация на основе кошелька (подписи EIP-712).
- Некоторые новые рынки могут иметь пустую историю цен.
- К торговле применяются географические ограничения, но данные только для чтения доступны по всему миру.
