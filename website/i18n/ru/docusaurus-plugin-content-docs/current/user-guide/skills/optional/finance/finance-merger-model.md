# Модель слияния

Постройте анализ прироста/разводнения для сделок M&A. Моделирует условное влияние на прибыль на акцию, чувствительность к синергии и распределение покупной цены. Используйте при оценке потенциального приобретения, подготовке анализа последствий слияния для презентации или консультировании по условиям сделки.

## Рабочий процесс

### Шаг 1: Сбор исходных данных

**Покупатель:**
- Название компании, текущая цена акций, акции в обращении
- Долгосрочная и чистая прибыль на акцию (GAAP и скорректированные)
- мультипликатор P/E
- Стоимость долга до налогообложения, ставка налога
- Денежные средства на балансе, существующая задолженность

**Цель:**
- Название компании, текущая цена акций, акции в обращении (если они публичные)
- LTM и NTM EPS или чистая прибыль
- Стоимость предприятия или стоимость акционерного капитала

**Условия сделки:**
- Цена предложения за акцию (или премия к текущей)
- Сочетание вознаграждения: % денежных средств и % акций.
- Новый долг привлечен для финансирования денежной части
- Ожидаемый синергетический эффект (выручка и затраты) и график поэтапного внедрения.
- Комиссии за транзакции и затраты на финансирование
- Ожидаемая дата закрытия

## Важные примечания

- Всегда указывайте как GAAP, так и скорректированную (денежную) прибыль на акцию, где это необходимо.
- Сделки с акциями: используйте текущую цену покупателя для коэффициента обмена, обратите внимание на разбавление новыми акциями.
- Включить распределение цены покупки — гудвилл и нематериальную амортизацию для GAAP EPS.
- Поэтапное внедрение синергии имеет решающее значение — первый год часто обеспечивает лишь 25–50% синергии от текущих показателей.
- Не забывайте об упущенном процентном доходе по использованным денежным средствам и новых процентных расходах по привлеченному долгу.
- Ставка налога на синергию и корректировку процентных ставок должна соответствовать предельной ставке приобретателя.


## Источники данных — сначала MCP, резервный веб-интерфейс

Во многих отрывках ниже говорится: «Используйте S&P Kensho MCP / Daloopa MCP / FactSet MCP». Это коммерческие MCP финансовых данных из исходного контекста плагина Cowork. В Гермесе:

- **Если у вас настроен какой-либо MCP для структурированных финансовых данных** (Hermes поддерживает MCP — см. навык `native-mcp`), предпочтите его для расчетов на определенный момент времени, прецедентных транзакций и отчетности.
- **В противном случае** вернитесь к:
  - `web_search` / `web_extract` против SEC EDGAR (`https://www.sec.gov/cgi-bin/browse-edgar`) по документам, поданным в США.
  - Страницы компаний IR для пресс-релизов, отчетов о доходах
  - `browser_navigate` для порталов интерактивных данных
  - Данные, предоставленные пользователем (явно запрашивайте, если в контексте их нет)
- **Никогда не выдумывайте**. Если невозможно получить множественный, прецедентный или регистрационный номер, пометьте ячейку как `[UNSOURCED]` и передайте ее пользователю.
