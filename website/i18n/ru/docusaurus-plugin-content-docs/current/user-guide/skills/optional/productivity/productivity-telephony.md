# Телефония — номера, звонки и текстовые сообщения без изменений в основных инструментах

Этот дополнительный навык дает Hermes практические возможности работы с телефоном, исключая при этом телефонию из основного списка инструментов.

Он поставляется со вспомогательным сценарием `scripts/telephony.py`, который может:
- сохранить учетные данные провайдера в `${HERMES_HOME:-~/.hermes}/.env`
- найти и купить номер телефона Twilio
- запомните этот принадлежащий номер для последующих сеансов
- отправить SMS/MMS со своего номера
- опрос входящих SMS на этот номер без необходимости использования сервера веб-перехватчика
- совершать прямые вызовы Twilio с помощью TwiML `<Say>` или `<Play>`.
- импортировать принадлежащий номер Twilio в Vapi
- совершать исходящие AI-звонки через Bland.ai или Vapi

## Что это решает

Этот навык предназначен для решения практических задач, которые действительно нужны пользователям телефона:
- исходящие звонки
- текстовые сообщения
- наличие многоразового агентского номера
- проверка сообщений, которые приходят на этот номер позже
- сохранение этого номера и связанных с ним идентификаторов между сеансами
- Перспективная телефонная идентификация для опроса входящих SMS и других средств автоматизации.

Это **не** превращает Hermes в шлюз входящей телефонной связи в режиме реального времени. Входящие SMS обрабатываются путем опроса API REST Twilio. Этого достаточно для многих рабочих процессов, включая уведомления и получение некоторых одноразовых кодов, без добавления базовой инфраструктуры веб-перехватчиков.

## Правила безопасности — обязательные

1. Всегда подтверждайте, прежде чем звонить или отправлять текстовое сообщение.
2. Никогда не набирайте номера экстренных служб.
3. Никогда не используйте телефонную связь для преследования, рассылки спама, выдачи себя за другое лицо или для чего-либо противозаконного.
4. Относитесь к сторонним телефонным номерам как к конфиденциальным оперативным данным:
   - не сохраняйте их в памяти Гермеса
   - не включайте их в документацию по навыкам, сводки или последующие примечания, если только пользователь явно не желает этого.
5. Можно сохранить **номер Twilio, принадлежащий агенту**, поскольку он является частью конфигурации пользователя.
6. Номера VoIP **не гарантируются** для всех сторонних потоков 2FA. Используйте с осторожностью и четко устанавливайте ожидания пользователей.

## Дерево решений — какой сервис использовать?

Используйте эту логику вместо жестко запрограммированной маршрутизации поставщика:

### 1) «Я хочу, чтобы у Гермеса был настоящий номер телефона»
Используйте **Twilio**.

Почему:
- самый простой способ купить и сохранить номер
- лучшая поддержка SMS/MMS
- простейшая история опроса входящих SMS
- самый чистый будущий путь к входящим веб-перехватчикам или обработке вызовов

Варианты использования:
- получать сообщения позже
- отправлять оповещения о развертывании/уведомления cron
- поддерживать многоразовый идентификатор телефона для агента
- поэкспериментируйте с потоками аутентификации на телефоне позже

### 2) «Мне сейчас нужен только самый простой исходящий телефонный звонок с искусственным интеллектом»
Используйте **Bland.ai**.

Почему:
- самая быстрая настройка
- один ключ API
- не нужно сначала покупать/импортировать номер самостоятельно

Компромисс:
- менее гибкий
- качество передачи речи достойное, но не самое лучшее

### 3) «Мне нужно лучшее качество голоса при разговоре с искусственным интеллектом»
Используйте **Twilio + Vapi**.

Почему:
- Twilio дает вам собственный номер
- Vapi обеспечивает лучшее качество разговорных вызовов AI и большую гибкость голоса/модели.

Рекомендуемый поток:
1. Купите/сохраните номер Twilio.
2. Импортируйте его в Vapi.
3. Сохраните возвращенный `VAPI_PHONE_NUMBER_ID`.
4. Используйте `ai-call --provider vapi`

### 4) «Я хочу позвонить с помощью заранее записанного голосового сообщения»
Используйте **Прямой вызов Twilio** с общедоступным URL-адресом аудио.

Почему:
- самый простой способ воспроизвести собственный MP3
- хорошо сочетается с Hermes `text_to_speech`, а также общедоступным файловым хостом или туннелем

## Файлы и постоянное состояние

Навык сохраняет состояние телефонии в двух местах:

### `${HERMES_HOME:-~/.hermes}/.env`
Используется для долгосрочных учетных данных поставщика и идентификаторов собственных номеров, например:
- `TWILIO_ACCOUNT_SID`
- `TWILIO_AUTH_TOKEN`
- `TWILIO_PHONE_NUMBER`
- `TWILIO_PHONE_NUMBER_SID`
- `BLAND_API_KEY`
- `VAPI_API_KEY`
- `VAPI_PHONE_NUMBER_ID`
- `PHONE_PROVIDER` (провайдер AI-вызовов: безвкусный или vapi)

### `~/.hermes/telephony_state.json`
Используется для состояния только навыков, которое должно сохраняться между сеансами, например:
- запоминание номера/SID Twilio по умолчанию
- запомнил идентификатор номера телефона Vapi
- SID/дата последнего входящего сообщения для контрольных точек опроса входящих сообщений

Это означает:
- при следующей загрузке навыка `diagnose` может сообщить вам, какой номер уже настроен.
- `twilio-inbox --since-last --mark-seen` может продолжить с предыдущей контрольной точки.

## Настройка провайдера

### Twilio — собственный номер, SMS/MMS, прямые вызовы, опрос входящих SMS

Зарегистрируйтесь по адресу:
- https://www.twilio.com/try-twilio

Затем сохраните учетные данные в Hermes:

```bash
python3 "$SCRIPT" save-twilio ACXXXXXXXXXXXXXXXXXXXXXXXXXXXX your_auth_token_here
```

Поиск доступных номеров:

```bash
python3 "$SCRIPT" twilio-search --country US --area-code 702 --limit 5
```

Купите и запомните номер:

```bash
python3 "$SCRIPT" twilio-buy "+17025551234" --save-env
```

Список принадлежащих номеров:

```bash
python3 "$SCRIPT" twilio-owned
```

Позже установите один из них по умолчанию:

```bash
python3 "$SCRIPT" twilio-set-default "+17025551234" --save-env
# or
python3 "$SCRIPT" twilio-set-default PNXXXXXXXXXXXXXXXXXXXXXXXXXXXX --save-env
```

### Bland.ai — самые простые исходящие вызовы с помощью ИИ

Зарегистрируйтесь по адресу:
- https://app.bland.ai

Сохраняем конфигурацию:

```bash
python3 "$SCRIPT" save-bland your_bland_api_key --voice mason
```

### Vapi — лучшее качество разговорной речи

Зарегистрируйтесь по адресу:
- https://dashboard.vapi.ai

Сначала сохраните ключ API:

```bash
python3 "$SCRIPT" save-vapi your_vapi_api_key
```

Импортируйте свой номер Twilio в Vapi и сохраните возвращенный идентификатор номера телефона:

```bash
python3 "$SCRIPT" vapi-import-twilio --save-env
```

Если вы уже знаете идентификатор номера телефона Vapi, сохраните его:

```bash
python3 "$SCRIPT" save-vapi your_vapi_api_key --phone-number-id vapi_phone_number_id_here
```

## Диагностика текущего состояния

В любой момент проверьте, что навык уже знает:

```bash
python3 "$SCRIPT" diagnose
```

Используйте это в первую очередь при возобновлении работы в следующем сеансе.

## Общие рабочие процессы

### A. Купите номер агента и продолжайте использовать его позже

1. Сохраните учетные данные Twilio:
```bash
python3 "$SCRIPT" save-twilio AC... auth_token_here
```

2. Найдите номер:
```bash
python3 "$SCRIPT" twilio-search --country US --area-code 702 --limit 10
```

3. Купите его и сохраните в состоянии `${HERMES_HOME:-~/.hermes}/.env` +:
```bash
python3 "$SCRIPT" twilio-buy "+17025551234" --save-env
```

4. В следующем сеансе запустите:
```bash
python3 "$SCRIPT" diagnose
```
Здесь отображается запомненный номер по умолчанию и состояние контрольной точки папки «Входящие».

### Б. Отправьте СМС с номера агента

```bash
python3 "$SCRIPT" twilio-send-sms "+15551230000" "Your deployment completed successfully."
```

Со СМИ:

```bash
python3 "$SCRIPT" twilio-send-sms "+15551230000" "Here is the chart." --media-url "https://example.com/chart.png"
```

### C. Проверьте входящие тексты позже без сервера веб-перехватчика.

Опросите почтовый ящик, чтобы узнать номер Twilio по умолчанию:

```bash
python3 "$SCRIPT" twilio-inbox --limit 20
```

Показывайте только сообщения, пришедшие после последней контрольной точки, и переходите к контрольной точке, когда закончите читать:

```bash
python3 "$SCRIPT" twilio-inbox --since-last --mark-seen
```

Это основной ответ на вопрос: «Как мне получить доступ к сообщениям, которые получит номер в следующий раз при загрузке навыка?»

### D. Сделайте прямой вызов Twilio с помощью встроенного TTS.

```bash
python3 "$SCRIPT" twilio-call "+15551230000" --message "Hello! This is Hermes calling with your status update." --voice Polly.Joanna
```

### E. Звонок с помощью заранее записанного/собственного голосового сообщения

Это основной путь повторного использования существующей поддержки `text_to_speech` компании Hermes.

Используйте это, когда:
- вы хотите, чтобы при вызове использовался настроенный TTS-голос Hermes, а не Twilio `<Say>`
- вам нужна односторонняя голосовая доставка (брифинг, оповещение, шутка, напоминание, обновление статуса)
- вам **не** нужен живой разговорный телефонный звонок

Сгенерируйте или разместите аудио отдельно, затем:

```bash
python3 "$SCRIPT" twilio-call "+155****0000" --audio-url "https://example.com/briefing.mp3"
```

Рекомендуемый рабочий процесс Hermes TTS -> Twilio Play:

1. Создайте аудио с помощью Hermes `text_to_speech`.
2. Сделайте полученный MP3 общедоступным.
3. Выполните вызов Twilio с `--audio-url`.

Пример потока агента:
- Попросите Hermes создать аудиосообщение с помощью `text_to_speech`.
- При необходимости предоставьте файлу временный статический URL-адрес хоста/туннеля/объектного хранилища.
– Используйте `twilio-call --audio-url ...`, чтобы доставить его по телефону.

Хорошие варианты хостинга для MP3:
- временный общедоступный URL-адрес объекта/хранилища.
- недолговечный туннель к локальному статическому файловому серверу
- любой существующий URL-адрес HTTPS, который оператор телефонной связи может получить напрямую.

Важное примечание:
- Hermes TTS отлично подходит для предварительно записанных исходящих сообщений.
- Bland/Vapi лучше подходят для **разговорных вызовов AI в реальном времени**, поскольку они сами обрабатывают аудиостек телефонной связи в реальном времени.
- Hermes STT/TTS сам по себе не используется здесь в качестве полнодуплексной системы телефонного разговора; это потребует гораздо более сложной интеграции потоковой передачи/вебхука, чем пытается представить этот навык.

### F. Навигация по дереву телефонов/IVR с помощью прямых вызовов Twilio

Если вам нужно нажать цифры после соединения вызова, используйте `--send-digits`.
Twilio интерпретирует `w` как короткое ожидание.

```bash
python3 "$SCRIPT" twilio-call "+18005551234" --message "Connecting to billing now." --send-digits "ww1w2w3"
```

Это полезно для доступа к определенной ветке меню перед передачей ее пользователю или доставке короткого сообщения о состоянии.

### G. Исходящий телефонный звонок через AI с помощью Bland.ai

```bash
python3 "$SCRIPT" ai-call "+15551230000" "Call the dental office, ask for a cleaning appointment on Tuesday afternoon, and if they do not have Tuesday availability, ask for Wednesday or Thursday instead." --provider bland --voice mason --max-duration 3
```

Проверить статус:

```bash
python3 "$SCRIPT" ai-status <call_id> --provider bland
```

После завершения задайте вопросы по анализу Бланда:

```bash
python3 "$SCRIPT" ai-status <call_id> --provider bland --analyze "Was the appointment confirmed?,What date and time?,Any special instructions?"
```

### H. Исходящий телефонный звонок через AI с Vapi на ваш номер

1. Импортируйте свой номер Twilio в Vapi:
```bash
python3 "$SCRIPT" vapi-import-twilio --save-env
```

2. Сделайте звонок:
```bash
python3 "$SCRIPT" ai-call "+15551230000" "You are calling to make a dinner reservation for two at 7:30 PM. If that is unavailable, ask for the nearest time between 6:30 and 8:30 PM." --provider vapi --max-duration 4
```

3. Проверьте результат:
```bash
python3 "$SCRIPT" ai-status <call_id> --provider vapi
```

## Рекомендуемая процедура агента

Когда пользователь просит позвонить или написать сообщение:

1. Определите, какой путь соответствует запросу, с помощью дерева решений.
2. Запустите `diagnose`, если состояние конфигурации неясно.
3. Соберите полную информацию о задаче.
4. Подтвердите контакт с пользователем перед набором номера или отправкой текстового сообщения.
5. Используйте правильную команду.
6. При необходимости опросите результаты.
7. Подвести итог, не сохраняя в памяти Гермеса сторонние цифры.

## Чего еще не делает этот навык

- ответ на входящие звонки в режиме реального времени
- передача SMS-сообщений в реальном времени на основе веб-перехватчика в цикл агента
- гарантированная поддержка произвольных сторонних провайдеров 2FA

Для этого потребуется больше инфраструктуры, чем просто дополнительный навык.

## Подводные камни

- Пробные учетные записи Twilio и региональные правила могут ограничивать круг лиц, которым вы можете звонить и отправлять текстовые сообщения.
- Некоторые сервисы отклоняют номера VoIP для 2FA.
- `twilio-inbox` опрашивает REST API; это не мгновенная доставка.
- Исходящие звонки Vapi по-прежнему зависят от наличия действующего импортированного номера.
- Блэнд проще всего, но не всегда звучит лучше всего.
- Не храните произвольные сторонние номера телефонов в памяти Hermes.

## Контрольный список проверки

После настройки вы сможете делать все следующее, используя только этот навык:

1. `diagnose` показывает готовность поставщика и запомненное состояние.
2. найти и купить номер Twilio
3. сохраните это число на `${HERMES_HOME:-~/.hermes}/.env`.
4. отправить СМС со своего номера
5. позже опросить входящие тексты на наличие принадлежащего номера
6. совершить прямой вызов Twilio
7. сделать AI-вызов через Bland или Vapi.
