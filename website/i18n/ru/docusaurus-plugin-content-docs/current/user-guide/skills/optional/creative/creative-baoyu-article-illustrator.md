# Иллюстратор статей

Адаптировано из [baoyu-article-illustrator](https://github.com/JimLiu/baoyu-skills) для экосистемы инструментов агента Hermes.

Анализируйте статьи, определяйте позиции иллюстраций, создавайте изображения с единообразием **Тип × Стиль × Палитра**.

## Когда использовать

Активируйте этот навык, когда пользователь просит проиллюстрировать статью, добавить изображения в статью, создать иллюстрации для контента или использует такие фразы, как «为文章配图», «иллюстрировать статью» или «добавить изображения». Пользователь предоставляет статью (путь к файлу или вставленное содержимое) и при необходимости указывает тип, стиль, палитру или плотность.

## Три измерения

| Размерность | Элементы управления | Примеры |
|-----------|----------|----------|
| **Тип** | Информационная структура | инфографика, сцена, блок-схема, сравнение, рамки, временная шкала |
| **Стиль** | Подход к рендерингу | идея, теплый, минималистичный, чертеж, акварель, элегантный |
| **Палитра** | Цветовая схема (необязательно) | макарон, теплый, неон — переопределяет цвета стиля по умолчанию |

Свободно комбинируйте: `type=infographic, style=vector-illustration, palette=macaron`.

Или используйте пресеты: `edu-visual` → тип + стиль + палитра в одном кадре. См. [style-presets.md](https://github.com/NousResearch/hermes-agent/blob/main/optional-skills/creative/baoyu-article-illustrator/references/style-presets.md).

## Типы

| Тип | Лучшее для |
|------|----------|
| `infographic` | Данные, показатели, технические |
| `scene` | Повествования эмоциональные |
| `flowchart` | Процессы, рабочие процессы |
| `comparison` | Рядом, варианты |
| `framework` | Модели архитектурные |
| `timeline` | История, эволюция |

## Структура вывода

<!-- ascii-guard-ignore -->
```
{output-dir}/
├── source-{slug}.{ext}    # Only for pasted content
├── outline.md
├── prompts/
│   └── NN-{type}-{slug}.md
└── NN-{type}-{slug}.png
```
<!-- ascii-guard-ignore-end -->

**Каталог вывода по умолчанию**:

| Ввод | Выходной каталог | Путь вставки Markdown |
|-------|------------------|----------------------|
| Путь к файлу статьи | `{article-dir}/imgs/` | `imgs/NN-{type}-{slug}.png` |
| Вставленный контент | `illustrations/{topic-slug}/` (cwd) | `illustrations/{topic-slug}/NN-{type}-{slug}.png` |

Если пользователь просит другой макет (например, изображения рядом со статьей или подкаталог `illustrations/`), учтите это.

**Слизень**: 2–4 слова, кебаб-кейс. **Конфликт**: добавьте `-YYYYMMDD-HHMMSS`.

## Основные принципы

– **Визуализируйте концепции, а не метафоры**. Если в статье используется метафора (например, «电锯切西瓜»), иллюстрируйте основную концепцию, а не буквальный образ.
– **Ярлыки используют данные статьи** — реальные цифры, термины и цитаты из статьи, а не общие заполнители.
- **Файлы подсказок представляют собой записи воспроизводимости** — для каждой иллюстрации необходимо сохранить файл подсказки под `prompts/`, прежде чем будет создано какое-либо изображение.
- **Удалить секреты** — сканируйте исходное содержимое на наличие ключей API, токенов или учетных данных, прежде чем записывать что-либо на диск.

## Рабочий процесс

```
- [ ] Step 1: Detect reference images (if provided)
- [ ] Step 2: Analyze content
- [ ] Step 3: Confirm settings (clarify tool, one question at a time)
- [ ] Step 4: Generate outline
- [ ] Step 5: Generate prompts
- [ ] Step 6: Generate images (image_generate)
- [ ] Step 7: Finalize
```

### Шаг 1. Найдите эталонные изображения

Если пользователь предоставляет эталонные изображения (вставленные пути, вложения или URL-адрес):

1. Для каждой ссылки позвоните по номеру `vision_analyze`, указав путь/URL-адрес и вопрос о стиле, палитре, композиции и теме. Запишите возвращенное описание в `{output-dir}/references/NN-ref-{slug}.md` через `write_file`.
2. **Не** пытайтесь скопировать двоичный файл через `write_file`/`read_file` — они предназначены только для текста. Если вам нужна локальная копия записи, используйте `terminal` (`cp "$src" "{output-dir}/references/NN-ref-{slug}.{ext}"`). Сам навык никогда не требует чтения двоичного файла; это работает на основе описания видения.
3. Поскольку `image_generate` не принимает входные изображения, описание видения — это то, что встраивается в подсказки на шаге 5.

Полные процедуры: [references/workflow.md](https://github.com/NousResearch/hermes-agent/blob/main/optional-skills/creative/baoyu-article-illustrator/references/workflow.md#step-1-detect-reference-images).

### Шаг 2: Анализ

| Анализ | Выход |
|----------|--------|
| Тип контента | Технический / Учебное пособие / Методология / Повествование |
| Цель | информация / визуализация / воображение |
| Основные аргументы | 2-5 основных пунктов |
| Позиции | Где иллюстрации повышают ценность |

Прочитайте источник (путь к файлу → `read_file` или вставленный текст) и запишите анализ в `{output-dir}/analysis.md`, используя `write_file`.

Полные процедуры: [references/workflow.md](https://github.com/NousResearch/hermes-agent/blob/main/optional-skills/creative/baoyu-article-illustrator/references/workflow.md#step-2-analyze).

### Шаг 3. Подтвердите настройки

Используйте инструмент `clarify`. Поскольку `clarify` обрабатывает по одному вопросу за раз, сначала задайте самый важный вопрос. Пропускайте любой вопрос, ответ на который уже присутствует в запросе пользователя.

| Заказать | Вопрос | Опции |
|-------|----------|---------|
| 1 квартал | **Предустановка или тип** | [Рекомендуемый пресет], [альтернативный пресет] или руководство: инфографика, сцена, блок-схема, сравнение, структура, временная шкала, смешанный |
| 2 квартал | **Плотность** | минимальный (1-2), сбалансированный (3-5), по разделам (рекомендуется), насыщенный (6+) |
| 3 квартал | **Стиль** *(пропустите, если в Q1 выбрана предустановка)* | [Рекомендуется], минимально-плоский, научно-фантастический, нарисованный от руки, редакционный, сцена, плакат |
| 4 квартал | **Палитра** *(необязательно)* | По умолчанию (цвета стиля), макарон, теплый, неон |
| Q5 | **Язык** *(только если язык статьи неоднозначен)* | язык статьи/язык пользователя |

Не задавайте более 2–3 `clarify` вопросов подряд. Если пользователь уже указал их в своем запросе, пропустите полностью.

Полные процедуры: [references/workflow.md](https://github.com/NousResearch/hermes-agent/blob/main/optional-skills/creative/baoyu-article-illustrator/references/workflow.md#step-3-confirm-settings).

### Шаг 4. Создайте схему → `outline.md`

Сохраните `{output-dir}/outline.md`, используя `write_file`, с вставкой (тип, плотность, стиль, палитра, количество изображений) и одной записью для каждой иллюстрации:

```yaml
## Illustration 1
**Position**: [section/paragraph]
**Purpose**: [why]
**Visual Content**: [what to show]
**Filename**: 01-infographic-concept-name.png
```

Полный шаблон: [references/workflow.md](https://github.com/NousResearch/hermes-agent/blob/main/optional-skills/creative/baoyu-article-illustrator/references/workflow.md#step-4-generate-outline).

### Шаг 5: Создание подсказок

**БЛОКИРОВКА**: перед созданием любого изображения каждая иллюстрация должна иметь сохраненный файл подсказки — файл подсказки является записью воспроизводимости.

Для каждой иллюстрации:

1. Создайте файл подсказки для [references/prompt-construction.md](https://github.com/NousResearch/hermes-agent/blob/main/optional-skills/creative/baoyu-article-illustrator/references/prompt-construction.md).
2. Сохраните в `{output-dir}/prompts/NN-{type}-{slug}.md`, используя `write_file` с заголовком YAML.
3. В подсказках ДОЛЖНЫ использоваться шаблоны для конкретного типа со структурированными разделами (ЗОНЫ / ЭТИКЕТКИ / ЦВЕТА / СТИЛЬ / АСПЕКТ).
4. ЭТИКЕТКИ ДОЛЖНЫ включать данные по конкретной статье: фактические цифры, сроки, показатели, котировки.
5. Обрабатывать ссылки (`direct`/`style`/`palette`) для каждого заголовка приглашения — для использования `direct` вставьте текстовое описание ссылки в приглашение (поскольку `image_generate` не принимает входные данные ссылочного изображения).

### Шаг 6: Создание изображений

Для каждого файла подсказки:

1. Позвоните `image_generate(prompt=..., aspect_ratio=...)`. `image_generate` возвращает результат JSON, содержащий URL-адрес изображения; он НЕ записывает на диск и НЕ принимает путь вывода.
2. Сопоставьте подсказку `ASPECT` с перечислением `image_generate`: `16:9` → `landscape`, `9:16` → `portrait`, `1:1` → `square`. Пользовательские пропорции → ближайший именованный аспект.
3. Загрузите возвращенный URL-адрес на `{output-dir}/NN-{type}-{slug}.png` через `terminal` (например, `curl -sSL -o "{output-dir}/NN-{type}-{slug}.png" "{url}"`).
4. В случае сбоя генерации автоматически повторите попытку один раз.

Примечание. Базовый механизм создания изображений настраивается пользователем (по умолчанию: FAL FLUX 2 Klein 9B) и НЕ выбирается агентом через `image_generate`. Не записывайте названия моделей в подсказки, ожидая их маршрутизации.

### Шаг 7: Завершение

Вставьте `![description](https://github.com/NousResearch/hermes-agent/blob/main/optional-skills/creative/baoyu-article-illustrator/{relative-path}/NN-{type}-{slug}.png)` после соответствующего абзаца. Альтернативный текст: краткое описание на языке статьи.

Отчет:

```
Article Illustration Complete!
Article: [path] | Type: [type] | Density: [level] | Style: [style] | Palette: [palette or default]
Images: X/N generated
```

## Подводные камни

1. **Целостность данных имеет первостепенное значение** — никогда не обобщайте, не перефразируйте и не изменяйте исходную статистику. «Увеличение на 73%» остается «увеличением на 73%».
2. **Удалить секреты** — сканируйте исходный контент на предмет ключей API, токенов или учетных данных перед включением в любой выходной файл.
3. **Не иллюстрируйте метафоры буквально** — визуализируйте основную концепцию.
4. **Файлы подсказок обязательны** — создание изображения невозможно без сохраненного файла подсказки. Файл — это то, что позволяет вам позже регенерировать или переключать серверы.
5. **`image_generate` соотношения сторон** — инструмент поддерживает `landscape`, `portrait` и `square`. Пользовательские коэффициенты сопоставляются с ближайшим вариантом.
6. **`image_generate` возвращает URL-адрес, а не локальный файл** — всегда загружайте через `terminal` (`curl`) перед вставкой локальных путей к изображениям в статью.
7. **Агент не выбирает серверную часть** — `image_generate` использует любую модель, настроенную пользователем (по умолчанию: FAL FLUX 2 Klein 9B). Не записывайте `"use <model> to generate this"` в подсказки, ожидая, что он будет маршрутизирован.
