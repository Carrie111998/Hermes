# Сувенирные карточки — навык карточного повторения с интервалами

## Обзор

Memento предоставляет вам локальную файловую систему карточек с планированием интервальных повторений.
Пользователи могут общаться в чате с помощью своих карточек, отвечая в произвольном тексте, а агент оценивает ответ, прежде чем планировать следующий обзор.
Используйте его всякий раз, когда пользователь хочет:

- **Запомните факт** — превратите любое утверждение в карточку вопросов/ответов.
- **Исследование с интервальным повторением** – просматривайте карточки с адаптивными интервалами и произвольными текстовыми ответами, оцениваемыми агентом.
- **Викторина из видео на YouTube** – получите стенограмму и создайте тест из 5 вопросов.
- **Управление колодами** — группируйте карты в коллекции, экспортируйте/импортируйте CSV.

Все данные карты хранятся в одном файле JSON. Никаких внешних ключей API не требуется — вы (агент) сами создаете содержимое карточек и вопросы викторины.

Стиль ответа, ориентированный на пользователя, для карточек Memento:
- Используйте только простой текст. Не используйте форматирование Markdown в ответах пользователю.
- Делайте обзоры и отзывы викторин краткими и нейтральными. Избегайте лишних похвал, напутствий и длинных объяснений.

## Когда использовать

Используйте этот навык, когда пользователь хочет:
- Сохраняйте факты в виде карточек для последующего просмотра.
- Просмотрите карточки выполнения с интервальным повторением.
- Создайте тест из стенограммы видео YouTube.
- Импорт, экспорт, проверка или удаление данных флэш-карты.

Не используйте этот навык для общих вопросов и ответов, помощи в кодировании или задач, не связанных с памятью.

## Краткий справочник

| Намерение пользователя | Действие |
|---|---|
| «Запомни это X» / «сохрани это как карточку» | Создайте карточку вопросов и ответов, позвоните `memento_cards.py add` |
| Отправляет факт без упоминания карточек | Спросите: «Хотите, чтобы я сохранил это как карточку на память?» — создавать только в случае подтверждения |
| «Создать карточку» | Спросите вопросы, ответы, сбор; позвоните `memento_cards.py add` |
| «Просмотрите мои карты» | Позвоните `memento_cards.py due`, предъявите карточки по одной |
| «Задайте мне вопрос на [URL YouTube]» | Позвоните `youtube_quiz.py fetch VIDEO_ID`, задайте 5 вопросов, позвоните `memento_cards.py add-quiz` |
| «Экспортировать мои карты» | Позвоните `memento_cards.py export --output PATH` |
| «Импорт карточек из CSV» | Позвоните `memento_cards.py import --file PATH --collection NAME` |
| «Показать мою статистику» | Позвоните `memento_cards.py stats` |
| «Удалить карту» | Позвоните `memento_cards.py delete --id ID` |
| «Удалить коллекцию» | Позвоните `memento_cards.py delete-collection --collection NAME` |

## Хранилище карт

Карты хранятся в файле JSON по адресу:

```
~/.hermes/skills/productivity/memento-flashcards/data/cards.json
```

**Никогда не редактируйте этот файл напрямую.** Всегда используйте подкоманды `memento_cards.py`. Скрипт обрабатывает атомарные записи (запись во временный файл, затем переименование), чтобы предотвратить повреждение.

Файл создается автоматически при первом использовании.

## Процедура

### Создание карточек на основе фактов

### Правила активации

Не каждое фактическое утверждение должно стать карточкой. Используйте эту трехуровневую проверку:

1. **Явное намерение** — пользователь упоминает слова «память», «карточка», «запомнить это», «сохраните эту карточку», «добавить карточку» или подобную фразу, которая явно запрашивает карточку → **создайте карточку напрямую**, подтверждение не требуется.
2. **Неявное намерение** — пользователь отправляет фактическое утверждение, не упоминая карточки (например, «Скорость света 299 792 км/с») → **сначала спросите**: «Хотите, чтобы я сохранил это как карточку на память?» Создавайте карту только в том случае, если пользователь подтвердит.
3. **Нет намерения** — сообщение представляет собой задачу кодирования, вопрос, инструкцию, обычный разговор или что-то, что явно не является фактом для запоминания → **НЕ активируйте этот навык вообще**. Позвольте другим навыкам или поведению по умолчанию справиться с этим.

Когда активация будет подтверждена (уровень 1 напрямую, уровень 2 после подтверждения), сгенерируйте флеш-карту:

**Шаг 1.** Превратите утверждение в пару вопросов и ответов. Используйте этот формат внутри:

```
Turn the factual statement into a front-back pair.
Return exactly two lines:
Q: <question text>
A: <answer text>

Statement: "{statement}"
```

Правила:
- Вопрос должен проверять напоминание ключевого факта.
- Ответ должен быть кратким и прямым.

**Шаг 2:** Вызовите скрипт для сохранения карты:

```bash
python3 ~/.hermes/skills/productivity/memento-flashcards/scripts/memento_cards.py add \
  --question "What year did World War 2 end?" \
  --answer "1945" \
  --collection "History"
```

Если пользователь не указывает коллекцию, используйте `"General"` по умолчанию.

Скрипт выводит JSON, подтверждающий создание карты.

### Создание карты вручную

Когда пользователь явно просит создать карточку, попросите его:
1. Вопрос (лицевая сторона карточки)
2. Ответ (обратная сторона карточки)
3. Название коллекции (необязательно — по умолчанию `"General"`).

Затем позвоните `memento_cards.py add`, как указано выше.

### Проверка карточек оплаты

Когда пользователь хочет просмотреть, извлеките все карточки с сроками:

```bash
python3 ~/.hermes/skills/productivity/memento-flashcards/scripts/memento_cards.py due
```

Возвращает массив карточек JSON, где `next_review_at <= now`. Если необходим фильтр сбора:

```bash
python3 ~/.hermes/skills/productivity/memento-flashcards/scripts/memento_cards.py due --collection "History"
```

**Последовательность проверки (оценка в произвольном порядке):**

Вот пример ТОЧНОЙ модели взаимодействия, которой вы должны следовать. Пользователь отвечает, вы оцениваете его, сообщаете правильный ответ, а затем оцениваете карту.

**Пример взаимодействия:**

> **Агент:** В каком году пала Берлинская стена?
>
> **Пользователь:** 1991 г.
>
> **Агент:** Не совсем. Берлинская стена пала в 1989 году. Следующий обзор завтра.
> *(вызов агента: memento_cards.py тариф --id ABC --rating hard --user-ответ "1991")*
>
> Следующий вопрос: Кто был первым человеком, ступившим на Луну?

**Правила:**

1. Покажите только вопрос. Подождите, пока пользователь ответит.
2. Получив ответ, сравните его с ожидаемым и оцените:
   - **правильно** → пользователь правильно усвоил ключевой факт (даже если он сформулирован по-другому)
   - **частично** → правильный путь, но не хватает основных деталей
   - **неправильно** → неправильно или не по теме
3. **Вы ДОЛЖНЫ сообщить пользователю правильный ответ и указать, как он это сделал.** Делайте это коротким и простым текстом. Используйте этот формат:
   - правильно: "Верно. Ответ: &#123;ответ&#125;. Следующий отзыв через 7 дней."
   - частичный: «Закрыть. Ответ: «ответ». «Что они пропустили». Следующий отзыв через 3 дня».
   - неверно: "Не совсем. Ответ: &#123;ответ&#125;. Следующий обзор завтра."
4. Затем вызовите команду скорости: правильно→легко, частично→хорошо, неправильно→сложно.
5. Затем покажите следующий вопрос.

```bash
python3 ~/.hermes/skills/productivity/memento-flashcards/scripts/memento_cards.py rate \
  --id CARD_ID --rating easy --user-answer "what the user said"
```

**Никогда не пропускайте шаг 3.** Прежде чем двигаться дальше, пользователь всегда должен видеть правильный ответ и отзыв.

Если карточки не подлежат проверке, сообщите пользователю: «Сейчас нет карточек, подлежащих проверке. Зайдите позже!»

**Переопределение удаления из обращения.** В любой момент пользователь может сказать «Снять с учета эту карту», ​​чтобы навсегда удалить ее из отзывов. Используйте для этого `--rating retire`.

### Алгоритм интервального повторения

Рейтинг определяет следующий интервал проверки:

| Рейтинг | Интервал | легкость_стрик | Изменение статуса |
|---|---|---|---|
| **жесткий** | +1 день | сбросить до 0 | продолжает учиться |
| **хорошо** | +3 дня | сбросить до 0 | продолжает учиться |
| **легко** | +7 дней | +1 | если easy_streak >= 3 → на пенсии |
| **уйти на пенсию** | постоянный | сбросить до 0 | → пенсионер |

- **обучение**: карта активно вращается.
- **снято**: карта не будет отображаться в обзорах (пользователь освоил ее или удалил ее вручную).
- Три последовательных «легких» рейтинга автоматически снимают карту.

### Генерация викторин YouTube

Когда пользователь отправляет URL-адрес YouTube и хочет пройти тест:

**Шаг 1.** Извлеките идентификатор видео из URL (например, `dQw4w9WgXcQ` из `https://www.youtube.com/watch?v=dQw4w9WgXcQ`).

**Шаг 2.** Получите расшифровку:

```bash
python3 ~/.hermes/skills/productivity/memento-flashcards/scripts/youtube_quiz.py fetch VIDEO_ID
```

Возвращает `{"title": "...", "transcript": "..."}` или ошибку.

Если сценарий сообщает `missing_dependency`, попросите пользователя установить его:
```bash
pip install youtube-transcript-api
```

**Шаг 3.** Создайте 5 вопросов викторины на основе стенограммы. Используйте эти правила:

```
You are creating a 5-question quiz for a podcast episode.
Return ONLY a JSON array with exactly 5 objects.
Each object must contain keys 'question' and 'answer'.

Selection criteria:
- Prioritize important, surprising, or foundational facts.
- Skip filler, obvious details, and facts that require heavy context.
- Never return true/false questions.
- Never ask only for a date.

Question rules:
- Each question must test exactly one discrete fact.
- Use clear, unambiguous wording.
- Prefer What, Who, How many, Which.
- Avoid open-ended Describe or Explain prompts.

Answer rules:
- Each answer must be under 240 characters.
- Lead with the answer itself, not preamble.
- Add only minimal clarifying detail if needed.
```

Используйте первые 15 000 символов стенограммы в качестве контекста. Создавайте вопросы сами (вы — магистр права).

**Шаг 4.** Убедитесь, что выходные данные действительны в формате JSON, содержащем ровно 5 элементов, каждый из которых имеет непустые строки `question` и `answer`. Если проверка не удалась, повторите попытку один раз.

**Шаг 5.** Сохраните карточки с тестами:

```bash
python3 ~/.hermes/skills/productivity/memento-flashcards/scripts/memento_cards.py add-quiz \
  --video-id "VIDEO_ID" \
  --questions '[{"question":"...","answer":"..."},...]' \
  --collection "Quiz - Episode Title"
```

Скрипт выполняет дедупликацию `video_id` — если карточки для этого видео уже существуют, он пропускает создание и сообщает о существующих карточках.

**Шаг 6.** Предлагайте вопросы один за другим, используя один и тот же алгоритм оценивания в произвольном порядке:
1. Показать «Вопрос 1/5: ...» и дождаться ответа пользователя. Никогда не включайте ответ или какой-либо намек на его раскрытие.
2. Подождите, пока пользователь ответит своими словами.
3. Оцените ответ, используя подсказку для оценки (см. раздел «Просмотр карточек выполнения»).
4. **ВАЖНО: прежде чем делать что-либо еще, НЕОБХОДИМО ответить пользователю отзывом.** Покажите оценку, правильный ответ и дату следующего сдачи карточки. НЕ переходите молча к следующему вопросу. Делайте это коротким и простым текстом. Пример: «Не совсем. Ответ: «ответ». Следующий обзор завтра».
5. **После отображения отзыва** вызовите команду оценки, а затем покажите следующий вопрос в том же сообщении:
```bash
python3 ~/.hermes/skills/productivity/memento-flashcards/scripts/memento_cards.py rate \
  --id CARD_ID --rating easy --user-answer "what the user said"
```
6. Повторите. Каждый ответ ДОЛЖЕН получить видимую обратную связь перед следующим вопросом.

### Экспорт/импорт CSV

**Экспорт:**
```bash
python3 ~/.hermes/skills/productivity/memento-flashcards/scripts/memento_cards.py export \
  --output ~/flashcards.csv
```

Создает CSV-файл с тремя столбцами: `question,answer,collection` (без строки заголовка).

**Импорт:**
```bash
python3 ~/.hermes/skills/productivity/memento-flashcards/scripts/memento_cards.py import \
  --file ~/flashcards.csv \
  --collection "Imported"
```

Считывает CSV со столбцами: вопрос, ответ и, при необходимости, подборка (столбец 3). Если столбец коллекции отсутствует, используется аргумент `--collection`.

### Статистика

```bash
python3 ~/.hermes/skills/productivity/memento-flashcards/scripts/memento_cards.py stats
```

Возвращает JSON с:
- `total`: общее количество карт.
- `learning`: карты в активной ротации
- `retired`: мастер-карты
– `due_now`: карточки подлежат проверке прямо сейчас.
- `collections`: разбивка по названию коллекции.

## Подводные камни

- **Никогда не редактируйте `cards.json` напрямую** — всегда используйте подкоманды сценария, чтобы избежать повреждения.
- **Ошибки расшифровки** — некоторые видео на YouTube не имеют расшифровки на английском языке или расшифровка отключена; сообщите пользователю и предложите другое видео
- **Необязательная зависимость** — `youtube_quiz.py` требуется `youtube-transcript-api`; если отсутствует, попросите пользователя запустить `pip install youtube-transcript-api`
- **Большой импорт** — импорт CSV с тысячами строк работает нормально, но вывод JSON может быть подробным; подвести итог для пользователя
- **Извлечение идентификатора видео** — поддержка форматов URL `youtube.com/watch?v=ID` и `youtu.be/ID`.
