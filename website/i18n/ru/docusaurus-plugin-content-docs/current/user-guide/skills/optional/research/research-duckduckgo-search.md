# Поиск DuckDuckGo

Бесплатный поиск в Интернете с помощью DuckDuckGo. **Ключ API не требуется.**

Предпочтительно, когда `web_search` недоступен или не подходит (например, когда `FIRECRAWL_API_KEY` не установлен). Также может использоваться как отдельный путь поиска, когда результаты DuckDuckGo особенно желательны.

## Порядок обнаружения

Прежде чем выбирать подход, проверьте, что действительно доступно:

```bash
# Check CLI availability
command -v ddgs >/dev/null && echo "DDGS_CLI=installed" || echo "DDGS_CLI=missing"
```

Дерево решений:
1. Если установлен `ddgs` CLI, выберите `terminal` + `ddgs`.
2. Если `ddgs` CLI отсутствует, не предполагайте, что `execute_code` может импортировать `ddgs`.
3. Если пользователю нужен именно DuckDuckGo, сначала установите `ddgs` в соответствующей среде.
4. В противном случае вернитесь к встроенным инструментам веб-браузера.

Важное примечание во время выполнения:
- Терминал и `execute_code` — отдельные среды выполнения.
- Успешная установка оболочки не гарантирует, что `execute_code` сможет импортировать `ddgs`.
- Никогда не предполагайте, что сторонние пакеты Python предустановлены внутри `execute_code`.

## Установка

Устанавливайте `ddgs` только в том случае, если поиск DuckDuckGo особенно необходим и среда выполнения еще не предоставляет его.

```bash
# Python package + CLI entrypoint
pip install ddgs

# Verify CLI
ddgs --help
```

Если рабочий процесс зависит от импорта Python, убедитесь, что та же среда выполнения может импортировать `ddgs`, прежде чем использовать `from ddgs import DDGS`.

## Способ 1: поиск через интерфейс командной строки (предпочтительно)

Используйте команду `ddgs` через `terminal`, если она существует. Это предпочтительный путь, поскольку он позволяет избежать предположения, что в песочнице `execute_code` установлен пакет Python `ddgs`.

```bash
# Text search
ddgs text -q "python async programming" -m 5

# News search
ddgs news -q "artificial intelligence" -m 5

# Image search
ddgs images -q "landscape photography" -m 10

# Video search
ddgs videos -q "python tutorial" -m 5

# With region filter
ddgs text -q "best restaurants" -m 5 -r us-en

# Recent results only (d=day, w=week, m=month, y=year)
ddgs text -q "latest AI news" -m 5 -t w

# JSON output for parsing
ddgs text -q "fastapi tutorial" -m 5 -o json
```

### Флаги CLI

| Флаг | Описание | Пример |
|------|-------------|---------|
| `-q` | Запрос — **обязательно** | `-q "search terms"` |
| `-m` | Максимальные результаты | `-m 5` |
| `-r` | Регион | `-r us-en` |
| `-t` | Ограничение по времени | `-t w` (неделя) |
| `-s` | Безопасный поиск | `-s off` |
| `-o` | Выходной формат | `-o json` |

## Способ 2: API Python (только после проверки)

Используйте класс `DDGS` в `execute_code` или другой среде выполнения Python только после проверки того, что там установлен `ddgs`. Не думайте, что `execute_code` по умолчанию включает сторонние пакеты.

Безопасная формулировка:
- «При необходимости используйте `execute_code` с `ddgs` после установки или проверки пакета»

Избегайте говорить:
- "`execute_code` включает `ddgs`"
- «Поиск DuckDuckGo работает по умолчанию в `execute_code`»

**Важно!** `max_results` всегда следует передавать в качестве **аргумента ключевого слова** — позиционное использование приводит к ошибке во всех методах.

### Текстовый поиск

Лучше всего подходит для: общих исследований, компаний, документации.

```python
from ddgs import DDGS

with DDGS() as ddgs:
    for r in ddgs.text("python async programming", max_results=5):
        print(r["title"])
        print(r["href"])
        print(r.get("body", "")[:200])
        print()
```

Возвращает: `title`, `href`, `body`.

### Поиск новостей

Подходит для: текущих событий, последних новостей, последних обновлений.

```python
from ddgs import DDGS

with DDGS() as ddgs:
    for r in ddgs.news("AI regulation 2026", max_results=5):
        print(r["date"], "-", r["title"])
        print(r.get("source", ""), "|", r["url"])
        print(r.get("body", "")[:200])
        print()
```

Возвращает: `date`, `title`, `body`, `url`, `image`, `source`.

### Поиск изображений

Лучше всего подходит для: визуальных ссылок, изображений продуктов, диаграмм.

```python
from ddgs import DDGS

with DDGS() as ddgs:
    for r in ddgs.images("semiconductor chip", max_results=5):
        print(r["title"])
        print(r["image"])
        print(r.get("thumbnail", ""))
        print(r.get("source", ""))
        print()
```

Возвращает: `title`, `image`, `thumbnail`, `url`, `height`, `width`, `source`.

### Поиск видео

Лучше всего подходит для: обучающих программ, демонстраций, пояснений.

```python
from ddgs import DDGS

with DDGS() as ddgs:
    for r in ddgs.videos("FastAPI tutorial", max_results=5):
        print(r["title"])
        print(r.get("content", ""))
        print(r.get("duration", ""))
        print(r.get("provider", ""))
        print(r.get("published", ""))
        print()
```

Возвращает: `title`, `content`, `description`, `duration`, `provider`, `published`, `statistics`, `uploader`.

### Краткий справочник

| Метод | Используйте, когда | Ключевые поля |
|--------|----------|------------|
| `text()` | Общие исследования, компании | заголовок, href, тело |
| `news()` | Текущие события, обновления | дата, заголовок, источник, текст, URL |
| `images()` | Наглядные изображения, диаграммы | заголовок, изображение, миниатюра, URL |
| `videos()` | Учебники, демо | название, содержание, продолжительность, поставщик |

## Рабочий процесс: поиск и извлечение

DuckDuckGo возвращает заголовки, URL-адреса и фрагменты, а не полное содержимое страницы. Чтобы получить полное содержимое страницы, сначала выполните поиск, а затем извлеките наиболее релевантный URL-адрес с помощью `web_extract`, инструментов браузера или Curl.

Пример интерфейса командной строки:

```bash
ddgs text -q "fastapi deployment guide" -m 3 -o json
```

Пример Python, только после проверки того, что `ddgs` установлен в этой среде выполнения:

```python
from ddgs import DDGS

with DDGS() as ddgs:
    results = list(ddgs.text("fastapi deployment guide", max_results=3))
    for r in results:
        print(r["title"], "->", r["href"])
```

Затем извлеките лучший URL-адрес с помощью `web_extract` или другого инструмента поиска контента.

## Ограничения

- **Ограничение скорости**: DuckDuckGo может регулировать скорость после множества быстрых запросов. При необходимости добавьте небольшую задержку между поисками.
– **Без извлечения содержимого**: `ddgs` возвращает фрагменты, а не полное содержимое страницы. Используйте `web_extract`, инструменты браузера или Curl для просмотра всей статьи/страницы.
- **Качество результатов**: в целом хорошее, но менее настраиваемое, чем поиск Firecrawl.
- **Доступность**: DuckDuckGo может блокировать запросы с некоторых облачных IP-адресов. Если результаты поиска пусты, попробуйте другие ключевые слова или подождите несколько секунд.
- **Изменчивость полей**: поля возврата могут различаться в зависимости от результатов или версий `ddgs`. Используйте `.get()` для необязательных полей, чтобы избежать `KeyError`.
- **Раздельные среды выполнения**: успешная установка `ddgs` в терминале не означает автоматически, что `execute_code` может его импортировать.

## Устранение неполадок

| Проблема | Вероятная причина | Что делать |
|---------|--------------|------------|
| `ddgs: command not found` | CLI не установлен в среде оболочки | Установите `ddgs` или вместо этого используйте встроенные инструменты веб-браузера |
| `ModuleNotFoundError: No module named 'ddgs'` | В среде выполнения Python не установлен пакет | Не используйте там Python DDGS, пока не будет подготовлена ​​среда выполнения |
| Поиск ничего не возвращает | Временное ограничение скорости или неправильный запрос | Подождите несколько секунд, повторите попытку или измените запрос |
| CLI работает, но импорт `execute_code` не удался | Терминал и `execute_code` — разные среды выполнения | Продолжайте использовать CLI или отдельно подготовьте среду выполнения Python |

## Подводные камни

- **`max_results` используется только по ключевым словам**: `ddgs.text("query", 5)` вызывает ошибку. Используйте `ddgs.text("query", max_results=5)`.
- **Не предполагайте, что CLI существует**: проверьте `command -v ddgs` перед его использованием.
- **Не предполагайте, что `execute_code` может импортировать `ddgs`**: `from ddgs import DDGS` может не работать с `ModuleNotFoundError`, если эта среда выполнения не была подготовлена ​​отдельно.
- **Имя пакета**: пакет `ddgs` (ранее `duckduckgo-search`). Установите с помощью `pip install ddgs`.
- **Не путайте `-q` и `-m`** (CLI): `-q` — для запроса, `-m` — для максимального количества результатов.
- **Пустые результаты**: если `ddgs` ничего не возвращает, возможно, его скорость ограничена. Подождите несколько секунд и повторите попытку.
