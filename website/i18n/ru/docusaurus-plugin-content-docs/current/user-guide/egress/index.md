# Выходной прокси

Дополнительный брандмауэр с внедрением исходящих учетных данных для изолированных программных сред удаленных терминалов. В песочнице хранятся только непрозрачные прокси-токены; настоящие ключи API никогда не покидают хост.

- [iron-proxy](./iron-proxy) — однобинарный прокси-сервер, перехватывающий TLS, от [ironsh/iron-proxy](https://github.com/ironsh/iron-proxy), лениво установленный и управляемый `hermes egress`.
