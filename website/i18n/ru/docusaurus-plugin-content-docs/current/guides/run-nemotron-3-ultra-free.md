# Запустите Nemotron 3 Ultra бесплатно в Hermes Agent

Nous Research включена в **Nemotron Coalition** ведущих лабораторий искусственного интеллекта, работающих с **NVIDIA** над продвижением фундаментальных моделей открытых границ. В честь этого мы заключили партнерство с **Nebius** и предоставили **Nemotron 3 Ultra** бесплатно на [Nous Portal](https://portal.nousresearch.com) на две недели (**с 4 по 18 июня**). Следуйте инструкциям ниже, чтобы опробовать эту модель в своем агенте Hermes уже сегодня.

:::информация Предложение ограничено по времени
Уровень `nvidia/nemotron-3-ultra:free` доступен с **4 по 18 июня**. Тег `:free` — это то, что позволяет использовать бесплатный план — выберите именно этот вариант.
:::

Выбирайте ту установку, которая вам подходит. **Настольное приложение** является самым простым — терминал не требуется. Если вы живете в терминале, установка **командной строки** находится прямо под ним.

## Вариант A — настольное приложение (рекомендуется)

Самый простой путь: установка в один клик с пошаговой настройкой. Терминал не нужен.

### 1. Загрузите и установите

[Загрузите установщик Hermes Desktop](https://hermes-agent.nousresearch.com/) для macOS или Windows, затем откройте его. При первом запуске он завершает настройку (обычно менее минуты).

### 2. Подключитесь к порталу Nous

Когда приложение откроется, вы увидите экран «Давайте настроим». Нажмите **Nous Portal** (с пометкой **Рекомендуется**). Откроется браузер — создайте учетную запись [Nous Portal](https://portal.nousresearch.com) (или войдите в нее), выберите план **Бесплатный** и авторизуйте Hermes. Приложение подключается автоматически.

### 3. Выберите бесплатную модель Nemotron 3 Ultra.

После подключения в приложении отображается карточка **Модель по умолчанию**. Нажмите **Изменить**, найдите **nemotron 3 ultra** и выберите вариант с пометкой **Уровень бесплатного пользования**:

```
nvidia/nemotron-3-ultra:free
```

Тег `:free` позволяет ему оставаться на бесплатном уровне — выберите этот вариант.

### 4. Начать общение

Нажмите **Начать чат**. Вот и все — вы разговариваете с Nemotron 3 Ultra бесплатно.

## Вариант Б — Командная строка

Предпочитаете терминал?

### 1. Установите агент Hermes

В macOS/Linux/WSL2/Android запустите

```bash
curl -fsSL https://hermes-agent.nousresearch.com/install.sh | bash
```

В Windows запустите

```powershell
iex (irm https://hermes-agent.nousresearch.com/install.ps1)
```

Предпочитаете сначала просмотреть? Загрузите [`install.sh`](https://hermes-agent.nousresearch.com/install.sh), проверьте его, затем запустите.

После завершения перезагрузите оболочку:

```bash
source ~/.bashrc   # or source ~/.zshrc
```

### 2. Запустите быструю настройку

```bash
hermes setup
```

Выберите **Быстрая настройка**. Гермес открывает вкладку браузера и ждет, пока вы выполните следующие шаги.

### 3. Создайте учетную запись на портале Nous.

В браузере создайте учетную запись [Nous Portal](https://portal.nousresearch.com) (или войдите в нее) и выберите план **Бесплатный**.

### 4. Подключите свою учетную запись

Когда будет предложено подключить вашу учетную запись к агенту Hermes, нажмите **Подключиться**. Вы увидите подтверждение, как только ссылка будет установлена.

### 5. Выберите бесплатную модель Nemotron 3 Ultra.

Вернитесь к своему терминалу. Из списка моделей выберите:

```
nvidia/nemotron-3-ultra:free
```

Тег `:free` удерживает его на бесплатном уровне, поэтому обязательно выберите этот вариант.

### 6. Начните общаться

Заполните оставшиеся запросы быстрой настройки, затем запустите:

```bash
hermes
```

Вот и все — вы разговариваете с Nemotron 3 Ultra бесплатно.

## Переключимся на него позже

Уже установили другую модель?

- **Приложение для ПК:** откройте окно выбора модели, найдите **nemotron 3 ultra** и выберите вариант **Уровень бесплатного пользования**.
- **CLI/TUI:** переключитесь в любой момент внутри сеанса с помощью `/model nvidia/nemotron-3-ultra:free` или запустите `/model`, чтобы открыть средство выбора и выбрать его из списка.

## Поиск неисправностей

- **Не видите модель в списке?** Убедитесь, что вы завершили подключение к Nous Portal и используете тарифный план **Бесплатный**. В CLI `hermes portal info` подтверждает, что вы вошли в систему и выполняете маршрутизацию через Nous.
- **Выбрали неправильный вариант?** Повторно выберите `nvidia/nemotron-3-ultra:free` — суффикс `:free` необходим, чтобы оставаться на бесплатном уровне.
- **Браузер не открылся/вы находитесь на удаленном хосте (CLI)?** См. обходные пути переадресации портов в разделе [OAuth через SSH/Удаленные хосты](/guides/oauth-over-ssh).
