# Google Близнецы

Агент Hermes поддерживает Google Gemini в качестве собственного поставщика, используя **Google AI Studio/Gemini API**, а не конечную точку, совместимую с OpenAI. Это позволяет Hermes транслировать свои внутренние сообщения и цикл инструментов в форме OpenAI в собственный API `generateContent` Gemini, сохраняя при этом вызовы инструментов, потоковую передачу, мультимодальные входные данные и метаданные ответа, специфичные для Gemini.

## Предварительные условия

- **Ключ Google AI Studio API** — создайте его на странице [aistudio.google.com/apikey](https://aistudio.google.com/apikey).
- **Проект Google Cloud с включенной оплатой** — рекомендуется для использования агентом. Уровень бесплатного пользования Gemini слишком мал для длительных сеансов агента, поскольку Hermes может совершать несколько вызовов модели за один ход пользователя.
- **Hermes установлен** — для собственного поставщика Gemini не требуется дополнительный пакет Python.

:::tip путь к ключу API
Установите `GOOGLE_API_KEY` или `GEMINI_API_KEY`. Hermes проверяет оба имени на наличие поставщика `gemini`.
:::

## Быстрый старт

```bash
# Add your Gemini API key
echo "GOOGLE_API_KEY=..." >> ~/.hermes/.env

# Select Gemini as your provider
hermes model
# → Choose "More providers..." → "Google AI Studio"
# → Hermes checks your key tier and shows Gemini models
# → Select a model

# Start chatting
hermes chat
```

Если вы предпочитаете прямое редактирование конфигурации, используйте собственный базовый URL-адрес Gemini API:

```yaml
model:
  default: gemini-3.7-flash
  provider: gemini
  base_url: https://generativelanguage.googleapis.com/v1beta
```

## Конфигурация

После запуска `hermes model` ваш `~/.hermes/config.yaml` будет содержать:

```yaml
model:
  default: gemini-3.7-flash
  provider: gemini
  base_url: https://generativelanguage.googleapis.com/v1beta
```

И в `~/.hermes/.env`:

```bash
GOOGLE_API_KEY=...
```

### Собственный API Gemini

Рекомендуемая конечная точка:

```text
https://generativelanguage.googleapis.com/v1beta
```

Hermes обнаруживает эту конечную точку и создает собственный адаптер Gemini. Внутри себя Hermes по-прежнему сохраняет цикл агента в сообщениях в форме OpenAI, а затем преобразует каждый запрос в собственную схему Gemini:

- `messages[]` → Близнецы `contents[]`
- системные подсказки → Близнецы `systemInstruction`
- схемы инструментов → Близнецы `functionDeclarations`
- результаты инструмента → Gemini `functionResponse` детали
- потоковые ответы → фрагменты потока в форме OpenAI для цикла Hermes

::: обратите внимание на подписи мыслей Gemini 3
При использовании инструмента Gemini 3 Hermes сохраняет значения `thoughtSignature`, прикрепленные к частям вызова функций, и воспроизводит их при следующем повороте инструмента. Это охватывает критический путь проверки для многоэтапных рабочих процессов агента.

Gemini 3 также может прикреплять мысли к другим частям ответа. Собственный адаптер Hermes сегодня оптимизирован для циклов агентских инструментов, поэтому он еще не воспроизводит каждую сигнатуру, не связанную с вызовом инструмента, с полной точностью на уровне детали.
:::

### Предпочитайте собственную конечную точку

Google также предоставляет конечную точку, совместимую с OpenAI:

```text
https://generativelanguage.googleapis.com/v1beta/openai/
```

Для сеансов агента Hermes отдайте предпочтение встроенной конечной точке Gemini, указанной выше. Hermes включает в себя собственный адаптер Gemini, поэтому он может отображать использование многооборотного инструмента, результаты вызова инструмента, потоковую передачу, мультимодальные входные данные и метаданные ответов Gemini непосредственно на API Gemini `generateContent`. Конечная точка, совместимая с OpenAI, по-прежнему полезна, когда вам особенно нужна совместимость с OpenAI API.

Если вы ранее установили `GEMINI_BASE_URL` для URL-адреса `/openai`, удалите его или измените:

```bash
GEMINI_BASE_URL=https://generativelanguage.googleapis.com/v1beta
```

## Доступные модели

Средство выбора `hermes model` показывает модели Gemini, хранящиеся в реестре поставщиков Hermes. Общие варианты включают в себя:

| Модель | удостоверение личности | Заметки |
|-------|----|-------|
| Близнецы 3.7 Флэш | `gemini-3.7-flash` | Рекомендуемый баланс скорости, возможностей и мультимодального понимания по умолчанию |
| Предварительный просмотр Gemini 3.1 Pro | `gemini-3.1-pro-preview` | Самая способная модель рассуждения, математики и кодирования |
| Близнецы 3.5 Flash Lite | `gemini-3.5-flash-lite` | Самый быстрый и дешевый вариант для легких задач |
| Близнецы 2.5 Флэш | `gemini-2.5-flash` | Быстрая модель предыдущего поколения с возможностями мышления |
| Близнецы 2.5 Про | `gemini-2.5-pro` | Модель комплексного рассуждения предыдущего поколения |

Доступность модели меняется со временем. Если модель исчезла или не активирована для вашего ключа, запустите `hermes model` еще раз и выберите одну из текущего списка.

:::info Идентификаторы моделей
Используйте собственные идентификаторы моделей Gemini, такие как `gemini-3.7-flash`, а не идентификаторы в стиле OpenRouter, такие как `google/gemini-3.7-flash`, когда `provider: gemini`.
:::

### Последние псевдонимы

Google публикует движущиеся псевдонимы для семейств Pro и Flash Gemini. `gemini-pro-latest` и `gemini-flash-latest` полезны, если вы хотите, чтобы Google автоматически продвигал модель без изменения конфигурации Hermes. Обратите внимание, что на ваши расходы на использование может повлиять, если в новых моделях будут установлены другие тарифы.

| Псевдоним | В настоящее время отслеживает | Заметки |
|-------|------------------|-------|
| `gemini-pro-latest` | Последняя модель Gemini Pro | Лучше всего, если вам нужна текущая версия Google Pro по умолчанию |
| `gemini-flash-latest` | Последняя модель Gemini Flash | Лучше всего, если вам нужен текущий Flash от Google по умолчанию |

```yaml
model:
  default: gemini-pro-latest
  provider: gemini
  base_url: https://generativelanguage.googleapis.com/v1beta
```

Если вам нужна строгая воспроизводимость, отдайте предпочтение явным идентификаторам модели, например `gemini-3.1-pro-preview` или `gemini-3.7-flash`.

### Джемма через API Gemini

Google также предоставляет модели Gemma через API Gemini. Hermes распознает их как модели Google, но скрывает записи Gemma с очень низкой пропускной способностью из средства выбора модели по умолчанию, чтобы новые пользователи случайно не выбрали модель уровня оценки для длительного сеанса агента.

Полезные идентификаторы оценки включают в себя:

| Модель | удостоверение личности | Заметки |
|-------|----|-------|
| Джемма 4 31Б ИТ | `gemma-4-31b-it` | Увеличенная модель Джеммы; полезно для совместимости и оценки качества |
| Джемма 4 26Б А4Б ИТ | `gemma-4-26b-a4b-it` | Меньший вариант с активными параметрами, если доступен |

Эти модели лучше всего рассматривать как варианты оценки ключей Gemini API. Цены на Google Gemma API указаны только для бесплатного уровня, а ограничения на использование низкие по сравнению с производственными моделями Gemini, поэтому постоянное использование агента Hermes обычно должно переходить на платную модель Gemini, самостоятельное развертывание или другого поставщика с соответствующей квотой.

Чтобы использовать модель Gemma, скрытую от средства выбора, установите ее напрямую:

```yaml
model:
  default: gemma-4-31b-it
  provider: gemini
  base_url: https://generativelanguage.googleapis.com/v1beta
```

## Переключение моделей в середине сеанса

Используйте команду `/model` во время разговора:

```text
/model gemini-3.7-flash
/model gemini-flash-latest
/model gemini-3.1-pro-preview
/model gemini-pro-latest
/model gemma-4-31b-it
/model gemini-3.1-flash-lite-preview
```

Если вы еще не настроили Gemini, выйдите из сеанса и сначала запустите `hermes model`. `/model` переключается между уже настроенными поставщиками и моделями; он не собирает новые ключи API.

## Диагностика

```bash
hermes doctor
```

Врач проверяет:

- Доступен ли `GOOGLE_API_KEY` или `GEMINI_API_KEY`.
- Можно ли разрешить настроенные учетные данные поставщика

## Шлюз (платформы обмена сообщениями)

Gemini работает со всеми шлюзовыми платформами Hermes (Telegram, Discord, Slack, WhatsApp, LINE, Feishu и т. д.). Настройте Gemini в качестве своего провайдера, затем запустите шлюз в обычном режиме:

```bash
hermes gateway setup
hermes gateway start
```

Шлюз считывает `config.yaml` и использует ту же конфигурацию поставщика Gemini.

## Устранение неполадок

### «Нативному клиенту Gemini требуется ключ API»

Гермес не смог найти пригодный для использования ключ API. Добавьте один из них в `~/.hermes/.env`:

```bash
GOOGLE_API_KEY=...
# or
GEMINI_API_KEY=...
```

Затем снова запустите `hermes model`.

### «Этот ключ API Google находится на уровне бесплатного пользования»

Hermes проверяет ключи API Gemini во время установки. Квоты бесплатного уровня могут быть исчерпаны после нескольких смен агентов, поскольку использование инструментов, повторные попытки, сжатие и вспомогательные задачи могут потребовать нескольких вызовов модели.

Включите биллинг для проекта Google Cloud, прикрепленного к вашему ключу, при необходимости повторно сгенерируйте ключ, а затем запустите:

```bash
hermes model
```

### "404 модель не найдена"

Выбранная модель недоступна для вашей учетной записи, региона или ключа. Запустите `hermes model` еще раз и выберите другую модель Gemini из текущего списка.

### Модель Джеммы не показана в `hermes model`

Hermes может по умолчанию скрывать модели Gemma с низкой пропускной способностью из средства выбора. Если вы намеренно хотите оценить одну из них, установите идентификатор модели непосредственно в `~/.hermes/config.yaml`.

### «Превышено 429 квот» на Джемме

Модели Gemma, предоставляемые через Gemini API, полезны для оценки, но ограничения уровня бесплатного использования Gemini API для них низкие. Используйте их для тестирования совместимости, а затем переключитесь на платную модель Gemini или другого поставщика для устойчивых сеансов агента.

### Конечная точка, совместимая с OpenAI, настроена

Проверьте `~/.hermes/.env` на наличие:

```bash
GEMINI_BASE_URL=https://generativelanguage.googleapis.com/v1beta/openai/
```

Измените его на собственную конечную точку или удалите переопределение:

```bash
GEMINI_BASE_URL=https://generativelanguage.googleapis.com/v1beta
```

### Вызов инструмента завершается сбоем из-за ошибок схемы

Обновите Гермес и перезапустите `hermes model`. Собственный адаптер Gemini очищает схемы инструментов для более строгого формата объявления функций Gemini; более старые сборки или пользовательские конечные точки могут не работать.
