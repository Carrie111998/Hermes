# Запустите агента Гермеса с помощью Nous Portal

В этом руководстве подробно описывается запуск агента Hermes по подписке на [Nous Portal](https://portal.nousresearch.com) — от регистрации до проверки правильности маршрутизации каждого инструмента. Если вам просто нужен обзор того, что такое Портал и что включено в подписку, посетите [страницу интеграции Nous Portal](/integrations/nous-portal). Эта страница представляет собой сценарий задачи.

## Предварительные условия

- Установлен агент Hermes ([Quickstart](/getting-started/quickstart))
- Веб-браузер на компьютере, который вы настраиваете (или переадресация портов SSH — см. [OAuth через SSH](/guides/oauth-over-ssh))
- Около 5 минут

Вам **не** нужны: ключ OpenAI, ключ Anthropic, учетная запись Firecrawl, учетная запись FAL, учетная запись использования браузера или любые другие учетные данные каждого поставщика. В этом вся суть.

## 1. Получите подписку

Откройте [portal.nousresearch.com/manage-subscription](https://portal.nousresearch.com/manage-subscription), зарегистрируйтесь и выберите план.

Уже подписались? Перейдите к шагу 2.

## 2. Запустите однократную настройку

```bash
hermes setup --portal
```

Эта единственная команда делает пять вещей:

1. Открывает ваш браузер на порталеportal.nousresearch.com для входа в систему OAuth.
2. Сохраняет токен обновления по адресу `~/.hermes/auth.json`.
3. Устанавливает `model.provider: nous` в `~/.hermes/config.yaml`.
4. Выбирает агентную модель по умолчанию (`anthropic/claude-sonnet-4.6` или аналогичную).
5. Включает Tool Gateway для веб-поиска, создания изображений, TTS и автоматизации браузера.

Когда он закончится, вы вернетесь к своему терминалу и будете готовы к общению.

### Что, если я подключусь к серверу по SSH?

Для OAuth нужен браузер, но обратный вызов закольцовки выполняется на компьютере, на котором работает Hermes. Два варианта:

```bash
# Option A: SSH port forwarding (preferred)
ssh -N -L 8642:127.0.0.1:8642 user@remote-host    # in a local terminal
hermes setup --portal                              # on the remote, open the printed URL in your local browser

# Option B: device-code login (works from Cloud Shell, Codespaces, EC2 Instance Connect)
hermes auth add nous --type oauth
# Then re-run `hermes setup --portal` to wire the provider + gateway
```

См. [OAuth через SSH/Удаленные хосты](/guides/oauth-over-ssh) для полного пошагового руководства, включая цепочки ProxyJump, mosh/tmux и ошибки ControlMaster.

## 3. Убедитесь, что все работает

```bash
hermes portal info
```

Вы должны увидеть:

```
  Nous Portal
  ───────────
  Auth:    ✓ logged in
  Portal:  https://portal.nousresearch.com
  Model:   ✓ using Nous as inference provider

  Tool Gateway
  ────────────
  Web search & extract  via Nous Portal
  Image generation      via Nous Portal
  Text-to-speech        via Nous Portal
  Browser automation    via Nous Portal
```

Если в какой-либо строке отображается что-то иное, чем «через Nous Portal», или в строке аутентификации указано «не вошел в систему», перейдите к [Устранение неполадок](#troubleshooting) ниже.

## 4. Начните свой первый разговор

```bash
hermes chat
```

Попробуйте что-нибудь, что проверит и модель, и Tool Gateway:

```
Hey, search the web for "Hermes Agent release notes" and summarize the top 3 hits.
```

Вы должны увидеть, как Гермес вызывает `web_search` (с поддержкой Firecrawl, через шлюз) и отвечает кратким описанием. Если поиск выполнен и ответ имеет смысл, все готово — Портал подключен от начала до конца.

## 5. Выберите модель, которая вам действительно нужна.

`hermes setup --portal` позволяет вам выбрать модель во время установки, но весь смысл подписки — это доступ к полному каталогу — переключайтесь в любой момент с помощью `/model` в середине сеанса:

```bash
/model anthropic/claude-sonnet-4.6     # best general-purpose agentic
/model openai/gpt-5.4                  # strong reasoning + tool calling
/model google/gemini-2.5-pro           # huge context window
/model deepseek/deepseek-v3.2          # cost-effective coder
/model anthropic/claude-opus-4.6       # heavyweight for hard problems
```

Или откройте окно выбора, чтобы просмотреть:

```bash
/model
```

Выберите другое значение по умолчанию навсегда:

```bash
# in your terminal, outside any session
hermes config set model.default anthropic/claude-sonnet-4.6
```

### Не выбирайте Гермес-4 для агентурной работы

«Гермес-4-70Б» и «Гермес-4-405Б» доступны на Портале с большими скидками, но это **модели для чата/рассуждения**, а не настраиваемые с помощью инструментов. Им придется бороться с многоэтапными циклами агентов. Используйте их для общения/исследовательской работы через [прокси-сервер подписки](/user-guide/features/subscription-proxy) из неагентских инструментов. Что касается самого агента «Гермес», придерживайтесь описанных выше пограничных агентных моделей.

Собственная [информационная страница] Портала (https://portal.nousresearch.com/info) также содержит это предупреждение — это официальное руководство Nous, а не просто мнение компании Hermes.

## 6. (Необязательно) Настройка маршрутизации Tool Gateway

Шлюз предполагает подписку на каждый инструмент, а не по принципу «все или ничего». Если у вас уже есть учетная запись Browserbase и вы хотите продолжать использовать ее при маршрутизации веб-поиска и создании изображений через Nous, это поддерживается:

```bash
hermes tools
# → Web search       → "Nous Subscription"     (recommended)
# → Image generation → "Nous Subscription"     (recommended)
# → Browser          → "Browserbase"           (your existing key)
# → TTS              → "Nous Subscription"     (recommended)
```

Эти строки появляются в `hermes tools` даже до того, как вы вошли в Nous Portal — если вы выберете «Nous Subscription» без активного сеанса, Hermes запустит встроенный вход в портал (без смены поставщика логических выводов или других инструментов).

Проверьте свой микс с помощью:

```bash
hermes portal tools
```

Вы увидите маршрутизацию для каждого инструмента — `via Nous Portal` для тех, которые маршрутизируются через подписку, и имя партнера (`browserbase`, `firecrawl` и т. д.) для тех, которые используют ваши собственные ключи.

## 7. (Необязательно) Включить голосовой режим

Поскольку Tool Gateway включает OpenAI TTS, [голосовой режим](/user-guide/features/voice-mode) работает без отдельного ключа OpenAI:

```bash
hermes setup tts
# → pick "Nous Subscription" for TTS
# → pick a speech-to-text backend (local faster-whisper is free, no setup)
```

Затем в любом сеансе платформы обмена сообщениями (Telegram, Discord, Signal и т. д.) отправьте голосовое сообщение, и Hermes расшифрует его, ответит и ответит синтезированным голосом — и все это по вашей подписке на Портал.

## 8. (Необязательно) Cron + постоянные рабочие процессы

Подписка на портал работает для [заданий cron](/user-guide/features/cron) и [пакетной обработки](/user-guide/features/batch-processing) так же, как и для интерактивного чата — токен обновления OAuth используется повторно автоматически. Никаких дополнительных настроек; просто запланируйте задания cron, и они выставят счет за вашу подписку.

```bash
hermes cron create "0 9 * * *" \
  "Search the web for top AI news and summarize the 5 most important stories" \
  --name "Daily AI news"
```

Задание cron выполняется автоматически, вызывает модель + веб-поиск + суммирование на протяжении всей вашей подписки на портал.

## Профили и многопользовательские настройки

Если вы используете [профили Hermes](/user-guide/profiles) (например, отдельную конфигурацию для каждого проекта), токен обновления портала автоматически распределяется между всеми профилями через общее хранилище токенов. Авторизуйтесь один раз в любом профиле, а остальные подберут его автоматически.

В групповых конфигурациях, когда несколько человек используют один компьютер, каждый человек имеет свою собственную учетную запись на портале → каждый домашний каталог содержит свой собственный `~/.hermes/auth.json` → общий доступ к токену между пользователями отсутствует. Это правильная граница.

## Устранение неполадок

### `hermes portal info` показывает «не вошел в систему» после `hermes setup --portal`

Поток OAuth не завершен. Перезапустите его:

```bash
hermes portal
```

Если ваш браузер не открывается или обратный вызов завершается неудачей, скорее всего, вы находитесь на удаленном/безголовом хосте — см. [OAuth через SSH](/guides/oauth-over-ssh) для обходных путей переадресации портов.

### «Модель: в настоящее время openrouter» (или какой-либо другой поставщик) вместо «использование Nous в качестве поставщика вывода»

Ваша локальная конфигурация сместилась. OAuth сработал, но `model.provider` по-прежнему указывает на другого провайдера. Исправление:

```bash
hermes config set model.provider nous
```

Или в интерактивном режиме:

```bash
hermes model
# pick Nous Portal
```

Повторно подтвердите с помощью `hermes portal info`.

### Инструменты Tool Gateway, показывающие имена партнеров вместо «через Nous Portal»

Конфигурация каждого инструмента переопределяет шлюз. Запустить:

```bash
hermes tools
# pick "Nous Subscription" for any tool you want gateway-routed
```

Некоторые пользователи намеренно смешивают — например. маршрутизация Интернета через Nous, но с использованием собственного ключа Browserbase для браузера. Если это намеренно, оставьте это в покое. Если нет, эта команда исправляет это.

### «Требуется повторная аутентификация» в середине сеанса

Ваш токен обновления портала был признан недействительным (смена пароля, отзыв вручную, истечение срока действия сеанса). Токен теперь помещен в карантин локально, поэтому Гермес не воспроизводит его бесконечно. Просто войдите снова:

```bash
hermes auth add nous
```

Карантин автоматически очищается при успешном повторном входе в систему.

### Модель, которую я хочу, отсутствует в средстве выбора `/model`

Каталог портала основан на списке моделей OpenRouter (более 300), а также на моделях, предоставляемых собственными или вторичными поставщиками. Если модель отсутствует, попробуйте напрямую ввести пул в стиле OpenRouter:

```bash
/model anthropic/claude-opus-4.6
/model openai/o1-2025-12-17
```

Если модель действительно недоступна, [откройте проблему](https://github.com/NousResearch/hermes-agent/issues) — большинство пробелов представляют собой конфигурацию маршрутизации, которую мы можем обновить.

### Платежи не отображаются в моей учетной записи на портале

`hermes portal info` сообщит вам, маршрутизируете ли вы на самом деле через Портал или через какого-либо другого провайдера. Распространенные причины:

- `model.provider` установлен на `openrouter`/`anthropic`/и т. д. вместо `nous`
- Ошибка обновления OAuth, из-за которой был использован другой настроенный поставщик.
- Несколько профилей Hermes, из которых вы используете неправильный (проверьте `hermes profile list`).

### Хотите отозвать и начать с чистого листа

```bash
hermes auth logout nous       # wipes the local refresh token
# Then re-run setup or remove the subscription from the Portal web UI
```

## Что это вам даст, простыми цифрами

| Без портала | С порталом |
|----------------|-------------|
| 1 × ключ OpenRouter/Anthropic/OpenAI в `.env` | 1 токен обновления OAuth, без ключей `.env` |
| 1 × ключ FireCrawl для Интернета | Веб-маршрутизация через шлюз |
| 1 × ключ FAL для генерации изображений | Генерация изображений направляется через шлюз |
| 1× Использование браузера / Базовый ключ для браузера | Браузер маршрутизируется через шлюз |
| 1× клавиша OpenAI для TTS/голосового режима | TTS маршрутизируется через шлюз |
| 5 отдельных панелей управления, пополнения, счета | 1 подписка, 1 счет |
| Кросс-машина: скопировать все 5 ключей | Межмашинное взаимодействие: повторите OAuth один раз |

Таково дело. В любом случае, если вы используете более двух таких серверов, подписка окупается.
