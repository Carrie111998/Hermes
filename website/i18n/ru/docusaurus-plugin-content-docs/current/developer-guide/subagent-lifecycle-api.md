# API жизненного цикла общедоступного субагента

Плагины могут запускать и контролировать новые дочерние сеансы Hermes без импорта.
`tools.delegate_tool`, внутренние данные шлюза, состояние TUI или поля `AIAgent`.
Служба разрешает своего родителя из текущего хода агента, поэтому она работает в
CLI, шлюз, неинтерактивные сеансы и сеансы канбан-работников. Запуск за пределами
Очередь активного агента не закрывается с помощью `No active Hermes parent session`.

```python
from agent.subagent_lifecycle import SubagentLaunchRequest

def launch_review(ctx):
    # Call from a plugin tool or hook while an agent turn is active.
    service = ctx.subagent_lifecycle
    handle = service.launch(SubagentLaunchRequest(
        goal="Review this change for regressions.",
        context="Only inspect the supplied repository.",
        role="leaf",
        correlation_id="review-42",
        allowed_toolsets=("file",),
    ))
    # Persist handle.to_dict() if desired.
    if service.wait(handle, timeout_seconds=2).timed_out:
        return handle.to_dict()
    return service.result(handle)
```

`SubagentHandle` является сериализуемым и имеет непрозрачные возможности управления версиями.
Передайте его обратно `status`, `wait`, `cancel`, `result` или `reconnect`; уродливый
или поддельные дескрипторы возвращают `UNKNOWN`/`UNKNOWN_HANDLE` и не могут получить доступ к дочернему элементу.

Стабильные состояния: `PENDING`, `STARTING`, `RUNNING`, `SUCCEEDED`, `FAILED`,
`INTERRUPTED`, `CANCEL_REQUESTED`, `CANCELLED` и `UNKNOWN`.

`cancel(handle, reason=...)` сотрудничает: он просит дочернего агента
прерывание на следующей безопасной границе и возвращает `CANCEL_REQUESTED`; это никогда
завершение утверждений до тех пор, пока `wait` или `result` не достигнет конечного состояния. Терминал
результаты неизменяемы, идемпотентны, ограничены 32 тыс. символов, транскрипты отсутствуют
и скрытые рассуждения, а также включать хэш стабильного результата.

Этот API представляет собой асинхронное выполнение, управляемое жизненным циклом. Детское конструирование и
при завершении использовать тот же путь, принадлежащий хосту, что и `delegate_task`, включая родительский
восстановление разрешения инструмента, уведомление о памяти, сериализованный `subagent_stop`
перехватчики, очистка ресурсов и объединение дочерних затрат. Это не меняет
синхронный инструмент `delegate_task`, пакетное делегирование или его шлюз/отображение TUI.
Первоначальная реализация сохраняет метаданные и результаты терминала в процессе для
один час.
После перезапуска процесса `reconnect` возвращает `RECONNECT_UNAVAILABLE` и никогда
начинает замену ребенка. Запуск потоков Python также не может выжить в процессе
выход; вызывающие стороны должны рассматривать эти дескрипторы как прерванные выходом из процесса.

Запросы завершаются неудачно: размеры цели/контекста/метаданных ограничены, неизвестны или
Наборы инструментов родительского расширения отклоняются, а блоки для каждого инструмента, рабочий каталог
переопределения, а тайм-ауты для каждого запуска явно отклоняются до тех пор, пока Hermes не сможет
поддержите их, не ослабляя изоляции. Используйте `allowed_toolsets`, чтобы сузить
ребенок; Существующий блок небезопасных инструментов Hermes остается в силе.
