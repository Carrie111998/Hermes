# Карта владения кодовой базой

Hermes — это большой репозиторий, и большинство материалов затрагивают только одну подсистему. На этой странице каждая подсистема сопоставлена ​​с ее исходными каталогами и точкой входа в документацию, которую вам следует прочитать перед ее изменением. Используйте его, чтобы найти правильный стартовый документ, подходящее место для изменений и правильный каталог для тестирования (источник зеркала тестов: код в `tools/` тестируется в `tests/tools/`, плагины в `tests/plugins/<type>/` и т. д.).

| Оперативная сборка | `agent/prompt_builder.py`, `agent/system_prompt.py` | [Быстрая сборка](prompt-assembly.md) |

Несколько соглашений, выпадающих из этой карты:

- **Изменения должны оставаться внутри их подсистемы.** Плагин, который должен редактировать файлы ядра, — это запах дизайна — вместо этого расширьте общую поверхность плагина (см. рубрику вклада в `AGENTS.md` репозитория).
- **Запускайте зеркальный тестовый каталог для каждого исходного каталога, к которому вы обращаетесь.** Для изменения `plugins/platforms/telegram/` требуется зеленый цвет `tests/plugins/platforms/`, а не только тестовый файл, о котором вы подумали.
- **Когда задействованы две подсистемы, изменения принадлежат более узкой.** Предпочитайте исправление в адаптере или плагине, а не ветку в ядре агента; ядро — это узкая талия, и каждое добавление там оплачивается при каждом вызове API.
