# Интеграции

Агент Hermes подключается к внешним системам для вывода ИИ, серверов инструментов, рабочих процессов IDE, программного доступа и многого другого. Эта интеграция расширяет возможности Hermes и расширяет возможности его работы.

:::совет Начните здесь
Если у вас есть время для настройки только одной интеграции, настройте [Nous Portal](/integrations/nous-portal) — один вход OAuth охватывает более 300 моделей, а также четыре инструмента Tool Gateway (веб-поиск, генерация изображений, TTS и автоматизация браузера).
:::

## Поставщики искусственного интеллекта и маршрутизация

Hermes поддерживает несколько поставщиков логических выводов искусственного интеллекта «из коробки». Используйте `hermes model` для интерактивной настройки или установите их в `config.yaml`.

- **[Поставщики ИИ](/интеграции/провайдеры)** — OpenRouter, Anthropic, OpenAI, Google и любые конечные точки, совместимые с OpenAI. Hermes автоматически определяет такие возможности, как зрение, потоковая передача и использование инструментов, для каждого поставщика.
- **[Маршрутизация поставщика](/user-guide/features/provider-routing)** — детальный контроль над тем, какие базовые поставщики обрабатывают ваши запросы OpenRouter. Оптимизируйте затраты, скорость и качество с помощью сортировки, белых и черных списков и явного порядка приоритетов.
- **[Резервные поставщики](/user-guide/features/fallback-providers)** — автоматическое переключение на резервные поставщики LLM, когда в основной модели возникают ошибки. Включает откат основной модели и независимый откат вспомогательных задач для визуализации, сжатия и извлечения веб-страниц.

## Серверы инструментов (MCP)

- **[Серверы MCP](/user-guide/features/mcp)** — Подключите Hermes к внешним серверам инструментов через протокол контекста модели. Получите доступ к инструментам GitHub, базам данных, файловым системам, стекам браузеров, внутренним API и многому другому без написания собственных инструментов Hermes. Поддерживает транспорты stdio и SSE, фильтрацию инструментов для каждого сервера и регистрацию ресурсов/подсказок с учетом возможностей.

## Серверы веб-поиска

Инструменты `web_search` и `web_extract` поддерживают восемь серверных поставщиков, настроенных через `config.yaml` или `hermes tools`:

| Бэкэнд | Конверт Вар | Поиск | Экстракт | Сканирование |
|---------|---------|--------|---------|-------|
| **Firecrawl** (по умолчанию) | `FIRECRAWL_API_KEY` | ✔ | ✔ | ✔ |
| **ИскатьXNG** | `SEARXNG_URL` | ✔ | — | — |
| **Храбрый** (уровень бесплатного пользования) | `BRAVE_SEARCH_API_KEY` | ✔ | — | — |
| **DuckDuckGo** (ddgs) | _(нет)_ | ✔ | — | — |
| **Тавили** | `TAVILY_API_KEY` (необязательно) | ✔ | ✔ | — |
| **Экса** | `EXA_API_KEY` | ✔ | ✔ | — |
| **Параллельно** | `PARALLEL_API_KEY` | ✔ | ✔ | — |
| **xAI** | `XAI_API_KEY` | ✔ | — | — |

Пример быстрой настройки:

```yaml
web:
  backend: firecrawl    # firecrawl | searxng | brave-free | ddgs | tavily | exa | parallel | xai
```

Если `web.backend` не установлен, серверная часть автоматически определяется по любому доступному ключу API. Самостоятельное размещение Firecrawl также поддерживается через `FIRECRAWL_API_URL`. Выбор Тавили в `hermes tools` работает без ключа.

## Автоматизация браузера

Hermes включает в себя полную автоматизацию браузера с несколькими опциями серверной части для навигации по веб-сайтам, заполнения форм и извлечения информации:

- **Облако для использования браузера** — управляемый Chromium со скрытыми, резидентными прокси, решением CAPTCHA и многоразовыми профилями браузера.
- **Browserbase** — альтернативный поставщик облачных браузеров с управляемыми браузерами, инструментами защиты от ботов, решением CAPTCHA и резидентными прокси.
- **Локальный CDP семейства Chromium** — подключитесь к работающему браузеру Chrome, Brave, Chromium или Edge с помощью `/browser connect`.
- **Local Chromium** — локальный браузер без заголовка через интерфейс командной строки `agent-browser`.

См. [Автоматизация браузера](/user-guide/features/browser) для настройки и использования.

## Поставщики голоса и TTS

Преобразование текста в речь и речь в текст на всех платформах обмена сообщениями:

| Провайдер | Качество | Стоимость | API-ключ |
|----------|---------|------|---------|
| **Пограничный TTS** (по умолчанию) | Хорошо | Бесплатно | Ничего не нужно |
| **ЭлевенЛабс** | Отлично | Платный | `ELEVENLABS_API_KEY` |
| **OpenAI TTS** | Хорошо | Платный | `VOICE_TOOLS_OPENAI_KEY` |
| **МиниМакс** | Хорошо | Платный | `MINIMAX_API_KEY` |
| **xAI TTS** | Хорошо | Платный | `XAI_API_KEY` |
| **НейТТС** | Хорошо | Бесплатно | Ничего не нужно |

Преобразование речи в текст поддерживает восемь провайдеров: локальный fast-whisper (бесплатный, работает на устройстве), локальную оболочку команд, Groq, OpenAI Whisper API, Mistral, xAI, ElevenLabs Scribe и DeepInfra. Транскрипция голосовых сообщений работает в Telegram, Discord, WhatsApp и других платформах обмена сообщениями. Подробности см. в разделах [Голос и TTS](/user-guide/features/tts) и [Голосовой режим](/user-guide/features/voice-mode).

## Интеграция IDE и редактора

- **[Интеграция IDE (ACP)](/user-guide/features/acp)** — используйте агент Hermes внутри ACP-совместимых редакторов, таких как VS Code, Zed и JetBrains. Hermes работает как сервер ACP, отображая сообщения чата, действия инструментов, различия файлов и команды терминала внутри вашего редактора.

## Программный доступ

- **[API-сервер](/user-guide/features/api-server)** — предоставить Hermes как конечную точку HTTP, совместимую с OpenAI. Любой интерфейс, поддерживающий формат OpenAI — Open WebUI, LobeChat, LibreChat, NextChat, ChatBox — может подключаться и использовать Hermes в качестве серверной части с полным набором инструментов.

## Память и персонализация

- **[Встроенная память](/user-guide/features/memory)** — постоянная, курируемая память с помощью файлов `MEMORY.md` и `USER.md`. Агент поддерживает ограниченные хранилища личных заметок и данных профилей пользователей, которые сохраняются во время сеансов.
- **[Поставщики памяти](/user-guide/features/memory-providers)** — подключите внешние модули памяти для более глубокой персонализации. Поддерживаются восемь провайдеров: Honcho (диалектическое рассуждение), OpenViking (многоуровневый поиск), Mem0 (извлечение из облака), Hindsight (графы знаний), Holographic (локальный SQLite), RetainDB (гибридный поиск), ByteRover (на основе CLI) и Supermemory.

### Ссылки быстрого подключения

На крупных платформах есть канонический URL-адрес «создайте своего бота/приложения», а некоторые принимают параметры, которые предварительно открывают нужную форму. Пропустите поиск консоли и идите прямо туда:

| Платформа | Прямая ссылка | Что это открывает |
|----------|-------------|---------------|
| **Телеграмма** | [t.me/BotFather](https://t.me/BotFather) | Пообщайтесь с BotFather — отправьте `/newbot`, чтобы создать токен бота |
| **Раздор** | [discord.com/developers/applications?new_application=true](https://discord.com/developers/applications?new_application=true) | Портал разработчика с предварительно открытым диалоговым окном **Новое приложение** |
| **Слабость** | [api.slack.com/apps?new_app=1](https://api.slack.com/apps?new_app=1) | Диалоговое окно **Создать новое приложение** — выберите *Из манифеста приложения* и вставьте манифест, сгенерированный `hermes slack manifest --agent-view` |
| **ЛИНИЯ** | [developers.line.biz/console](https://developers.line.biz/console/) | Консоль разработчика LINE для создания канала API сообщений |
| **Фейшу/Жаворонок** | [open.feishu.cn/app](https://open.feishu.cn/app) | Консоль открытой платформы Feishu для создания собственного приложения |

На странице настройки каждой платформы описано, что делать, когда вы окажетесь там.

## Рабочие пространства для совместной работы

- **[Buzz](/integrations/buzz)** — рабочее пространство человека и агента Block на базе Nostr. Три пути интеграции: Buzz Desktop создает Hermes как управляемую среду выполнения ACP, релейный мост `buzz-acp` размещает серверную часть идентификации Hermes или собственная платформа шлюза объединяет каналы Buzz с полной памятью/навыками/утверждениями/хроном Hermes. На обзорной странице сравниваются все три.

## Домашняя автоматизация

- **[Home Assistant](/user-guide/messaging/homeassistant)** — управляйте устройствами умного дома с помощью четырех специальных инструментов (`ha_list_entities`, `ha_get_state`, `ha_list_services`, `ha_call_service`). Набор инструментов Home Assistant активируется автоматически при настройке `HASS_TOKEN`.

## Плагины

- **[Система плагинов](/user-guide/features/plugins)** — Расширьте Hermes с помощью специальных инструментов, обработчиков жизненного цикла и команд CLI без изменения основного кода. Плагины обнаруживаются из `~/.hermes/plugins/`, локальных `.hermes/plugins/` проекта и точек входа, установленных в pip.
- **[Создать плагин](/developer-guide/plugins)** — Пошаговое руководство по созданию плагинов Hermes с помощью инструментов, перехватчиков и команд CLI.

## Обучение и оценка

- **[Пакетная обработка](/user-guide/features/batch-processing)** — запускайте агент параллельно с сотнями запросов, генерируя структурированные данные траектории в формате ShareGPT для создания или оценки обучающих данных.
