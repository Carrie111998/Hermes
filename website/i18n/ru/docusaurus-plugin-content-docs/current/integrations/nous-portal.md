# Портал Ноуса

[Nous Portal](https://portal.nousresearch.com) — это единый шлюз подписки Nous Research и **рекомендуемый способ запуска агента Hermes**. Один вход OAuth заменяет жонглирование отдельными учетными записями, ключами API и платежными отношениями для каждой лаборатории моделей, API поиска, генератора изображений и поставщика браузера, которые в противном случае вам пришлось бы подключать вручную.

Если у вас есть время настроить только одну вещь, установите это. Самый быстрый путь:

```bash
hermes setup --portal
```

Эта единственная команда запускает Portal OAuth, позволяет вам выбрать модель Nous, устанавливает Nous в качестве поставщика вывода в `config.yaml` и включает Tool Gateway. Вы готовы `hermes chat` сразу после этого.

У вас еще нет подписки? [portal.nousresearch.com/manage-subscription](https://portal.nousresearch.com/manage-subscription) — зарегистрируйтесь, затем вернитесь и выполните команду выше.

Под капотом портал направляет каждую модель на серверную часть, которая лучше всего для нее подходит — некоторые модели проходят через OpenRouter, другие — через проприетарных или вторичных поставщиков, и маршрутизация для данной модели может со временем меняться. В любом случае все счета оплачиваются по вашей подписке Nous. Переключайтесь между Claude Sonnet 4.6 для кода и Gemini 3 Pro для подробного контекста с помощью `/model` в середине сеанса — никаких новых учетных данных, никаких пополнений, никаких неожиданных ошибок нулевого баланса.

:::примечание
Поскольку маршрутизация осуществляется для каждой модели и не всегда через OpenRouter, расширения запросов, специфичные для OpenRouter (такие как настройки маршрутизации `provider`, липкая маршрутизация `session_id` или `cache_control` верхнего уровня), не являются частью контракта API портала и могут игнорироваться в зависимости от того, какой сервер обслуживает модель.
:::

### Шлюз инструментов Nous

Эта же подписка разблокирует [Tool Gateway](/user-guide/features/tool-gateway), который маршрутизирует вызовы инструментов агента Hermes через инфраструктуру, управляемую Nous. Пять бэкэндов, один логин:

| Инструмент | Партнер | Что он делает |
|------|---------|--------------|
| **Интернет-поиск и извлечение** | Огонь | Агентский поиск и полностраничное извлечение. Нет ключа API Firecrawl, нет ограничений по скорости присмотра за детьми. |
| **Создание изображений** | ФАЛ | Девять моделей под одной конечной точкой: FLUX 2 Klein 9B, FLUX 2 Pro, Z-Image Turbo, Nano Banana Pro (Gemini 3 Pro Image), GPT Image 1.5, GPT Image 2, Ideogram V3, Recraft V4 Pro, Qwen Image. |
| **Преобразование текста в речь** | OpenAI TTS | Качественный TTS без отдельного ключа OpenAI. Включает [голосовой режим](/user-guide/features/voice-mode) на платформах обмена сообщениями. |
| **Автоматизация облачного браузера** | Использование браузера | Сеансы Headless Chromium для `browser_navigate`, `browser_click`, `browser_type`, `browser_vision`. Учетная запись в базе браузера не требуется. |
| **Песочница облачного терминала** | Модальный | Бессерверные терминальные песочницы для выполнения кода (дополнительная надстройка). |

Без шлюза подключение каждого из них означает учетную запись Firecrawl, учетную запись FAL, учетную запись использования браузера, ключ OpenAI и модальную учетную запись — пять отдельных регистраций, пять отдельных панелей мониторинга, пять отдельных потоков пополнения счета. При использовании шлюза все данные направляются через одну подписку.

Вы также можете включить только определенные инструменты шлюза (например, веб-поиск, но не генерацию изображений) — см. [Совмещение шлюза с вашими собственными бэкэндами](#mixing-the-gateway-with-your-own-backends) ниже.

### В ваших точечных файлах нет учетных данных

Поскольку все проходит через один сеанс портала с аутентификацией OAuth, вы не накапливаете файл `.env` с дюжиной долгоживущих ключей API. Токен обновления по адресу `~/.hermes/auth.json` — это единственные учетные данные на диске, и Hermes создает из него кратковременные JWT для каждого запроса — см. [Обработка токена](#token-handling) ниже.

### Межплатформенный паритет

[Встроенная версия Windows](/user-guide/windows-native) делает настройку ключа API для каждого инструмента сложной задачей — установка учетной записи Firecrawl, учетной записи FAL, учетной записи использования браузера, ключа OpenAI из Windows — самая трудная часть получения полезного агента. Подписка на портал сглаживает эту ситуацию: один OAuth охватывает модель и каждый инструмент шлюза, поэтому пользователи Windows получают те же возможности, что и macOS/Linux, без ручной настройки четырех серверных частей.

## Заметка о Гермесе 4

Семейство **Hermes 4** (Hermes-4-70B, Hermes-4-405B) компании Nous Research доступно через портал по значительно сниженным ценам. Это **передовые модели чата с гибридным рассуждением** — сильны в математике, естественных науках, следовании инструкциям, соблюдении схемы, ролевых играх и написании длинных форм.

Однако их **не рекомендуется использовать внутри Hermes Agent**. «Гермес 4» настроен на общение и рассуждения, а не на быстрый цикл вызова инструментов, на который полагается агент. Используйте их для исследовательских рабочих процессов или через [прокси-сервер подписки](/user-guide/features/subscription-proxy) из других инструментов, но для работы агентов вместо этого выберите пограничную агентную модель из каталога:

```bash
/model anthropic/claude-sonnet-4.6     # best general-purpose agentic model
/model openai/gpt-5.5-pro              # strong reasoning + tool calling
/model google/gemini-3-pro-preview     # huge context window
/model deepseek/deepseek-v4-pro        # cost-effective coder
```

Собственная [страница с информацией о модели] Портала (https://portal.nousresearch.com/info) содержит такое же предупреждение, так что это не мнение компании Hermes, а официальное руководство Nous Research.

## Настройка

### Свежая установка — одна команда

```bash
hermes setup --portal
```

Это запускает полную настройку за один раз:

1. Открывает ваш браузер на порталеportal.nousresearch.com для входа в систему OAuth.
2. Сохраняет токен обновления по адресу `~/.hermes/auth.json`.
3. Позволяет выбрать модель Nous из курируемого списка (или пропустить, чтобы сохранить текущую).
4. Назначает Nous поставщиком логических выводов в `~/.hermes/config.yaml` (когда вы выбираете модель)
5. Включает инструментальный шлюз (веб, изображения, TTS, маршрутизация браузера).
6. Возвращает вас к терминалу, готовому к `hermes chat`.

Если у вас еще нет подписки, сначала зарегистрируйтесь на [portal.nousresearch.com/manage-subscription](https://portal.nousresearch.com/manage-subscription).

### Существующая установка — добавьте портал вместе с другими поставщиками

Если у вас уже настроен Hermes с OpenRouter, Anthropic или любым другим провайдером, и вы хотите добавить к ним портал:

```bash
hermes model
# pick "Nous Portal" from the provider list
# browser opens, sign in, done
```

Ваши существующие поставщики остаются настроенными. Вы можете переключаться между ними с помощью `/model` в середине сеанса или `hermes model` между сеансами — Портал станет одним из ваших доступных поставщиков, а не единственным.

### Безголовый / SSH / удаленная настройка

Для OAuth нужен браузер, но обратный вызов закольцовки выполняется на компьютере, на котором работает Hermes. Для удаленных хостов см. [OAuth через SSH/Удаленные хосты](/guides/oauth-over-ssh) — для Портала работают те же шаблоны, что и для любого другого провайдера на основе OAuth (переадресация портов `ssh -L`).

### Настройка профиля

Если вы используете [профили Hermes](/user-guide/profiles), токен обновления портала автоматически распределяется между всеми профилями через общее хранилище токенов. Войдите один раз в любой профиль, а остальные подберут его автоматически — нет необходимости повторять поток OAuth для каждого профиля.

## Ежедневное использование портала

### Проверка подключений

```bash
hermes portal            # log in to Nous Portal + set it up (one-shot onboarding)
hermes portal info       # login status, subscription info, model + gateway routing
hermes portal status     # alias for `portal info`
hermes portal tools      # detailed Tool Gateway catalog with per-tool routing
hermes portal open       # open the subscription management page in your browser
```

`hermes portal` (без подкоманды) — это удобочитаемый псевдоним для `hermes auth add nous --type oauth` — он выполняет вход в систему, позволяет выбрать модель Nous, устанавливает Nous в качестве поставщика вывода и предлагает подписку на Tool Gateway (идентично `hermes setup --portal`, и тот же поток Nous, что и при первой быстрой настройке).

`hermes portal info` дает вам общий обзор:

```
  Nous Portal
  ───────────
  Auth:    ✓ logged in
  Portal:  https://portal.nousresearch.com
  Model:   ✓ using Nous as inference provider

  Tool Gateway
  ────────────
  Web search & extract  via Nous Portal
  Image generation      via Nous Portal
  Text-to-speech        via Nous Portal
  Browser automation    via Nous Portal
  Cloud terminal        not configured
```

### Переключение моделей

Внутри сеанса:

```bash
/model anthropic/claude-sonnet-4.6
/model openai/gpt-5.5-pro
/model google/gemini-3-pro-preview
```

Или откройте сборщик:

```bash
/model
# arrow keys, enter to select
```

Вне сеанса (мастер полной настройки, полезный при добавлении нового провайдера):

```bash
hermes model
```

### Совмещение шлюза с собственными бэкэндами

Если у вас уже есть, скажем, учетная запись Browserbase и вы хотите продолжать использовать ее при маршрутизации веб-поиска и создании изображений через Nous, это поддерживается. Используйте `hermes tools`, чтобы выбрать серверные части для каждого инструмента:

```bash
hermes tools
# → Web search       → "Nous Subscription"
# → Image generation → "Nous Subscription"
# → Browser          → "Browserbase"  (your existing key)
# → TTS              → "Nous Subscription"
```

Tool Gateway предполагает подписку на каждый инструмент, а не по принципу «все или ничего». Управляемые серверные части отображаются в `hermes tools` независимо от того, вошли ли вы в Nous Portal или нет — если вы выберете «Nous Subscription» перед аутентификацией, Hermes запустит встроенный вход в портал (это не изменит вашего поставщика логических выводов и не затронет другие ваши инструменты). Полную матрицу конфигурации для каждого инструмента см. в [документации Tool Gateway](/user-guide/features/tool-gateway).

### Управление подпиской

Управляйте своим планом, просматривайте использование или обновляйте/отменяйте его в любое время:

- **Интернет:** [portal.nousresearch.com/manage-subscription](https://portal.nousresearch.com/manage-subscription)
- **Ярлык CLI:** `hermes portal open` (открывает ту же страницу в браузере по умолчанию)

## Справочник по конфигурации

После `hermes setup --portal` `~/.hermes/config.yaml` будет выглядеть так:

```yaml
model:
  provider: nous
  default: anthropic/claude-sonnet-4.6     # or whatever model you picked
  base_url: https://inference-api.nousresearch.com/v1
```

Настройки Tool Gateway находятся в соответствующих разделах инструментов — каждая категория имеет одну клавишу выбора, а выбор **Nous Subscription** в `hermes tools` (или `hermes setup --portal`) записывает значение `nous`:

```yaml
web:
  backend: nous          # web search/extract routes through Tool Gateway

image_gen:
  provider: nous

tts:
  provider: nous

browser:
  cloud_provider: nous
```

Среда выполнения всегда следует сохраненному выбору — прямые ключи API, оставшиеся в `.env`, игнорируются, пока для категории установлено значение `nous`, а выбор прямого поставщика (например, `image_gen.provider: fal`) без его ключа приводит к явной ошибке, а не к тихому перенаправлению через шлюз. (В более старых конфигурациях использовался устаревший флаг `use_gateway: true`; он читается как эквивалент `nous`, но больше не записывается.)

Токен обновления OAuth хранится отдельно по адресу `~/.hermes/auth.json` (не в `config.yaml` — учетные данные и конфигурация по замыслу хранятся отдельно).

## Обработка токенов

Hermes создает кратковременный JWT из вашего сохраненного токена обновления портала при каждом вызове вывода, а не повторно использует долгоживущий ключ API. Жизненный цикл токена полностью автоматический — обновление, выпуск, повторная попытка на временной ошибке 401 — и вы никогда этого не увидите.

Если Портал делает недействительным токен обновления (смена пароля, отзыв вручную, истечение срока действия сеанса), недействительный токен обновления помещается **локально в карантин**, поэтому Hermes прекращает его воспроизведение, и вы не видите поток идентичных ошибок 401. Следующий вызов выдает четкое сообщение «требуется повторная аутентификация». Запустите `hermes auth add nous`, чтобы снова войти в систему; Карантин очищается при следующем успешном входе в систему.

## Устранение неполадок

### `hermes portal info` показывает «не вошел в систему»

Вы не завершили поток OAuth, или ваш токен обновления был удален. Запустить:

```bash
hermes portal
```

или используйте `hermes model` и повторно выберите Nous Portal.

### В середине сеанса получено сообщение «требуется повторная аутентификация».

Ваш токен обновления портала был признан недействительным (смена пароля, отзыв вручную или истечение срока действия сеанса). Запустите `hermes auth add nous`, и ваш следующий запрос будет использовать новые учетные данные. Карантин старого токена автоматически очищается при успешном повторном входе в систему.

### Хотите использовать конкретную модель поставщика, которую Портал не предоставляет

Портал направляет каждую модель на подходящий бэкэнд — некоторые через OpenRouter, другие через проприетарных или вторичных поставщиков — поэтому большинство моделей, поддерживаемых OpenRouter, обычно доступны. Если конкретная модель не отображается в `/model`, попробуйте напрямую использовать пул в стиле OpenRouter:

```bash
/model anthropic/claude-opus-4.6
```

Если модель действительно отсутствует, [откройте проблему] (https://github.com/NousResearch/hermes-agent/issues) — мы предоставляем каталог Портала Гермесу, и пробелы обычно означают, что конфигурацию маршрутизации мы можем обновить.

### Счета не отображаются в моей учетной записи на портале

Сначала проверьте `hermes portal info` — если он показывает, что вы используете другого провайдера (`Model: currently openrouter` вместо `using Nous as inference provider`), ваша локальная конфигурация изменилась. Запустите `hermes model`, выберите Nous Portal, и следующий запрос будет направлен через вашу подписку.
