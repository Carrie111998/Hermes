# Глоссарий символов CLI

Интерфейсы терминалов Hermes говорят на компактном визуальном языке: точки, шевроны, счетчики Брайля и глифы статуса. Эта страница представляет собой кольцо декодера. Он охватывает [TUI](../user-guide/tui.md) (где большинство из них отображается) и отмечает фрагменты, общие с [Classic CLI](../user-guide/cli.md).

:::note Скины могут изменить стиль некоторых из них.
Глифы, отмеченные *themeable* ниже, являются стандартными для бренда — [скин](../user-guide/features/skins.md) может переопределить их (например, `tool_prefix` и символ подсказки). Все остальное исправляется в рендерере.
:::

## Символы транскрипта

Что вы видите в ходе разговора, пока агент работает.

| Символ | Значение |
|--------|---------|
| `❯` | Подсказка ввода — место ввода. *Тематическое* (скины имеют собственный символ подсказки). |
| `●` | Вызов инструмента. Маркер предшествует имени инструмента и его аргументам. |
| `┊` | Направляющая активности инструментов показана линиями инструментов. *Тематическое* (`tool_prefix`). |
| `✓` / `✗` | Результат инструмента: удалось/не удалось. Добавляется в конец завершенной линейки инструментов. |
| `▸` / `▾` | Свернут/развёрнут шеврон раздела (мышление, инструменты, субагенты, разделы баннеров). Нажмите, чтобы переключиться. |
| `▍` | Курсор потоковой передачи — мигает, пока модель все еще выдает текст. |
| `│` `├─` `└─` | Рельсы дерева — соединяют родительский элемент (делегацию, путешествие) с дочерними записями; `└─` отмечает последнего дочернего элемента. |
| `◈` | Событие временной шкалы, предназначенное только для отображения (встроенные уведомления о сеансе, а не сообщения пользователя). |
| `◇` | Введенный эталонный блок, например. `◇ Reference 1/2 — <label>`. |
| `↳` | Прикрепленное приглашение — отображает сообщение пользователя, над которым в данный момент работает агент. |
| `☐` / `☑` / `•` | Элементы списка задач Markdown (открыто/выполнено) и маркеры простого списка. |
| `▶` | Свернутая сводка `<details>` внутри отображаемой уценки. |

## Символы строки состояния

Единственная строка внизу TUI. Сегменты появляются только при необходимости и сначала исчезают на узких терминалах.

| Символ | Значение |
|--------|---------|
| `⠋⠙⠹…` (шрифты Брайля) | Занятый спиннер. На этапах мышления и инструментов используются разные наборы анимаций Брайля. |
| `⚕ 🌀 🤔 ✨ 🍵 🔮` | Кадры стиля индикатора занятости `emoji` (`/indicator emoji`). Вместо этого стиль по умолчанию вращает лица каомодзи. |
| <code>&#124; / - &#92;</code> | Кадры в стиле индикатора занятости `ascii`. |
| `⏱` | Время, прошедшее для каждого запроса во время выполнения очереди, например `⏱ 12s/3m 45s` (время поворота/время сеанса). |
| `⏲` | Тот же таймер, зависающий после завершения хода. |
| `cmp N` | Сеанс был автоматически сжат N раз. |
| `▶ N` | N `/background` задач, выполняемых в данный момент. |
| `⚠ YOLO` | Режим YOLO включен (автоподтверждение). Также отображается в баннере запуска. |
| `⛓ N` | N субагентов активны в данный момент. |
| `↩ resumes when subagent finishes` | Заверение проявляется, когда вы бездействуете, но делегированная работа все еще выполняется — результат возвращается сам по себе. |
| `● REC` | Голосовой режим записывает. |
| `◉ STT` | Запись голоса остановлена; речь в текст транскрибируется. |
| `◉ focus` | Просмотр фокуса включен (сниженная мощность). Закреплен таким образом, чтобы он никогда не выпадал из узкого терминала. |
| `♥` | Вспышка привязанности — Гермес заметил, что вы к нему добры. |
| `⚡` / `🔋` | Индикатор заряда батареи (опционально): подключен/включен аккумулятор, с процентами. |
| `N bg` | В этом сеансе отслеживается N фоновых терминальных процессов. |
| `N live sessions` | Откройте сеансы TUI в этом процессе — щелкните, чтобы открыть переключатель сеансов. |

## Уведомления

Кратковременные уведомления в строке состояния имеют собственный ведущий символ, заданный в зависимости от серьезности:

| Символ | Значение |
|--------|---------|
| `✓` | Уведомление об успехе. |
| `•` | Информационное уведомление. |
| `⚠` | Предупреждение (также используется для кредитных предупреждений). |
| `✕` | Уведомление об ошибке. |

## Запросы на одобрение и подтверждение

| Символ | Значение |
|--------|---------|
| `⚠ approval required` | Инструмент хочет запустить что-то, для чего требуется ваше явное «да» (панель с рамкой и предварительным просмотром команды). |
| `⚠` / `?` | Заголовок диалога подтверждения: опасное действие/обычный вопрос. |
| `🔐` | Запрос пароля Sudo (ввод замаскирован). |
| `🔑` | Запрос на ввод учетных данных/секрета (ввод замаскирован). |

## Наложение субагентов (`/agents`)

| Символ | Значение |
|--------|---------|
| `●` | Субагент работает. |
| `○` | В очереди. |
| `✓` | Завершенный. |
| `■` | Прервано. |
| `✗` | Неуспешный. |
| `⌛` | Время истекло. |
| `⚠` | Ошибка. |
| `⚡N` | N активных в данный момент агентов в сводной строке. |
| `▁▂▃▄▅▆▇█` | Спарклайн активности — количество недавних событий по ветке. |

## Переключатель сеансов (`Ctrl+X`)

| Символ | Значение |
|--------|---------|
| `✓` | Сессия простаивает. |
| `…` | Начало. |
| `?` | Ожидание ввода. |
| `▶` | Работающий. |
| `✎ draft` | Композитор в этом сеансе хранит неотправленный черновик. |

## Сборщики и хабы

| Символ | Значение |
|--------|---------|
| `▸` | Текущая строка выбора (выбор модели и друзья). |
| `*` | Действующая в данный момент модель/провайдер. |
| `●` / `○` | Поставщик аутентифицирован/не аутентифицирован (выбор модели); Резервное состояние плагина (концентратор плагинов). |
| `✓` / `✗` | Плагин включен/выключен (хаб плагинов). |
| `↑ N more` / `↓ N more` | Больше строк выше/ниже видимого окна списка. |
| `┃` | Большой палец полосы прокрутки на прокручиваемых наложениях. |

## Цели

Уведомления о жизненном цикле цели (из [goals](../user-guide/features/goals.md)) указывают на их состояние:

| Символ | Значение |
|--------|---------|
| `✓` | Цель достигнута. |
| `↻` | Цель достигнута — запланирована еще одна итерация. |
| `⏸` | Гол приостановлен. |
