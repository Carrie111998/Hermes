# Каталог моделей

Hermes извлекает тщательно подобранные списки моделей для **OpenRouter** и **Nous Portal** из манифеста JSON, размещенного рядом с сайтом документации. Это позволяет сопровождающим обновлять списки выбора без выпуска новой версии `hermes-agent`.

Когда манифест недоступен (автономно, сеть заблокирована, сбой хостинга), Hermes автоматически возвращается к снимку в репозитории, который поставляется с CLI. Манифест никогда не нарушает работу средства выбора — в худшем случае вы увидите список, включенный в установленную версию.

## URL-адрес живого манифеста

```
https://hermes-agent.nousresearch.com/docs/api/model-catalog.json
```

Публикуется при каждом слиянии с `main` через существующий конвейер `deploy-site.yml` GitHub Pages. Источник истины находится в репозитории по адресу `website/static/api/model-catalog.json`.

## Схема

```json
{
  "version": 1,
  "updated_at": "2026-04-25T22:00:00Z",
  "metadata": {},
  "providers": {
    "openrouter": {
      "metadata": {},
      "models": [
        {"id": "z-ai/glm-5.2",         "description": "default", "default": true},
        {"id": "moonshotai/kimi-k3",   "description": "recommended", "metadata": {}},
        {"id": "openai/gpt-5.4",       "description": ""}
      ]
    },
    "nous": {
      "metadata": {},
      "models": [
        {"id": "z-ai/glm-5.2", "default": true},
        {"id": "anthropic/claude-opus-4.7"},
        {"id": "moonshotai/kimi-k3"}
      ]
    }
  }
}
```

Полевые примечания:

- **`version`** — версия целочисленной схемы. Будущие схемы сталкиваются с этим; Hermes отказывается от манифестов с версиями, которые он не понимает, и возвращается к жестко запрограммированному снимку.
- **`metadata`** — словарь в свободной форме на уровне манифеста, поставщика и модели. Любые ключи. Hermes игнорирует неизвестные поля, поэтому вы можете комментировать записи (`"tier": "paid"`, `"tags": [...]` и т. д.) без согласования изменения схемы.
- **`description`** — только для OpenRouter. Текст значка средства выбора дисков (`"recommended"`, `"free"`, `"default"` или пустой). Nous Portal не использует это — уровень бесплатного доступа определяется в реальном времени на основе конечной точки ценообразования портала.
- **`default`** — ровно одна запись от каждого поставщика может содержать `"default": true`. Эта модель является **тихой по умолчанию**: то, что получает Hermes, когда пользователь никогда не выбирал модель (карта подтверждения подключения графического интерфейса, `provider` настроен без `model`, пустой `model.default`). Только чтение кэша во время выполнения (`get_default_model_from_cache`), поэтому пути горячего разрешения никогда не попадают в сеть; когда кэшированного манифеста не существует, Hermes возвращается к константе `PREFERRED_SILENT_DEFAULT_MODEL` в репозитории, которая должна соответствовать помеченной записи. Это позволяет сопровождающим менять тихое значение по умолчанию без выпуска релиза. Это намеренно мощная недорогая модель, а не самый дорогой флагман.
– **Цены и длина контекста** НЕ указаны в манифесте. Они поступают из API-интерфейсов действующего поставщика (конечные точки `/v1/models`, models.dev) во время выборки.

## Получение поведения

| Когда | Что происходит |
|---|---|
| `/model` или `hermes model` | Выполняется, если дисковый кеш устарел, в противном случае используется кеш |
| Дисковый кэш свежий (&lt; TTL) | Нет попадания в сеть |
| Сбой сети с кешем | Тихий возврат к кэшу, одна строка журнала |
| Сбой сети, нет кэша | Тихий возврат к моментальному снимку в репозитории |
| Манифест не проходит проверку схемы | Рассматривается как недостижимый |

Местоположение тайника: `~/.hermes/cache/model_catalog.json`.

## Конфигурация

```yaml
model_catalog:
  enabled: true
  url: https://hermes-agent.nousresearch.com/docs/api/model-catalog.json
  ttl_hours: 1
  providers: {}
```

Установите `enabled: false`, чтобы полностью отключить удаленную выборку и всегда использовать моментальный снимок в репозитории.

### URL-адреса переопределения для каждого поставщика

Третьи лица могут самостоятельно размещать свой собственный список кураторов, используя ту же схему. Укажите поставщику пользовательский URL-адрес:

```yaml
model_catalog:
  providers:
    openrouter:
      url: https://example.com/my-openrouter-curation.json
```

Переопределяющему манифесту необходимо заполнить только те блоки провайдера, которые ему интересны. Другие поставщики продолжают разрешать запросы по основному URL-адресу.

### Скрытие поставщиков из средства выбора

`excluded_providers` позволяет скрыть определенных поставщиков из средства выбора `/model`, даже если существуют действительные учетные данные. Полезно, когда присутствуют учетные данные для устаревших или тестовых поставщиков, которые не должны появляться при обычном использовании (например, старый токен Copilot или OpenRouter, все еще кэшированный в `auth.json` или обнаруженный через `gh` CLI).

```yaml
model_catalog:
  excluded_providers:
    - copilot
    - openrouter
    - openai
```

Исключение сопоставляется без учета регистра с каждым ключом, под которым может появиться поставщик — идентификатором Hermes и идентификатором models.dev (встроенные сопоставленные поставщики), идентификатором наложения pid и разрешенным пулом Hermes (поставщики наложения) и каноническим пулом (канонические поставщики) — поэтому одна запись, такая как `copilot`, скрывает поставщика независимо от того, какой раздел его создает. Его поддерживают все поверхности выбора `/model`: средства выбора интерактивных/текстовых сообщений шлюза, средство выбора TUI и интерактивное средство выбора `hermes model` CLI. Пустой список (или отсутствие ключа) не имеет никакого эффекта.

## Обновление манифеста

Сопровождающие:

```bash
# Re-generate from the in-repo hardcoded lists (keeps manifest in sync after
# editing OPENROUTER_MODELS or _PROVIDER_MODELS["nous"] in hermes_cli/models.py).
python scripts/build_model_catalog.py
```

Затем PR полученное изменение с `website/static/api/model-catalog.json` на `main`. Сайт документации автоматически развертывается при слиянии, и новый манифест становится доступным в течение нескольких минут.

Вы также можете вручную редактировать JSON напрямую для детальных изменений метаданных, которые не входят в снимок в репозитории — сценарий генератора — это удобство, а не единственный источник истины.
