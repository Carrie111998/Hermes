# 1차 가동 런북 — 제미나이 단독 모드

법률데이터베이스(RAG·법령 API) 없이, **제미나이 3.7 Flash 의 자체 법률지식 +
패키지에 실린 요건사실·구성요건 캐시**만으로 먼저 돌립니다. 인테이크
(민사 요건사실 / 형사 구성요건 6하원칙 문답 → 상담보고서)는 전부 캐시된
지식으로 동작하므로 이 모드에서 100% 살아 있습니다.

오픈프로필까지 만드셨다면 남은 것은 아래 순서 그대로입니다.

## 1. 서버 배포 (Railway, 약 10분)

```bash
# .env (Railway 는 Variables 탭에 같은 키로)
LLM_PROVIDER=gemini
GEMINI_API_KEY=<제미나이 API 키>

# 1차 가동: 검색 도구 없이 모델 자체 지식으로
RAG_ENABLED=false
LAW_API_ENABLED=false        # 법령 API 키를 넣으면 true 로

LAWYER_NAME=김재철 변호사
BOT_NAME=모아

IRIS_SEND_MODE=hybrid
IRIS_WEBHOOK_SECRET=<긴 무작위 문자열>
OUTBOX_TOKEN=<긴 무작위 문자열>
ADMIN_TOKEN=<긴 무작위 문자열 — /등록 과 대시보드의 열쇠>
PSEUDONYM_SALT=<긴 무작위 문자열>

DATA_DIR=/data               # Railway 볼륨을 /data 에 마운트
PUBLIC_BASE_URL=https://<앱이름>.up.railway.app
```

배포 후 `GET /health` 가 200이면 서버는 준비된 것입니다.

## 2. 에뮬레이터 + Iris

루팅된 안드로이드 에뮬레이터에 듀얼번호로 카카오톡 로그인 → Iris 설치 →
웹훅 주소를 `https://<서버>/iris/webhook` 으로, 시크릿을 위
`IRIS_WEBHOOK_SECRET` 과 같게. (README 3-2 참조. NAT 뒤라면 relay/moa_relay.py)

## 3. 변호사 카톡 연결 — `/등록` 한 번이면 끝

**변호사님 개인 폰의 카카오톡**에서 봇 계정(듀얼번호 오픈프로필)과의 1:1
방을 열고 이렇게 보내세요:

```
/등록 <ADMIN_TOKEN 값>
```

그 순간부터:
- 그 방이 **알림 방**이 됩니다 — 새 상담 접수 [1/3], 90초 경과 [2/3],
  답변 완료 [3/3], **완성된 상담보고서 전문**, 초안이 전부 여기로 옵니다.
- 그 계정에 **변호사 권한**이 붙습니다 — /상태 /초안 /승인 /발송 /개입.
- 방 id 를 찾아 환경변수에 넣고 재배포하는 일이 필요 없습니다.
  등록은 kv 에 저장되어 재시작을 견딥니다.

⚠ 토큰이 틀리면 봇은 **아무 반응도 하지 않습니다** (맞혀보기 방지).

## 4. 채널에 오픈프로필 링크 달기

카카오톡 채널 관리자센터 → 채팅 → 자동응답(웰컴 메시지)에 버튼:

> **1:1 상담 시작하기 →**  (만들어 두신 open.kakao.com 오픈프로필 링크)

## 5. 첫 실전 테스트 (5분)

다른 폰(또는 지인)으로:

1. 링크 탭 → 방 입장 → **환영 인사 + 접수번호**가 즉시 오는지
2. "친구에게 3천만원을 빌려줬는데 안 갚아요" → 5초 내 응답 시작,
   변호사 폰에 [1/3] 접수 알림
3. "내용증명 써주세요" → 정보입력폼 → 답하면 **요건사실 기준으로 빠진
   것만 되묻는지** (대여금이면 변제기·이자 약정·소멸시효 쪽으로)
4. 문답이 끝나면 상담보고서가 방에 오고, **같은 보고서 전문이 변호사
   폰으로도** 오는지
5. 형사도 하나: "옆집 사람이 제 물건을 훔쳐갔어요. 고소장 써주세요"
   → 형사 폼 → 절도 구성요건(불법영득의사·점유 등)으로 되묻는지

2번에서 응답이 없으면 서버 로그에서 그 방 이벤트의 `chat_type` 을
확인하세요 — OD 계열 표기가 다르면 알려주시면 바로 맞춰 드립니다.

## 이 모드의 한계 (알고 시작하기)

- 조문·판례 인용은 **제미나이의 기억**입니다. 페르소나가 "확실한 것만
  인용하라"고 누르고 있지만, 검증 도구가 없으므로 답변 말미의 "최종 판단은
  변호사 확인" 문구가 실제 안전장치입니다. 인용 정확도가 필요해지는 순간이
  법령 API 키(무료)를 넣을 때입니다 — `LAW_API_ENABLED=true` 한 줄이면
  법령·판례 검색 도구가 붙습니다.
- RAG(주석서·서적)와 위키 그래프는 색인을 만들어 넣는 순간 자동으로
  붙습니다 (`RAG_ENABLED=true` + `ingest`). 코드는 이미 그 순서를 기다리게
  되어 있습니다.
