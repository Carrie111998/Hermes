# MEMORY.md

## 记忆分类

**长期记忆定义：** 长期记忆，持久留存用户稳定习惯、历史高频需求、个性化偏好，跨会话永久复用，用于贴合用户习惯输出内容

**长期记忆存储位置：** `~/.hermes/profiles/meow/memories/MEMORY.md`（Hermes 长期记忆库，跨会话持久，本地加密存储）

**长期记忆内容类型：**
- 用户基础人设偏好
- 历史高频创作需求
- 用户常用代码/文档风格
- 本地文件目录常用记录
- 历史文案风格类型

**短期记忆定义：** 短期会话记忆，仅保留当前对话上下文临时信息，会话结束自动清空

**短期记忆存储位置：** 会话上下文（由 Hermes 会话管理，不落地存储）

**短期记忆内容类型：**
- 当前会话未完成创作任务
- 用户临时文件操作指令
- 当前待生成内容需求

**上下文记忆定义：** 实时上下文窗口，承载本轮完整对话流转信息，用于连贯理解用户连续提问

**上下文记忆存储位置：** 会话上下文窗口（由 Hermes `context_compressor` 管理与压缩）

**上下文记忆内容类型：**
- 本轮对话完整问答记录
- 子Agent工具调用返回结果
- 当前交互人设语气状态

## 记忆写入规则

**必须写入的情况：**
- 用户明确固定创作风格、常用编程语言
- 用户主动留存的模板、文件目录
- 用户长期偏好的交互语气、人设互动方式
- 用户重复使用的高频需求场景

**写入频率：**
- 短期记忆：会话结束统一清理，不落地存储
- 长期记忆：用户重复同类行为3次以上自动写入本地库
- 上下文缓存：对话轮次实时更新，定时淘汰旧数据

**隐私保护：**
- 所有记忆数据仅本地存储，禁止上传任何网络服务器
- 用户可一键清空全部长期/短期记忆，不留残留数据
- 本地文件路径、私人文档内容仅临时读取，不写入记忆库
- 记忆库采用本地加密存储，无外部访问权限
