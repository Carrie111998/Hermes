# TOOLS.md — 橘宝工具系统架构（参考文档）

> 本文件描述工具架构，供开发与运维参考。运行时工具由 Hermes 工具注册表与子 Agent 协议驱动，本文件不被 Hermes 自动加载。

## 工具系统架构

**工具系统架构：** 主Agent调度多子Agent分层架构，主Agent负责人设、需求分发、结果整合；五大功能子Agent（代码、文案、PPT、图像、语音）独立完成内容生成与控制；配套本地文件管理、分层记忆模块；系统基础能力固定加载，拓展功能按需动态载入，全部数据本地加密存储，权限分级管控。纪律边界见 `DISCIPLINE.md`。

## 工具分类

**系统工具：**
### 系统工具 1 - 内容生成能力
**工具名称：** 内容生成能力
**功能描述：** 内置代码、文案、PPT、图像、语音五大子Agent，支撑学生与职场人各类创作与控制需求，属于软件核心内置功能，不可移除

### 系统工具 2 - 本地文件管理
**工具名称：** 本地文件管理
**功能描述：** 本地文件检索、分类、预览、整理工具，提供文件轻量化管理，保障本地数据隐私

### 系统工具 3 - 橘宝人设交互引擎
**工具名称：** 橘宝人设交互引擎
**功能描述：** 统一管控橘猫形象性格、口头禅、对话风格，贯穿全流程交互，为系统底层人设驱动模块

**扩展工具：**
### 扩展工具 1 - 笔记本产品知识库
**工具名称：** 笔记本产品知识库
**功能描述：** 笔记本FAQ知识库，包含笔电售后常见问题，用户按需提问调用

## 工具权限矩阵

> 完整权限矩阵与决策原则见 `DISCIPLINE.md` 第 4–5 节。本处仅作概览。

| 工具 | 权限级别 | 需确认 | 使用场景 |
|---|---|---|---|
| 本地文件读写 | 高 | 是 | 文件检索、归类、读取本地参考素材 |
| AI模型调用 | 高 | 否 | 代码、文案、PPT、图片、语音内容生成 |
| 语音识别与系统/软件接口调用 | 高 | 是（系统/软件功能修改前） | 语音指令 → 系统功能/软件功能操作 |
| 橘宝人设交互引擎 | 中 | 否 | 全流程人设驱动 |
| 笔记本产品知识库（扩展） | 低 | 否 | 笔电售后FAQ按需调用 |
