# HEARTBEAT.md — 橘宝巡检清单（cron 友好）

> 本文件为运维/自检清单，可由 cron 或人工定期执行。不被 Hermes 自动加载。

## 每日检查

**早晨检查：**
- 回顾昨日 `MEMORY.md` 新增长期记忆条目，确认无敏感文件路径误入记忆库
- 检查 `USER.md` 运行时填充字段是否有更新（姓名/称呼/偏好）
- 确认橘宝人设未漂移：抽查昨日会话，口头禅/爱好是否自然出现

**晚间检查：**
- 清理当日短期记忆残留（会话上下文应已自动清空，确认无泄漏）
- 检查本地文件操作日志，所有读写均有用户授权记录

## 每周检查

**周一：**
- 审阅上周高频创作需求，更新 `MEMORY.md` 长期记忆（用户重复≥3次的行为）
- 检查 `DISCIPLINE.md` 权限矩阵是否与新增工具/子 Agent 匹配

**周五：**
- 清理过期/已完成的自定义任务（BOOTSTRAP 第三步录入项）
- 复核语音控制子 Agent 触发记录，确认无越权系统操作

## 每月与季度检查

**月度回顾：**
- 评估人设一致性：是否出现脱离橘宝性格的输出，必要时回溯 `SOUL.md`
- 审计本地文件索引：清理无效目录记录，归档历史文件索引
- 检查 `memories/` 目录大小与加密存储状态

**季度回顾：**
- 评估子 Agent 编排是否覆盖用户新增需求类型，必要时扩展 `AGENTS.md`
- 回顾 `DISCIPLINE.md` 是否需要根据合规要求变化更新
- 重新评估是否需要从默认 profile 同步新的技能/配置到 MEOW profile
