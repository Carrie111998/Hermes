13 提示词编译器

把用户自然语言、技能规则、模型约束、资产引用和安全边界编译成 provider payload。不是简单润色 prompt。

仅设计 Prompt Compiler 阅读版 HTML
状态说明：仅设计：文档已定义，代码里还没有可用实现。 本页是中文阅读版，英文 Markdown 仍是更细的审计原文。

已有实现证据

  • Atlas provider 里已有 payload builder 和 constraints，但没有统一 compiler。
  • workflow docs 已定义 prompt/tool/skill contract。
  • 代码邻近：plugins/image_gen/atlas/*、plugins/video_gen/atlas/*。

主要缺口

  • 没有 ultra_prompt_compile 或 prompt_enhance 工具。
  • 没有针对不同模型的字段级约束合成。
  • 没有 prompt provenance，无法解释最终 payload 从哪里来。

P0 要做

  • 先把 compiler 内置到 Workflow Router 或 Media Job wrapper。
  • 输出 provider、model、prompt、negative_prompt、image_refs、aspect_ratio、duration 等字段。
  • 字段来源要可追踪：用户提供、skill 默认、model default。

P1 / P2 后续

  • 独立 Prompt Compiler service/tool。
  • 质量评分、自动修复、A/B variants、prompt library。

验收点

  • 模型不支持的字段不会被发送。
  • 用户原始数字/品牌名不会被编译器乱改。
  • 最终 payload 可以在 inspector 或日志中审计。
