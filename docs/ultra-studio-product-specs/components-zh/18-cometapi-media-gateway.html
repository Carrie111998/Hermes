18 CometAPI 媒体网关

处理长视频、外部社媒 URL、抽帧、转码、音频/字幕提取、多模态打包。它是媒体数据面，不是 TokenRouter。

仅设计 CometAPI Media Gateway 阅读版 HTML
状态说明：仅设计：文档已定义，代码里还没有可用实现。 本页是中文阅读版，英文 Markdown 仍是更细的审计原文。

已有实现证据

  • CometAPI 文档明确说不是 MVP 默认能力。
  • 代码里没有 cometapi/comet source hits。
  • 邻近实现只有上传、小文件处理、vision/transcription tools。

主要缺口

  • 没有 resolver、preprocess、packaging、cache、video_analyze/audio_analyze 工具。
  • 没有和 TokenRouter 的 delegated token 与 usage signal 集成。
  • MVP 的 simple worker path 也还没做。

P0 要做

  • 不把 CometAPI 放进第一版生成链路。
  • 如果用户上传普通图片/短视频，走普通 upload + Media Job。
  • 外部长视频分析请求要明确提示未接入，或走后续 video_analyze contract。

P1 / P2 后续

  • YouTube/TikTok/Instagram resolver、窗口化分析、抽帧缓存、转写对齐。
  • 大媒体计费、缓存权限、模型原生多模态 payload。

验收点

  • 30 分钟视频不会被整段塞进 prompt。
  • 失败 fallback 标明是 text-only 还是缺帧。
  • 数据面和凭证控制面职责不混淆。
