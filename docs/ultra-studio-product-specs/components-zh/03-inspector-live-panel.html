03 右侧检查器 / 实时面板

右侧面板显示当前 job、选中资产、QA、下载、重试、转 Element、建角色。它不是第二个聊天窗口。

部分实现 Inspector / Live Panel 阅读版 HTML
状态说明：部分实现：有真实底座，但产品合同还没完整接上。 本页是中文阅读版，英文 Markdown 仍是更细的审计原文。

已有实现证据

  • 已有 session card、connection badge、model/session id、工具调用 feed、pending input prompts。
  • 已有 image/video 同步工具和 Atlas provider 插件，但不是 durable job。
  • 代码证据：web/src/components/chat/ChatInspector.tsx、ToolCall.tsx、PendingPromptPanel.tsx、useGatewayChat.ts。

主要缺口

  • 没有 selected job/asset/tool run 的选择模型。
  • 没有资产预览、prompt/seed/dimension/duration/lineage、QA 面板、下载和导出。
  • 移动端隐藏 inspector 时，pending prompt 的可达性需要重新设计。

P0 要做

  • 显示当前 media job 状态、provider/model、输入约束和错误。
  • 选中生成资产后显示预览、下载链接、原 prompt、输入来源。
  • 失败时给 retry/repair plan，而不是只显示通用错误字符串。

P1 / P2 后续

  • Create Character、Convert to Element、QA score、provenance ledger drilldown。
  • 移动端底部抽屉版 inspector。

验收点

  • 用户点击一张生成图，右侧出现该图的真实元数据。
  • 下载按钮使用真实 asset URL 或本地文件路径。
  • 失败 job 可以从 inspector 找到原因和下一步。
