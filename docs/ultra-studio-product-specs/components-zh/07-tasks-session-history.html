07 任务 / 会话历史

左侧任务列表和历史恢复能力，用户可以回到某次创作，看到 transcript、工具、文件、资产和结果。

部分实现 Tasks / Session History 阅读版 HTML
状态说明：部分实现：有真实底座，但产品合同还没完整接上。 本页是中文阅读版，英文 Markdown 仍是更细的审计原文。

已有实现证据

  • 已有 SessionStore、FTS5 search、Sessions 页面和 resume in chat。
  • 已有会话标题、消息数、平台来源等基础信息。
  • 代码证据：hermes_state.py、web/src/pages/SessionsPage.tsx、web/src/lib/api.ts。

主要缺口

  • Tasks row 还不是创作任务模型，只是 session history。
  • 没有 job/output count、active media job、任务文件、skill profile 的恢复。
  • 没有 task lifecycle：running、waiting、failed、complete。

P0 要做

  • 保留 session list 和 resume chat。
  • 新增任务行时只显示真实 session/job 数据。
  • 生成完成的图片/视频能从历史会话重新打开。

P1 / P2 后续

  • 任务状态、运行中任务恢复、跨任务搜索、收藏和归档。
  • 按项目/客户/品牌组织任务。

验收点

  • 刷新浏览器后历史列表还在。
  • 点历史任务能恢复对话内容。
  • 生成结果不会只存在于当前 React 内存。
