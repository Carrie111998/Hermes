09 资产服务

资产库的后端实体和 API，负责 media_assets、lineage、下载、索引、collections、characters。

仅设计 Asset Service 阅读版 HTML
状态说明：仅设计：文档已定义，代码里还没有可用实现。 本页是中文阅读版，英文 Markdown 仍是更细的审计原文。

已有实现证据

  • 设计文档定义了资产、上下文、关系元数据和阶段路线。
  • 目前没有独立 asset service、entities、API 或索引实现。
  • 现有生成工具只返回 URL/文本，不能替代资产服务。

主要缺口

  • 没有 media_assets 表或等价持久模型。
  • 没有 asset_id、source_job_id、input_refs、lineage、ACL、download API。
  • 没有 collections/smart_groups/characters 的真实存储。

P0 要做

  • 建最小 media_assets 持久模型：id、type、url/path、provider、model、prompt、created_at、source_job_id。
  • 提供 list/detail/download 三个 API。
  • Media Job 成功后必须写 asset.ready。

P1 / P2 后续

  • 语义索引、相似搜索、collections、smart_groups、characters、元素库。
  • 权限、审计、清理、外部对象存储生命周期。

验收点

  • 生成成功但 asset 写入失败时不能说任务完成。
  • asset_id 可以反查 job、prompt、输入素材。
  • 删除或权限不足返回 typed error。
