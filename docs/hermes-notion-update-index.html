拆分原则
references/ 是 Hermes 认知层；TokenRouter 是控制面；CometAPI 是媒体数据面；Soul ID/Element 是资产模型；工具 schema 是接口合约。它们互相关联，但不应该写成一个文档。

专题文档

Hermes references 知识模型

Skill 内部 references、用户附件、生成资产引用三者拆分。

定义 System Prompt、SKILL.md、references/ 的热/温/冷知识层和导出保护。

TokenRouter 零信任凭证流

控制面、JWT、quota、vault key exchange。

定义 sandbox blind-state、四阶段凭证交换、策略输入和验收检查。

CometAPI 媒体数据面网关

媒体数据面，暂不作为 MVP 默认服务。

覆盖外部媒体解析、裁剪、抽帧、音频/字幕对齐和多模态 payload。

Soul ID 与 Element 资产模型

持久化语义资产模型。

定义 soul_id、element、media_input、image_job/video_job 和本地数据模型。

Soul ID 复现与测试计划

实验计划，不是生产事实。

记录模型探测、开源复现路径和评估指标，避免把猜测写进生产架构。

Notion 工具合约映射

default_api 工具清单和本地映射。

聚焦 ask_user_question、media_generate、identity_reference、asset_reference 等 MVP 工具。
