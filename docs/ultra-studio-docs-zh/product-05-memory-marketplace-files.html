这份文档解决什么

Inspector 是当前对象面板，这些页面是长期工作区。它们让资产、技能、文件、记忆和任务可浏览、可恢复、可审计。

P0 相关结论

  • Marketplace 第一版可以是本地 catalog 或空态，不能假装远程市场存在。
  • Memory 必须可见、可删、可追溯来源。
  • Files 区分上传原件、任务文件、生成 artifact 和可复用 asset。
