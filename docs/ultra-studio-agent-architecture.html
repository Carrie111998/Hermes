Current Whole-Agent Architecture

Ultra Studio Agent 总体架构图

这张图描述当前 Hermes fork 的目标形态：一个 Atlas-first 创作型 Agent。它把聊天 UI、Edge/Gateway、Sandbox VM、Hermes runtime、Skill、Prompt 编译、TokenRouter 控制面、CometAPI 媒体数据面、GPU worker、资产库和 Atlas provider 分开看。

日期：2026-06-10 完整调研附录 范围：Web Chat + Sandbox + TokenRouter + CometAPI + Skill + Media + Asset Library 原则：真实工具、真实资产、真实错误，不做 fake demo
绿色：已有代码 / 已落地 黄色：已有文档或原型，待接入 runtime 红色：P0/P1 缺口，需要实现 蓝色：外部服务 / provider 边界
读图方式：Notion/Lark 主链路不是“一个前端调模型”。用户先进入 Web/Edge 实时会话，后端挂接 Sandbox 并注入短期 HF_JWT_TOKEN；Agent 在沙箱里跑推理-工具循环；TokenRouter 处理控制面、JWT、quota、vault key exchange 和审计；CometAPI 处理视频/音频/图像的媒体数据面；生成结果进入资产库。

2. 一次生成请求的时序图

Notion 原始主链路：Browser/Web App 建立 SSE 或 WebSocket；Edge Gateway 解析 JWT 与 workspace；Backend Orchestrator 挂接 Sandbox；Volume Mounter 挂载用户数据和项目上下文；Sandbox 注入 HF_JWT_TOKEN；Hermes Agent 调默认工具和 Skill；TokenRouter 做四阶段零信任凭证流；异步生成进 Event Bus/GPU workers；CometAPI 只负责媒体数据面，不替代 TokenRouter。

3. 双网关与沙箱边界

组件负责什么不能做什么文档依据
Sandbox VM运行 Agent、terminal/process、临时 RootFS、workspace/project 挂载、短期 HF_JWT_TOKEN。不能持有真实 provider key；不能直接访问其他用户文件、metadata service 或 protected skill references。Lark 架构页 4.2/4.3；Notion TokenRouter TOKEN 注入。
TokenRouter控制面：JWT 校验、claims 提取、Redis quota/Boost 并发、Vault key exchange、负载均衡、安全门禁、计量审计。不传输大型二进制媒体；不把真实 key 暴露给 sandbox；cloud mode 不允许本地 key fallback。docs/notion-source/hermes/pages/06-tokenrouter.md
CometAPI媒体数据面：外部 URL 抓取、视频剪切、FPS 抽帧、分辨率降采样、音频/字幕/帧序列对齐、多模态 token packaging。不做通用凭证控制面；不替代 quota/billing/key exchange；失败要暴露给 Agent/UI。docs/notion-source/hermes/pages/07-cometapi.md
Async Event Bus / GPU Workers承接 higgsfield_generate async=true、job status、GPU 重任务、thumbnail/asset registration。不阻塞 Agent 会话；不绕过 TokenRouter 的 quota 和 audit。Lark 架构页端到端阶段 9-11。

4. 资产库与 Reference 模型

三类 reference 必须分开

  • Skill 内部 references：skills/<skill>/references/*，是受保护冷层知识，不给普通用户导出。
  • 用户上传 references：图片、视频、音频、PDF，进入 media_input。
  • 媒体生成 references：image_job、video_job、element、character、soul_id，用于后续生成。

Collection 和 Smart Group

  • Collection：手动维护的静态资产成员表。
  • Smart Group：保存查询规则，打开时实时查符合条件的资产。
  • Character：一级资产，不是普通 group，因为它要参与生成控制。
