# 模块研究

每个模块文档使用 [`../templates/MODULE-TEMPLATE.md`](../templates/MODULE-TEMPLATE.md)，并至少覆盖职责、状态、正常路径、失败恢复、不变量、扩展点、生产代码、测试和设计历史。

计划模块：Agent Loop、Prompt/Context/Cache、Provider/Transport、Tool Runtime、Memory、Session、Skills、Background Review、Curator、Delegation、Code Execution、Cron/Kanban、Gateway、Plugins 和 UI Surfaces。
