## 关键修正

- 共享 Agent Core 是代码内核复用，不是中央 Agent 服务。
- Dashboard 当前 profile 的 PTY TUI 会 attach 到 FastAPI 进程内 `/api/ws`；显式 profile chat 才需要独立 `tui_gateway.entry`。
- Desktop 使用 headless `hermes serve`，不是 Dashboard SPA，也不是 Ink TUI。
- API Server 是 Gateway platform adapter，不应与 Dashboard/serve API 混为一谈。
- Cron 默认由 Gateway 或 Desktop backend 内的 scheduler provider 触发，不是独立 daemon。
- compute-host 由 `dashboard.turn_isolation` 门控且默认关闭。
