## 关键判断

- Hermes 工具回合是 recovery-oriented mini transaction，不只是 `function call -> return string`。
- SessionDB 在工具边界承担轻量 write-ahead record：durable intent 先于 effect，durable observation 先于 further inference。
- UI progress 是 canonical state 的下游 projection；intent/result 明确落库失败时不应继续投影。
- 并发仅优化可证明安全的连续区段，不改变 transcript 的 emission order。
- Approval 是多层 gate；`tool.started` 不能被解释为所有 handler-native 审批已经完成。
