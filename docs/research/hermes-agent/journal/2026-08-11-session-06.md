## 关键判断

- Hermes 是共享 library kernel + 多种 surface orchestration，不是中央 Agent daemon。
- Agent reuse 同时保护性能和 prompt semantics；重建与错误复用都可能破坏正确性。
- `response_previewed`、`response_transformed`、delivery flags 与 `already_sent` 分属不同层，不能合并成一个布尔值。
- TUI/Desktop backend 用 authoritative terminal frame解决客户端 settle；消息 Gateway 面对真实平台 send/edit 失败，需要更复杂的 delivery reconciliation。
