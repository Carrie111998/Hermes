## 关键判断

- 文件拆分没有把 Agent 变成多个服务；阶段模块仍通过 `agent` attributes 共享 live state。
- Tool Runtime 的窄腰是 `model_tools → registry → handlers/backends`。
- `api_content` 是 prompt-cache stability 与 API 输入可审计性的连接点。
- SessionDB 同时承担恢复、provider replay、compression lineage 和跨进程 cache invalidation 协议。
- Memory/Skill 写入是 durable feedback，不应隐式改变当前 session 已缓存 prompt。
