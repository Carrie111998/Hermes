## 关键判断

- Classic CLI 的并发外壳服务于 UI 响应和 interrupt；Agent loop 本身仍是同步状态机。
- staged user dict 是 CLI surface 与 Agent persistence 的交接协议，不是重复的 canonical history。
- turn-start persistence 是 best-effort crash resilience；tool intent persistence 才是副作用前的 hard gate。
- canonical transcript、Provider wire projection 和最终 delivery projection 是三个不同的正确性对象。
- “最终响应已持久化”应解释为 canonical core response 可恢复，而不是每个展示 footer/插件变换都逐字回写。
