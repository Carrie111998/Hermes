04 技能市场

面向 Ultra Studio 的技能、模板、工作流和连接器目录。第一版可以是空态，但不能伪造市场数据。

仅设计 Marketplace 阅读版 HTML
状态说明：仅设计：文档已定义，代码里还没有可用实现。 本页是中文阅读版，英文 Markdown 仍是更细的审计原文。

已有实现证据

  • 已有 skill install/enable/discovery 基础能力，可作为 Marketplace 底座。
  • 已有插件 manifest 和 skill registry 相关代码，但没有市场页面。
  • 代码证据主要在 skill 管理、插件加载和 Hermes CLI 相关模块。

主要缺口

  • 没有 catalog API、搜索、分类、详情页、安装状态和发布流程。
  • 没有和 Ultra allowlist profile 的关系定义。
  • 没有权限、审核、版本兼容和撤回机制。

P0 要做

  • 左侧 Marketplace 入口可打开一个真实空态或本地 installed skills 列表。
  • 不要展示未安装的假技能卡。
  • 技能状态要区分 installed、enabled、blocked、missing requirements。

P1 / P2 后续

  • 远程 catalog、评分、版本、安装沙箱、审核队列、团队共享。
  • 技能包和 tool/prompt/schema 的兼容性检查。

验收点

  • 没有 catalog 后端时页面明确显示“未接入”，不是空白。
  • 本地已安装 creative skills 可以被列出并跳转查看。
  • 禁用技能不会被 agent router 误用。
