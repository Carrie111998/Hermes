颜色和状态

绿色：已实现

代码中已有可用能力，仍要看是否完整接入 Ultra Studio。

黄色：部分实现

有真实底座或原型，但产品合同、事件、持久化或 UI 还缺。

红色：仅设计

文档已定义，代码里没有可用实现。不能当作已落地。

当前总览

已实现

0 个组件目前没有单独归为 fully implemented。原因是 Ultra Studio 仍是组合产品，不是单点功能。

部分实现

12 个组件已有 Hermes 底座或 Atlas 插件，但需要接入 Ultra 的产品合同。

仅设计

7 个组件只有文档或原型，不能在 UI 里假装可用。

组件地图

组件状态一句话英文审计版
01 左侧导航外壳
Left Nav Shell		 部分实现 Ultra Studio 的固定左侧入口，承载 New task、Search、My office、Marketplace、Files、Memory、Tasks。它不是装饰栏，而是工作状态的主导航。 英文原文
02 创作聊天界面
Creative Chat UI		 部分实现 用户描述创作目标、上传素材、回答澄清问题、审批动作、查看生成进度的主工作区。打开页面不能自动开始生成。 英文原文
03 右侧检查器 / 实时面板
Inspector / Live Panel		 部分实现 右侧面板显示当前 job、选中资产、QA、下载、重试、转 Element、建角色。它不是第二个聊天窗口。 英文原文
04 技能市场
Marketplace		 仅设计 面向 Ultra Studio 的技能、模板、工作流和连接器目录。第一版可以是空态，但不能伪造市场数据。 英文原文
05 记忆系统
Memory		 部分实现 保存项目偏好、品牌设定、角色设定、用户选择和长期上下文。它要能被 agent 使用，也要能被用户审计。 英文原文
06 文件 / 任务文件浏览器
Files / Task File Browser		 部分实现 展示上传文件、任务工作目录、生成中间产物和可复用素材。它连接 chat upload、sandbox 文件和 asset library。 英文原文
07 任务 / 会话历史
Tasks / Session History		 部分实现 左侧任务列表和历史恢复能力，用户可以回到某次创作，看到 transcript、工具、文件、资产和结果。 英文原文
08 资产库界面
Asset Library UI		 仅设计 统一浏览生成资产、上传素材、角色、合集、智能分组和散装资产。它是创作复用的核心页面，不只是图库。 英文原文
09 资产服务
Asset Service		 仅设计 资产库的后端实体和 API，负责 media_assets、lineage、下载、索引、collections、characters。 英文原文
10 媒体任务服务
Media Job Service		 部分实现 把图片/视频生成从同步工具升级为可追踪 job：submit、poll、状态事件、产物入库、失败恢复。 英文原文
11 技能注册表
Skill Registry		 部分实现 管理 agent 可见技能、渐进加载、安装守卫、Ultra allowlist、评估和版本。它决定“做视频”时 agent 应该看到哪些技能。 英文原文
12 工作流路由器
Workflow Router		 部分实现 在真正生成前判断 intent、asset roles、缺失字段、workflow_skill 和下一步。它要先问清楚，而不是一进来就开跑。 英文原文
13 提示词编译器
Prompt Compiler		 仅设计 把用户自然语言、技能规则、模型约束、资产引用和安全边界编译成 provider payload。不是简单润色 prompt。 英文原文
14 沙箱生命周期
Sandbox Lifecycle		 部分实现 管理每个任务的执行环境：创建、挂载文件、运行工具、暂停、唤醒、销毁。Atlas-only P0 可以先弱化，但不能把它当已经完整。 英文原文
15 人工审批网关
Human Approval Gateway		 部分实现 对高风险动作、付费调用、删除、外发、重试消耗等操作做明确审批。要可恢复、可审计。 英文原文
16 观察与溯源账本
Observation / Provenance Ledger		 仅设计 记录每次生成、工具调用、观察结果、资产来源、QA 证据和决策链。它用来防止 agent 空口声称完成。 英文原文
17 TokenRouter 凭证与额度路由
TokenRouter		 仅设计 控制 provider 凭证、租户策略、额度、并发和计费。沙箱或浏览器不拿真实上游 key，只拿短期 Hermes token。 英文原文
18 CometAPI 媒体网关
CometAPI Media Gateway		 仅设计 处理长视频、外部社媒 URL、抽帧、转码、音频/字幕提取、多模态打包。它是媒体数据面，不是 TokenRouter。 英文原文
19 模型目录与供应商约束
Model Catalog / Provider Constraints		 部分实现 记录 Atlas 图片/视频模型、输入能力、画幅、时长、参考图、价格/限制，供 router、compiler、UI 使用。 英文原文

怎么使用这套中文页

  • 做实现时，看每页的 P0 要做 和 验收点。
  • 做审计时，点每页底部英文 Markdown，那里保留完整证据和 open questions。
  • 做排期时，优先处理黄色组件里的 P0 缺口，再处理红色组件里的最小后端合同。
