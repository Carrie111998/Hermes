10 媒体任务服务

把图片/视频生成从同步工具升级为可追踪 job：submit、poll、状态事件、产物入库、失败恢复。

部分实现 Media Job Service 阅读版 HTML
状态说明：部分实现：有真实底座，但产品合同还没完整接上。 本页是中文阅读版，英文 Markdown 仍是更细的审计原文。

已有实现证据

  • 已有 image/video generation tools 和 Atlas submit/poll client。
  • 已有 Atlas image/video catalog 和 provider constraints。
  • 代码证据：tools/image_generation_tool.py、tools/video_generation_tool.py、plugins/image_gen/atlas/*、plugins/video_gen/atlas/*。

主要缺口

  • 没有 durable media_jobs 表或统一 job envelope。
  • 没有 ultra_media_job_create/status/cancel/list。
  • 没有 media_job.* 事件流，也没有 asset.ready 产物事件。

P0 要做

  • 实现最小 media_jobs 持久记录：id、status、provider、model、input、error、asset_ids。
  • 把 Atlas submit/poll 包到 job create/status，而不是直接在聊天里等完。
  • 完成后写 Asset Service，失败后写 typed provider error。

P1 / P2 后续

  • 取消、重试、队列、并发控制、预算、TokenRouter decision id。
  • 异步 worker 和 webhook 回调。

验收点

  • 长视频生成时 UI 不冻结，能看到 queued/running/polling/completed。
  • 刷新后可查 job 状态。
  • 失败 job 有 provider response 和可操作恢复路径。
