19 模型目录与供应商约束

记录 Atlas 图片/视频模型、输入能力、画幅、时长、参考图、价格/限制，供 router、compiler、UI 使用。

部分实现 Model Catalog / Provider Constraints 阅读版 HTML
状态说明：部分实现：有真实底座，但产品合同还没完整接上。 本页是中文阅读版，英文 Markdown 仍是更细的审计原文。

已有实现证据

  • 已有 Atlas image/video catalog。图片默认 nano-banana-2，视频默认 wan-2.6-flash 等。
  • 工具 schema 已能读取部分 provider constraints。
  • 代码证据：plugins/image_gen/atlas/catalog.py、plugins/video_gen/atlas/catalog.py、provider schema。

主要缺口

  • 没有统一 queryable registry API。
  • 模型选择器、router、prompt compiler 没有全部从 catalog 取约束。
  • 价格、区域、失败率、冷启动等运行时信号未纳入。

P0 要做

  • 把 Atlas catalog 暴露给前端 model picker 和 workflow router。
  • 生成前校验 aspect_ratio、duration、reference image、mode 是否被模型支持。
  • 缺 key、模型不可用、参数不支持时返回 typed error。

P1 / P2 后续

  • 多 provider catalog、实时健康、价格展示、自动降级、eval score。
  • 按工作流推荐模型。

验收点

  • UI 不允许选择当前模型不支持的参数组合。
  • 猫图请求走 Atlas 图片模型，不回落到 FAL。
  • 视频请求使用 Atlas 视频模型，且能说明为什么选它。
