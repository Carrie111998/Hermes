11 技能注册表

管理 agent 可见技能、渐进加载、安装守卫、Ultra allowlist、评估和版本。它决定“做视频”时 agent 应该看到哪些技能。

部分实现 Skill Registry 阅读版 HTML
状态说明：部分实现：有真实底座，但产品合同还没完整接上。 本页是中文阅读版，英文 Markdown 仍是更细的审计原文。

已有实现证据

  • 已有 skill discovery、metadata scan、progressive loading、install guard。
  • 已有 creative skills 和 ultra_studio_skills allowlist 辅助代码。
  • 代码证据：agent/skill*、hermes_cli/ultra_studio_skills.py、skills/creative/*。

主要缺口

  • 没有完整 Ultra profile，把无关 87 个 skills 从运行时视野隔离。
  • 没有 skill eval、capability contract、tool schema binding。
  • 没有 marketplace/registry 的统一状态源。

P0 要做

  • 定义 Ultra creative allowlist：workflow-router、infographic-md-flow、product-photoshoot、media-qa、prompt-repair 等。
  • 默认创作 agent 只暴露视频/图片/资产相关技能。
  • 缺依赖时阻止加载并给用户可理解错误。

P1 / P2 后续

  • 技能版本、评分、测试样例、provider compatibility。
  • Marketplace 安装和团队级 allowlist。

验收点

  • 用户说“我要做视频”时不会加载 ascii-video、manim 等无关技能。
  • router 能看到有限且正确的 creative skills。
  • 禁用技能不会出现在 tool plan 里。
