12 工作流路由器

在真正生成前判断 intent、asset roles、缺失字段、workflow_skill 和下一步。它要先问清楚，而不是一进来就开跑。

部分实现 Workflow Router 阅读版 HTML
状态说明：部分实现：有真实底座，但产品合同还没完整接上。 本页是中文阅读版，英文 Markdown 仍是更细的审计原文。

已有实现证据

  • 已有 workflow-router skill 包和 creative allowlist helper。
  • 已有 clarify tool 可向用户提问。
  • 代码证据：skills/creative/workflow-router、hermes_cli/ultra_studio_skills.py、tools/clarify_tool.py。

主要缺口

  • 没有 runtime 强制先路由，再调用生成工具。
  • 没有 typed ultra_skill_route 输出 schema。
  • 没有 asset role 分类：logo、foundation、reference、product、character。

P0 要做

  • 实现路由结果：intent、workflow_skill、missing_fields、asset_roles、allowed_tools、ask_user_question。
  • 如果信息不足，只问一个最关键问题。
  • 只有 route 决策允许 create_video/create_image 时才提交 Media Job。

P1 / P2 后续

  • 多轮 route memory、skill confidence、fallback route、eval dataset。
  • Higgsfield 风格的 workflow family 路由。

验收点

  • “我要做一个视频”会问类型或素材，不会立即生成。
  • “帮我生成猫的图片”能路由到 image generation，而不是 FAL 默认。
  • 上传多图时能区分 logo 和参考图。
