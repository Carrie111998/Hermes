08 资产库界面

统一浏览生成资产、上传素材、角色、合集、智能分组和散装资产。它是创作复用的核心页面，不只是图库。

仅设计 Asset Library UI 阅读版 HTML
状态说明：仅设计：文档已定义，代码里还没有可用实现。 本页是中文阅读版，英文 Markdown 仍是更细的审计原文。

已有实现证据

  • 产品设计已有角色、合集、智能分组、散装资产边界。
  • 当前代码没有完整 asset library page、gallery、picker。
  • 邻近材料：asset library backend design、Notion source、demo HTML。

主要缺口

  • 没有 asset API，因此 UI 没有真实数据源。
  • 没有语义搜索、filters、collections、smart groups、characters。
  • 没有从 chat/inspector 复用资产的统一入口。

P0 要做

  • 先依赖 Asset Service 的最小 media_assets 列表。
  • 支持查看生成图片/视频、下载、复制 URL、回到来源任务。
  • 没有后端时只显示明确未接入空态。

P1 / P2 后续

  • Collection、Smart Group、Character、相似搜索、prompt 搜索。
  • 从聊天里 @asset 或选择 reference image/video。

验收点

  • 新生成资产自动出现在资产库。
  • 资产卡能显示来源模型、prompt、创建时间。
  • 用户可以从资产库把图片重新用于下一次生成。
