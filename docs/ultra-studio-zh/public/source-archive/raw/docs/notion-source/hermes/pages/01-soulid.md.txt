## Content

这是一个lora + 基座模型的设计。通过将用户输入的30张左右不同角度的含人脸的图片进行lora训练，得到一个lora

## 生成流程

多图训练 → 产生 reference_id → 带 ID 生成时条件化人脸

## 模型名称

text2image_soul_v2

### 猜测模型

1. SDXL 蒸馏版

1. Flux.1 [Schnell/Dev] 的优化版

## 训练

Soul ID 训练采用的是 轻量化微调技术，其机制如下：

- 数据量限制：系统支持 1-100 张图片。虽然上限是 100 张，但如果图片质量参差不齐（光线太暗、遮挡严重、清晰度低），反而会引入噪声，导致训练出的身份“坍缩”或失真。

- 100 张的作用：当你拥有极其丰富的多角度、多光影、多表情数据时，100 张照片可以帮助模型学习到更加立体、无死角的身份特征。

- 实际操作建议：
  - 5-10 张：可以达到基本的“像”，但在极端角度下可能会失真。
  - 10-30 张（推荐）：涵盖正面、侧面、仰视、俯视、不同表情和光照，这是获得商业级一致性的黄金区间。
  - 合成训练 (Bootstrap)：如果你一张照片都没有，Higgsfield 支持通过 1 张种子图（Seed）生成 4 张增强图（Augmentations），仅用 5 张合成图片 即可训练出一个相对稳定的 Soul ID。

### 架构中的训练流程

Soul ID 的训练被设计为 异步任务：

1. 上传：图片通过 higgsfield_upload 进入后端。

1. 触发训练：调用 higgsfield_soul_id(action='create')。

1. 计算资源分配：后端会将任务调度至 GPU 集群，进行 5-30 分钟的权重微调。

1. 身份锚定：训练完成后，生成的 reference_id 就像一个“视觉锚点”，在生成时通过交叉注意（Cross-Attention）机制将人脸特征注入到基础扩散模型中。

## 调用流程

### 1. 资产索引与权重检索（The Lookup）

当你向 higgsfield_generate 提交包含 soul_id 或 element_id 的请求时，后端系统会触发一个预处理逻辑：

- 数据库查询：后端根据 reference_id（UUID）在云端数据库中检索与之关联的 模型权重（Weights） 或 嵌入特征（Embeddings）。

- 热加载：这些数据是你在之前通过 higgsfield_soul_id(action='create') 训练出来的。系统会将这些经过微调的参数（通常是轻量化的算子集合，如 Identity-Adapter）加载到当前推理作业的计算节点中。

### 2. 特征注入与特征对齐（The Injection）

这是 AI 能够“认出”角色的核心环节。生成模型（如 text2image_soul_v2）在推理时，并不是只看你的文字提示词（Prompt）：

- 交叉注意力机制 (Cross-Attention)：AI 会将你的 Prompt 转化为文字向量，同时将 reference_id 对应的身份特征转化为图像特征向量。

- 潜空间约束：在扩散模型生成像素的初始阶段（去噪过程），身份特征向量会对 潜空间（Latent Space） 产生强制性的数学约束。简单来说，它告诉模型：“无论你画什么背景，画面中心这个位置的数学特征必须符合这个特定 ID 的面部几何结构。”

### 3. 多模态融合渲染（The Rendering）

在具体的执行层面，针对不同类型的 ID，注入方式略有不同：

- 对于 Soul ID (人脸一致性)：
  - 专用通道：text2image_soul_v2 模型拥有专门处理身份信息的输入通道。
  - 像素级微调：它能在保持面部细微特征（如眼睛形状、鼻梁高度）的同时，根据你的 Prompt 调整表情和光影。

- 对于 Element (角色/道具/场景)：
  - 占位符解析：如果你在 Prompt 中使用了 <element-tag value="element_id">element\_id</element-tag>，后端的 Prompt 编译器会将其解析为一个高维的空间特征。
  - 语义融合：模型会理解这个占位符代表一个具体实体（例如“那个红色的特定水壶”），并将其纹理和形状特征融入到场景中。

### 4. 总结架构链路

这个流程在外部架构上表现为：

1. 用户侧：输入一个字符串 ID。

1. 后端编排层：验证权限，提取对应的训练产物（Weights）。

1. 计算层 (GPU Cluster)：将权重动态注入扩散模型。

1. 产出：生成一张既符合文字描述、又精准还原 ID 特征的图片
