系统底层构建与架构组件

1. 服务架构与传输协议

- Higgsclaw 服务模式：通过 Vercel AI SDK Data Stream Protocol (UIMessageChunks) 向 Web 客户端流式传输数据。

- 调度与定时任务：higgsclaw-cron 服务，通过环境变量 CRON_BASE_URL 交互。

- 文件与网页提取：Firecrawl 服务（包含 /v2/parse 解析接口）。

- 模型代理与分发：TokenRouter（执行 Gemini 模型调用），以及 CometAPI（用于视频分析的 native endpoint）。

default_api 是该系统中所有原生工具和接口的默认命名空间前缀。

在底层的工具调用机制中，系统将所有暴露给 Agent 的底层工具函数（如文件读写、网页浏览器、终端执行、Higgsfield 媒体生成等）挂载在名为 default_api 的命名空间下。

当 Agent 发起工具调用时，发送的 JSON 结构体会指定工具名称为 default_api:工具名（例如 default_api:read_file 或 default_api:terminal），后端执行器（Hermes system runner）收到请求后，通过该命名空间路由到具体的系统函数或外部服务接口。
