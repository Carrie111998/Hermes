### 最接近 Soul ID 的开源实现路径（2026 年现状）

目前没有完美复刻，但以下几种方式能做到最接近的效果：


  | 方案 | 接近 Soul ID 程度 | 训练方式 | 一致性 | 使用体验 | 推荐指数 | 备注 |
  | Flux LoRA + PuLID 混合 | ★★★★★ | 训 LoRA + 参考注入 | 最高 | 接近 | 最推荐 | 当前开源最强组合 |
  | 纯 Flux LoRA | ★★★★☆ | 只训 LoRA | 很高 | 接近 | 强 | 简单直接 |
  | PuLID (Flux版本) | ★★★★☆ | 几乎免训练 | 高 | 最接近“一键” | 强 | 最快，但稍弱于混合 |
  | InstantID | ★★★☆☆ | 免训练 | 中高 | 很快 | 中 | 成熟但一致性一般 |
  | 纯 SDXL LoRA | ★★★☆☆ | 只训 LoRA | 高 | 一般 | 中 | 效果不如 Flux 路线 |

### 最推荐的复现方案：Flux LoRA + PuLID 混合

这是目前开源社区里公认最接近 Higgsfield Soul ID 的做法：

核心思路：

1. 先用照片训练一个 Flux 角色 LoRA（负责角色整体风格和细节）。

1. 生成时结合 PuLID（负责强力的人脸/身份锁定）。

1. 两者结合使用，效果远强于单独用 LoRA 或单独用 PuLID。

为什么这个最接近 Soul ID？

- Soul ID 本质是「基模 + 身份锚点」。

- 这个方案用 Flux（强基模） + LoRA（角色适配） + PuLID（身份注入），三者结合后，一致性和可用性最接近。

- 很多人在尝试后认为这个组合在多角度、多光影、一致性上已经非常能打。

### 其他可行的复现方向

1. 纯 Flux LoRA 路线（最直接）
  - 只训练 Flux LoRA，不用 PuLID。
  - 优点：流程简单，一致性已经很强。
  - 缺点：极端角度和光影变化时，可能不如混合方案稳。

1. PuLID 主导路线（最接近「免训练」Soul ID）
  - 基本不训 LoRA，或只做很轻的 LoRA。
  - 用 PuLID + Flux 直接做参考注入。
  - 优点：最接近 Higgsfield「上传照片 → 快速可用」的体验。
  - 缺点：一致性天花板通常比「LoRA + PuLID」低一些。

1. InstantID 路线
  - 目前最成熟的免训练一致性方案。
  - 适合快速验证，但整体效果和稳定性不如上面两种。

### 总结建议（直接给你结论）

如果目标是尽可能复现 Soul ID 的效果，我推荐优先走以下路径：

首选：Flux LoRA + PuLID 混合方案
这是目前开源里效果天花板最高、最接近 Higgsfield Soul ID 的做法。

备选：
