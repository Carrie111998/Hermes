1. amazon-product-listing

skill: amazon-product-listing
category: workflow-generation
primary_subject: Amazon marketplace image asset set

定位

生成 Amazon 商品图资产，不是普通电商海报，也不是品牌广告。

核心目标：

把真实产品图 / 产品 URL
转成 Amazon 可用的主图、secondary images、A+ 内容模块。

输入门槛

必须有：

真实产品图
或可解析出产品图的产品 URL

如果没有产品参考：

必须停下问用户补产品图 / 产品链接
不能虚构商品

触发

Amazon listing
Amazon main image
secondary images
A+ content
A+ page
Amazon infographic
Suppressed Listing
white background product image
Amazon compliance

不触发

普通产品棚拍 → product-photoshoot
普通产品商业片 → productMD-flow
社媒广告图 → product photoshoot / ad workflow
UGC 产品视频 → UGC 系列

终极 pipeline

REQUEST_PARSE
  ↓
PRODUCT_REFERENCE_GATE
  ↓
PRODUCT_IDENTITY_LOCK
  ↓
AMAZON_COMPLIANCE_MODE
  ↓
MAIN_IMAGE_GENERATION
  ↓
SECONDARY_IMAGE_SET
  ↓
A_PLUS_MODULE_SET
  ↓
COMPLIANCE_QA
  ↓
DELIVERY

资产结构

AmazonListingSet:
  main_image:
    role: white-background compliant hero
  secondary_images:
    - infographic
    - multi_angle
    - detail_closeup
    - lifestyle
    - whats_in_box
  a_plus_modules:
    - hero_banner
    - pain_points
    - features
    - ingredients_or_materials
    - efficacy_or_benefits
    - how_to_use
    - brand_endorsement

硬规则

产品不能被重新设计
主图必须以产品为唯一主体
主图背景必须符合 marketplace 白底逻辑
不能用模型想象包装不存在的套装
不能编造成分、功效、认证
不能把 lifestyle 图当主图

text_legibility: 0-5

3. productMD-flow

skill: productMD-flow
category: workflow-generation
primary_subject: premium product commercial reel

定位

高端真实产品商业片。

不是产品图，不是 UGC，不是普通 motion reel。

核心：

真实产品照片是硬门槛
产品几何、材质、比例、关键特征必须锁定

输入门槛

必须有：

真实产品图

可选：

logo
品牌名
tagline
商业片方向
参考 tier
多个产品图 / 多角度

没有产品图：

停止
不能生成真实产品商业片
可建议换到概念 / high motion 方向

人物路由

如果 brief 里出现：

model wearing product
person holding product
actor using product
human talent
face / body / portrait

则应路由到：

tv-ad
UGC
cinematic

而不是 productMD。

核心 pipeline

PRODUCT_PHOTO_GATE
  ↓
PERSON_DETECTION_ROUTE
  ↓
ASPECT_RATIO_GATE
  ↓
MULTI_PRODUCT_CLASSIFICATION
  ↓
OPTIONAL_LOGO_GATE
  ↓
REFERENCE_TIER_SELECTION
  ↓
STAGE A — PRODUCT CHARACTER SHEET
  ↓
USER_CONFIRMATION
  ↓
STAGE B — 9-SHOT 3×3 STORYBOARD
  ↓
STAGE C — VIDEO RENDER
  ↓
VARIANT_SELECTION_IF_ANY

Stage A

产品 character sheet：

不是人物 character
而是产品生产圣经
锁定产品外观、材质、角度、细节

输出：

ProductCharacterSheet:
  hero_view
  angle_views
  macro_detail
  palette
  material_callouts
  product_identity_lock

Stage B

固定：

9-shot 3×3 storyboard

不是 6-panel motion design。

Stage C

用 storyboard 生成视频。

强原则：

最终视频阶段主要参考 storyboard
不要把 character sheet 和 storyboard 同时混乱塞入最终视频

参考 tier

reference_tier:
  - luxury_chiaroscuro
  - premium_dynamic_mechanical
  - athletic_lifestyle
  - motion_design_hyperkinetic
  - editorial_technical

硬规则

真实产品图硬门槛
产品不能被重设计
Stage A → Stage B → Stage C 严格顺序
9-shot 3×3
默认单个最终 take，用户明确要求才多变体
logo 可作为 opener / closer / both
产品是 hero，不是人

material_fidelity: 0-5
commercial_quality: 0-5
shot_variety: 0-5
brand_resolve: 0-5

17. video-adapt

skill: video-adapt
category: workflow-generation
primary_subject: source video adaptation

定位

视频改编 / 复刻 / 重构 pipeline。

它不是普通视频生成，而是：

先分析源视频
再抽取结构
再生成替换元素
再编织成新版本

输入门槛

必须有：

源视频 URL 或视频文件

并且用户意图是：

recreate
adapt
remake
make this but with X
use this as reference
copy structure

pipeline

STEP 0A — USER CHOICES
  ↓
SOURCE_VIDEO_ANALYSIS
  ↓
PROFILE_SELECTION
  ↓
PLAN_INPUT_BUILD
  ↓
ADAPTATION_PLAN
  ↓
SLOT_ELEMENT_GENERATION
  ↓
ELEMENT_CREATION
  ↓
TOKEN_WEAVING
  ↓
SEEDANCE_PREP
  ↓
RENDER

关键点

不能直接看视频后写一个 prompt
必须有分析 → plan → slot → element → adapt → render

用户必须明确的内容

对于源视频改编，通常要明确：

目标画幅
分析深度
保留什么
替换什么
输出风格

尤其是：

不要从 YouTube Shorts 链接自动推断 9:16
不要从标题自动推断分析深度

中间产物

  scenes
  timing

  subject_slots

  slots
  generated_elements
  render_hints
  composite_recommendations

  source_slot -> generated_asset

  seedance_prompts
  refs
  aspect_ratio

硬规则

视频分析只做一次，缓存复用
不要重复分析同一 URL
源视频只覆盖到分析到的范围，不要编造后续场景
slot 生成后要创建可复用元素
不要直接跳到 render
