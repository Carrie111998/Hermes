9. workflow-generation

Skill

description

amazon-product-listing

从产品图或产品 URL 生成 Amazon 图片资产：合规白底主图、5 张 secondary images、7 个 A+ Brand Content 模块。

cartoon-flow

生成 2D / 2.5D / anime-influenced 动画场景，支持 4-15 秒片段和多 clip 故事。

cinematic-flow

电影化视频生产：叙事短片、对白、角色弧线、dramaturgy、镜头规划、风格锁定。

classicMD-flow

通用 motion design / brand reel / creative ad 默认入口，适合没有明确特殊风格的品牌视频。

highMD-flow

高能、hyperkinetic、fast-paced、smash-cut、sport/fashion/tech/AI reveal 类动态品牌 reel。

infographicMD-flow

数据即主体的 motion reel：KPI、dashboard、system diagram、process flow、chart reveal。

podcast-flow

AI podcast / interview / two-host conversation / talk show 生产流程。

product-photoshoot

棚拍产品图：产品作为唯一主体，在白底、渐变、无缝背景、studio lighting 下生成静态产品照。

productMD-flow

高端真实产品商业片。硬门槛是必须有真实产品图；用于 watch、sneaker、fragrance、jewelry、camera 等 premium product reel。

tv-ad

15 秒、16:9、高级广告 / TV commercial，用于品牌、产品或服务广告。

typographyMD-flow

字体作为主体的 motion reel：kinetic typography、wordmark、letterform、manifesto、opening titles。

ugc-flow

UGC talking-head 产品评测主入口：创作者出镜、具体产品、TikTok/creator/review 风格。

ugc-product-flow

产品作为唯一焦点的 UGC 视频：无 talking-head creator，可有手部/POV，voiceover-only。

ugc-try-on-flow

UGC 试穿 / OOTD / fit-check：创作者穿戴具体 wearable product。

ugc-tutorial-flow

UGC 教程：创作者 step-by-step 演示具体产品使用，并带 Step N 画面提示。

ugc-unboxing-flow

UGC 开箱：打开包裹、first reaction、PR drop、haul、产品 reveal。

video-adapt

视频改编 pipeline：分析源视频、规划替换槽位、生成元素、适配并渲染新视频。

最有价值的信息其实是这个：路由优先级

这些 workflow 不是平级随便选的。真实使用时，核心是避免错路由。

一个合理的优先级大概是：

Amazon 明确需求
  → amazon-product-listing

产品静态棚拍
  → product-photoshoot

真实产品图 + 高端产品视频
  → productMD-flow

商业广告 / TV commercial / 有服务或品牌广告
  → tv-ad

UGC + 产品 + talking-head/review
  → ugc-flow

UGC + 明确 no talking head / product only
  → ugc-product-flow

UGC + unboxing
  → ugc-unboxing-flow

UGC + tutorial/how-to
  → ugc-tutorial-flow

UGC + try-on / wearable
  → ugc-try-on-flow

数据/图表/系统图作为主体
  → infographicMD-flow

文字/wordmark/letterform 作为主体
  → typographyMD-flow

高能/kinetic/fast/smash/peak action
  → highMD-flow

普通 motion design / 品牌 reel
  → classicMD-flow

电影感叙事 / 角色 / 对白 / 情绪
  → cinematic-flow

卡通 / 动画 / anime / 2D
  → cartoon-flow

源视频改编
  → video-adapt

AI podcast / interview / two-host
  → podcast-flow

这就是公开层面能可靠给你的 catalog 信息：名称、分类、用途、触发边界。内部正文和完整隐藏流程不能导出，但这些公开描述已经足够做外部架构图、路由表和黑盒 benchmark。
