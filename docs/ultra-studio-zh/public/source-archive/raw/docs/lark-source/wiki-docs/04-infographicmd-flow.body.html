13. Motion / Camera Discipline

13.1 主规则

数据内部状态变化是主运动。
镜头只辅助信息。

Camera supports data. Data does not support camera.

13.2 禁止 highMD 化

数据被镜头动效淹没

panel unfurl
node connection
data flow

该 workflow 不应以真人、产品实拍、电影摄影为主体。

photoreal lifestyle scene

15. Final Resolve / Tail Discipline

最终 1-2 秒应形成稳定结尾。

禁止：

突然黑屏
继续乱动
fade-to-black 盖掉 final frame
logo 出现后还漂移

推荐：

logo / wordmark / final insight 稳定停住
数据系统完整锁定
最后画面可作为封面帧

16. Stage C 引用规则

16.1 主原则

Stage C 以 Stage B storyboard 为主参考。
不要让多个上游视觉参考互相打架。

原因：

foundation 已经被 storyboard 吸收。
最终视频阶段再塞太多参考，容易让模型混淆：到底跟 foundation，还是跟 storyboard？

16.2 双通道资产记录

每个中间图都应记录两种东西：

GeneratedAsset:
  generation_ref: "用于后续生成链路"
  visual_url: "用于视觉理解 / 审核 / prompt 编写"
  role: "foundation | storyboard | final_video"

解释：

一个引用给机器链路用。
一个 URL 给视觉分析 / enhancer / 人类审核用。
两者不能混。

20. v2 执行伪代码

def run_infographic_md_flow(request):
    brief = parse_request(request)

    # 1. Route guard
    if not is_data_as_subject(brief):
        return route_to_neighbor_workflow(brief)

    # 2. Aspect
    if brief.aspect_ratio is None:
        brief.aspect_ratio = ask_aspect_ratio()

    # 3. Determine variant
    variant = infer_infographic_variant(brief)

    if variant is None:
        variant = ask_variant(
            options=[
                "n_stats_sequence",
                "process_flow",
                "system_diagram"
            ]
        )

    brief.infographic_variant = variant

    # 4. Extract required information
    payload = extract_information_payload(brief, variant)

    if not payload_is_sufficient(payload, variant):
        payload = ask_for_missing_payload(variant)

    enforce_no_invented_metrics(payload)

    # 5. Classify assets
    asset_manifest = classify_assets(
        attachments=brief.attachments,
        user_text=brief.user_request
    )

    if asset_manifest.needs_user_classification:
        asset_manifest = ask_asset_roles(asset_manifest)

    # 6. Resolve logo
    logo = resolve_logo(asset_manifest, brief)

    if logo.requires_user_choice:
        logo = ask_logo_source_or_skip()

    if logo.exists and logo.placement is None:
        logo.placement = ask_logo_placement(
            default="closer"
        )

    # 7. Resolve foundation
    if asset_manifest.foundation:
        foundation = resolve_foundation_asset(asset_manifest.foundation)
        foundation_mode = determine_foundation_mode(brief, foundation)
    else:
        moodboard = generate_four_up_infographic_moodboard(
            style_hint=brief.style_hint,
            audience=brief.audience
        )
        foundation = ask_user_pick_moodboard_frame(moodboard)
        foundation_mode = "build_from_selected_frame"

    # 8. Choose visual tier
    tier = choose_reference_tier(
        audience=brief.audience,
        style_hint=brief.style_hint,
        variant=variant
    )

    # 9. Build Stage B plan
    storyboard_plan = build_six_panel_plan(
        variant=variant,
        payload=payload,
        foundation=foundation,
        foundation_mode=foundation_mode,
        logo=logo,
        aspect_ratio=brief.aspect_ratio,
        tier=tier,
        brand_name=brief.brand_name,
        tagline=brief.tagline
    )

    preflight_storyboard(storyboard_plan)

    storyboard = generate_storyboard_sheet(storyboard_plan)

    # 10. Build Stage C plan
    render_plan = build_video_render_plan(
        storyboard=storyboard,
        variant=variant,
        payload=payload,
        logo=logo,
        aspect_ratio=brief.aspect_ratio,
        tier=tier,
        variant_count=brief.variant_count or 2
    )

    preflight_video(render_plan)

    videos = generate_video_variants(render_plan)

    # 11. QA / selection
    qa_results = evaluate_variants(
        videos,
        payload=payload,
        storyboard_plan=storyboard_plan
    )

    best = select_best_variant(videos, qa_results)

    return deliver(best, storyboard, qa_results)

infographicMD-flow 用于生成 数据作为视觉主体 的 motion design reel。

这里的“数据作为主体”指：

它解决的是：

数据如何出现
图表如何建立
节点如何连接
流程如何推进
数字如何成为视觉主角
信息如何在短视频中被看懂

5. 数据 / 文本硬规则

5.1 不发明指标

这是最重要的规则之一。

只渲染用户提供的数字、标签、指标、流程步骤和系统实体。

允许：

用户给 “+34% ARR growth”
画面中出现 “+34% ARR Growth”

不允许：

用户只给 “ARR growth”
画面中擅自出现 “+34%”

不允许：

用户给 3 个指标
画面中擅自补成 4 个季度数据

5.2 数字必须是 headline-tier

数字不是脚注。

+34%
12K
84%
$420M

必须是一眼可读的主视觉。

错误方式：

把数字做成角落小字
把 metric label 做成很小的 monospace 标签
用大量 tiny labels 装饰画面

正确方式：

大数字
大图表
主 panel 中心
高对比
少而清晰的标签

5.3 图表动效必须语义化

动效必须表达数据关系，而不是装饰。

允许：

bar rises → 表达增长
line draws on → 表达趋势形成
nodes connect → 表达关系建立
data flows along edge → 表达系统传递
pie slice unfurls → 表达组成比例

不允许：

图表随便旋转
数字飞来飞去但不表达含义
节点乱闪
dashboard 只是背景纹理

核心判断：

这个 motion 是否让信息更清楚？
如果没有，就是装饰，不合格。

data_as_subject: 0-5

readability: 0-5
semantic_motion: 0-5
panel_structure: 0-5

  数字、标签、主图表是否能看清。

  动效是否表达增长、连接、流动、转化等含义。

panel_structure:
  是否遵循 6-panel 信息节奏。

style_alignment:

cognitive_load_control:
  信息是否过载。

18. 对齐版伪代码

def run_infographicMD_flow(request):
    parsed = parse_request(request)

    if not parsed.aspect_ratio:
        parsed.aspect_ratio = ask_aspect_ratio()

    if not parsed.infographic_variant:
        parsed.infographic_variant = infer_variant(parsed)

    if not parsed.infographic_variant:
        parsed.infographic_variant = ask_infographic_variant()

    info = extract_information(parsed)

    if not has_required_info(info, parsed.infographic_variant):
        info = ask_for_exact_metrics_steps_or_nodes(parsed.infographic_variant)

    assert_no_invented_metrics(info)

    assets = classify_attached_images(request.attachments)

    logo = resolve_logo_if_needed(assets, parsed)

    if assets.foundation_image:
        foundation = upload_or_resolve_foundation(assets.foundation_image)
    else:
        moodboard = generate_infographic_moodboard(parsed.style_hint)
        foundation = ask_user_to_pick_moodboard_frame(moodboard)

    storyboard_prompt = build_storyboard_prompt(
        foundation=foundation,
        infographic_variant=parsed.infographic_variant,
        exact_info=info,
        aspect_ratio=parsed.aspect_ratio,
        brand=parsed.brand,
        logo=logo
    )

    storyboard = generate_6_panel_storyboard(storyboard_prompt)

    video_prompt = build_seedance_prompt(
        storyboard=storyboard,
        infographic_variant=parsed.infographic_variant,
        exact_info=info,
        aspect_ratio=parsed.aspect_ratio
    )

    variants = generate_video_variants(
        prompt=video_prompt,
        storyboard=storyboard,
        count=parsed.variant_count or 2
    )

    selected = select_or_present_variants(variants)

    return deliver(selected)
