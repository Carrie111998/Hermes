2. Manus 对照缺口

Gap 1: Sandbox Lifecycle

Manus 的 task sandbox 有 create、sleep、awake、recycle、restore files、artifact visibility。Ultra Studio 现在只画了 Sandbox VM 和 Hermes Cloud Attach，没有定义生命周期。

  • sandbox.create
  • sandbox.attach
  • sandbox.sleep
  • sandbox.wake
  • sandbox.recycle
  • sandbox.restore_artifacts
  • restored vs non-restored manifest

Gap 2: Artifact Browser / Task Files

资产库不等于任务文件浏览器。任务里会产生 prompt JSON、storyboards、scripts、logs、intermediate renders、downloaded media。

  • task_files panel
  • session/job/sandbox file tree
  • artifact bundle export
  • task_file / asset / reference / protected_skill_reference
  • promote to asset library

Gap 3: Cloud Browser / Local Browser Split

创作 agent 需要竞品广告、产品页、社媒趋势、登录态资源和反爬敏感网站。一个 generic browser tool 不够。

  • cloud_browser for general web research
  • my_browser / local bridge for logged-in sites
  • explicit takeover state
  • per-site session controls
  • browser artifacts captured into asset library

Gap 4: Local Desktop Bridge

创作用户有本地媒体文件、设计文件、剪辑素材、本地 CLI/GPU。需要文件夹级授权，不应默认全盘访问。

  • folder-scoped connector
  • allow once / always / deny command approval
  • local file import into asset library
  • local render/export handoff
  • local GPU optional, never assumed

Gap 5: Skill Progressive Disclosure

启动时只加载 metadata，触发时加载 SKILL.md，scripts/references/assets 按需加载。否则主 prompt 会越来越重。

  • production workflow has SKILL.md
  • references/ for schema/compiler/rubric/examples
  • scripts/ for deterministic validators/compilers
  • assets/ for templates
  • trigger tests and eval fixtures
  • skill versioning and changelog

Gap 6: Human Approval / Takeover

电脑使用、浏览器和媒体花费不能只有普通 tool-call 权限。高成本、高隐私、高风险操作必须停下来问。

  • spend credits / Boost concurrency
  • long GPU video job
  • paid external model
  • private media upload
  • logged-in browser context
  • local command
  • publish/share/export externally

Gap 7: Sharing / Collaboration Privacy

分享 conversation 不等于分享 sandbox。协作模式应默认禁用 connector/session credentials。

  • share conversation
  • share selected artifacts only
  • never share sandbox filesystem by default
  • disable connectors in collaboration mode
  • asset ACL and redaction review

Gap 8: Provenance / Anti-Fake

每个媒体结果和研究结论都要有证据链，防止 agent 伪造“已完成”。

  • job id, model, provider, prompt hash, inputs, status
  • research claim links to source or asset
  • no markdown-only generated URL as final proof
  • failed job trace: request -> TokenRouter -> worker log -> asset state
  • QA separates observed output from inference

3. 第二轮跨系统调研发现

A. Sandbox 是产品原语

E2B 把 sandbox 定义为按需创建的 secure Linux VM；Daytona 把 sandbox 定义为有 kernel、filesystem、network stack、vCPU、RAM、disk 的 composable computer。

Ultra Studio 含义：用户应该看到 job 在哪个 task computer 里跑，文件、日志、代码、prompt JSON、输出都能从 session 检查。

组件：Task Computer Service

B. Browser 需要持久 Context

Browserbase Contexts 持久化 cookie、auth、localStorage、IndexedDB。创作场景需要登录态电商、社媒、广告库、灵感站点。

组件：Browser Context Store、Browser Session Manager、Browser Artifact Capture、Agent Identity / Credential Boundary

C. Computer Use 需要强审批

OpenAI Operator 和 Anthropic computer use 都强调用户接管/确认。Anthropic 还强调 VM/container、domain allowlists、避免敏感数据暴露。

组件：Human Approval Gateway，支持 approve、edit、reject、respond。

D. Durable Execution 是长媒体 job 的骨架

Temporal 的 durable execution 解决 crash-proof workflow；Inngest 关注 tool loop、sub-agent、HITL、可靠 orchestration 和 observability。

组件：Durable Workflow Engine、Media Job Event Log、Workflow Checkpoints、Approval Pause State

E. 媒体 API 都收敛到 Queue + Status + Webhook + Upload

fal 有 queue submit/status/result/cancel/webhook；Runway 有 generation tasks、uploads、input constraints。Atlas 也不应该只作为裸 provider 调用暴露给 agent。

组件：MediaJob envelope、Provider Constraint Registry、ultra_media_job_* 工具组。

F. Skill 需要 Registry

Codex、Microsoft Agent Skills、Manus 都收敛到 SKILL.md + scripts + references + assets + progressive disclosure。文件夹不等于可控 runtime。

组件：Skill Registry、Skill Allowlist Profile、Skill Version Manifest、Skill Trigger Eval、Skill Output Contract Eval

G. Action 需要 Observation Loop

电脑/浏览器 agent 不能只返回 success flag。每一步都要有 before/after observation、截图/DOM/stdout/file diff/media preview/job status。

组件：Observation Ledger。它和 Provenance Ledger 分工：observation 记录行动真相，provenance 记录资产血缘。

5. MediaJob Envelope

Provider 原始 API 不应该直接暴露给 agent。需要统一媒体 job envelope，把 Atlas、fal、Runway 类能力统一成 create/status/cancel/retry/finalize。

Tool职责
ultra_media_job_create创建 provider-neutral media job，挂上 session/run/tool/asset refs。
ultra_media_job_status查询状态，支持 poll/webhook/streaming update。
ultra_media_job_cancel取消排队或运行中的 job。

ultra_media_constraints_get给 prompt compiler 暴露模型输入限制、上传格式、参考图能力。

9. Revised Build Order

P0

  1. Define MediaJob and provider constraint schema.
  2. Add durable media job event log with create/status/cancel/retry/finalize.
  3. Add human approval gateway for cost, private media, browser auth, local commands, publish actions.
  4. Add task file browser and artifact promotion into Asset Library.
  5. Add skill registry with allowlist, version manifest, and trigger evals.
  6. Add observation/provenance ledger to prevent fake completion.

P1

  1. Browser Context Store and cloud browser session manager.
  2. Durable workflow engine integration if event log is not enough.
  3. Local desktop bridge with folder-scoped access and command approval.
  4. Skill scripts for prompt compilation and input validation.
  5. Collaboration privacy boundary and share artifact flow.

P2

  1. Full local GPU route.
  2. Public project sharing.
  3. Scheduled recurring creative tasks.
  4. Automated skill packaging from successful sessions.

10. 未压缩执行清单

这部分直接按“要建什么”列，不再压成一句话。它可以变成 issue list、PRD checklist 或里程碑。

Sandbox Lifecycle

  • sandbox.create：按 session/job 创建隔离任务电脑。
  • sandbox.attach：把 Hermes runtime、workspace、volume、短期 token 挂上去。
  • sandbox.sleep：长任务等待时释放重资源，但保留恢复点。
  • sandbox.wake：从恢复点继续，不让用户重新描述任务。
  • sandbox.recycle：异常或安全过期后重建环境。
  • sandbox.restore_artifacts：只恢复 manifest 里声明要保留的文件。
  • 记录 restored / disposable / promoted 三类文件状态。

Task File Browser

  • 按 session、run、job、sandbox 展示文件树。
  • 支持 prompt JSON、storyboard、脚本、日志、中间帧、最终视频。
  • 区分 task_file、asset、reference、protected_skill_reference。
  • 支持下载 artifact bundle。
  • 支持一键 promote 到 Asset Library。
  • promote 时生成 provenance record 和 asset id。

Browser / Desktop

  • cloud_browser：公开网页研究、素材抓取、灵感站点。
  • my_browser：用户授权的登录态、本机浏览器或远端持久 context。
  • 每个 browser context 必须 workspace scoped、可撤销、可过期。
  • browser artifact capture：截图、下载文件、HTML/markdown snapshot、source URL、timestamp。
  • local desktop bridge 只允许用户授权文件夹。
  • 本地命令必须走 allow once / always / deny 审批。

Approval Gateway

  • 公开读取默认 allow，但要记录 provenance。
  • 使用登录态浏览器、上传私有媒体、花费 credits、Boost 并发都默认 ask。
  • 长 GPU 任务必须先显示预估成本、模型、输入资产、输出类型。
  • 发布、发邮件、checkout、外部分享必须 explicit approval。
  • 金融、法律、不可逆高风险动作默认 block 或 manual-only。
  • 审批结果必须可恢复：approve、edit、reject、respond。

Skill Runtime

  • 启动只加载 skill metadata，不把所有 SKILL.md 塞进主 prompt。
  • 触发后加载 SKILL.md，references/scripts/assets 按需加载。
  • 每个创作 workflow 必须有 route、inputs schema、prompt compiler、QA rubric。
  • skill allowlist profile 决定当前 agent 能看到哪些技能。
  • trigger eval 测 route 是否误触发。
  • output contract eval 测 handoff、asset roles、missing fields 是否完整。

Media Job Contract

  • 所有 Atlas/fal/Runway 类调用统一进入 MediaJob。
  • agent 只调用 create/status/cancel/retry/finalize/constraints。
  • provider constraints 在 prompt 编译前可见，包括上传限制、URL 格式、尺寸、参考图数量。
  • job 必须绑定 session、run、tool_call、tokenrouter_decision、input assets。
  • finalize 负责注册 output assets、thumbnail、lineage 和 usage event。
  • 失败不能降级成“生成好了”，必须暴露 provider error 和 worker log。

Evidence Ledgers

  • Observation Ledger 记录 action requested、executed、before/after、stdout、screenshot、job status。
  • Provenance Ledger 记录 provider、model、prompt hash、seed、input refs、output refs、worker log。
  • 研究 claim 必须链接 source 或本地 artifact。
  • 媒体卡片必须展示 job id、model、status、inputs、prompt hash。
  • UI 不允许只显示 markdown URL 当作完成证明。
  • QA 报告必须区分 observed output 和 inferred quality。

Sharing / Collaboration

  • conversation sharing 不等于 sandbox sharing。
  • 默认只分享消息和用户选择的 artifacts。
  • connector/session credentials 在协作模式默认禁用。
  • 分享前做 asset ACL、redaction review 和 license/source 检查。
  • 团队模式再引入 role、workspace、project-level policy。
最终原则：Ultra Studio = chat + sandbox/task filesystem + browser contexts + durable media jobs + human approvals + skill registry + provider constraints + artifact/provenance ledgers + asset library。Agent 不能在没有 artifact、observation 或 ledger record 的情况下声称完成。
