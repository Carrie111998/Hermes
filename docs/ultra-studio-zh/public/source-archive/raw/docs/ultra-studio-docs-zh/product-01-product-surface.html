这份文档解决什么

防止它退化成“套皮聊天框”。创作 agent 必须能处理文件、任务、资产、记忆、市场和实时检查，而不只是一条聊天流。

P0 相关结论

  • 左侧至少要有 New task、Search、Marketplace、Files、Memory、Tasks 的真实入口或明确空态。
  • 中心聊天不能自动生成，必须由用户意图驱动。
  • 右侧 Inspector 显示当前 job/asset 的状态、错误、下载和元数据。
