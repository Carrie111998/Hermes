Hermes Web MVP

云端多租户 Agent 最小纵向闭环 PRD

目标不是复刻 Higgsfield Supercomputer 全量能力，而是跑通真实 Web Agent、Skill、资产引用、异步媒体 job、TokenRouter 和多租户隔离的第一条闭环。

日期：2026-06-04 定位：MVP PRD 范围：云端多租户 supercomputer
一页结论
用户登录 -> workspace/project -> 真实 Agent chat -> 上传素材 -> Skill / 工具 -> 资产引用 -> 异步媒体 job -> TokenRouter 鉴权和凭证隔离 -> Worker 执行 -> UI 展示状态和结果 -> 输出资产复用。

必须证明的三件事

真实 Agent

Web 端是真实 Hermes gateway 会话入口，不是 demo job runner。

真实隔离

身份、数据、文件、资产、凭证、worker、审计一起建，不能后补。

真实异步 job

媒体生成要有 job、状态、错误、输出资产和审计，不伪造结果。

模块级拆解

模块用户目标接口 / 数据权限与验收
Web Chat 新建、恢复、继续真实 Agent 会话。 session.create、session.resume、prompt.submit、slash.exec；记录 sessions、runs、messages、tool_calls。 session 绑定 tenant/workspace/project；刷新后可恢复；工具进度和错误可见。
Identity / Project 用户进入正确 workspace/project，不能串租户。 服务端生成 identity tuple：sub、tenant_id、workspace_id、project_id、session_id、tool_scopes、budget、exp。 不信任前端 tenant_id；改 URL 或 payload 不能进入别的 project。
Upload / Attachment 上传素材并让 Agent 安全引用。 POST /api/chat/uploads；返回 upload_asset_id、media_input、attachment marker；对象 key 按 tenant/workspace/project 分区。 Agent 看到 marker，不看到任意本地路径；其他 tenant 无法读取。
Skill Registry 用户看公开 Skill；Agent 按需加载受保护 reference。 skills_list、skill_view、skill_reference_access_logs。 禁止 ../、symlink escape、bulk export；每次加载记录 allow/deny reason。
References 安全 区分 Skill 内部、用户上传、媒体资产三类引用。 Skill references/、upload references、soul_id/element_id/media_input/job_id。 Skill internals 默认不可导出；媒体资产 id 使用前查 ACL/status/revocation。
Structured Question Agent 用结构化方式让用户补信息。 ask_user_question 支持 text、entity、files。 不能让用户手抄 asset id；picker 只展示有权限资产；取消返回结构化 cancel。
Asset Service 创建并复用 Element、Soul ID、media_input、job asset。 asset_references、asset_reference_sources、identity_jobs、generation_jobs、asset_acl。 not_ready/failed/revoked 不能用于生成；output asset 必须记录 lineage。
Media Job 异步执行生成，UI 可见状态和结果。 validate -> create -> queue -> run -> finalize -> reuse；状态为 created/queued/running/completed/failed/cancelled。 idempotency key 防重复提交；provider 未配置返回可见错误，不伪造结果。
TokenRouter 凭证、配额、策略、审计控制面。 verify token、extract claims、OPA decision、asset/quota check、OpenBao secret exchange、proxy/job create、audit。 token 过期、OPA bundle 缺失、quota 缺失、vault failure、关键 audit failure 都 fail closed。
Sandbox / Volume / Egress 隔离任意代码和工具执行。 Kata / microVM、授权 /workspace path set、cgroup、egress proxy。 无 provider key、无 hidden Skill references、无 metadata egress、不能直连 provider。
Worker / Job Manager 受控执行媒体 job。 Job Manager 校验 job 和生成 manifest；worker 只拿 lease/input manifest，只写 assigned output_prefix。 MVP 单 queue、单 GPU pool、one model worker；不做复杂 Kueue 策略。
Audit / Observability 失败和成本能追踪。 session event、tool call、token decision、asset access、job event、usage event。 failed job 可从 job_id 追到 run、tool_call、TokenRouter decision、worker log、usage event。
MVP 不做
不做完整 CometAPI、不做 fake job、不自动生成、不公开化 default_api:*、不承诺 Soul ID 底层训练、不做 Boost upsell、不做跨 region GPU 调度、不用普通 Docker 承载任意租户代码。

核心对象

tenant、workspace、project、session/thread、run、tool_call、upload、asset_reference、identity_job、generation_job、usage_event、audit_event

产品体验

  • 中间是真实 Agent transcript，展示流式消息。
  • 右侧是 tool progress、assets、job status、structured prompt 面板。
  • 附件上传必须进入真实 attachment flow。
  • ask_user_question 支持 text、entity、files。
  • 资产面板展示 upload、Element、Soul ID、media job、生成结果。

技术里程碑

  1. PRD 与设计冻结：确认范围和不做事项。
  2. Identity + Session + Web Chat：真实会话、流式消息、工具事件。
  3. Skill + References：registry、skill_view、protected references。
  4. Upload + Asset Service：上传、Element、Soul ID pending/status、asset picker。
  5. TokenRouter MVP：JWT、OPA、OpenBao、quota、asset ACL、audit。
  6. Media Job MVP：异步 job、单 worker、状态流、输出资产、全链路追踪。

验收标准

  • 用户能创建/恢复真实 Hermes 会话，并看到流式消息和工具进度。
  • 上传文件返回真实 attachment marker，不硬编码路径。
  • 普通用户不能导出 protected Skill references/。
  • media_generate 返回 job id，UI 显示 queued/running/completed/failed。
  • 未授权或未 ready 的资产不能被 job 使用。
  • sandbox 和 mounted files 中没有 provider key。
  • failed job 可从 job_id 追到 TokenRouter decision、worker log、usage event。
