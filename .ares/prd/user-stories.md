# User Stories

## Primary
1. As a developer, I want to define agents in simple markdown files so I don't need complex profile setup
2. As a developer, I want to delegate tasks to specific agents with full config control
3. As a developer, I want agents to communicate with each other via delegation
4. As a developer, I want to override agent config per task (temperature, reasoning, etc.)

## Secondary
5. As a developer, I want to list all available agents so I know what's available
6. As a developer, I want to validate agent definitions so I catch errors early
7. As a developer, I want skills to stay in their existing location (.hermes/skills/)
8. As a developer, I want backward compatibility with existing delegate_task

## Tertiary
9. As a developer, I want agent definitions to hot-reload so I don't need to restart
10. As a developer, I want agent templates so I can start quickly
11. As a developer, I want agent inheritance so I can create variations
