# Optional Skill Engineering Guide

Before changing an optional skill, read both [`../AGENTS.md`](../AGENTS.md) and
[`../skills/AGENTS.md`](../skills/AGENTS.md). Hermes does not automatically merge
parent and child context files. The skill guide's authoring, layout, test, and
review rules apply to both `skills/` and `optional-skills/`. Keep heavy or niche
skills here rather than activating them by default.
