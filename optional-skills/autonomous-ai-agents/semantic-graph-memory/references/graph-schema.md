# Graph schema reference

Core node types: Actor, Entity, Concept, Event, Claim, Preference, Goal,
Decision, Procedure, Artifact, Evidence, Evaluation, Temporal.

Domain extensions use `subtype` namespaces (for example `poetry.Image`,
`meeting.ActionItem`, `research.EmpiricalFinding`, `code_review.SecurityFinding`).

Statuses: candidate, asserted, accepted, rejected, superseded.
Authorities: user, assistant, tool, external, system, subagent.
