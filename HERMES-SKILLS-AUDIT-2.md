## Cross-cutting result

The defect is systemic, not confined to a few stale numbers:

1. **GitHub workflows normalize safeguard bypass.** Several skills teach REST ref updates when guarded force-push is blocked, blanket conflict-side selection, `reset --hard`, broad staging, stashing unexplained work, and forced branch deletion.
2. **Home and profile boundaries are not respected.** Knowledge/deployment skills scan broad home paths, infer destinations, move/delete files, and automate profile removal.
3. **Secrets are treated as movable configuration.** One skill exposes a GitHub token in process arguments; another copies secrets across profiles; SSH skills risk overwriting or weakening private keys.
4. **Current claims are cached as doctrine.** Vendor prices, API quotas, benchmark/cost tables, social thresholds, named incidents, project paths, and user preferences appear in reusable instructions without a current-source requirement.
5. **Patch count is not a quality signal.** The highest-patch skills contain the densest and most consequential defects.
